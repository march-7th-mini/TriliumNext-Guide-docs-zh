> [!WARNING]
> Windows 二进制文件已获得证书升级，这意味着根据您安装应用程序的方式，您可能会收到 SmartScreen 警告。这已经是一个[已知问题](https://github.com/TriliumNext/Trilium/issues/9548)，解决方法是在安装程序上右键单击 → 属性，然后勾选窗口底部的安全框。

## 💡 主要亮点

1.  现在支持一种期待已久的笔记类型：电子表格，提供熟悉的（类似 Excel 的）编辑体验，支持公式，由 Univer Sheets 提供支持。
    *   对其的支持被认为是测试版，并且在此过程中可能会面临一些变化。
    *   有关使用电子表格时的重要注意事项，请参阅[文档](https://docs.triliumnotes.org/user-guide/note-types/Spreadsheets)。
2.  [支持预览和同步滚动的基础 Markdown 支持。](https://docs.triliumnotes.org/user-guide/note-types/markdown)
3.  内置对图像以及 PDF 和 Office（Word、PowerPoint、电子表格）文本提取的 OCR 支持，并与搜索功能集成。有关配置，请参阅选项中的_媒体_页面。
4.  [自定义词典现在可以在多个实例之间同步](https://github.com/TriliumNext/Trilium/issues/1801)
5.  [Linux 下的新部署方式正在测试中：AppImage](https://github.com/TriliumNext/Trilium/issues/409)
6.  文本笔记中的书签功能已彻底改革
    *   _书签_已重命名为_锚点_，以避免与 Trilium 中笔记书签的概念重叠。
    *   锚点现在可以在笔记之间使用，因为它们已集成到_添加链接_功能中。有关更多信息，请参阅文档。
    *   添加了相应的斜杠命令，以便轻松引入新的锚点。
7.  我们[重新引入了大语言模型对话功能](https://docs.triliumnotes.org/user-guide/llm#reintroduction-in-v0-103-0)，提供全尺寸对话以及带有工具的侧边栏，允许其修改您的笔记甚至创建脚本。

## 🚨 破坏性变更

*   后端脚本：
    *   [`api.axios` 已被移除](https://docs.triliumnotes.org/user-guide/scripts/breaking-changes/axios-removal)。它已被标记为弃用超过两年，鉴于最近的安全事件以及它实际上并未在 Trilium 代码库中使用，我们决定将其完全移除。请更新您的脚本以使用内置的 `fetch()`。
    *   [`api.cheerio` 已被标记为弃用](https://docs.triliumnotes.org/user-guide/scripts/breaking-changes/cheerio-deprecated)，但尚未移除。作为替代方案，我们提供 `node-html-parser`，它具有更面向 DOM 的语法。
