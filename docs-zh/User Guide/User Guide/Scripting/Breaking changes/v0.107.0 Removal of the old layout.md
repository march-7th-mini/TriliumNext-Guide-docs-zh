# v0.107.0：移除旧版布局

_新布局_ 是 v0.101.0 中引入的一系列 UI/UX 变更，这些变更大幅改变了现有的 UI 元素，同时也添加了一些新元素。新布局的目标是使应用程序现代化、更加直观，同时减少杂乱。

从 v0.107.0 开始，旧版布局已被**完全移除**。本页面作为迁移说明，帮助您更好地理解发生了哪些变化。

## 新引入的功能

*   在窗口底部有一个新的栏，称为 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Status%20bar.md">状态栏</a>。该栏包含多个项目，例如面包屑导航以及当前笔记的信息和设置，如[内容语言](../../Note%20Types/Text/Content%20language%20%26%20Right-to-left%20support.md)和 <a class="reference-link" href="../../Advanced%20Usage/Attributes.md">属性</a>。
*   当创建一个空的 <a class="reference-link" href="../../Note%20Types/Text.md">文本</a> 笔记时，标题下方会出现一个 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Notes/New%20note%20type%20switcher.md">新建笔记类型切换器</a>，方便切换到不同的笔记类型、模板或集合。
*   <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Notes/Note%20badges.md">笔记徽章</a> 出现在笔记标题右侧，指示只读、已分享笔记等状态以及相应的操作（临时将笔记标记为可编辑、查看分享笔记等）。这些替代了部分浮动按钮。
*   <a class="reference-link" href="#root/_hidden/_options/_optionsTextNotes">文本笔记</a> 有了新的行内标题，其文字更大，并显示创建和修改日期，滚动时会折叠回较小的标题。
*   以下部分已设为可折叠，并显示在[笔记标题](../../Basic%20Concepts%20and%20Features/Notes/Title.md)下方：
    *   <a class="reference-link" href="../../Advanced%20Usage/Attributes/Promoted%20Attributes.md">提升属性</a>
        *   之前用于触发提升属性功能区标签页的键盘快捷键（已不再有效）已被重新用途，改为切换提升属性的显示。
    *   _编辑过的笔记_（现更名为 _当天编辑的笔记_），出现在 <a class="reference-link" href="../../Advanced%20Usage/Advanced%20Showcases/Day%20Notes.md">日记笔记</a> 中，现在显示在标题下方。
        *   该部分是折叠还是展开取决于 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → 外观中的选择。
    *   _搜索属性_，出现在完整的 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Navigation/Search.md">搜索</a> 和 <a class="reference-link" href="../../Note%20Types/Saved%20Search.md">保存的搜索</a> 中。
*   <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Notes/Save%20status%20indicator.md">保存状态指示器</a> 出现在 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Notes/Note%20badges.md">笔记徽章</a> 区域，指示是否有未保存的更改。

## 现有布局的变化

### 移除功能区

最显著的变化是移除了功能区。功能区中的所有操作和选项已整合到应用程序的其他位置。

以下是曾经属于功能区的各个标签页在新布局中的位置：

*   “格式化工具栏”已移至页面顶部。
    *   现在每个标签页只有一个格式化工具栏，而不是每个分屏一个。这为工具栏项目提供了更多空间。
*   “拥有的属性”和“继承的属性”已合并并移至状态栏区域（上下显示）。
*   “基本属性”已整合到 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">笔记菜单</a> 中。
    *   唯一的例外是语言下拉框，现在可以在状态栏中找到（屏幕右上角）。
*   “文件”和“图片”标签页
    *   按钮已移至笔记标题右侧，作为 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">笔记菜单</a> 中的专用条目。
    *   信息部分已合并到状态栏的 _笔记信息_ 部分。
*   编辑过的笔记
    *   移至标题下方，显示在可折叠区域中，笔记以徽章/标签形式呈现。
    *   该部分是展开还是折叠取决于选项 → 外观 → _用户界面_ 中的 _在日记笔记中展开“当天编辑的笔记”_ 设置。
*   搜索定义标签页
    *   移至标题下方的可折叠区域。
    *   新搜索默认展开，保存的搜索默认折叠。
*   笔记地图现在位于笔记操作菜单中。
    *   笔记地图不再在功能区的面板中打开，而是在侧边栏的 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/Connections%20tab.md">连接标签页</a> 中打开，也可以在那里最大化。
*   “笔记信息”标签页已移至状态栏中的一个小 (i) 图标。
*   “相似笔记”标签页
    *   相似笔记不再在功能区的面板中打开，而是显示在侧边栏的 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/Connections%20tab.md">连接标签页</a> 中。
    *   `similarNotesWidgetDisabled` 不再有任何效果。
*   集合属性标签页已移至笔记标题下方，并分组为：
    *   一个用于快速切换视图的下拉框。
    *   当前视图的单独设置位于子菜单中。
*   一些较小的功能区标签页已转换为徽章，出现在面包屑区域的笔记标题附近：
    *   剪藏网页的原始 URL 指示器（`#pageUrl`）。
    *   SQL 和脚本执行按钮。

> [!NOTE]
> 功能区的键盘快捷键（例如 `toggleRibbonTabClassicEditor`）已被重新用途并重命名（_聚焦格式化工具栏_、_切换拥有的属性_、_显示笔记地图_ 等），以适用于新布局，它们将切换相应的面板。

### 移除浮动按钮

大部分按钮已移至笔记标题右侧的 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">笔记菜单</a> 区域，但以下除外：

*   编辑按钮显示在笔记标题附近，作为徽章。
*   _反链_ 现在显示在侧边栏的 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/Connections%20tab.md">连接标签页</a> 中。
    *   或者，反链数量显示在状态栏中，点击后侧边栏会打开到相应部分。
*   关系图缩放按钮现在是关系图本身的一部分。
*   导出图片为 PNG/SVG 现在位于笔记操作菜单中的 _导出为图片_ 选项。

### 侧边栏的变化

侧边栏（也称为右侧面板）也收到了一些重要变化。

最重要的是，v0.105.0 将侧边栏拆分为多个标签页，并增加了额外功能：

*   <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/Outline%20tab.md">大纲标签页</a>，汇集了目录和高亮列表。
*   <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/Attributes%20tab.md">属性标签页</a>，提供了一种图形化的方式来编辑标签、关系和（提升）属性定义。
*   专用的 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/AI%20chat%20tab.md">AI 对话标签页</a>。
*   <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/Connections%20tab.md">连接标签页</a>，将笔记地图、笔记路径、反链和相似笔记组合在一起。

之前版本的侧边栏会根据是否有任何项目需要显示而上下文地出现。这在分屏视图中在两个窗格之间移动时偶尔会导致内容偏移。在新布局中，侧边栏更像 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a> 窗格，即使没有内容可显示也保持可见。

因此：

*   文本笔记选项中的 _目录_ 卡片（最小标题数）已移除。无论标题数量多少，都会显示目录。
*   `#toc` / `#toc=show` / `#toc=hide` 不再有任何效果。
*   `#hideHighlightWidget` 不再有任何效果。高亮类别仍然从齿轮菜单或文本笔记选项中全局设置，但无法为单个笔记隐藏。

为了切换侧边栏，屏幕右上角靠近窗口按钮处（在 Windows 和 Linux 上）有一个新按钮。

现在侧边栏的每个部分（例如“目录”、“高亮列表”）都可以单独折叠，并会记住其折叠状态。

一些侧边栏项目还有上下文菜单，由标题上的三个点表示。例如，高亮过滤器可以直接从该菜单调整。

自定义小组件仍然受支持。对于自定义脚本，三点菜单允许快速导航到相应的脚本笔记。
