# v0.90.7-beta
## ⚠️ 重要说明

*   0.90.5-beta 和 0.90.6-beta 版本在使用思维导图时与旧版同步服务器存在不兼容问题，可能导致思维导图被转换为文件。如果您受到此问题影响，请参阅 [思维导图笔记突然显示为文件笔记](https://github.com/TriliumNext/Notes/issues/467#issuecomment-2402853189)。
*   同步版本已从 32 提升至 33，以防止思维导图笔记出现问题。这意味着服务器也需要更新到此版本，否则同步将被拒绝。
