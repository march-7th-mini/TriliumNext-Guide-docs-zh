# 内容语言与从右到左支持
![](Content%20language%20&%20Right-to-left%20support_image.jpg)

内容语言决定以下事项：

*   在浏览器中时，笔记的拼写检查。桌面安装版有专门的拼写检查部分。
*   文本是否从右到左显示，适用于阿拉伯语、希伯来语等语言。
*   输入的引号如何被[自动替换](Automatic%20replacements.md)（例如英语使用 `“text”`，而某些语言使用 `«text»`）。仅当<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _文本_ → _单/双引号_ 设置为 _基于笔记的内容语言_ 时适用。
*   <a class="reference-link" href="In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>提供哪些语言用于翻译。
*   在[共享页面](../../Advanced%20Usage/Sharing.md)上内容所标记的语言和文本方向，屏幕阅读器和浏览器会遵循这些设置。

## 设置单个笔记的语言

要设置<a class="reference-link" href="../Text.md">文本</a>笔记内容的语言，<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Status%20bar.md">状态栏</a>中有一个由 <span class="tn-icon bx bx-globe"></span> 图标指示的语言选择器。

## 调整语言列表

默认情况下不会配置任何语言，可以通过前往<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → 语言与地区，或在设置语言时选择 _配置语言_ 项来进行配置。

## 默认内容语言

没有自己语言的笔记遵循<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _语言与地区_ → _默认内容语言_。初始设置为英语，可以设置为任何内容语言，或设置为 _基于应用程序的语言_。

如果笔记设置了语言，它始终优先于默认值。
