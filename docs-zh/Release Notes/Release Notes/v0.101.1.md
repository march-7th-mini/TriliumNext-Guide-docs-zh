## 💡 主要亮点

*   引入了新布局，该布局大幅改变了现有 UI 元素，并添加了一些新元素（由 @eliandoran 和 @adoriandoran 完成，特别感谢 @rom1dep 提供的宝贵建议）。
    *   此新布局的目标是使应用程序现代化，使其更直观，同时减少杂乱。
    *   查看变更及新 UI 元素的[文档](https://docs.triliumnotes.org/user-guide/concepts/ui/new-layout)。
    *   使用标签栏下方显示的导航路径，可以更轻松地在层级结构中导航笔记。
    *   旧布局目前仍可使用。欢迎提供反馈。
*   标签栏附近现在有[内置按钮，可在历史记录中转到上一条或下一条笔记](https://github.com/TriliumNext/Trilium/pull/8003/files)（仅当后退/前进按钮尚未放置在启动栏中时）。
*   **脚本全面改革：** 自定义小组件和渲染笔记现在可以使用 JSX 以 Preact 编写，而不是旧格式（jQuery + 自定义组件框架）。有关更多信息，请参阅 [Trilium 中 Preact 的文档](https://docs.triliumnotes.org/user-guide/scripts/frontend-basics/Preact)。

## ✨ 改进

*   改进了自定义小组件的错误处理。
*   启动栏：
    *   现在可以通过滚动鼠标滚轮来滚动水平启动栏。
    *   工具提示显示更快（无淡入效果）。
*   改进了错误处理
    *   HTTP 错误现在更加用户友好。
    *   对 Traefik 请求失败发出警告。
    *   CKEditor 崩溃会收到通知，并提供简便方式提供错误报告信息。
*   在选项中隐藏功能区。
*   移除了代码编辑器的边距和圆角。
*   后端日志：减少多余内边距并减小字体大小以提高可读性。
*   改进了自定义小组件的错误处理。
*   代码笔记现在将根据语言拥有默认图标（例如，JS 代码笔记的自定义图标）。只有部分语言有专用图标。
*   打印集合时，如果一个或多个笔记不可打印，将显示消息。
*   由 @adoriandoran 完成的 UI 改进
