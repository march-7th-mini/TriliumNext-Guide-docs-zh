# v0.90.4

此版本主要侧重于改善 Docker 容器的使用体验。

## Docker ARM 构建

*   [重新引入了适用于 Docker 的 ARM 构建](https://github.com/TriliumNext/Notes/issues/302)，并自本版本起在 [Docker Hub](https://hub.docker.com/r/triliumnext/notes) 和 [GHCR](https://github.com/TriliumNext/Notes/pkgs/container/notes) 上提供。
    *   请注意，目前仅支持 `ARMv7` 和 `ARM64/v8` 架构。
    *   由于与 Node 20 存在兼容性问题，已放弃对 `ARMv6` 的支持。
