# v0.106.1
> [!IMPORTANT]
> 这是针对**服务器和 Docker 镜像**的安全版本。如果你将 Trilium 作为服务器运行，尤其是可从互联网访问的服务器，请尽快更新。

### 🔒 安全

1.  [更新了 Docker 镜像中的 Node.js](https://github.com/TriliumNext/Trilium/issues/12223) 至 24.22.1（旧版镜像为 22.23.4），纳入了 2026 年 10 月 21 日的 Node.js 安全版本：
    1.  **Brotli 解码器越界写入（CVE-2026-111497）。** Trilium 在身份验证之前会解压 Brotli 编码的请求体，因此在较早版本中，任何能访问服务器的客户端都可以发送恶意请求。出站请求（链接预览、图片下载、网络搜索）也通过其接收的响应受到影响。
    2.  **已吊销的 eMudhra/emSign 证书颁发机构。** Node.js 捆绑的证书存储信任了密钥已被泄露的证书颁发机构。这使得拥有相应网络访问权限的中间人可以冒充 Trilium 连接的 HTTPS 服务器（与另一实例同步、链接预览、LLM 提供商）。
    3.  同一 Node.js 版本中对 TLS、HTTP 和 DNS 处理的其他修复。
