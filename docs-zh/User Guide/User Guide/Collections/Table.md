# 表格
<figure class="image"><img style="aspect-ratio:1050/259;" src="Table_image.png" width="1050" height="259"></figure>

表格视图以网格形式显示信息，其中行是各个笔记，列是<a class="reference-link" href="../Advanced%20Usage/Attributes/Promoted%20Attributes.md">提升属性</a>。此外，值是可编辑的。

## 工作原理

表格结构表示如下：

*   每个子笔记是表格中的一行。
*   如果子行也有子笔记，它们将显示在展开器下（嵌套笔记）。
*   每一列是定义在集合笔记上的[提升属性](../Advanced%20Usage/Attributes/Promoted%20Attributes.md)。
    *   实际上，提升属性和非提升属性都受支持，但要求使用标签/关系定义。
    *   提升属性通常定义为可继承，以便在子笔记中显示，但这不是必需的。
*   如果有多个具有相同 `name` 的属性定义，只会显示一个。
*   如果属性定义有多个值，它们将全部归组在单个列下，并用标签块指示各个值。

还有一些预定义的列：

*   当前项目编号，由 `#` 符号标识。
    *   这只是对笔记进行计数，并受排序影响。
*   <a class="reference-link" href="../Advanced%20Usage/Note%20ID.md">笔记 ID</a>，表示 Trilium 内部使用的唯一 ID
*   笔记的标题。

## 交互

### 创建新表格

在<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a>中右键单击现有笔记，然后选择 _插入子笔记_ → _集合_ → _表格_。

### 添加列

每一列是定义在集合笔记上的[提升或非提升属性](../Advanced%20Usage/Attributes/Promoted%20Attributes.md)。

要创建新列，可以：

*   按表格底部的 _添加新列_。
*   右键单击现有列，然后选择向左/向右添加列。
*   右键单击列标题的空白区域，然后在 _新建列_ 部分选择 _标签_ 或 _关系_。

### 添加新行

每一行实际上是一个作为集合笔记子笔记的笔记。

要创建新笔记，可以：

*   按表格底部的 _添加新行_。
*   右键单击现有行，然后选择 _在上方插入行_、_插入子笔记_ 或 _在下方插入行_。

默认情况下，它会尝试编辑新创建笔记的标题。

或者，可以从<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a>或[脚本](../Scripting.md)创建笔记。

### 上下文菜单

有多个菜单：

*   右键单击列，允许：
    *   按所选列排序并重置排序。
    *   隐藏所选列或调整每列的可见性。
    *   在列的左侧或右侧添加新列。
    *   编辑当前列。
    *   删除当前列。
*   右键单击列右侧的空白区域，允许：
    *   调整每列的可见性。
    *   添加新列。
*   右键单击行，允许：
    *   在新标签页、分屏、窗口或快速编辑中打开该行对应的笔记。
    *   在所选行的上方或下方插入新笔记。这些选项仅在表格未排序时启用。
    *   为所选行插入新的子笔记。
    *   删除该行。

### 编辑数据

只需单击行中的单元格即可更改其值。更改不仅会反映在表格中，还会反映为相应笔记的属性。

*   编辑将遵循提升属性的类型，例如呈现普通文本框、数字选择器或日期选择器。
*   也可以更改笔记的标题。
*   编辑关系也是可以的
    *   只需单击关系，它就会变为可编辑状态。输入要查找的笔记文本并单击它。
    *   要移除关系，请从文本框中移除笔记的标题，然后单击单元格外部。

### 编辑列

可以通过右键单击列并选择 _编辑列…_ 来编辑列。这基本上会更改集合级别的标签/关系定义。

如果更改了列的 _名称_ 字段，这将触发批量操作，其中相应的标签/关系将在所有子笔记中重命名。

### 只读表格

在[只读](../Basic%20Concepts%20and%20Features/Notes/Read-Only%20Notes.md)表格上，单元格无法编辑，行也无法拖动。_新建行_ 和 _新建列_ 按钮被隐藏，上下文菜单仅提供保持笔记原样的操作：排序和隐藏列，以及打开笔记。列仍然可以调整大小和重新排序，但布局不会被保存。_表格属性_ 对话框不可用。

## 处理数据

### 按列排序

默认情况下，笔记的顺序与<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a>中的顺序一致。但是，可以按列的值对数据进行排序：

*   为此，只需单击列。
*   要在升序或降序排序之间切换，只需再次单击同一列。列旁边的箭头将指示排序方向。
*   要禁用排序并恢复原始顺序，请右键单击标题上的任意列，然后选择 _清除排序。_

### 重新排序和隐藏列

*   可以通过拖动列的标题来重新排序列。
*   可以通过右键单击列并单击与该列对应的项目来隐藏或显示列。

### 重新排序行

可以拖动笔记来更改其顺序。为此，将鼠标移到编号行附近的三个垂直点上方，然后将鼠标拖动到所需位置。

这也会更改笔记在<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a>中的顺序。

重新排序确实有一些限制：

*   如果父笔记有 `#sorted`，重新排序将被禁用。
*   如果使用嵌套表格，则重新排序也将被禁用。
*   目前，即使使用列排序，也可以重新排序笔记，但结果可能不一致。

### 嵌套树

如果集合的子笔记也有自己的子笔记，那么它们将按层次结构显示。

每个元素的标题旁边都会有一个展开或折叠按钮。默认情况下，所有项目都是展开的。

由于嵌套并不总是可取的，可以将嵌套限制在一定的层级数，甚至完全禁用。为此，请转到<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">笔记菜单</a> → _表格属性_ 并设置 _最大嵌套深度_（在 _包含的笔记_ 部分下），或设置集合的 `#maxNestingDepth` [标签](../Advanced%20Usage/Attributes/Labels.md)：

*   `0` 禁用嵌套，仅显示集合的子笔记。
*   `1` 还会显示它们的子笔记，`2` 显示再下一层，依此类推。
*   移除该标签会再次显示所有层级。

限制：

*   在此模式下，无法重新排序笔记。

## 限制

*   不支持按特定条件筛选行。对于该用例，请考虑在搜索中使用表格视图。

## 在搜索中使用

表格视图可以通过添加 `#viewType=table` 属性在<a class="reference-link" href="../Note%20Types/Saved%20Search.md">保存的搜索</a>中使用。

与在集合中使用时不同，保存的搜索不限于笔记的子层次结构，并且借助<a class="reference-link" href="../Basic%20Concepts%20and%20Features/Navigation/Search.md">搜索</a>的强大功能，允许进行高级查询。

但是，也有一些限制：

*   无法重新排序笔记。
*   无法添加新行。

支持列，通过在<a class="reference-link" href="../Note%20Types/Saved%20Search.md">保存的搜索</a>笔记上定义为<a class="reference-link" href="../Advanced%20Usage/Attributes/Promoted%20Attributes.md">提升属性</a>。

也支持编辑。
