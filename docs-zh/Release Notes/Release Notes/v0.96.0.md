## 💡 主要亮点

*   得益于与 CKEditor 的合作，我们现在拥有了一系列原本仅限商业许可才能使用的功能。
    *   斜杠命令，可通过键盘轻松执行命令。
    *   文本片段，用于插入可复用的文本块（类似于模板，但针对文本内容块）。
    *   更多信息，请参阅用户指南 → 笔记类型 → 文本 → 高级功能。
