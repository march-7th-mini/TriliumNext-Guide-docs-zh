# 脚注
<figure class="image image-style-align-right"><img style="aspect-ratio:199/187;" src="Footnotes_image.png" width="199" height="187"></figure>

脚注是插入段落引用或详细信息的理想位置，这些内容会显示在笔记底部。

## 交互

*   要插入新脚注，请按 <span class="tn-icon cke cke-trilium-insert-footnote"></span>（或按右箭头并选择 _新建脚注_）。
*   要插入对现有脚注的引用，请按右箭头并选择 _插入脚注_，然后输入要插入的脚注编号。
*   将鼠标悬停在引用（例如 `[1]`）上时，会在工具提示中显示脚注内容，方便查阅。
*   点击文本中的引用（例如 `[1]`）将跳转到对应的脚注。
*   同样，点击脚注的 `^` 按钮将跳转到文本中对应的引用。
