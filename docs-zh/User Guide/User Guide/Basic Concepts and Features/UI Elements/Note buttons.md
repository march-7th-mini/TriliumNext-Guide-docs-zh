# 笔记按钮
在[功能区](Ribbon.md)的右侧还有几个按钮：

*   <span class="tn-icon bx bx-history"></span> 显示该特定笔记的[笔记修订](../Notes/Note%20Revisions.md)，仅在旧版布局中可用。
*   <span class="tn-icon bx bx-dots-vertical-rounded"></span> 提供针对该笔记或其子树的命令，例如导入、导出、查看[笔记源代码](../../Advanced%20Usage/Note%20source.md)或[附件](../Notes/Attachments.md)。
*   在<a class="reference-link" href="New%20Layout.md">新布局</a>中，按钮区域由一些针对当前笔记的更多按钮填充。例如，对于图片和<a class="reference-link" href="../../Note%20Types/File.md">文件</a>笔记，下载和复制按钮被重新放置在那里。
