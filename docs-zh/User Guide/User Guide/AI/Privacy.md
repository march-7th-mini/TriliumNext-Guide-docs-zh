# 隐私

在您发送消息之前，Trilium 不会向 AI 提供商发送任何内容。启用集成、添加提供商或打开对话本身不会传输任何数据，唯一的例外是列出提供商的模型时会向该提供商发送您的 API 密钥，以便获取模型列表。

一旦您发送消息或运行<a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>，离开您设备的数据取决于您选择的提供商以及启用的上下文选项。

## 您的笔记去向

| 提供商类型 | 目的地 |
| --- | --- |
| 云提供商 | 提供商的服务器（Anthropic、OpenAI、Google、DeepSeek） |
| 基于订阅 | 提供商的服务器，通过本地运行的 Claude Code |
| 本地 / 自托管 | 数据不会离开运行模型的设备 |
| 自定义端点 | 您指定的任何位置——可能是您自己的硬件或托管服务 |

这就是提供商列表如此分组的原因，也是 Trilium 不预先选择任何项的原因：您的笔记去向的选择，是在发送任何内容之前，由您明确做出的。

> [!NOTE]
> <a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a> 有自己的模型选择器，因此它可能由与对话中不同的提供商来回答。助手菜单底部的行始终显示当前使用的提供商。

## 实际发送的内容

*   **每次发送消息时都会发送**
    *   对话本身：您的消息和助手的回复，包括之前的轮次
    *   Trilium 的系统提示词，描述如何格式化答案和使用工具。
*   **当前笔记，仅在启用笔记上下文时发送。**
    *   在侧边栏对话中，这是底部的文件图标；专门的对话笔记类型从不发送当前笔记。
    *   发送的是一个元数据块：笔记的 ID、标题、类型、创建和修改日期、其父笔记 ID、最多 20 个子笔记的标题、最多 20 个属性，以及内容的预览。
    *   超过大小阈值的笔记会发送大小提示而不是文本，模型必须调用工具才能进一步读取。
*   **模型请求的任何笔记，在启用笔记访问时发送。**
    *   工具允许模型搜索您的笔记树并读取当前笔记之外的笔记、属性和附件。
    *   由模型决定获取什么；没有针对单个笔记的权限系统，因此可访问的范围是您的整个笔记树。
*   **附件和提及**，当您添加它们时：图片、PDF 和文本文件会发送给提供商，`@` 提及会使该笔记可被获取。
*   **您的搜索查询**，当启用网络搜索时，模型的搜索词会到达提供商自己的搜索基础设施。

## 编辑器内 AI 助手

运行<a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a> 发送的内容与对话消息不同。对于快速操作，它在您选择操作的那一刻就发送，没有发送按钮可供重新考虑。对于自由形式的 _Ask AI_，有专门的发送按钮和模型选择器。

*   **您选中的段落**，或者当您未选择任何内容而选择快速操作时光标所在的段落。
*   **该段落两侧各最多 1500 个字符的笔记内容**，作为纯文本。助手被告知这只是上下文，不得重写，但无论您是否选中，它都会被发送：即使只对单个句子运行，也会传输其周围的段落。
*   **笔记的位置**：其标题及其父笔记的标题，作为面包屑导航。
*   **Trilium 的写作助手指令**，描述它可能产生的格式。
*   **同一对话的先前轮次**，当您对回复进行跟进时。

不会发送笔记元数据块，网络搜索永远不会启用，助手也没有笔记工具，因此它无法读取上述文本之外的任何内容。

## 受保护的笔记

当您的[受保护会话](../Basic%20Concepts%20and%20Features/Notes/Protected%20Notes.md)被锁定时，受保护的笔记不会发送标题或内容。**当它被解锁时，它们会被视为任何其他笔记一样，** 模型通过工具读取的笔记会完整地发送给提供商。如果您在受保护的笔记中保存敏感材料，请注意解锁会在会话期间移除该边界。

这同样适用于<a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>：它作用于编辑器中打开的任何内容，因此在解锁的受保护笔记中运行它会像其他任何笔记一样发送该笔记的文本。

## 您可以控制的内容

*   **选择哪个提供商**：这是决定是否有任何数据离开您设备的关键决策。
*   **笔记访问**：从对话底部的模型选择器中关闭工具，模型就只能读取您输入的内容。
*   **当前笔记**：侧边栏对话中的文件图标。
*   **网络搜索**：也在模型选择器中。
*   **编辑器助手**：它没有每次运行的开关。您可以控制的是是否运行它、运行前选择什么以及由哪个模型回答。

在笔记访问和笔记上下文都关闭的情况下，提供商只会收到您输入的文本。

## 保持一切本地化

添加 Ollama 或 LM Studio 提供商可将每条消息保留在运行模型的设备上，并且 Trilium 会将其模型标记为免费，因为不涉及按量计费的 API。权衡在于质量和硬件：小型本地模型可能无法处理云模型可以处理的工具调用，因此，如果本地设置出现问题，在将其报告为错误之前，值得与云提供商进行基准测试。

## 遥测与安全

Trilium 本身不会从 AI 集成中收集任何遥测数据。

您的 API 密钥存储在您的数据库中，仅发送给其所属的提供商，并且通过选项 API 是只写的，因此恶意的<a class="reference-link" href="../Scripting.md">脚本</a>无法访问它。如果您启用了后端或 SQL 控制台访问权限，恶意脚本**可能能够窃取您的 API 密钥**。

内置的 MCP 服务器默认关闭。启用后，每个请求都必须携带 ETAPI 令牌，该令牌授予与 REST API 相同的对您笔记的完全读写权限；请像对待密码一样对待它。在桌面上，除非您打开<a class="reference-link" href="../Installation%20%26%20Setup/Desktop%20Installation/Network%20Access.md">网络访问</a>，否则只能从 `localhost` 访问它。
