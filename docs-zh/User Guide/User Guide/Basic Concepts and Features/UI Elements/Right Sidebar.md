# 右侧边栏
<figure class="image"><img style="aspect-ratio:1990/1168;" src="Right Sidebar_image.png" width="1990" height="1168"></figure>

右侧边栏显示当前笔记的特定内容。该边栏分为多个标签页：

*   <a class="reference-link" href="Right%20Sidebar/Outline%20tab.md">大纲标签页</a>，根据笔记类型显示目录、高亮以及其他导航相关部分。
*   <a class="reference-link" href="Right%20Sidebar/Attributes%20tab.md">属性标签页</a>，为当前笔记的<a class="reference-link" href="../../Advanced%20Usage/Attributes.md">属性</a>提供可视化编辑器。
*   <a class="reference-link" href="Right%20Sidebar/AI%20chat%20tab.md">AI 对话标签页</a>，使用<a class="reference-link" href="../../AI.md">AI</a>集成进行对话，可选择访问当前笔记。
*   <a class="reference-link" href="Right%20Sidebar/Connections%20tab.md">连接标签页</a>，将笔记地图、笔记路径、反链和相似笔记分组在一起。

> [!WARNING]
> 目前有两种类型的边栏；此处的文档仅涉及<a class="reference-link" href="New%20Layout.md">新布局</a>中定义的边栏。旧布局具有不同的边栏机制，仅显示目录和高亮。

## 切换右侧边栏

有两种方式可以切换右侧边栏：

*   通过标题栏附近的 <span class="tn-icon bx bx-sidebar bx-flip-horizontal"></span> 图标，用于切换边栏是否停靠。
*   通过 _切换右侧面板_ [键盘快捷键](../Keyboard%20Shortcuts.md)，默认未分配。

## 窥视边栏

在应用右边缘附近有一个小条，显示一个箭头图标。

*   当边栏隐藏时，按下边缘将_窥视_边栏。
    *   在此模式下，边栏临时显示在内容上方，不会移动笔记内容。
    *   在窥视模式下点击边栏外部将直接隐藏边栏。X 按钮和点击右边缘同样如此。
    *   按下固定图标将停靠边栏。
*   当边栏停靠时，按下边缘将隐藏边栏（类似于顶部的切换图标）。
