# v0.90.1-beta
此版本的主要亮点是大量的库更新，将它们升级到了最新版本。

## ⚙️ Windows 安装程序

现在每个版本都附带一个基于 Squirrel 的 Windows 64 位平台安装程序。

只需下载安装程序并运行，应用程序就会自动安装。

## 🐞 错误修复

与 v0.90.0 相比，以下因转换为 TypeScript 而导致的回归问题已得到解决：

*   [搜索笔记内容失败](https://github.com/TriliumNext/Notes/issues/211)
*   [画布：“复制图片引用到剪贴板”不再工作](https://github.com/TriliumNext/Notes/pull/227)
*   [v.0.90.0-beta 加载笔记时出现随机错误](https://github.com/TriliumNext/Notes/issues/238)
*   [前端 JS 代码执行错误](https://github.com/TriliumNext/Notes/issues/244)
*   [同步失败：无法读取未定义的属性（读取“utcDateChanged”）](https://github.com/TriliumNext/Notes/issues/210)
