# 会议转录
> [!IMPORTANT]
> **会议转录功能处于测试阶段**
> 
> 会议转录是一项新功能，仍处于测试阶段。它尚未在每种操作系统、音频设置和会议应用上进行过测试，因此可能无法捕获音频、遗漏部分会议内容，或出现与本页描述不同的行为。在依赖它进行重要会议之前，请先在简短的通话中试用。
> 
> 如果出现问题，请[报告该问题](Troubleshooting/Reporting%20issues.md)，并注明你的操作系统和你使用的会议应用。下文所述的 _保留录音以供故障排查_ 选项会保留重现问题所需的内容。

会议转录会在会议进行时将会议内容转为文字：Trilium 会监听你的麦克风以及通过你的扬声器传来的其他参与者所说的话，并在新笔记中记录谁说了什么。识别完全在你的设备上运行，因此不会有任何音频离开你的设备（见下文 _隐私_）。

会议转录仅在桌面应用中可用。通过浏览器访问 Trilium 时不可用，在移动应用中也不可用。

## 启用会议转录

会议转录默认关闭。要开启它，请转到 <a class="reference-link" href="Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _转录_，然后开启 _会议转录_。这会将 <span class="tn-icon bx bx-microphone"></span> _转录会议_ 按钮添加到 <a class="reference-link" href="Basic%20Concepts%20and%20Features/UI%20Elements/Launch%20Bar.md">启动栏</a>，并带有 _Beta_ 徽章。

语音识别模型并不包含在 Trilium 中。首次转录会议时，Trilium 会请求下载它们；有关大小以及如何管理它们，请参见 <a class="reference-link" href="Installation%20%26%20Setup/Downloaded%20resources.md">已下载的资源</a>。每台设备都会下载自己的副本。

## 转录会议

1.  按下 <a class="reference-link" href="Basic%20Concepts%20and%20Features/UI%20Elements/Launch%20Bar.md">启动栏</a> 中的 <span class="tn-icon bx bx-microphone"></span> _转录会议_ 按钮。
2.  如果模型尚未下载，请确认下载并等待其完成。
3.  Trilium 会在 <a class="reference-link" href="Basic%20Concepts%20and%20Features/Notes/Note%20Inbox.md">笔记收件箱</a> 中创建一个以当前日期和时间命名的文本笔记（例如 _会议 2026-10-15 14:30_），打开它并开始转录。转录期间，该按钮会变为 <span class="tn-icon bx bx-stop-circle"></span> _停止转录_ 按钮，并显示已用时间。在它旁边，会有一条提醒，要求你让会议中的每个人知道会议正在被转录并征求他们的同意；该提醒会在 10 秒后自动关闭，或在你点击它时关闭。
4.  要结束转录，请按下 <span class="tn-icon bx bx-stop-circle"></span> _停止转录_ 按钮。Trilium 会在停止前完成对已经说过的内容的转录。

一次只能转录一场会议。该笔记本身是一个普通的文本笔记：你可以在会议期间在其中做笔记、重命名它，或将其移动到树中的任何位置。它带有 `#meetingRecording` 标签。

当你的麦克风或会议的音频未被转录时，Trilium 会告知你。它会显示一条消息，说明是哪一个以及原因，按钮上的时间会变红，按钮的工具提示会说明某些音频未被转录：

*   **未捕获**：转录开始时没有该音频，例如因为没有麦克风，或因为 Trilium 未被允许录制屏幕及其音频。连接麦克风或允许录制，然后停止转录并重新开始。
*   **无音频**：已有 10 秒没有从它那里收到任何内容，例如其捕获挂起时。停止转录并重新开始；在此之前已转录的内容会被保留。
*   **仅有静音**：它只传出了静音，从你的麦克风持续 15 秒，或从会议持续一分钟。在系统设置中静音的麦克风，或带有自身静音按钮的麦克风，都会导致这种情况。一分钟内无人说话的会议也会如此，因此当其他人只是安静时，可以忽略此消息。

每条消息只显示一次。一旦再次有声音到达，_无音频_ 和 _仅有静音_ 会自行清除。

如果转录自行停止，例如因为无法再捕获音频，Trilium 会显示一条消息，并保留在此之前转录的所有内容。在会议期间关闭 Trilium 会先等待转录完成。

## 转录文本

转录文本作为会议笔记的[附件](Basic%20Concepts%20and%20Features/Notes/Attachments.md)存储，并显示在笔记内容上方的可折叠 _转录文本_ 部分中。它会随着会议的进行而更新，每个发言轮次一段，每段都带有其开始时间。在会议被转录期间，_转录文本_ 部分的标题会显示你的麦克风（_我_）和会议音频（_其他人_）的音量水平，因此即使该部分处于折叠状态，你也可以判断两者都在被听到；未被转录的来源会标记为 _未捕获_、_无音频_ 或 _仅有静音_。当有人说话时，在其话语被转录之前，其姓名下方会显示 _正在说话…_。如果你正在阅读转录文本的末尾，它会滚动以跟随新文本。

每次打开笔记时，_转录文本_ 部分都会展开。要折叠它，请点击其标题；它只会在笔记再次打开之前保持折叠。

转录文本也会列在笔记的附件中，位于 _由 Trilium 生成_ 下。从那里打开它会显示相同的转录文本视图。删除该附件会删除转录文本，该部分也会从笔记中消失。

*   你对着麦克风说的话标记为 _我_。
*   其他参与者说的话标记为 _发言人 1_、_发言人 2_ 等（当 _识别发言人_ 开启时）；否则标记为 _其他人_。
*   要命名发言人，请点击其姓名，输入新名称并按 <kbd>Enter</kbd>。该发言人的每个轮次上的名称都会改变。按 <kbd>Esc</kbd> 取消，或清除名称以恢复默认名称。
*   要显示或隐藏包含“呃”、“嗯”和结巴词语等犹豫词的转录文本，请按下其上方 <span class="tn-icon bx bx-eraser"></span> _隐藏填充词_ 按钮，隐藏时该按钮显示为按下状态。当它们显示时，会以灰色显示，以便你可以看到隐藏它们会移除什么。这仅影响显示的内容；存储的转录文本会保留每一个词。
*   要将转录文本复制为纯文本，请按下其上方 <span class="tn-icon bx bx-copy"></span> _复制转录文本_ 按钮。每个轮次都会按显示的样子连同发言人姓名和开始时间一起复制，因此当填充词被隐藏时，副本会省略它们。

如果会议笔记是[受保护的](Basic%20Concepts%20and%20Features/Notes/Protected%20Notes.md)，且受保护会话在会议期间被锁定，则无法保存转录文本。Trilium 会将其保留在内存中，并在你再次进入受保护会话后保存它，前提是 Trilium 保持打开状态。

## 配置

设置位于 <a class="reference-link" href="Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _转录_，并在 _会议转录_ 开启后显示。

| 选项 | 描述 |
| --- | --- |
| _欧洲语言_ | 语音识别模型。两者都是 NVIDIA 的 Parakeet TDT 0.6B v3 模型的版本，可识别 25 种欧洲语言并判断所讲的是哪一种。_标准_ 下载量更小，在大多数计算机上运行良好。_高精度_ 错误更少，但下载量更大，转录时需要多约 1.6 GB 内存。首次使用某个模型转录时会下载该模型。 |
| _识别发言人_ | 使用 TitaNet 模型区分其他参与者并分别标记每个人。声音仅在会议期间进行比较：不会存储任何关于声音的信息，也不会从一场会议到下一场会议识别出任何人。如果它混淆了声音，请将其关闭。更改从下一次会议开始生效。 |
| _保留录音以供故障排查_ | 保留会议的音频、所使用的设置以及当时生成的转录文本，以便报告和重现问题。每小时会议约占用 230 MB，且永远不会自动删除。保存它们的文件夹显示在该选项下方。 |

> [!WARNING]
> 在开启 _保留录音以供故障排查_ 之前，请征得会议中每个人的同意进行录音。在多个国家和美国多个州，未经所有人同意录制对话属于刑事犯罪。即使对于受保护的笔记，音频也会以未加密方式存储。当该选项开启时，_转录会议_ 按钮的工具提示会说明这一点，转录开始时显示的提醒也会提到音频会被保留。

模型的大小和许可证列在 <a class="reference-link" href="Installation%20%26%20Setup/Downloaded%20resources.md">已下载的资源</a> 中。

## 隐私

会议转录不使用任何在线服务：

*   音频由开源 sherpa-onnx 引擎在你的设备上识别。Trilium 不会将音频或转录文本发送到任何在线服务，也不需要账户或 API 密钥。
*   仅在从 Hugging Face 和 GitHub 上的 sherpa-onnx 项目下载模型时需要互联网连接。下载完成后，会议转录可离线工作。
*   发言人识别仅在会议期间比较声音。不会存储任何关于声音的信息。
*   除非 _保留录音以供故障排查_ 开启，否则不会保留音频。这些录音保存在你设备上的文件夹中，且永远不会被同步。

转录文本本身是会议笔记的附件，因此会像你的其他笔记一样被处理。如果你使用 <a class="reference-link" href="Installation%20%26%20Setup/Synchronization.md">同步</a>，它会同步到你的同步服务器和其他设备。要保持加密，请转录到[受保护的](Basic%20Concepts%20and%20Features/Notes/Protected%20Notes.md)笔记中：受保护笔记的转录文本也受到保护。

## 限制

*   会议转录需要一个并非在每台计算机上都能加载的语音识别引擎，例如在早于 Ubuntu 22.04 或 Debian 12 的 Linux 发行版上。在无法加载的地方，_转录会议_ 按钮不会出现，_转录_ 选项会说明这一点，日志会记录原因。
*   转录文本是根据你的设备播放的音频生成的。其声音未从你的扬声器或耳机传出的参与者，例如同一房间中的某人，只会按你的麦克风拾取到的程度被转录，并被标记为 _我_。
*   发言人识别在有几个明显不同的声音时效果最佳。相似的声音、众多参与者或较差的通话质量可能导致发言人被合并或拆分。
*   非英语语言的准确度较低，且模型可能会在短段落中切换到错误的语言。
*   转录会占用相当多的处理器时间和内存，尤其是在使用 _高精度_ 模型时。
