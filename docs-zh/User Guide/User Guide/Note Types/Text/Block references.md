# 块引用

块引用[链接](Links.md)到文本或 Markdown 笔记中的某个块，例如段落、标题、列表项或表格，或者链接到一系列连续的块。块引用可以作为链接粘贴到另一篇笔记中，也可以转换为 <a class="reference-link" href="Include%20Note.md">包含笔记</a>，仅显示被引用的块。对于 Markdown 笔记，请参阅 <a class="reference-link" href="../Markdown.md">Markdown</a> 中的*引用锚点*。

## 复制引用

1.  将光标置于要引用的块中。要引用多个连续的块，请选中它们。
2.  右键点击块手柄（块左侧的一串圆点，参见 <a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a>），然后选择*复制引用*。使用固定格式工具栏时，点击块手柄会打开相同的菜单。或者，右键点击文本，在*复制*子菜单中选择*复制对此块的引用*，若选中了多个块则选择*复制对这些块的引用*。被引用的块会短暂闪烁。
3.  转到要插入链接的笔记，按 <kbd>Ctrl</kbd>+<kbd>V</kbd>。

在[表格](Tables.md)、[旁注](Aside%20blocks.md)或 <a class="reference-link" href="Content%20tabs.md">内容标签页</a>块内部，引用指向整个块。要链接到单个标签页，请改用标签页块的 <span class="tn-icon cke cke-three-vertical-dots"></span> *更多操作*菜单中的*复制对此标签页的引用*。在 <a class="reference-link" href="Multicolumn%20layout.md">多栏布局</a>内部，引用指向该栏中的块，而包含笔记会显示这些块，但不包含周围的布局。

链接显示笔记的标题，后跟被引用文本的开头部分。指向同一笔记中块的链接仅显示被引用文本的开头部分，而指向同一笔记中标题的链接则显示整个标题。

如果笔记已[共享](../../Advanced%20Usage/Sharing.md)，块手柄的菜单还会提供*复制公开链接*。它会复制共享页面的网址并附加引用，以便发送给在 Trilium 之外阅读该笔记的人。打开该地址会将共享页面滚动到被引用的块并使其闪烁。在共享页面上，指向另一篇共享笔记中块的链接也会执行相同的操作。

要引用标题，你也可以在 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/Outline%20tab.md">大纲标签页</a>中右键点击它，然后选择*复制引用*或*复制公开链接*。这在只读笔记中同样有效。

右键菜单的*粘贴*子菜单提供了另外两种插入已复制引用的方式：

*   *将引用粘贴为链接*仅插入链接，即使引用是以纯文本或连同其他内容一起复制的。
*   *将引用粘贴为摘录*插入被引用块的包含笔记，如下所述。

在浏览器中，文本编辑器的右键菜单仅在右键点击选中的文本时才会打开。在其他位置，浏览器会显示自己的菜单。

## 链接到标题

自 v0.107.0 起，可以从*添加链接*对话框创建指向同一笔记中标题的链接：

*   将光标置于链接的所需位置，或选中要转换为链接的文本。
*   按 <kbd>Ctrl</kbd>+<kbd>K</kbd> 或 <a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a>中的 <span class="tn-icon cke cke-link"></span> 按钮，然后在对话框顶部选择*标题 / 锚点*。或者，在 <a class="reference-link" href="Slash%20Commands.md">斜杠命令</a>中选择*链接到标题或锚点*，这会在该页面打开对话框。
*   在*标题*下，点击所需的标题以勾选它。子标题列在其父标题下，默认处于折叠状态；使用标题前的箭头展开或折叠标题，或在标题获得焦点时使用 <kbd>→</kbd> 和 <kbd>←</kbd>。可选地，输入*链接标题*。
*   按 <kbd>Enter</kbd> 或*插入链接*以确认。

未设置链接标题时，链接显示标题的文本。如果标题发生更改，在你停止输入后不久，链接会自动重命名为新文本。带有自身标题的链接会保留该标题。

该链接是指向该标题的块引用，因此当标题被移动时它仍然有效。要更改链接，请点击它并按弹出窗口中的 <span class="tn-icon cke cke-pencil"></span> *编辑链接*按钮。对于带有自身标题的链接，将光标置于其中并按 <kbd>Ctrl</kbd>+<kbd>K</kbd> 也同样有效。对话框会在*标题 / 锚点*页面打开，并勾选该标题。在那里清空*链接标题*会使链接重新显示标题的文本。

### 另一篇笔记中的标题

自 v0.108.0 起，链接也可以指向另一篇笔记中的标题：

*   在*添加链接*对话框中，在*笔记*页面选择笔记。其标题和锚点会列在*链接标题*下方、*链接到笔记（默认）*之后。
*   在*链接到标题*下，点击所需的标题以勾选它，然后按 <kbd>Enter</kbd> 或*插入链接*。链接可以在列表出现之前插入；此时它会链接到笔记本身。
*   或者，输入 `@` 并选择笔记：菜单随后会列出相同的标题，接下来输入的文本会缩小范围。参见[就地链接](Links/Internal%20\(reference\)%20links.md)。

此链接也是块引用。链接到标题会在其中保存一个不可见标识符，即使该笔记为只读时也是如此。如果无法引用该标题（例如因为它在此期间被更改），则会显示错误并且不插入链接。对话框保持打开。从 `@` 菜单中，链接会继续指向整篇笔记。

PDF 的标题以及 Word 或 OpenDocument Text 文档的标题也会以相同方式列出，链接到其中一个不会更改文件。参见 <a class="reference-link" href="../File/PDFs.md">PDF</a> 和 <a class="reference-link" href="../File/Office%20documents.md">Office 文档</a>。

## 跟随引用

点击块引用会打开笔记，滚动到被引用的块并使其闪烁。如果被引用的块已被删除，则会显示错误消息。当范围中仅第一个或最后一个块仍然存在时，笔记会滚动到该块。

指向链接所在笔记中块的链接（例如指向标题的链接）会滚动到这些块并使其闪烁，而不会离开该笔记，就像网页内的链接一样。这在只读笔记和共享页面上同样有效。编辑时，点击链接会显示其弹出窗口：在其中按*跳转到标题*，对于其他块则按*跳转到块*。

## 包含被引用的块

要在另一篇笔记中显示被引用的块，请在正在编辑的笔记中右键点击该链接并选择*将链接转换为笔记摘录*，或者使用*粘贴* → *将引用粘贴为摘录*粘贴已复制的引用。包含笔记仅显示被引用的块，而不显示笔记的其余部分，并在其标题中用*摘录*徽章标记它们。它初始为*完整*框尺寸，因此所有被引用的块都可见。要查看整篇笔记，请按同一标题中的 <span class="tn-icon bx bx-link-external"></span> 按钮，它会在新标签页中打开笔记。将包含笔记转换回链接会保留引用。

要在不离开笔记的情况下编辑被引用的块，请按包含笔记标题中的 <span class="tn-icon bx bx-pencil"></span> *编辑摘录*按钮，或在其工具栏中打开*可编辑*（<span class="tn-icon bx bx-edit-alt"></span>），与任何 <a class="reference-link" href="Include%20Note.md">包含笔记</a>一样。再次按该按钮可停止编辑。更改会保存到被引用的块，笔记的其余部分保持不变。在无法编辑块的地方（例如只读笔记中），该按钮会灰显。摘录没有*全屏*按钮。

如果被引用的块已被删除，包含笔记会显示*引用已损坏*。

## 限制

*   引用只能从正在编辑的笔记中复制，且在移动端布局中不可用。
*   仅覆盖列表或引用的一部分的范围（例如从其第二项到其后的段落）的包含笔记无法就地编辑。单个代码块或图表的包含笔记也无法就地编辑。
*   要编辑来自 Markdown 笔记的摘录，请打开源笔记。摘录本身是只读的。
*   删除块，或使用 <kbd>Backspace</kbd> 将其合并到上方的块中，会破坏对它的引用。
