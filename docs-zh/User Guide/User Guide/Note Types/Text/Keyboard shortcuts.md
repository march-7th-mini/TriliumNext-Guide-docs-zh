## 常用快捷键

> [!TIP]
> 本节中的键盘快捷键是我们所使用的编辑器技术 <a class="reference-link" href="../../Advanced%20Usage/Technologies%20used/CKEditor.md">CKEditor</a> 所支持的快捷键的子集。这些快捷键取自[官方文档](https://ckeditor.com/docs/ckeditor5/latest/features/accessibility.html#keyboard-shortcuts)。请注意，原始文档中的快捷键并非全部适用（由于使用了不同的配置）。

### 与块交互

块是指图片、表格、引用块、注释。

| 操作 | PC | Mac |
| --- | --- | --- |
| 在小组件之后直接插入新段落 | <kbd>Enter</kbd> |  |
| 在小组件之前直接插入新段落 | <kbd>Shift</kbd>+<kbd>Enter</kbd> | <kbd>⇧Enter</kbd> |
| 移动光标以允许直接在小组件之前输入 | <kbd>↑</kbd>, <kbd>←</kbd> |  |
| 移动光标以允许直接在小组件之后输入 | <kbd>↓</kbd>, <kbd>→</kbd> |  |
| 进入嵌套可编辑区域后，将选择移动到最近的祖先小组件。例如：从图片说明移动到整个图片小组件。 | <kbd>Tab</kbd> 然后 <kbd>Esc</kbd> |  |

列表专用：

| 操作 | PC | Mac |
| --- | --- | --- |
| 增加列表项缩进 | <kbd>⇥</kbd> |  |
| 减少列表项缩进 | <kbd>Shift</kbd>+<kbd>⇥</kbd> | <kbd>⇧⇥</kbd> |

表格中：

| 操作 | PC | Mac |
| --- | --- | --- |
| 将选择移动到下一个单元格 | <kbd>⇥</kbd> |  |
| 将选择移动到上一个单元格 | <kbd>Shift</kbd>+<kbd>⇥</kbd> | <kbd>⇧⇥</kbd> |
| 插入新的表格行（当位于表格最后一个单元格时） | <kbd>⇥</kbd> |  |
| 在表格中导航 | <kbd>↑</kbd>, <kbd>→</kbd>, <kbd>↓</kbd>, <kbd>←</kbd> |  |

### 常规 UI 快捷键

| 操作 | PC | Mac |
| --- | --- | --- |
| 关闭上下文气泡、下拉菜单和对话框 | <kbd>Esc</kbd> |  |
| 打开无障碍帮助对话框 | <kbd>Alt</kbd>+<kbd>0</kbd> | <kbd>⌥0</kbd> |
| 在表单字段（输入框、按钮等）之间移动焦点 | <kbd>⇥</kbd>, <kbd>Shift</kbd>+<kbd>⇥</kbd> | <kbd>⇥</kbd>, <kbd>⇧⇥</kbd> |
| 将焦点移动到工具栏，在工具栏之间导航 | <kbd>Alt</kbd>+<kbd>F10</kbd> | <kbd>⌥F10</kbd>（可能需要 <kbd>Fn</kbd>） |
| 在工具栏或菜单栏中导航 | <kbd>↑</kbd>, <kbd>→</kbd>, <kbd>↓</kbd>, <kbd>←</kbd> |  |
| 导航到下一个可聚焦字段或编辑器外部的元素 | <kbd>Tab</kbd>, <kbd>Shift</kbd>+<kbd>Tab</kbd> |  |
| 执行当前聚焦的按钮。执行与编辑器内容交互的按钮会将焦点移回内容。 | <kbd>Enter</kbd>, <kbd>Space</kbd> |  |
| 将焦点移入和移出活动对话框窗口 | <kbd>Ctrl</kbd>+<kbd>F6</kbd> | <kbd>⌘F6</kbd>（可能需要 <kbd>Fn</kbd>） |
