# 快速入门
## 选择安装方式

**仅本地桌面/笔记本电脑** - 允许在桌面上运行单个实例，并将笔记本地保存在该桌面上。

*   <a class="reference-link" href="Installation%20%26%20Setup/Desktop%20Installation.md">桌面安装</a>

**仅通过 Web 访问的服务器** - 在服务器上安装应用程序，并允许从任何设备（包括移动设备）上的任何 Web 浏览器进行访问。

1.  <a class="reference-link" href="Installation%20%26%20Setup/Server%20Installation.md">服务器安装</a>
2.  <a class="reference-link" href="Installation%20%26%20Setup/Mobile%20Frontend.md">移动前端</a>（可选）
3.  <a class="reference-link" href="Installation%20%26%20Setup/Server%20Installation/Third-party%20cloud%20hosting.md">第三方云托管</a>

**服务器与桌面/笔记本电脑组合** - 在服务器和桌面实例上都安装应用程序，以实现 Web 访问和数据同步。这允许所有数据存储在服务器上，并可通过 Web 浏览器或桌面应用程序访问。桌面应用程序将本地同步和存储数据，以便在离线时使用。

1.  <a class="reference-link" href="Installation%20%26%20Setup/Server%20Installation.md">服务器安装</a>
2.  <a class="reference-link" href="Installation%20%26%20Setup/Mobile%20Frontend.md">移动前端</a>（可选）
3.  <a class="reference-link" href="Installation%20%26%20Setup/Desktop%20Installation.md">桌面安装</a>
4.  <a class="reference-link" href="Installation%20%26%20Setup/Synchronization.md">同步</a>
