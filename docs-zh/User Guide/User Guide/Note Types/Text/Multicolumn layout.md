# 多栏布局
多栏布局将内容并排排列为两到四栏。每一栏可以容纳任何类型的内容，包括表格、图片以及另一个多栏布局。

栏周围的边框仅在编辑时作为参考。在[只读笔记](../../Basic%20Concepts%20and%20Features/Notes/Read-Only%20Notes.md)、[共享笔记](../../Advanced%20Usage/Sharing.md)和打印输出中，栏没有边框，其文本与笔记的其余部分对齐。

## 插入布局

*   在格式栏中，转到 _插入_ → <span class="tn-icon cke cke-trilium-multicolumn"></span> _多栏布局_ 以插入一个两栏布局。其子菜单提供 _2 栏_、_3 栏_ 和 _4 栏_。
*   或者，输入 `/columns` 并选择 _2 栏布局_、_3 栏布局_ 或 _4 栏布局_，如 <a class="reference-link" href="Slash%20Commands.md">斜杠命令</a> 中所述。

新布局的各栏宽度相等。如果在插入布局时选中了文本，所选内容会移动到第一栏。

## 更改栏

当光标位于布局内时，其上方会出现一个工具栏，其中有一个显示当前布局的按钮。点击它会打开一排图形，每个可用布局对应一个图形；将鼠标悬停在某个图形上会显示其栏数及各栏宽度：

| 栏数 | 宽度 |
| --- | --- |
| 2 | 50%-50%、25%-75%、75%-25% |
| 3 | 33%-33%-33%、25%-50%-25% |
| 4 | 25%-25%-25%-25% |

*   选择栏数更多的布局会在末尾添加空栏。
*   选择栏数更少的布局会移除最后几栏，并将其内容移动到最后一个保留栏的末尾。

## 移除布局

*   要移除布局但保留其内容，请点击布局工具栏中的 <span class="tn-icon cke cke-cancel"></span> _移除布局_ 按钮。各栏的内容会依次放置在原布局所在的位置，空栏会被省略。
*   要连同其内容一起删除布局，请点击其左上角的手柄以选中它，然后按 <kbd>Delete</kbd>。

## 窄屏幕

当布局的空间不足以容纳其各栏时（窄于约 500 像素，例如在手机上），各栏会上下堆叠。在编辑时，交替的背景颜色会取代边框。这适用于每个布局本身，因此窄栏内的布局会堆叠，而外层布局仍保持并排。

## 打印和导出

*   在打印或[导出为 PDF](../../Basic%20Concepts%20and%20Features/Notes/Printing%20%26%20Exporting%20as%20PDF.md)时，各栏会并排打印，不带边框。
*   Markdown 没有栏的概念，因此 Markdown 导出会依次写入各栏的内容。
