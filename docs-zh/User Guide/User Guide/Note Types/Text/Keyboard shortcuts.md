# 键盘快捷键
## Trilium 专用快捷键

| 操作 | PC | Mac |
| --- | --- | --- |
| 调出行内格式工具栏（用方向键 ←、→ 导航，Enter 应用） | Alt+F10 | ⌥+F10 |
| 调出块格式工具栏 | Alt+F10 | ⌥+F10 |
| 创建[外部链接](Links.md) | Ctrl+K | ⌘+K |
| 创建[内部（笔记）链接](Links.md) | Ctrl+L | ⌘+L |
| 在光标位置插入当前日期和时间 | Alt+T | ⌥+T |
| 增加段落缩进 | Tab | ⇥ |
| 减少段落缩进 | Shift + Tab | ⇧ + ⇥ |
| 将选中文本标记为[键盘快捷键](Developer-specific%20formatting.md) | Ctrl + Alt + K | ⌘+ ⌥+ K |
| 插入 <a class="reference-link" href="Math%20Equations.md">数学公式</a> | Ctrl + M | ⌘+ M |
| 向上移动块（列表、段落等），或在[表格](Tables.md)中向上移动行 | Alt+↑ | ⌥+↑ |
| 向下移动块（列表、段落等），或在[表格](Tables.md)中向下移动行 | Alt+↓ | ⌥+↓ |
| 将选中内容移动到 <a class="reference-link" href="Multicolumn%20layout.md">多栏布局</a> 的另一列 | Ctrl+←, Ctrl+→, Ctrl+Shift+Home, Ctrl+Shift+End | ⌘+←, ⌘+→, ⌘+⇧+Home, ⌘+⇧+End |
| 移动多栏布局的当前列 | Ctrl+Alt+←, Ctrl+Alt+→, Ctrl+Alt+Home, Ctrl+Alt+End | ⌘+⌥+←, ⌘+⌥+→, ⌘+⌥+Home, ⌘+⌥+End |
| 在多栏布局中当前列之后或之前添加一列 | Ctrl+Enter, Ctrl+Shift+Enter | ⌘+Enter, ⌘+⇧+Enter |
| 将选中内容移动到 <a class="reference-link" href="Content%20tabs.md">内容标签页</a> 的另一标签页 | Ctrl+←, Ctrl+→, Ctrl+Shift+Home, Ctrl+Shift+End | ⌘+←, ⌘+→, ⌘+⇧+Home, ⌘+⇧+End |
| 移动标签页块的当前标签页 | Ctrl+Alt+←, Ctrl+Alt+→, Ctrl+Alt+Home, Ctrl+Alt+End | ⌘+⌥+←, ⌘+⌥+→, ⌘+⌥+Home, ⌘+⌥+End |
| 在标签页块中当前标签页之后或之前添加一个标签页 | Ctrl+Enter, Ctrl+Shift+Enter | ⌘+Enter, ⌘+⇧+Enter |

## 常用快捷键

> [!TIP]
> 本节键盘快捷键列出了我们所使用的编辑器技术 <a class="reference-link" href="../../Advanced%20Usage/Technologies%20used/CKEditor.md">CKEditor</a> 所支持的部分键盘快捷键。这些快捷键取自[官方文档](https://ckeditor.com/docs/ckeditor5/latest/features/accessibility.html#keyboard-shortcuts)。请注意，原始文档中并非所有快捷键都适用（因为使用了不同的配置）。

### 与块交互

块包括图片、表格、块引用、注释。

| 操作 | PC | Mac |
| --- | --- | --- |
| 直接在小组件之后插入新段落 | Enter |  |
| 直接在小组件之前插入新段落 | Shift+Enter | ⇧Enter |
| 将光标移动到小组件之前以便直接输入 | ↑, ← |  |
| 将光标移动到小组件之后以便直接输入 | ↓, → |  |
| 进入嵌套可编辑区域后，将选区移动到最近的祖先小组件。例如：从图片说明移动到整个图片小组件。 | Tab 然后 Esc |  |

| --- | --- | --- |
