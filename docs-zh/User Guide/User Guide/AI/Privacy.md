# 隐私

在你发送消息之前，Trilium 不会向 AI 提供商发送任何内容。启用集成、添加提供商或打开对话本身都不会传输任何数据，唯一的例外是：列出某个提供商的模型时，会将你的 API 密钥发送给该提供商，以便获取模型列表。

一旦你发送消息或运行<a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>，离开你机器的内容取决于你所选择的提供商以及启用了哪些上下文选项。

## 你的笔记会去向何处

| 提供商类型 | 目的地 |
| --- | --- |
| 云提供商 | 提供商的服务器（Anthropic、OpenAI、Google、DeepSeek） |
| 基于订阅 | 提供商的服务器，通过本地运行的 Claude Code |
| 本地 / 自托管 | 不会离开运行模型的机器 |
| 自定义端点 | 指向的任何位置，可能是你自己的硬件或托管服务 |

这就是提供商列表如此分组的原因，也是 Trilium 不预选任何提供商的原因：你的笔记内容发送到何处，是由你在发送任何内容之前明确做出的选择。

> [!NOTE]
> <a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>有自己独立的模型选择，因此它可能由与对话中不同的提供商来回答。助手菜单底部的行始终会标明当前正在使用的提供商。

## 实际发送的内容

*   **每条消息都会发送**
    *   对话本身：你的消息和助手的回复，包括之前的轮次
    *   Trilium 的系统提示词，描述如何格式化回答以及使用工具。
*   **当前笔记，仅在启用笔记上下文时发送。**
    *   在侧边栏对话中，这是底部的文件图标；专用的对话笔记类型从不发送当前笔记。
    *   传输的内容是一个元数据块：笔记的 ID、标题、类型、创建和修改日期、其父级 ID、最多 20 个子笔记的标题、最多 20 个属性，以及内容的预览。
    *   超过大小阈值的笔记会发送大小提示而非文本，模型必须调用工具才能进一步读取。
*   **模型请求的任何笔记，在启用笔记访问时。**
    *   工具允许模型搜索你的笔记树，并读取当前笔记之外的笔记、属性和附件。
    *   由模型决定获取什么，每次调用都会等待你允许，除非对话的权限模式允许读取或所有调用自行运行，或者你已为该对话允许了该工具。没有按笔记的权限系统，因此可触及的范围是你的整个笔记树。
*   **附件和提及**，当你添加它们时：图片、PDF 和文本文件会发送给提供商，而 `@` 提及会使该笔记可被获取。
*   **你的搜索查询**，在启用网络搜索时，模型的搜索词会到达提供商自己的搜索基础设施，或 _工具_ 菜单中选择的搜索提供商（Brave Search、Tavily、Exa、Serper、Perplexity 或你的 SearXNG 实例）。
*   **模型读取的页面**，当网络搜索通过搜索提供商进行时：Trilium 会从网站本身获取模型请求的每个页面，因此网站会看到来自运行 Trilium 的机器的请求。页面的文本随后会发送给模型的提供商。

## 编辑器内 AI 助手

运行<a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>发送的内容集与对话消息不同。对于快捷操作，它会在你选择操作的那一刻发送，没有发送按钮可供反悔。对于自由形式的 _Ask AI_，有专门的发送按钮和模型选择器。

*   **你选中的段落**，或者当你选择快捷操作而未选中任何内容时光标所在的段落。
*   **该段落两侧各最多 1500 个字符的笔记内容**，以纯文本形式。助手会被告知这仅是上下文，不得重写，但无论你是否选中它都会被发送：对单个句子运行仍会传输其周围的段落。
*   **笔记所在位置**：其标题及其父级的标题，作为面包屑导航。
*   **Trilium 的写作助手指令**，描述它可能生成的格式。
*   **同一交互的之前轮次**，一旦你对某个回复进行追问。

不会发送笔记元数据块，网络搜索从不启用，助手也没有笔记工具，因此它无法读取上述文本之外的任何内容。

## 受保护的笔记

当你的[受保护会话](../Basic%20Concepts%20and%20Features/Notes/Protected%20Notes.md)处于锁定状态时，受保护的笔记既不发送标题也不发送内容。**当它解锁时，它们会被当作任何其他笔记对待**，模型通过工具读取的笔记会完整发送给提供商。如果你在受保护的笔记中保存敏感材料，请注意解锁它们会在会话期间移除该边界。

这同样适用于<a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>：它作用于编辑器中打开的任何内容，因此在已解锁的受保护笔记中运行它，会像任何其他笔记一样发送该笔记的文本。

## 你可以控制的内容

*   **使用哪个提供商**：这一单一决定决定了是否有任何内容离开你的机器。
*   **笔记访问**：在对话底部的 <span class="tn-icon bx bx-shield-quarter"></span>_工具_ 菜单中将其关闭，模型便无法读取你输入内容之外的任何东西。
*   **当前笔记：** 侧边栏对话中的文件图标。
*   **网络搜索：** 同样在 _工具_ 菜单中。
*   **哪些工具调用会先询问：** _工具_ 菜单的 _权限_ 子菜单。_始终询问_ 会让每次调用都等待你，包括读取。新对话会以你上次选择的模式开始，因此在一个设置为 _不询问_ 的对话之后开启的对话也不会询问任何事情。在你选择模式之前，对话以 _更改前询问_ 开始，此时 AI 会在不询问的情况下读取和搜索你的笔记。
*   **编辑器助手**：它没有按次运行的开关。你能控制的是是否运行它、运行前选中什么以及由哪个模型回答。

在笔记访问和笔记上下文都关闭的情况下，提供商只会收到你输入的词语。

## 保持一切本地化

添加 Ollama 或 LM Studio 提供商会使每条消息都留在运行模型的机器上，Trilium 会将其模型标记为免费，因为不涉及计费 API。代价是质量和硬件：小型本地模型可能在工具调用上失败，而云模型可以处理，因此行为异常的本地设置值得在报告为 bug 之前与云提供商进行基准对比。

## 遥测与安全

Trilium 本身不会从 AI 集成中收集任何遥测数据。

你的 API 密钥存储在你的数据库中，仅发送给其所属的提供商，并且通过选项 API 是只写的，因此恶意的<a class="reference-link" href="../Scripting.md">脚本</a>无法访问它。如果你启用了后端或 SQL 控制台访问，恶意脚本**有可能窃取你的 API 密钥**。

内置的 MCP 服务器默认关闭。启用后，每个请求都必须携带 ETAPI 令牌，该令牌授予与 REST API 相同的完整笔记读写访问权限；请像对待密码一样对待它。在桌面上，除非你开启<a class="reference-link" href="../Installation%20%26%20Setup/Desktop%20Installation/Network%20Access.md">网络访问</a>，否则只能从 `localhost` 访问。
