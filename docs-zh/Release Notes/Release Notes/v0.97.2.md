## 💡 主要亮点

*   新增了一种集合类型：一种看板，子笔记在其中按列分组。
*   地理地图现在默认使用矢量地图。
    *   矢量样式将提供更流畅的体验，更多信息请查阅文档。
    *   此外，在功能区中的“_集合属性_”部分有多种样式可供选择，包括深色主题。
    *   另外，新增了在地图上显示比例尺的选项。
*   “跳转到笔记”功能得到增强，允许快速触发命令（例如那些可以分配键盘快捷键的命令）。
    *   按 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> 进行测试。
    *   该功能已重命名为简单的“跳转到…”，以更好地适应其新角色。
    *   更多信息，请查看“跳转到…”的用户指南。
