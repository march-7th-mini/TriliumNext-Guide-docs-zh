## ✨ 改进

*   添加周笔记和季度笔记支持，由 @JYC333 实现
*   Markdown 导入/导出：
    *   减少列表项之间多余的空格。
    *   保留包含笔记。
    *   处理包含内联代码的笔记标题。
    *   支持待办事项列表。
*   应用内帮助：
    *   文档结构现在已预先计算，因此启动时间应略有改善。
    *   优化了内容以减少磁盘占用。
*   移动端改进：
    *   以下对话框现在可访问：批量操作、分支前缀、包含笔记、添加链接、排序子笔记、笔记类型选择器、移动/克隆到、导入/导出、Markdown 导入、笔记修订、信息对话框。
    *   删除笔记现在需要确认。
    *   模态框底部现在有安全边距并且可以滚动。
*   [将搜索结果在快速搜索栏下居中显示](https://github.com/TriliumNext/Notes/issues/1679)
*   恢复 Windows 原生 ARM 构建。
*   为 macOS 提供基本的 Touch Bar 支持。
*   [支持 Bearer Token](https://github.com/TriliumNext/Notes/issues/1701)
*   标签栏在标签过多时现在可以滚动，由 @SiriusXT 实现
*   使笔记路径的每个部分都可点击，由 @SiriusXT 实现
*   允许设置 CORS 头，由 @yiranlus 实现

## 📖 文档
