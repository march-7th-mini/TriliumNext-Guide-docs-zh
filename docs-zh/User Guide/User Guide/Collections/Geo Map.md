# 地理地图
<figure class="image"><img style="aspect-ratio:1561/1149;" src="Geo Map_image.png" width="1561" height="1149"></figure>

此笔记类型基于某个属性，将子笔记显示在地理地图上。也可以使用内置界面在特定位置添加新笔记。

## 功能

*   在地图上添加标记，可自定义图标、颜色和文本。
*   搜索地图上已有的笔记，并查找世界任何地方的地点。
*   点击地图上已显示的地点，将其转换为标记。
*   在地图上绘制路径、区域、矩形和圆形。
*   使用 `.gpx` 文件在地图上显示轨迹。
*   在地图上显示您自己的位置，并在移动时跟随它。
*   地图的 3D 视图，在使用矢量地图时显示建筑物。

## 系统要求

从 v0.105.0 开始，地理地图使用 MapLibre GL，需要 WebGL v1 支持。一般来说，大多数设备都支持，因为浏览器/Electron 在需要时可以通过软件渲染。

如果因为无法初始化 WebGL 而无法绘制地图，将显示错误消息而不是地图（_此地图无法绘制，因为 WebGL 不可用……_）。

显示您位置的按钮仅在通过 HTTPS 访问 Trilium、在桌面应用程序或移动应用程序中时提供。浏览器拒绝与通过纯 HTTP 提供服务的页面共享设备位置，因此在此类服务器上该按钮不会出现。

## 交互

*   左上角是搜索栏。它搜索地图上已有的笔记，当您要求时也可以在线搜索地点。当您在搜索结果中移动时，其下方会出现一个带有上一个（<span class="tn-icon bx bx-chevron-left"></span>）和下一个（<span class="tn-icon bx bx-chevron-right"></span>）按钮的计数器。
*   底部中央有一个中央工具栏，提供编辑功能：在地图上添加新标记（<span class="tn-icon bx bx-pin"></span>）和导入 GPX 轨迹（<span class="tn-icon bx bx-trip"></span>）。
*   右下角是视口项目：
    *   放大/缩小（<span class="tn-icon bx bx-plus-circle"></span> / <span class="tn-icon bx bx-minus-circle"></span>）
        *   在移动端这些是隐藏的，请改用双指缩放。
        *   在桌面端，也可以使用滚轮调整缩放。
    *   一个 <span class="tn-icon bx bx-current-location"></span> 按钮，在地图上显示您的位置并跟随它（参见下面的_前往您的位置_）。
    *   <span class="tn-icon bx bx-fullscreen"></span> 全屏按钮，将整个地图聚焦到屏幕上，同时仍允许编辑。
*   顶部中央（桌面端，或移动端和分屏视图中的左侧中央）是绘图工具，如路径、区域、矩形和圆形。
    *   当地图为只读时，不显示工具栏。

## 创建新的地理地图

在<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a>中右键单击现有笔记，然后选择_插入子笔记_ → _集合_ → _地理地图_。

默认情况下，地图将是空的并显示整个世界。

## 重新定位地图

*   单击并拖动地图以在地图上移动。
*   使用鼠标滚轮、触控板上的双指手势或右下角的 +/- 按钮调整缩放。

地图上的位置和缩放保存在地图笔记内部，再次访问该笔记时会恢复。

尚未保存位置的地图在打开时会以其包含的标记为中心进行框选，因此它们都在视野内，无需去寻找它们。不包含标记的地图则显示整个世界。

实际上，这适用于标记是通过脚本或通过<a class="reference-link" href="../Advanced%20Usage/ETAPI%20(REST%20API).md">ETAPI (REST API)</a>从外部添加的地图。当您自己添加标记时，您已经移动地图到达您要标记的地点，而该移动会保存位置。

## 前往您的位置

按地图右下角缩放按钮旁边的_显示您的位置_（<span class="tn-icon bx bx-current-location"></span>）按钮。第一次时，浏览器或操作系统会询问 Trilium 是否可以知道设备的位置。在桌面应用程序中，由操作系统的位置设置决定。

然后地图移动到设备所在位置，并用蓝点标记它。点周围的较浅圆圈显示位置的准确度：带 GPS 的手机给出街道上的点，而通过网络连接定位的计算机可能给出覆盖一个街区的圆圈。地图跟随点的移动，按钮在跟随期间保持按下状态。

拖动地图会停止跟随。点保留并继续移动，再次按下按钮会将地图带回它。在地图跟随期间按下按钮会关闭点。

单击点可在显示搜索地点的面板中查看其坐标。从那里可以将位置保留为标记（参见_将地点保留为标记_）。单击点周围的较浅圆圈是对地图的单击。

如果无法找到位置，会显示一条消息，按钮会继续等待；再次按下以停止。如果您拒绝权限，按钮将被禁用，直到再次打开地图。若要最终允许，请在浏览器或系统的位置设置中更改 Trilium 的权限。

您的位置不会存储在笔记中，Trilium 也不会自行将其发送到任何地方。将地图移动到那里所做的与任何其他平移或缩放相同：地图样式背后的瓦片提供商会看到当前屏幕上区域的坐标。地图确实会记住您离开它的位置，就像任何其他移动后一样，因此您带到您位置的地图下次会在那里打开。

## 搜索地图

地图左上角的搜索栏在两个地方搜索。它始终搜索地图上已有的笔记。它也可以在线搜索地点，但仅在您要求时。

### 搜索地图上已有的笔记

在搜索栏中输入，地图上的笔记会在您输入时按标题匹配。重音符号会被忽略，无论是您输入的内容还是标题中，因此 `zurich` 会找到 _Zürich Hauptbahnhof_。每个词单独搜索，因此 `hotel paris` 会找到 _Paris Hotel_。没有 `#geolocation` 属性的笔记不会被提供，因为没有可去的地方。绘制的形状和 GPS 轨迹会被提供，即使它们没有此类属性：选择一个会将整个形状或路线带入视野。

如果匹配的笔记多于列表可显示的数量，会向您提供最接近您正在查看区域的笔记。

### 在线搜索地点

查找地点会将您输入的内容发送到第三方服务。因此，它绝不会在您输入时发生。相反，结果列表的最后一行提供搜索。该行显示_在线搜索"……"_，其下方是服务名称。仅当您按下该行或用 Enter 选择它时，搜索才会运行。

Trilium 使用 Nominatim，这是由 OpenStreetMap 基金会运行的地点搜索。它不需要账户和 API 密钥。其名称显示在属于它的每一行上：提供搜索的行、显示搜索正在运行的行，以及报告未找到任何内容或无法访问服务的行。

搜索优先考虑您正在查看的区域。当前视图内的地点会首先被搜索并列在其他地点之上。因此，如果您在查看自己城镇时搜索一家商店，您会找到该镇的连锁店，而不是另一个大陆上同名的店。视图始终被视为至少 25 公里宽，因此放大到单条街道时进行的搜索仍覆盖其周围的城镇。

### 前往某个点

如果您在搜索栏中输入或粘贴坐标，会在所有其他结果之上提供_前往_行。选择它会将地图移动到该确切位置并标记它。然后您可以将其保留为标记，方式与保留通过搜索找到的地点相同。

点默认无标题；相应笔记打开时会选中默认名称，以便轻松替换。如果地图有<a class="reference-link" href="../Advanced%20Usage/Default%20Note%20Title.md">默认笔记标题</a>标签，则标记会改为按该模板命名。

支持的形式有：

*   简单的坐标对，例如 `45.9432, 24.9668`。这是 Google Maps 和 OpenStreetMap 在您请求地点坐标时都会给出的，也是 `#geolocation` 属性所保存的。
*   地图本身通过_打开位置_操作为地点提供的 `geo:` 链接。
*   Google Maps 或 OpenStreetMap 上地点的地址，完整粘贴。

不是地球上位置的坐标对，例如 `1234, 5678`，不会被提供。

### 读取结果

结果按标题分组，每组按距地图中心的距离排序：

*   _在此地图上_：已在地图上的笔记，无论其距离如何。
*   _附近_：在视图约 25 公里范围内找到的地点。
*   _远处_：所有其他地点。

仅当三组中至少有两组包含内容时，标题才会出现。每个有位置的行都会显示其距离，根据您的区域设置以公里或英里为单位。在线找到的地点第一行显示其名称，第二行显示其地址。

### 选择结果

选择地图上已有的笔记会移动到其标记并在旁边打开笔记，就像单击标记一样。

选择在线找到的地点会将地图移动到它并用临时图钉标记它。图钉的颜色与地图自己的标记不同。地图会适配到该地点覆盖的区域，因此国家会填满视图，而房屋则以街道级别显示。有些地点有边界，例如国家、县或公园。当服务报告边界时，该边界会在图钉下方勾勒出来。

然后会打开一个面板，显示地点的完整地址及其坐标：桌面端在右上角，移动端在地图底部，顶部保留给搜索栏和结果计数器。按下坐标会将其复制到剪贴板。

### 将地点保留为标记

在该面板中按_添加为标记_以保留该地点。在地图下创建一个子笔记。它以地点的名称命名，并使用与地点类型匹配的图标。其 `#geolocation` 属性已设置。笔记在地图旁边打开，因此您可以立即编辑它。临时图钉消失，因为该地点现在像其他标记一样是标记。

在无法编辑的地图上不提供该按钮，但面板仍可读取。

按面板的关闭按钮或 Escape 键，可在不保留的情况下关闭地点。图钉也随之消失。

### 逐步浏览结果

选择结果后，搜索栏下方会出现一个计数器，带有上一个（<span class="tn-icon bx bx-chevron-left"></span>）和下一个（<span class="tn-icon bx bx-chevron-right"></span>）按钮。这些按钮按列出顺序遍历搜索提供的所有内容。因此，您可以比较多个结果而无需再次打开列表。按下计数器本身会将地图移回当前结果，这在您将地图移开之后很有用。

### 键盘

*   <kbd>Enter</kbd> 当其行被选中时运行在线搜索，否则移动到高亮的结果。在取得结果后按下，会带回列表。
*   <kbd>Escape</kbd> 关闭结果列表，并关闭地点面板。
*   返回搜索栏会重新打开它之前显示的列表。
*   栏末的 <span class="tn-icon bx bx-x"></span> 按钮会清空它，这也会将搜索的地点、其图钉和面板从地图上移除。

## 使用地图添加标记

### 使用_添加标记_按钮添加新笔记

1.  要创建标记，首先导航到地图上的所需点。然后按地图底部中央的_添加标记_（<span class="tn-icon bx bx-pin"></span>）按钮。
2.  按下后，地图将进入插入模式，如通知所示。此外，光标位置会显示标记的预览。
    
    只需单击地图上放置标记的点。要取消，请按 Escape 键或再次按_添加标记_按钮。
3.  单击后，标记将显示在地图上，右侧会显示一个弹出窗口，标题已被选中以便更改。

### 使用上下文菜单添加新笔记

1.  在地图上任何位置右键单击，以放置新创建的标记（及相应笔记）。
2.  选择_在此位置添加标记_（<span class="tn-icon bx bx-pin"></span>）。
3.  在地图上单击位置后，标记将显示在地图上，右侧会显示一个弹出窗口，标题已被选中以便更改。

### 从笔记树添加现有笔记

1.  在<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a>中选择所需的笔记。
2.  将鼠标按住笔记并将其拖动到地图上的所需位置。
3.  地图应更新为新标记。

这适用于：

*   不属于地理地图的笔记，此时将创建[克隆](../Basic%20Concepts%20and%20Features/Notes/Cloning%20Notes.md)。
*   是地理地图的子笔记但尚未在地图上定位的笔记。
*   是地理地图的子笔记且已定位的笔记，此时标记将重新定位到新位置。

> [!NOTE]
> 拖动现有笔记仅在处于编辑模式时有效。有关更多信息，请参见_只读_部分。

### 从地图已显示的地点添加笔记

当使用矢量地图样式时，地图本身会绘制正在查看区域周围的商店、咖啡馆、博物馆和其他地点。一旦地图放大到足以绘制这些地点，就可以单击它们：

1.  寻找以橙色绘制的地点。这与搜索找到的地点使用的颜色相同。这些是您可以单击的地点。它们绘制得几乎实心，而地图上的其他地点保持淡灰色。
2.  将鼠标停留在其中一个上。其名称会出现在其上方，鼠标光标变为指针。地图将这些地点绘制为无名称的图标，因此您通过悬停来读取名称。如果一次显示所有名称，它们会挤掉您自己标记的标题。
3.  单击它。会出现与搜索找到的地点相同的面板。它显示地点的名称及其坐标，并在地图上放置一个图钉。
4.  按_添加为标记_以保留它。笔记以地点名称作为标题创建，并使用与地点类型匹配的图标。

地点从已下载的地图数据中读取，因此单击一个不会向互联网发送任何内容。

需要注意的一些事项：

*   地图数据中没有名称的地点，如长椅或停车位，不显示名称且无法单击。单击它们没有任何作用，就像单击地图的空白部分一样。
*   地图自己的标记优先。如果标记覆盖了地点，单击它会打开笔记而不是地点。
*   这不适用于栅格（OpenStreetMap）样式，因为其地点是地图图像的一部分。它也不适用于_Neutrino_样式，该样式不绘制地点。
*   在只读模式下，您仍然可以单击地点并读取它，但不能将其保留为标记。

## 标记的位置如何存储

标记的位置存储在子笔记的 `#geolocation` 属性中：

如果需要，可以手动添加此值。属性值由纬度和经度组成，用逗号分隔。

在图像地图上，位置改为存储在 `#mapPosition` 中（参见<a class="reference-link" href="Geo%20Map/Image%20maps.md">图像地图</a>）。

## 重新定位标记

设置标记后，可以使用以下两种方式之一重新定位它：

*   右键单击标记并选择_移动到另一位置_（<span class="tn-icon bx bx-move"></span>）。
*   单击标记打开弹出窗口，然后选择标题栏下方的_移动到另一位置_（<span class="tn-icon bx bx-move"></span>）按钮。

单击移动标记的按钮后，在地图上单击所需位置以替换它。要取消操作，请按 Escape。

> [!NOTE]
> 如果地图被锁定以进行编辑（见下文），则需要先解锁地图才能移动标记。

## 与标记、轨迹或形状的交互

*   将鼠标悬停在标记上会显示一个<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tooltip.md">笔记工具提示</a>，其中包含其所属笔记的内容。
    *   单击工具提示中的笔记标题将在当前视图中导航到该笔记。
*   右键单击标记将打开上下文菜单（如下所述）。
*   单击标记将聚焦于标记并显示包含详细信息的专用弹出窗口。无论地图是否可编辑，这都有效。

### 弹出视图

当单击标记、[形状](Geo%20Map/Drawing%20shapes.md)或轨迹时，右侧会打开一个弹出窗口，其中包含以下信息：

*   标记的标题和图标，两者均可编辑。
*   坐标指示器（<span class="tn-icon bx bx-crosshair"></span>）；单击它会将坐标复制到剪贴板。
*   一个 <span class="tn-icon bx bx-expand-alt"></span> 按钮以最大化弹出窗口。
*   与当前项目交互的按钮：
    *   <span class="tn-icon bx bx-log-in"></span> 在同一窗格中打开标记，或使用 <span class="tn-icon bx bx-dots-horizontal-rounded"></span> 在新标签页、分屏等中打开它。
    *   一个 <span class="tn-icon bx bx-map-alt"></span> 按钮以在专用应用程序中打开位置（例如移动端的 Google Maps）。
    *   <span class="tn-icon bx bx-palette"></span> 颜色选择器以更改标记的颜色。
    *   <span class="tn-icon bx bx-move"></span> 标记也可以移动，与轨迹或形状不同（后者需要重新绘制）。
    *   <span class="tn-icon bx bx-trash"></span> 按钮以从地图上移除标记，可选择删除其相应笔记。
        *   移除标记而不删除笔记只会移除其 `#geolocation` 属性（在这种情况下，必须手动重新添加坐标才能使笔记再次显示在地图上）。
        *   同样，移除形状会移除其 `#geoShape` 属性。
*   标记的<a class="reference-link" href="../Advanced%20Usage/Attributes/Promoted%20Attributes.md">提升属性</a>（如果有）。
*   笔记的内容，可直接从面板编辑。

要关闭弹出窗口：

*   按弹出窗口右上角的 X 按钮。
*   在地图上，按弹出窗口外的任何位置。
*   或直接按 Escape 键。

单击标记时，地图会自动调整视口，以便在弹出窗口打开时标记仍然可见。当前选中的标记显示得稍大一些。

即使弹出视图已打开，也可以通过单击标记在它们之间切换。

标记之间可以有<a class="reference-link" href="../Note%20Types/Text/Links/Internal%20(reference)%20links.md">内部（引用）链接</a>，单击此类链接会自动将视口和弹出视图调整到新笔记。

### 上下文菜单

可以按鼠标右键显示上下文菜单。

1.  如果右键单击地图的空白部分（不在标记上），它可以：
    1.  <span class="tn-icon bx bx-crosshair"></span> 显示纬度和经度。单击此选项会将它们复制到剪贴板。
    2.  <span class="tn-icon bx bx-map-alt"></span> 使用外部应用程序打开位置（如果操作系统支持）。
    3.  <span class="tn-icon bx bx-pin"></span> 在该位置添加新标记。
2.  如果右键单击标记，它可以：
    1.  <span class="tn-icon bx bx-crosshair"></span> 显示纬度和经度。单击此选项会将它们复制到剪贴板。
    2.  <span class="tn-icon bx bx-map-alt"></span> 使用外部应用程序打开位置（如果操作系统支持）。
    3.  在新标签页、分屏或窗口中打开笔记。
    4.  <span class="tn-icon bx bx-move"></span> 将标记移动到另一位置。
    5.  <span class="tn-icon bx bx-trash"></span> 按钮以从地图上移除标记，可选择删除其相应笔记。移除标记而不删除笔记只会移除其 `#geolocation` 属性（在这种情况下，必须手动重新添加坐标才能使笔记再次显示在地图上）。
3.  形状也可以右键单击，菜单与标记类似，但它们无法移动。

### 图标和颜色

<figure class="image image-style-align-right image_resized" style="width:47.42%;"><img style="aspect-ratio:885/321;" src="3_Geo Map_image.png" width="885" height="321"></figure>

标记将具有与笔记相同的图标。

可以通过为标记分配 `#color` 属性（如 `#color=green`）来为其添加自定义颜色。

### 手动添加坐标

搜索地点通常更快（参见上面的_搜索地图_）。以下步骤对于手头已有的坐标或搜索无法找到的地点仍然有用。

简而言之，创建一个子笔记并将 `#geolocation` 属性设置为坐标。

属性值由纬度和经度组成，用逗号分隔。

#### 从 Google Maps 添加

1.  在 Web 上的 Google Maps 中：
    1.  寻找所需位置，右键单击它，会出现上下文菜单。
    2.  只需单击显示坐标的第一项，它们就会被复制到剪贴板。
2.  在 Trilium 中，在地图下创建一个子笔记。
3.  然后将文本框中的值粘贴到地图子笔记的 `#geolocation` 属性中（不要忘记用 `"` 字符包围该值）。

#### 从 OpenStreetMap 添加

与 Google Maps 方法类似：

1.  转到 openstreetmap.org 上的任何位置，右键单击以调出上下文菜单。选择_显示地址_项。
2.  地址将在屏幕左上角可见，位于搜索栏的位置。选择坐标并将它们复制到剪贴板。
3.  只需将文本框中的值粘贴到地图子笔记的 `#geolocation` 属性中，然后它就应该显示在地图上。

## 添加 GPS 轨迹（.gpx）

<figure class="image"><img style="aspect-ratio:1566/1155;" src="1_Geo Map_image.png" width="1566" height="1155"></figure>

Trilium 可以以 `.gpx` 文件的形式在地理地图上显示 GPS 轨迹。

要添加轨迹，可以：

1.  将 `.gpx` 文件拖放到笔记树中的地理地图内。
    1.  为了使文件被识别为 GPS 轨迹，它需要在_文件类型_字段中显示为 `application/gpx+xml`。
2.  按_从 GPX 文件添加 GPS 轨迹_（<span class="tn-icon bx bx-trip"></span>）按钮，它会直接提示选择 GPX 文件并将其作为集合的子笔记导入。

返回地图时，轨迹现在应该可见。

轨迹的起点将显示为标记，下方是笔记的名称。起点标记也会遵循笔记的图标和 `color`。终点标记使用不同的图标显示。

如果轨迹文件包含多条轨迹，它们都将作为标记显示。Trilium 还会拆分恰好具有非连续点的单条轨迹。

如果 GPX 包含航点，它们也会显示，包括其名称。

单击轨迹时，整个路线会带入视野，右侧弹出窗口会指示轨迹的详细信息，如距离、持续时间和海拔图。单击 `.gpx` 笔记本身时也会显示此信息。

单击轨迹的标记时（无论是起点或终点内置标记，还是属于轨迹的自定义标记），只会将那个标记带入视野，而不是整个路线。

## 只读模式

当地图处于[只读](../Basic%20Concepts%20and%20Features/Notes/Read-Only%20Notes.md)状态时，所有编辑功能都将被禁用，例如：

*   地图底部的_添加标记_（<span class="tn-icon bx bx-pin"></span>）按钮。
*   重新定位标记。
*   从上下文菜单编辑（移除位置或添加新项目）。
*   将地点保留为标记，无论您是通过搜索找到的还是在地图上单击的。您仍然可以搜索和单击，仍然可以查看地点并复制其坐标。
*   绘制[形状](Geo%20Map/Drawing%20shapes.md)。
*   _地理地图属性_对话框；其入口从<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">笔记菜单</a>中隐藏。

要将地图设置为只读，请转到<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">笔记菜单</a> → _可编辑_ → _只读_。

## 配置

### 地图样式

地图的样式可以在<a class="reference-link" href="Collection%20Properties.md">集合属性</a>中调整，位于_地理地图属性_对话框的_背景_下，或通过 `#map:style` 属性手动调整。

地理地图附带两种不同类型的样式：

*   栅格样式
    *   对于这些样式，地图表示为不同缩放级别的图像网格。这是 OpenStreetMap 传统的运作方式。
    *   缩放略微受限。
    *   目前，唯一的栅格主题是原始的 OpenStreetMap 样式。
*   矢量样式
    *   矢量样式不表示为图像，而是表示为几何形状。这使得渲染更加平滑，例如在缩放和查看建筑物边缘时。
    *   地图可以放大得多得多。
    *   这些有多种样式，既有浅色（Colorful、Graybeard、Neutrino）也有深色（Eclipse、Shadow）。
    *   矢量样式来自 [VersaTiles](https://versatiles.org/)，这是一个免费开源项目，提供基于 OpenStreetMap 的地图瓦片。
    *   VersaTiles 图层还提供 3D 建筑物信息（见下文）。

默认主题是 Versatiles Colorful（矢量）。

#### 带建筑物的 3D 视图

<figure class="image"><img style="aspect-ratio:2727/1642;" src="2_Geo Map_image.png" width="2727" height="1642"></figure>

Trilium v0.105.0 引入了 3D 视图，由 MapLibre GL 提供。要进入 3D 模式，只需按地图右下角的_3D_按钮或按住 Ctrl 并在地图上拖动。

建筑物仅从缩放级别 14 开始出现，以避免卡顿。

> [!NOTE]
> 要获得 3D 建筑物，请确保您使用的是通过 `versatiles-shortbread` 源提供建筑物信息的 _VersaTiles_ 样式。

### 自定义地图样式 / 瓦片

从 v0.102.0 开始，可以使用自定义瓦片集，但仅限栅格格式。

要使用一个：

1.  从<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">笔记菜单</a>打开_地理地图属性_对话框。
2.  在_背景_下，将_类型_设置为_自定义瓦片集_。
3.  在_瓦片 URL_ 中，输入瓦片集的地址，用 `{z}`、`{x}` 和 `{y}` 表示缩放级别和瓦片位置。例如，要使用 Esri.NatGeoWorldMap，输入 [`https://server.arcgisonline.com/ArcGIS/rest/services/NatGeo_World_Map/MapServer/tile/{z}/{y}/{x}`](https://server.arcgisonline.com/ArcGIS/rest/services/NatGeo_World_Map/MapServer/tile/%7Bz%7D/%7By%7D/%7Bx%7D)。离开字段后 URL 即被保存；不以 `http://` 或 `https://` 开头，或缺少三个占位符之一的 URL 不会被保存。绘制在图像上的地图会保留其图像，直到保存 URL。
4.  如果瓦片是深色的，请打开_深色瓦片集_，它会以浅色绘制标记标题，使其保持可读。

此外：

*   通过 `{r}` 占位符支持高 DPI 瓦片。
*   通过 `{quadkey}` 占位符（代替 `{z}`、`{x}` 和 `{y}`）支持按 quadkey 编号瓦片的服务器。

要返回内置样式，请将_类型_设置回_矢量与栅格_。瓦片集是被关闭而不是被移除：其标签被重命名为 `#disabled:map:style`，因此再次将_类型_设置为_自定义瓦片集_会带回相同的 URL。从父笔记或模板继承的瓦片集会被默认样式覆盖。

瓦片集也可以手动设置：URL 放在 `#map:style` [标签](../Advanced%20Usage/Attributes/Labels.md)中，`#map:darkStyle` 标签将其标记为深色。`#map:darkStyle` 也会覆盖内置样式。

> [!NOTE]
> 有关瓦片集列表，请参见 [Leaflet Providers 预览](https://leaflet-extras.github.io/leaflet-providers/preview/)页面。选择所需的瓦片集，然后从_纯 JavaScript_ 示例中复制 URL。

自定义矢量地图支持已计划，但尚未实现。

### 其他选项

以下选项可以通过<a class="reference-link" href="Collection%20Properties.md">集合属性</a>单击设置（<span class="tn-icon bx bx-cog"></span>）按钮进行配置。或者，这些选项中的每一个也有相应的[标签](../Advanced%20Usage/Attributes/Labels.md)可以手动设置。

*   比例尺，在地图左下角以公里或英里显示地图的比例。
    *   单位由_语言与区域_中的_格式区域设置_选项决定。
*   标记的名称默认显示在地图上图钉下方。从 v0.102.0 开始，可以隐藏这些标签，这在地图上有许多标记时提高了性能并减少了杂乱。
*   v0.105.0 还引入了一个名为_分组附近标记_的功能，它会在低缩放级别将多个标记聚集在一起。
    *   聚类显示其包含的项目数。颜色也会根据数量变化。
    *   单击聚类会自动放大，以便组成聚类的各个标记现在可见。

相同的选项也列在 <span class="tn-icon bx bx-cog"></span>_地理地图属性_对话框的_常规_下，该对话框可从<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">笔记菜单</a>或<a class="reference-link" href="Collection%20Properties.md">集合属性</a>的设置菜单打开。其_包含的笔记_部分设置是否显示已归档笔记以及_最大嵌套深度_（见下文），其_背景_部分包含地图样式、当_类型_设置为_自定义瓦片集_时自定义瓦片集的 URL（见上文），或者，当_类型_设置为_自定义图像_时，改为在您自己的图像上绘制地图，如<a class="reference-link" href="Geo%20Map/Image%20maps.md">图像地图</a>中所述。

地图显示其整个子树的笔记，而不仅仅是其子笔记。_最大嵌套深度_（`#maxNestingDepth`）限制它在地图下方查看的深度：`0` 仅显示子笔记，`1` 添加它们的子笔记，依此类推。没有值时，显示每一层。
