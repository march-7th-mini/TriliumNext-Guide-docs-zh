# 在笔记类型之间转换
笔记的类型可以转换为另一种：

*   <a class="reference-link" href="Text.md">文本</a>笔记转换为 <a class="reference-link" href="Markdown.md">Markdown</a> 笔记
*   Markdown 笔记转换为文本笔记

转换之前会自动保存一个修订版本，因此如果转换产生了不理想的结果，你可以恢复原始版本，或从中找回任何丢失的元素。详细了解 <a class="reference-link" href="../Basic%20Concepts%20and%20Features/Notes/Note%20Revisions.md">笔记修订</a>。

## 转换单个笔记

### Markdown 转换为文本笔记

Markdown 笔记可以转换为文本笔记，格式保真度损失可以忽略不计。

为此，请转到 <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">笔记菜单</a> → _高级_，然后选择 _转换为文本笔记_。

### 文本笔记转换为 Markdown

> [!WARNING]
> 由于 Markdown 并不支持文本笔记的所有功能，此转换在格式方面是有损的：部分格式可能会丢失，某些不受支持的元素甚至可能被丢弃。强烈建议你在转换后检查内容，确认是否有任何信息可能已经丢失。

要将文本笔记转换为 Markdown，请转到 <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">笔记菜单</a> → _高级_，然后选择 _转换为 Markdown 笔记_。

## 转换多个笔记

也可以使用 <a class="reference-link" href="../Advanced%20Usage/Bulk%20Actions.md">批量操作</a> 对整个子树或一组多个笔记执行笔记类型转换。
