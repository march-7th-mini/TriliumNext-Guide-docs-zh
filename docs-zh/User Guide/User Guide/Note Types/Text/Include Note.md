# 包含笔记

文本笔记可以“包含”另一条笔记，作为只读小组件或交互式小组件，具体取决于笔记的类型。

这可用于例如包含动态生成的图表（来自脚本和“渲染 HTML”笔记）或其他更高级的用例。

## 包含笔记

在 <a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a> 中，查找 <span class="tn-icon cke cke-trilium-note"></span> 按钮。也为它定义了键盘快捷键，但默认未分配。

_包含笔记_ 对话框在桌面端以光标旁的弹出窗口打开，包含两行：_笔记_，用于搜索要包含的笔记，以及 _框尺寸_（见下方 _框尺寸_），一行按钮，每个按钮带有一个尺寸的小图示，下方有一句话描述所选尺寸。选定笔记后，按 _包含笔记_ 或 <kbd>Enter</kbd> 将其包含。输入不存在的笔记标题会提示创建它。

在对话框中选择的图像笔记、<a class="reference-link" href="../Canvas.md">Canvas</a> 或 <a class="reference-link" href="../Mermaid%20Diagrams.md">Mermaid 图表</a> 笔记会作为图像插入而非包含，因此 _框尺寸_ 行会说明这一点，而不是显示尺寸按钮。在文本笔记中，图像进入文本后可以调整大小，对话框会提醒这一点，同时也会提醒包含的尺寸可以稍后更改。

要包含已链接的笔记，右键单击正在编辑的文本笔记中指向它的引用链接，然后在菜单末尾选择 _将链接转换为包含的笔记_。包含会获得适合该笔记的框尺寸，与通过按钮添加的相同。

[附件](../../Basic%20Concepts%20and%20Features/Notes/Attachments.md) 可以通过相同方式包含，从其链接的上下文菜单中操作（参见其中的 _嵌入附件_）。

指向文本笔记块的链接也以相同方式转换，使用 _将链接转换为笔记摘录_，然后包含仅显示那些块。参见 <a class="reference-link" href="Block%20references.md">块引用</a>。

## 框尺寸

框尺寸设置显示多少包含的笔记内容，以及框是否可以调整大小。

*   _紧凑_ 显示单行而非内容：笔记的图标、其标题及上方指向该笔记的路径，以及作用于该笔记的按钮。包含的笔记从不渲染，因此在编辑器之外显示笔记的任何地方，例如打印时、工具提示中或共享页面上，_紧凑_ 包含会显示为指向被包含笔记的链接。包含的音频文件是例外：其 _紧凑_ 框是一行播放器控件，在打开 _显示标题_ 之前没有标题。
*   _可调整大小_ 在可调整到任意宽度和高度的框中显示内容（见下方 _调整大小_）。文本在框内滚动，而图片、图表或视频会缩小以适应框。在调整大小之前，框占据笔记的整个宽度和约 20 行的高度。
*   _完整_ 以笔记的整个宽度显示全部内容。
*   _可展开_ 仅显示标题，直到按下其 <span class="tn-icon bx bx-chevron-right"></span> 箭头。在只读笔记中，单击标题行上除按钮和链接以外的任何位置也会展开或折叠它。它占据笔记的整个宽度，展开后可以调整其高度。

> [!NOTE]
> 自 v0.107.0 起，框尺寸经过重新设计：_小_ 和 _中_ 被 _可调整大小_ 取代。由早期版本保存为 _小_ 或 _中_ 的包含会以 _可调整大小_ 打开，保持其原有高度。

新的包含会获得适合其显示内容的尺寸：

*   _紧凑_ 用于没有预览的笔记或附件，例如关系图或归档，以及音频。
*   _完整_ 用于代码笔记或代码文件，例如 `.js`、`.py` 或 `.txt` 附件，以及文本笔记块的摘录。
*   _可调整大小_ 用于其他任何内容。

_包含笔记_ 对话框在选定笔记后会在其 _框尺寸_ 按钮中选择该尺寸，你也可以在那里选择另一个。要稍后更改尺寸，选择包含并使用其工具栏中的 _框尺寸_ 菜单，或其 _更多操作_ 菜单的 _尺寸_ 子菜单。两者都有 _默认_，将包含恢复为其初始尺寸，不保留调整后的宽度或高度；当包含已经处于该状态时不可用。对于包含的代码或 Markdown 笔记以及嵌入的代码或 Markdown 文件，_框尺寸_ 菜单是 <span class="tn-icon bx bx-move-vertical"></span> 按钮，其工具提示显示当前尺寸。

## 调整大小

_可调整大小_ 的包含可以调整到任意宽度和高度，_可展开_ 的包含可以调整高度。_紧凑_ 或 _完整_ 的包含始终适应其内容。

*   要调整包含的大小，选择它并拖动其右下角的控制柄。要仅更改宽度或仅更改高度，改为拖动其右边缘或下边缘的中间位置，触摸屏在那里也会显示控制柄。在从右到左的文本中，控制柄位于左下角，宽度从左侧边缘更改。
*   调整大小可使用鼠标、触控笔或手指。
*   在高度变化时，将控制柄移到笔记顶部或底部附近会滚动笔记。
*   比笔记窄的包含会居中，因此更改其宽度会移动其两侧。左对齐或右对齐的包含会保持该侧不动，控制柄位于另一侧（见下方 _定位_）。将包含设为与笔记一样宽会恢复为全宽。
*   要取消调整大小，在释放控制柄之前按 <kbd>Esc</kbd>。
*   要重置尺寸，双击角落控制柄，或在触摸屏上双击它。双击右边缘或下边缘仅重置宽度或高度。
*   选择 _紧凑_ 或 _完整_ 会移除调整后的宽度和高度，选择 _可展开_ 会移除宽度，因为它占据笔记的整个宽度。_可调整大小_ 保留两者，_默认_ 移除两者。
*   当 _可展开_ 的包含处于折叠状态时，无法调整其大小。

## 定位

包含可以独占若干行，也可以让文本环绕它，就像 [图像](Images.md) 一样。

*   要更改位置，在正在编辑的笔记中打开包含的 _更多操作_ 菜单（见下方 _打开包含的笔记_），并选择其 _位置_ 子菜单中的条目：
    *   在 _断开文本_ 下，<span class="tn-icon cke cke-object-left"></span> _左对齐_、<span class="tn-icon cke cke-object-center"></span> _居中对齐_ 和 <span class="tn-icon cke cke-object-right"></span> _右对齐_ 将包含放在独占的行上，位于笔记的该侧。_居中对齐_ 是默认值。
    *   在 _环绕文本_ 下，<span class="tn-icon cke cke-object-inline-left"></span> _左对齐_ 和 <span class="tn-icon cke cke-object-inline-right"></span> _右对齐_ 将包含放在该侧，并让文本在其旁边排列。
*   只有 _可调整大小_ 的包含可以放置在文本中。在调整大小之前，它占据笔记的整个宽度，因此新位置在调整得更窄后才会显示（见上方 _调整大小_）。_可展开_ 的包含占据整个宽度，仅提供 _断开文本_ 位置，这些位置对齐其框内的内容。_紧凑_ 或 _完整_ 的包含没有 _位置_ 子菜单。位置在框尺寸更改后保持不变，并在包含变为 _可调整大小_ 后再次显示。
*   在移动布局中，位置不是 _居中对齐_ 的包含占据整个宽度，且只能调整其高度。

## 标题说明

包含可以有一个标题说明，居中显示在其框的底部。标题说明是文本笔记的一部分，因此可以像其余文本一样格式化，例如加粗或带链接。

*   要添加标题说明，选择包含，按其工具栏中的 <span class="tn-icon cke cke-caption"></span> _切换标题说明开启_ 按钮并输入标题说明。当光标在标题说明中时，包含保持选中并保留其工具栏。
*   要移除标题说明，再次按同一按钮。再按一次会恢复其原有文本，只要笔记保持打开。
*   _紧凑_ 的包含没有标题说明，除非它是音频文件。将包含切换为 _紧凑_ 会移除其标题说明，切换回较大尺寸会恢复标题说明，只要笔记保持打开。
*   _可展开_ 的包含在内容折叠时在标题下显示其标题说明，展开后在内容下显示。

## 标题

包含的标题行链接到被包含的笔记并容纳其按钮。要仅显示内容，在包含的菜单中关闭 _显示标题_，该菜单通过右键单击标题行或按其 <span class="tn-icon bx bx-dots-vertical-rounded"></span> _更多操作_ 按钮打开（见下方 _打开包含的笔记_）。

*   当标题隐藏时，选择包含并按工具栏中的 <span class="tn-icon cke cke-three-vertical-dots"></span> _更多操作_ 按钮打开同一菜单，在其中打开 _显示标题_ 会再次显示标题。
*   _紧凑_ 或 _可展开_ 的包含始终显示其标题，因此其菜单中的 _显示标题_ 不可用。_紧凑_ 状态下的音频文件是例外：它开始时没有标题，_显示标题_ 会在其控件上方显示标题。

## 打开包含的笔记

要在新标签页中打开包含的笔记，按其标题末尾的 <span class="tn-icon bx bx-link-external"></span> _在新标签页中打开_ 按钮。嵌入的附件有相同的按钮。

标题行末尾的 <span class="tn-icon bx bx-dots-vertical-rounded"></span> _更多操作_ 按钮打开与右键单击标题行任意位置相同的菜单：打开笔记的其他位置，以及对于嵌入的附件，作用于附件的操作。

在正在编辑的笔记中，菜单还有 _尺寸_ 子菜单、_显示标题_ 和 _显示标题说明_，每个都是一个开关，生效时为开启状态，以及 _尺寸_ 之后的 _位置_ 子菜单（见上方 _定位_）。菜单以 <span class="tn-icon bx bx-trash"></span> _删除块_ 结束，它从笔记中移除包含，随后是 _转换为链接_。对于嵌入的附件，_删除附件..._ 在 _删除块_ 之后，_将附件转换为笔记..._ 在 _转换为链接_ 之后。绘图画布、Mermaid 图表、包含的文本、代码或 Markdown 笔记以及嵌入的代码或 Markdown 文件还有 _可编辑_，位于 _尺寸_ 之上。包含的代码或 Markdown 笔记、嵌入的代码或 Markdown 文件以及 Mermaid 图表还有 _自动换行_ 和 _行号_ 子菜单，位于 _可编辑_ 之后（见下方 _就地编辑包含_）。Mermaid 图表、包含的 Markdown 笔记和嵌入的 Markdown 文件在这些子菜单之后还有 _源码视图_、_分屏视图_ 和 _预览_。对于嵌入的附件，它们在其第一组操作之后；对于包含的笔记，在打开它的位置之后。

要在整个屏幕上显示 _可调整大小_ 或 _完整_ 尺寸的包含，按其标题末尾的 <span class="tn-icon bx bx-fullscreen"></span> _全屏_ 按钮。笔记块的摘录在那里有一个 <span class="tn-icon bx bx-pencil"></span> _编辑摘录_ 按钮；参见 <a class="reference-link" href="Block%20references.md">块引用</a>。要返回，按右上角的 <span class="tn-icon bx bx-exit"></span> _退出全屏_，或按 <kbd>Esc</kbd>。

_紧凑_ 的包含改为具有这些按钮，随后是相同的 _更多操作_ 按钮：

*   对于笔记，<span class="tn-icon bx bx-edit"></span> _快速编辑_ 在 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Navigation/Quick%20edit.md">快速编辑</a> 中打开笔记，<span class="tn-icon bx bx-link-external"></span> _在新标签页中打开_ 在新标签页中打开它。
*   对于嵌入的附件，<span class="tn-icon bx bx-file-find"></span> _在外部打开_ 在另一个应用程序中打开文件，<span class="tn-icon bx bx-download"></span> _下载_ 下载它。文件的大小显示在其标题下。

## 将包含转换为链接

要用指向被包含笔记的链接替换包含，在其 _更多操作_ 菜单的最后一组中选择 _转换为链接_。嵌入的附件以相同方式变为指向该附件的链接。

## 包含笔记内部的包含

被包含笔记的包含也会显示在各自的框中，只读，无论嵌套多深。如果某条笔记的包含已经在其周围显示，则改为显示为指向该笔记的链接，因此链条在此结束。例如，如果笔记 _A_ 包含笔记 _B_，而 _B_ 包含 _A_，打开 _A_ 会在框中显示 _B_，并在该框内显示指回 _A_ 的链接。

## 缺失的笔记和附件

其笔记或附件不再存在的包含（例如因为被删除），会保持其尺寸并在内容位置显示 <span class="tn-icon bx bx-error-alt"></span> 图标，以及缺失笔记或附件的 ID。要移除包含，选择它并按 <kbd>Delete</kbd>。

由较新版本 Trilium 添加的、此版本无法显示的内容，会以相同方式显示 <span class="tn-icon bx bx-error"></span> 图标。编辑笔记会保持该内容不变，因此在 Trilium 更新后会再次显示。

## 共享功能中的包含笔记

如果 [共享笔记](../../Advanced%20Usage/Sharing.md) 包含一个或多个包含的笔记，它们将显示在笔记内容中，就像它们是笔记本身的一部分。调整得比笔记窄的包含会保持其宽度和位置。在窄屏幕上，位置不是 _居中对齐_ 的包含占据整个宽度。包含的标题说明显示在被包含内容的下方。_紧凑_ 的包含改为显示为指向被包含笔记的链接，会显示已在其周围显示的笔记的包含也是如此，例如包含自身的笔记。打印或导出的笔记也是如此。

为此，包含的笔记也必须被共享。但是，它们仍可通过 `#shareHiddenFromTree` 从笔记树中隐藏。

其笔记或附件缺失或未共享的包含会在其位置显示 _此内容不可用_，由较新版本 Trilium 添加的内容也是如此。

## 交互式笔记

自 v0.104.0 起，包含的笔记可能根据其笔记类型变为交互式：

*   <a class="reference-link" href="../../Collections.md">集合</a>（例如 <a class="reference-link" href="../../Collections/Geo%20Map.md">地理地图</a>）将完全交互式渲染，包括创建新笔记。
*   <a class="reference-link" href="../Saved%20Search.md">保存的搜索</a> 也会显示结果。
*   <a class="reference-link" href="../Web%20View.md">网页视图</a> 提供网站的交互式预览。

## 包含的图像

包含的图像，无论是图像笔记还是图像附件，都显示在图像查看器中，可缩放和平移：

*   要缩放，按图像右下角的 <span class="tn-icon bx bx-plus-circle"></span> _放大_ 和 <span class="tn-icon bx bx-minus-circle"></span> _缩小_ 按钮，或在触摸屏上捏合。它们之间的百分比可重置缩放。
*   要用鼠标滚轮缩放，先单击图像。在此之前，鼠标滚轮滚动笔记。
*   要平移已放大的图像，拖动它。在其适应尺寸下，在触摸屏上拖动图像会滚动笔记。
*   要返回适应尺寸，双击图像。

在 _可调整大小_ 的框中，图像会缩小以适应框的高度。在全屏中，它适应屏幕。

## 就地编辑包含

包含的文本笔记、包含的代码笔记以及嵌入的代码文件（例如 `.js`、`.py` 或 `.txt` 附件）可以在不离开包含它们的笔记的情况下编辑。在此之前，代码笔记或文件在代码编辑器中以只读方式显示，其中可以选择和复制其代码，并通过其装订线中的箭头折叠和展开其块。包含的 Markdown 也可以编辑，见下方 _包含的 Markdown_。

*   要编辑，选择包含并打开其工具栏开头的 <span class="tn-icon bx bx-edit-alt"></span> _可编辑_ 按钮，或在其 <span class="tn-icon cke cke-three-vertical-dots"></span> _更多操作_ 菜单中打开 _可编辑_。关闭 _可编辑_ 以停止编辑。
*   当 _可编辑_ 开启时，方向键将光标移入包含并移出，如同穿过其余文本。从上方或左侧进入会将光标放在包含的开头，从下方或右侧进入会将其放在末尾。折叠的 _可展开_ 包含会被跳过。
*   当包含的文本笔记获得焦点时，格式工具栏应用于它。它依次包含的笔记保持只读。
*   代码在与 <a class="reference-link" href="../Code.md">代码</a> 笔记相同的代码编辑器中编辑，使用其主题、缩进和自动换行设置。
*   在代码中输入 `/` 会列出其语言的 <a class="reference-link" href="../../Advanced%20Usage/Snippets/Code%20Snippets.md">代码片段</a>，如同在代码笔记中一样。
*   包含的代码笔记或嵌入的代码文件的工具栏还有 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Status%20bar.md">状态栏</a> 的语言和缩进菜单，位于 _可编辑_ 和 <span class="tn-icon bx bx-move-vertical"></span> _框尺寸_ 菜单之间：_更改语言模式_，显示当前语言，以及 _更改制表符宽度_，显示当前缩进。_重新缩进内容为_ 转换代码本身的缩进并将其保存到包含的笔记或文件，无论 _可编辑_ 是否开启。
    *   对于包含的笔记，菜单更改笔记，如同在其自己的标签页中一样。
    *   对于嵌入的代码文件，语言和缩进设置仅更改此包含显示文件的方式，并与包含它的笔记一起保存。语言替换文件名给出的语言，_使用默认值_ 条目返回 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _代码笔记_ 中设置的缩进。这些设置不改变文件本身，它的其他包含保持自己的设置。
*   包含的代码或 Markdown 笔记、嵌入的代码或 Markdown 文件以及 [Mermaid 图表](Insert%20buttons.md) 的 <span class="tn-icon cke cke-three-vertical-dots"></span> _更多操作_ 菜单在 _可编辑_ 之后还有两个子菜单，每个都有 _自动_、_开启_ 和 _关闭_。它们更改代码编辑器显示源码的方式。
    *   _自动换行_ 换行长行而非滚动它们。_自动_ 遵循 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _代码笔记_ 中的设置。对于包含的笔记，它设置笔记的 `#wrapLines` 标签，如同其 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">笔记菜单</a> 的 _自动换行_ 子菜单对代码笔记所做的那样。对于嵌入的文件或 Mermaid 图表，它仅更改此包含。
    *   _行号_ 显示或隐藏每行开头的数字。_自动_ 遵循 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _代码笔记_ 中的设置。它仅更改此包含，对于包含的笔记也是如此。
*   更改在输入时保存到包含的笔记或附件，如同在其自己的标签页中一样。
*   在包含的代码编辑器中所做的更改是包含它的笔记的撤销历史的一部分，与其文本的更改一起，按所做的顺序排列。这包括包含的 Markdown 和 [Mermaid 图表](Insert%20buttons.md) 的源码，以及对绘图画布的更改（见下文）。
    *   <kbd>Ctrl</kbd>+<kbd>Z</kbd> 撤销笔记的最后一次更改，<kbd>Ctrl</kbd>+<kbd>Y</kbd> 或 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> 重做它，无论光标在文本中还是在包含中，且在 _可编辑_ 关闭时也是如此。格式工具栏的 <span class="tn-icon cke cke-undo"></span> _撤销_ 和 <span class="tn-icon cke cke-redo"></span> _重做_ 按钮做同样的事。使用 Vim 键绑定时，包含中的 `u` 和 <kbd>Ctrl</kbd>+<kbd>R</kbd> 也做同样的事。
    *   焦点移动到被撤销或重做的更改：进入包含的代码编辑器或绘图画布，或回到文本。
    *   撤销包含笔记的更改会再次保存包含的笔记。一旦包含的笔记在别处被更改，例如在另一个标签页中，其较早的更改就无法再从这里撤销，撤销会跳过它们。
    *   包含的文本笔记保持自己的撤销历史。
*   <a class="reference-link" href="Block%20references.md">块引用</a> 的包含仅编辑被引用的块。
*   在 [只读笔记](../../Basic%20Concepts%20and%20Features/Notes/Read-Only%20Notes.md) 中、对于标记为 `#readOnly` 的包含笔记、或对于另一条笔记的附件，编辑不可用。
*   <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Navigation/Search%20in%20note.md">在笔记中搜索</a> 会在其周围笔记的结果中找到包含的文本和代码笔记的文本，并在 _可编辑_ 开启时替换它。

## 包含的 Markdown

包含的 <a class="reference-link" href="../Markdown.md">Markdown</a> 笔记和嵌入的 Markdown 文件（例如 `.md` 附件）以与 Markdown 笔记在其自己的标签页中相同的三种视图显示（参见 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20types%20with%20split%20view.md">带分屏视图的笔记类型</a>）：<span class="tn-icon bx bx-code"></span> _源码视图_、<span class="tn-icon bx bxs-dock-left"></span> _分屏视图_ 和 <span class="tn-icon bx bx-show"></span> _预览_。

*   要切换视图，按包含标题行中的三个按钮之一。在正在编辑的笔记中，包含的工具栏在 _可编辑_ 之后有相同的按钮，其 <span class="tn-icon cke cke-three-vertical-dots"></span> _更多操作_ 菜单将它们作为 _源码视图_、_分屏视图_ 和 _预览_。
*   在选择视图之前，包含显示 _预览_，在 _可编辑_ 开启时显示 _分屏视图_。
*   要编辑 Markdown，打开 _可编辑_（见上方 _就地编辑包含_）。源码在 Markdown 笔记的代码编辑器中编辑，预览在输入时跟随更改。当 _可编辑_ 关闭时，源码可以阅读和复制但不能更改。
*   源码具有 <a class="reference-link" href="../Markdown.md">Markdown</a> 笔记的斜杠命令以及 `@` 和 `[[` 笔记链接。从 `@` 或 `[[` 列表创建的笔记会放在包含的笔记下，对于嵌入的文件则放在包含它的笔记下，`/image` 将图像上传到同一笔记。
*   _更多操作_ 菜单的 _自动换行_ 和 _行号_ 子菜单更改源码的显示方式，如同代码一样（见上方 _就地编辑包含_）。
*   如同在 Markdown 笔记中，预览随源码滚动并高亮光标所在的块，<kbd>Ctrl</kbd>+<kbd>B</kbd>、<kbd>Ctrl</kbd>+<kbd>I</kbd>、<kbd>Ctrl</kbd>+<kbd>M</kbd> 和 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> 格式化所选内容。
*   在正在编辑的笔记中，视图与包含一起保存，因此同一笔记的两个包含可以显示不同的视图。在 [只读笔记](../../Basic%20Concepts%20and%20Features/Notes/Read-Only%20Notes.md) 中，视图也可以更改，直到笔记再次打开。
*   当源码显示时，以及在 Markdown 可编辑的任何地方，包含具有其框尺寸的高度，或调整到的高度，因此打开或关闭 _可编辑_ 会保持其尺寸。否则，如同在只读笔记中，预览适应其文本直到该高度。_完整_ 的包含改为适应其内容。
*   <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Navigation/Search%20in%20note.md">在笔记中搜索</a> 在源码显示时搜索源码，否则搜索预览。

## 绘图画布

绘图画布是 Excalidraw 画布，如同 <a class="reference-link" href="../Canvas.md">Canvas</a> 笔记的画布，直接在文本笔记中绘制。它不是自己的笔记：绘图保存在文本笔记的 `Canvas.excalidraw` [附件](../../Basic%20Concepts%20and%20Features/Notes/Attachments.md) 中，并与文本一起保存。

*   要插入绘图画布，打开 <a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a> 的 <span class="tn-icon cke cke-plus"></span> _插入_ 菜单并选择 <span class="tn-icon bx bx-pen"></span> _绘图画布_，位于 _Mermaid 图表_ 之上。它也可在 <a class="reference-link" href="Slash%20Commands.md">斜杠命令</a> 中作为 _绘图画布_ 使用。画布以空的可编辑状态添加，位于标题隐藏的 _可调整大小_ 框中，并获得焦点，准备绘制。
*   要在图像上绘制或书写，选择图像并按工具栏中的 <span class="tn-icon bx bxs-pen"></span> _将图像转换为绘图画布_ 按钮。图像被替换为 _可调整大小_ 框中的可编辑绘图画布，标题隐藏且焦点在其中。图像以原始尺寸位于画布中央，缩放以显示全部，并被锁定，以免意外选中或移动。当它被锁定时，画布可以在图像上放大，但不能缩小超过它或滚动超出其边缘。要移动或调整图像大小，右键单击它并选择 _解锁_。图像的标题说明被保留，但其对齐或链接不保留。只有独占一行的图像可以转换，段落内的图像不行。撤销会恢复图像。
*   通过 _附加并嵌入文件_（位于 <span class="tn-icon cke cke-paper-clip"></span>_附加文件_ 按钮下）附加的 Excalidraw 文件（`.excalidraw`）也会成为绘图画布，位于以文件名命名的 _可调整大小_ 框中。它开始时 _可编辑_ 关闭，因此绘图显示但在打开 _可编辑_ 之前无法更改（见下文）。
*   要在没有焦点的画布上绘制，先单击它。画布随后具有 Canvas 笔记的工具、菜单和键盘快捷键。工具栏、菜单和所选形状的属性仅在画布有焦点时显示，因此在其他地方绘图读起来像文本中的图片。
*   鼠标滚轮和触摸板在画布上也滚动笔记，如同在文本上一样。要缩放，使用画布工具栏的缩放按钮。它们之间的百分比打开一个菜单，包含 _缩放以适应_（显示整个绘图）和 _重置缩放_。要在绘图中移动，使用 <span class="tn-icon bx bxs-hand"></span> _手形_ 工具。缩放和位置与绘图一起保存，因此画布在离开的地方再次打开，无论笔记在何处显示。在全屏中，鼠标滚轮改为移动和缩放绘图。
*   画布保持其绘制时的尺寸。在较窄的笔记中，例如在手机上，它会缩小到该尺寸的四分之三，然后改为横向滚动。调整大小控制柄在相同缩放下显示更多或更少的绘图，_完整_ 将其加宽到整个笔记。全屏有自己的缩放和位置，并保持画布的缩放和位置不变。
*   画布工具栏工具中的第一个 <span class="tn-icon bx bx-block"></span> _无工具_ 按钮不干扰绘图：鼠标在其上不起作用，在其上的触摸手势会滚动笔记而非绘制、选择或移动绘图。在移动布局中，画布开始时无工具，并在失去焦点时返回该状态，以便笔记在其绘图上滚动，直到选择工具。全屏不需要它：无工具的画布在进入全屏时切换到 _选择_ 工具。
*   画布工具栏取代 Excalidraw 菜单：_导出图像_、_在画布上查找_、_库_ 和 _帮助_ 位于其 <span class="tn-icon bx bx-category"></span> _更多工具_ 菜单的末尾。在全屏中，Excalidraw 菜单再次显示。在移动布局中，画布工具栏位于屏幕底部的格式工具栏中，在 _画布 ›_ 按钮之后。
*   <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Navigation/Search%20in%20note.md">在笔记中搜索</a> 会在笔记的结果中找到绘图的文本，并在画布上高亮每个结果，画布仅移动以显示其视图外的结果。在画布内，搜索的快捷键（桌面端为 <kbd>Ctrl</kbd>+<kbd>F</kbd>）打开它而非 Excalidraw 搜索，后者仍可作为 _在画布上查找_ 使用。
*   对绘图的更改是文本笔记撤销历史的一部分（见上方 _就地编辑包含_）。<kbd>Ctrl</kbd>+<kbd>Z</kbd>、<kbd>Ctrl</kbd>+<kbd>Y</kbd> 以及画布工具栏的 <span class="tn-icon bx bx-undo"></span> _撤销_ 和 <span class="tn-icon bx bx-redo"></span> _重做_ 按钮撤销和重做笔记的最后一次更改，无论是在绘图中还是在文本中。
*   新绘图具有笔记的背景色。从 Excalidraw 菜单选择的背景会替换它。
*   要保护已完成的绘图免受意外更改，选择它并在其 <span class="tn-icon cke cke-three-vertical-dots"></span> _更多操作_ 菜单中关闭 _可编辑_。绘图随后显示为静止图片，保持其缩放和位置，且无法再更改、缩放或移动。要再次绘制，打开其工具栏开头的 <span class="tn-icon bx bx-edit-alt"></span> _可编辑_ 按钮（仅在 _可编辑_ 关闭时显示），或在菜单中重新打开 _可编辑_。
*   框尺寸、调整大小、标题说明和标题的工作方式与包含的笔记相同，但绘图工具栏将框尺寸和位置留给其 _更多操作_ 菜单（见上方 _定位_）。_紧凑_ 的绘图画布仅显示其标题行，不显示绘图。
*   在桌面布局中，Excalidraw 无论框多小都保持其桌面界面。在移动布局中，窄或短的框会将其切换为紧凑界面。要获得更多空间，选择 _完整_，或显示标题并按 <span class="tn-icon bx bx-fullscreen"></span> _全屏_。
*   在紧凑界面中，当画布有焦点时，选择按钮位于屏幕侧边的栏上，因此无论画布滚动到哪里它们都触手可及：<span class="tn-icon bx bx-palette"></span> _编辑_ 在屏幕底部的面板中打开所选形状或所选工具的属性，位于格式工具栏之上，<span class="tn-icon bx bx-duplicate"></span> _复制_ 和 <span class="tn-icon bx bx-trash"></span> _删除_ 作用于所选形状，<span class="tn-icon bx bx-check"></span> _完成_ 结束逐点绘制的线或箭头。该栏仅显示适用的按钮，当没有适用按钮时离开。属性在清除选择时关闭，仅在 _编辑_ 时再次打开。在全屏中，这些按钮改为位于画布底部。
*   添加到绘图的图片存储在同一附件中。转换的图像改为作为笔记的图像附件保留，以生成的代码命名。
*   在 [只读笔记](../../Basic%20Concepts%20and%20Features/Notes/Read-Only%20Notes.md) 中，绘图也显示为静止图片，在绘制之前其位置显示灰色框。
*   在 [共享页面](../../Advanced%20Usage/Sharing.md) 上，绘图显示为相同的图片，使用浅色或深色以匹配页面。对绘图的每次更改都会将此图片保存为笔记的 SVG 图像附件，也以生成的代码命名，附件列表在 _由 Trilium 生成_ 下显示它。

### 限制

*   Excalidraw 形状库不会为绘图画布保存。
*   在编辑器之外，例如在工具提示中、打印时或附件列表中，绘图显示为图片。
*   绘图在第一次更改之前没有用于共享页面的图片，从图像转换的除外。在此之前，例如对于附加的 `.excalidraw` 文件，共享页面改为显示下载绘图的链接。
*   在 Safari 中，共享页面上绘图的图片遵循系统的浅色或深色外观，而非页面上选择的主题。
*   粘贴到同一笔记中的绘图画布副本与原始共享绘图，包括缩放和位置。粘贴到另一条笔记中的副本获得自己的绘图。
