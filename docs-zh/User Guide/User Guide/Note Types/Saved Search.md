# 已保存的搜索

Trilium 允许你将常用搜索保存为笔记树中的笔记。搜索结果将作为这些“已保存的搜索”笔记的子笔记显示。以下是一个工作示例：

## 位置

默认情况下，已保存的搜索存储在日记笔记中。但是，你可以通过标记 `#searchHome` 标签来指定一个不同的笔记来存储已保存的搜索。此外，对于[工作区](../Basic%20Concepts%20and%20Features/Navigation/Workspaces.md)，你可以使用 `#workspaceSearchHome` 标签来指定该工作区内已保存搜索的存储位置。
