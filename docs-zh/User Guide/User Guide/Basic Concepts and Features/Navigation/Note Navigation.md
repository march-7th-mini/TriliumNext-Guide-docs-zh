# 笔记导航
Trilium 的目标之一是在笔记之间提供快速舒适的导航。

## 后退和前进

要在已查看笔记的历史记录中后退和前进，请按 <kbd>Alt</kbd>+<kbd>←</kbd> 和 <kbd>Alt</kbd>+<kbd>→</kbd>，或使用 <a class="reference-link" href="../UI%20Elements/Tabs.md">标签页</a> 左侧的 <span class="tn-icon bx bx-left-arrow-alt"></span> 和 <span class="tn-icon bx bx-right-arrow-alt"></span> 按钮。

这与浏览器的后退/前进功能完全相同，实际上它使用的是浏览器对此的内置支持。

要一次后退或前进多个笔记，请右键单击其中一个按钮或按住它。后退按钮列出当前笔记之前的笔记，前进按钮列出当前笔记之后的笔记，最近的排在最前面。每个条目显示笔记的标题，并在行末显示其父笔记的路径。选择某个笔记即可直接跳转到该笔记。

<a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">启动栏</a> 的 _转到上一个笔记_ 和 _转到下一个笔记_ 启动器会列出相同的笔记，位于启动栏自身项目之下。

## 跳转到笔记

这对于快速查找和查看任意笔记很有用——点击顶部的 `Jump to` 按钮或按 <kbd>Ctrl</kbd> + <kbd>J</kbd>。然后输入笔记名称的一部分，自动补全将帮助你选择所需的笔记。

更多信息请参阅 <a class="reference-link" href="Jump%20to%20%26%20command%20palette.md">跳转到笔记</a>。
