# 外部链接
外部链接是指向例如网站的标准网页链接。例如，[https://en.wikipedia.org/wiki/South\_China\_Sea](https://en.wikipedia.org/wiki/South_China_Sea) 就是一个指向维基百科页面的外部链接。

要创建不带自定义文本的链接：

*   在<a class="reference-link" href="../Formatting%20toolbar.md">格式工具栏</a>中按下 <span class="tn-icon cke cke-link"></span>：
    *   将出现一个弹出窗口，在框中输入或粘贴 URL。
    *   按 <kbd>Enter</kbd> 或勾选图标以确认。
*   或者，按 <kbd>Ctrl</kbd>+<kbd>K</kbd> 触发上述弹出窗口。
*   更简单的方法是粘贴原始链接并按空格键，将其自动转换为链接。
*   自 v0.107.0 起，<a class="reference-link" href="Internal%20(reference)%20links.md">内部（引用）链接</a>的_添加链接_对话框（<kbd>Ctrl</kbd>+<kbd>L</kbd> 或 <span class="tn-icon cke cke-trilium"></span> 按钮）也会创建外部链接。在对话框顶部选择_网页链接_，输入或粘贴地址，并可选择填写_链接标题_；若不填写，链接将显示其地址。不带协议的地址（如 `example.com`）会自动补上 `https://`。将 URL 粘贴到_笔记_字段中，或从其搜索中选择，会将对话框切换为_网页链接_。当选中的文本是 URL 时，对话框也会打开为_网页链接_。

要创建带自定义文本的链接：

*   首先，输入并选中将要转换为链接的文本。
*   按照前面的步骤打开链接界面（通过格式工具栏，或 <kbd>Ctrl</kbd>+<kbd>K</kbd>）。
*   或者，直接在选中的文本上粘贴（<kbd>Ctrl</kbd>+<kbd>V</kbd>）将其转换为链接。

插入链接后：

*   如有需要，可以更改链接内的文本，但链接本身将保持不变。
*   要修改链接，点击链接以显示弹出窗口，然后按 <span class="tn-icon cke cke-pencil"></span> _编辑链接_按钮。自 v0.107.0 起，它会打开_编辑链接_对话框，其中填充了链接的地址和文本，将光标置于链接内并按 <kbd>Ctrl</kbd>+<kbd>L</kbd> 或 <span class="tn-icon cke cke-trilium"></span> 按钮也是如此。_保存链接_会更改整个链接，包括其文本，该对话框还可以将其转换为指向笔记的链接。
*   要移除链接，点击它并按 <span class="tn-icon cke cke-unlink"></span> _取消链接_按钮。

你可以通过双击（将在新标签页/窗口中打开）外部链接，或右键点击它们并选择“在新标签页中打开”来访问外部链接。
