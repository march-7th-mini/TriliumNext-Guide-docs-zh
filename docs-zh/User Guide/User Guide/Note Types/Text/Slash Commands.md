# 斜杠命令
<figure class="image image-style-align-right"><img style="aspect-ratio:419/571;" src="Slash Commands_image.png" width="419" height="571"></figure>

斜杠命令是<a class="reference-link" href="../Text.md">文本</a>笔记的一项功能，它允许仅通过键盘轻松访问常用命令，而无需记住专用的<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Keyboard%20Shortcuts.md">键盘快捷键</a>。

## 交互

*   顾名思义，要触发斜杠命令，只需按 / 键即可触发。请注意，它可以位于段落中的任何位置，只要它不是单词的一部分即可；如果没有显示出来，只需按一下空格再按 / 键即可。
*   使用 ↑ 和 ↓ 键在选项之间导航。
*   默认情况下，会显示完整的命令列表。
*   要搜索，只需开始输入：命令会通过其标题或其他别名找到（例如 `h2` 对应 _标题 2_）。
*   要触发高亮的操作，请按 Enter 或 Tab。

## 与其他功能的集成

除了一组通用命令外，一些功能还与斜杠命令进行了特殊集成：

*   对于[警示框](Block%20quotes%20%26%20admonitions.md)，每种警示框类型（例如 note、tip）都会单独显示。
*   每个<a class="reference-link" href="Text%20Snippets.md">文本片段</a>也会单独显示，便于插入它们。
*   <a class="reference-link" href="In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>：专用的 _Ask AI_ 项以及所有预定义和[自定义快速操作](In-editor%20AI%20assistant/Custom%20AI%20quick%20actions.md)。
