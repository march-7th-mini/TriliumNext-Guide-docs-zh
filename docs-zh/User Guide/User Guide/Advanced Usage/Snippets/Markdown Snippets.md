# Markdown 片段

Markdown 片段与<a class="reference-link" href="../Templates.md">模板</a>密切相关，但片段并非定义整个笔记的内容，而是一段可复用的 Markdown 文本，可以轻松插入到<a class="reference-link" href="../../Note%20Types/Markdown.md">Markdown</a>笔记中。

## 创建 Markdown 片段

在<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a>中：

1.  右键单击你想要放置片段的位置。
2.  选择 **插入子** _笔记_。
3.  选择 _**Markdown 片段**_。

然后只需在笔记中输入所需内容即可。

笔记的标题将成为片段的标题。你也可以在<a class="reference-link" href="../Attributes/Promoted%20Attributes.md">提升属性</a>部分添加描述。

## 插入片段

要插入片段，请输入 `/snippet` 并从下拉菜单中选择其标题。

语言模式设置为“纯文本”的<a class="reference-link" href="Code%20Snippets.md">代码片段</a>也会在此列出。

## 限制

*   与<a class="reference-link" href="../Templates.md">模板</a>不同，片段不能限制在特定的[工作区](../../Basic%20Concepts%20and%20Features/Navigation/Workspaces.md)中。
