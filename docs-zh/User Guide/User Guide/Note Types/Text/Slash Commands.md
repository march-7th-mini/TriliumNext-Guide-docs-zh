# 斜杠命令
<figure class="image image-style-align-right"><img style="aspect-ratio:419/571;" src="Slash Commands_image.png" width="419" height="571"></figure>

斜杠命令是<a class="reference-link" href="../Text.md">文本</a>笔记的一项功能，它允许用户仅通过键盘轻松访问常用命令，而无需记住专门的<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Keyboard%20Shortcuts.md">键盘快捷键</a>。

## 交互方式

*   顾名思义，要触发斜杠命令，只需按下 <kbd>/</kbd> 键即可。请注意，这可以位于段落的任意位置，只要它不是单词的一部分即可；如果未显示，请按一下空格键，然后再次按下 <kbd>/</kbd> 键。
*   使用 <kbd>↑</kbd> 和 <kbd>↓</kbd> 键在选项之间导航。
*   默认情况下，会显示完整的命令列表。
*   要按标题或描述进行搜索，只需开始输入操作名称即可。
*   要触发某个操作，请按 <kbd>Enter</kbd> 键。

## 与其他功能的集成

除了常用命令集之外，某些功能还与斜杠命令进行了特殊集成：

*   对于[警示框](Block%20quotes%20%26%20admonitions.md)，每种警示框类型（例如，注意、提示）都会单独显示。
*   每个<a class="reference-link" href="Text%20Snippets.md">文本片段</a>也会单独显示，方便插入。
