# 格式刷
<figure class="image image-style-align-right"><img style="aspect-ratio:220/76;" src="Format Painter_image.png" width="220" height="76"></figure>

格式刷是文本笔记中的一项功能，允许用户复制文本的格式（如**粗体**、_斜体_、~~删除线~~等），并将其应用到文档的其他部分。它有助于保持格式一致，并加快富文本内容的创建。

## 使用说明

点击你想要复制格式的文本，然后使用格式刷工具栏按钮（<span class="tn-icon cke cke-paint-roller"></span>）复制样式。接着用鼠标选中目标文本以应用格式。

*   **复制格式**：将光标放在带有某种格式的文本中，然后点击格式刷工具栏按钮。鼠标光标会发生变化，表示格式刷已激活。
*   **使用复制的格式进行刷涂**：用鼠标选中目标文本。松开鼠标按钮时格式即被应用，格式刷随即解除——光标恢复正常。
*   **取消而不刷涂**：再次点击工具栏按钮或按 <kbd>Escape</kbd>。

## 限制

1.  尚不支持使用块级格式（如标题或图片样式）进行刷涂。这是因为在 <a class="reference-link" href="../../Advanced%20Usage/Technologies%20used/CKEditor.md">CKEditor</a> 中，它们被视为内容的一部分，而非文本格式。
2.  格式刷作用于选区，而非单个词：点击单个词不会对其应用格式。单击只会定位光标，因此你在该处输入的文本会采用复制的格式。
3.  格式刷是一次性的；每次刷涂都需要重新复制格式。
