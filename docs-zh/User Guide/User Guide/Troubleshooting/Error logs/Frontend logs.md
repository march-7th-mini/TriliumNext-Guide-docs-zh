# 前端日志
要提供前端日志，我们需要打开开发者控制台。通常最简单的方法是按 <kbd>Ctrl</kbd>\-<kbd>Shift</kbd>\-<kbd>I</kbd>，这在大多数浏览器（以及桌面应用）中都应该有效。请确保在复制粘贴错误之前刚刚执行了产生错误的操作，因为应用重启时控制台会被清空。

如果上述方法无效，那么：

*   在 Trilium 桌面应用中，转到左上角菜单按钮 -> 高级 -> 开发者工具
*   在 Firefox/Chrome 中，右键点击页面任意位置并点击"检查"：

![](Frontend%20logs_error-logs-firefox-context-men.png)

打开开发者工具后，点击"控制台"标签页：

![](Frontend%20logs_image.jpg)

复制粘贴（或截图）日志。最好不仅提供错误信息，而是提供完整日志，这样在分析 bug 时可以提供上下文。
