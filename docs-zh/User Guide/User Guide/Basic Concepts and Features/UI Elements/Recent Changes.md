## 访问最近更改

*   要查看所有文档中的更改概览，请按 <a class="reference-link" href="Launch%20Bar.md">启动栏</a> 中的 <span class="tn-icon bx bx-history"></span> 按钮。
    *   如果存在[提升的笔记](../Navigation/Note%20Hoisting.md)或[工作区](../Navigation/Workspaces.md)，最近更改列表将仅限于提升的笔记或工作区的后代。
    *   右键单击或按住该按钮会列出最多 15 个最近更改且未在标签页中打开的笔记。选择某个笔记会在新标签页中打开它。
*   要将最近更改列表限制为某个笔记及其后代，请在<a class="reference-link" href="Note%20Tree/Note%20tree%20contextual%20menu.md">笔记树上下文菜单</a> → 高级中查找相应选项。
*   右键单击或按住<a class="reference-link" href="Tabs.md">标签页</a>栏的 <span class="tn-icon bx bx-plus"></span> 按钮会列出最近更改且未在标签页中打开的笔记。该菜单底部的*所有最近更改*会打开此对话框。

## 交互

*   已更改的笔记将按时间倒序显示（最新更新在前）。
*   显示笔记的标题以及笔记路径。单击笔记标题将关闭对话框并导航到该特定笔记。
*   已删除的笔记也会在此处列出，显示其删除时间。按旁边的*取消删除*链接以恢复它们。
