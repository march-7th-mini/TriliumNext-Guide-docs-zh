# 隐私

在你发送消息之前，Trilium 不会向 AI 提供商发送任何内容。启用集成、添加提供商或打开对话本身都不会传输任何内容，唯一的例外是列出提供商的模型时会将你的 API 密钥发送给该提供商，以便获取模型列表。

一旦你发送消息或运行<a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>，离开你机器的内容取决于你选择的提供商以及启用了哪些上下文选项。

## 你的笔记去向何处

| 提供商类型 | 目的地 |
| --- | --- |
| 云端提供商 | 提供商的服务器（Anthropic、OpenAI、Google、DeepSeek） |
| 基于订阅 | 提供商的服务器，通过本地运行的 Claude Code |
| 本地 / 自托管 | 不会离开运行模型的机器 |
| 自定义端点 | 指向的任何位置，可能是你自己的硬件或托管服务 |

这就是提供商列表如此分组的原因，也是 Trilium 不预选任何提供商的原因：将你的笔记内容发送到何处，是由你在发送任何内容之前明确做出的选择。

> [!NOTE]
> <a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>有自己的模型选择，因此它可能由与对话中不同的提供商来回答。助手菜单底部的那一行始终标明正在使用的是哪一个。

## 实际发送的内容

*   **始终，随每条消息发送**
    *   对话本身：你的消息和助手的回复，包括之前的轮次
    *   Trilium 的系统提示词，描述如何格式化回答和使用工具。
*   **当前笔记，仅在启用笔记上下文时发送。**
    *   在侧边栏对话中，这是底部的文件图标；专用对话笔记类型从不发送当前笔记。
    *   传输的是一个元数据块：笔记的 ID、标题、类型、创建和修改日期、其父级 ID、最多 20 个子笔记的标题、最多 20 个属性，以及内容的预览。
    *   超过大小阈值的笔记会发送大小提示而非文本，模型必须调用工具才能进一步读取。
*   **模型请求的任何笔记，在启用笔记访问时。**
    *   工具让模型可以搜索你的笔记树，并读取当前笔记之外的笔记、属性和附件。
    *   由模型决定获取什么；没有逐笔记的权限系统，因此可触及的范围是你的整个笔记树。
*   **附件和提及**，当你添加它们时：图像、PDF 和文本文件会被发送给提供商，而 `@` 提及会使该笔记可被获取。
*   **你的搜索查询**，当启用网络搜索时，模型的搜索词会到达提供商自己的搜索基础设施。

## 编辑器内 AI 助手

一次<a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>的运行发送的内容集与对话消息不同。对于快捷操作，它在你选择操作的那一刻就发送，没有发送按钮可供反悔。对于自由形式的 _Ask AI_，有专门的发送按钮和模型选择器。

*   **你选中的段落**，或者当你选择快捷操作而未选中任何内容时，光标所在的段落。
*   **该段落两侧各最多 1500 个字符的笔记内容**，以纯文本形式。助手被告知这仅是上下文，不得重写，但无论你是否选中它都会被发送：对单个句子运行仍会传输其周围的段落。
*   **笔记所在的位置**：其标题及其父级的标题，作为面包屑导航。
*   **Trilium 的写作助手指令**，描述它可以生成的格式。
*   **同一交流的之前轮次**，一旦你对某个回复进行追问。

不会发送笔记元数据块，网络搜索从不启用，助手也没有笔记工具，因此它无法读取上述文本之外的任何内容。

## 受保护的笔记

当你的[受保护会话](../Basic%20Concepts%20and%20Features/Notes/Protected%20Notes.md)处于锁定状态时，受保护的笔记既不会发送标题也不会发送内容。**当它解锁时，它们会被当作任何其他笔记一样对待，**模型通过工具读取的笔记会被完整发送给提供商。如果你在受保护的笔记中保存敏感材料，请注意解锁它们会在会话期间移除该边界。

这同样适用于<a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>：它作用于编辑器中打开的任何内容，因此在已解锁的受保护笔记中运行它，会像任何其他笔记一样发送该笔记的文本。

## 你能控制的内容

*   **哪个提供商**：决定是否有任何内容离开你机器的唯一决策。
*   **笔记访问**：从对话底部的模型选择器关闭工具，模型就无法读取你输入内容之外的任何东西。
*   **当前笔记：**侧边栏对话中的文件图标。
*   **网络搜索：**同样在模型选择器中。
*   **编辑器助手**：它没有逐次运行的开关。你能控制的是是否运行它、运行前选中什么，以及由哪个模型回答。

在笔记访问和笔记上下文都关闭的情况下，提供商只会收到你输入的词句。

## 保持一切本地化

添加 Ollama 或 LM Studio 提供商会让每条消息都留在运行模型的机器上，Trilium 将其模型标记为免费，因为不涉及计量的 API。代价是质量和硬件：小型本地模型可能在工具调用上失败，而云端模型能处理，因此行为异常的本地设置值得先与云端提供商进行基准对比，再作为 bug 报告。

## 遥测与安全

Trilium 本身不从 AI 集成收集任何遥测数据。

你的 API 密钥存储在你的数据库中，仅发送给所属的提供商，并且通过选项 API 是只写的，因此恶意的<a class="reference-link" href="../Scripting.md">脚本</a>无法访问它。如果你启用了后端或 SQL 控制台访问，恶意脚本**有可能窃取你的 API 密钥**。

内置的 MCP 服务器默认关闭。启用后，每个请求都必须携带 ETAPI 令牌，它授予与 REST API 相同的对你笔记的完整读写访问权限；请像对待密码一样对待它。在桌面上，除非你开启<a class="reference-link" href="../Installation%20%26%20Setup/Desktop%20Installation/Network%20Access.md">网络访问</a>，否则它只能从 `localhost` 访问。
