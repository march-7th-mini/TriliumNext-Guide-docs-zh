# 集合属性
<figure class="image"><img style="aspect-ratio:1177/98;" src="Collection Properties_image.png" width="1177" height="98"></figure>

_集合属性_ 是一个工具栏，显示在每个[集合笔记](../Collections.md)的顶部。

对于 v0.102.0 之前的版本，此功能仅适用于<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/New%20Layout.md">新布局</a>。从该版本开始，集合属性也在旧布局中启用，并且<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Ribbon.md">功能区</a>不再包含专门的集合属性选项卡。

集合属性包含：

*   视图类型的快速选择器（例如网格、日历、看板）。
*   一个设置按钮，包含：
    *   当前视图的设置，例如在日历中隐藏周末。
    *   集合的通用设置，例如[隐藏子笔记](../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree/Hiding%20the%20subtree.md)或显示[已归档笔记](../Basic%20Concepts%20and%20Features/Notes/Archived%20Notes.md)。
*   当前视图的特定交互，例如日历的月份选择器和视图切换器。
