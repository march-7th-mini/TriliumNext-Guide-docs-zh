# 笔记导航
Trilium 的目标之一是在笔记之间提供快速舒适的导航。

## 后退和前进

你可以使用 alt-left 和 alt-right 在浏览过的页面历史中后退和前进。

这与浏览器的后退/前进功能完全相同，实际上它使用的是浏览器内置的支持。

![](Note%20Navigation_image.jpg)

## 跳转到笔记

这对于快速查找和查看任意笔记非常有用——点击顶部的 `Jump to` 按钮或按 <kbd>Ctrl</kbd> + <kbd>J</kbd>。然后输入笔记名称的一部分，自动补全将帮助你选择所需的笔记。

更多信息请参阅 <a class="reference-link" href="Jump%20to%20%26%20command%20palette.md">跳转到笔记</a>。
