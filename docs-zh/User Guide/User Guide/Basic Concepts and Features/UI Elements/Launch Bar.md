# 启动栏
## 启动栏的位置

在桌面端，根据所选的布局，启动器栏要么位于屏幕左侧并垂直显示按钮，要么位于屏幕顶部。更多信息请参阅<a class="reference-link" href="Vertical%20and%20horizontal%20layout.md">垂直和水平布局</a>。

在移动端，启动栏始终位于底部。

如果启动栏中的项目过多而无法容纳在屏幕内，它将变为可滚动。

## 术语

*   **启动器**：可以（或正在）显示在启动栏上的按钮。
*   **可用启动器**：未显示在启动栏上但可以添加的启动器。
*   **可见启动器**：当前显示在启动栏上的启动器。

## 配置桌面端启动栏

有两种方式可以配置启动栏：

*   在启动栏上启动器之间的空白处右键单击，然后选择 _配置启动栏…_
*   单击<a class="reference-link" href="Global%20menu.md">全局菜单</a>并选择 _配置启动栏_。

这将打开一个新标签页，其中包含列出启动器的<a class="reference-link" href="Note%20Tree.md">笔记树</a>。

![](Launch%20Bar_image.jpg)

展开 _可用启动器_ 部分将显示未显示在启动栏上的启动器列表。_可见启动器_ 将显示当前已显示的启动器。

## 配置移动端启动栏

移动端的启动栏使用与桌面端不同的配置。原因是并非所有桌面图标在移动端都可用，而且移动端屏幕能容纳的图标更少。

要配置移动端的启动栏，请转到<a class="reference-link" href="Global%20menu.md">全局菜单</a>并选择 _配置启动栏_。

要在桌面端配置移动端启动栏（这对于配置更复杂的启动器如脚本或自定义小组件特别有用），请转到<a class="reference-link" href="Global%20menu.md">全局菜单</a> → 高级 → 隐藏笔记，然后查找 _移动端启动栏_ 部分。在隐藏子树中，还可以在 _移动端启动栏_ 和（桌面端）_启动栏_ 部分之间拖动启动器。

### 添加/移除和重新排序启动器

要在启动栏中显示新的启动器，首先在 _可用启动器_ 部分中查找它。然后右键单击它并选择 _移动到可见启动器_。也可以手动拖放该项目。

同样，要从启动栏中移除它，只需在 _可见启动器_ 中查找它，然后右键单击并选择 _移动到可用启动器_ 或使用拖放。

在树中拖放项目以更改它们的顺序。有关更多交互选项（包括使用键盘快捷键），请参阅<a class="reference-link" href="Note%20Tree.md">笔记树</a>。

### 通过拖放添加笔记

要将笔记添加到启动栏，请将其从<a class="reference-link" href="Note%20Tree.md">笔记树</a>拖到启动栏上。启动器之间的线显示笔记将被放置的位置。如果启动栏可滚动，请将笔记保持在任一端附近以滚动它。放下笔记会添加一个带有笔记标题和图标的按钮，单击时会打开该笔记。

*   在树中选中的多个笔记可以一次放下；它们会保持其顺序。
*   已经在启动栏上的笔记，或从 _可用启动器_ 部分拖动的启动器，将被移动到新位置而不是再次添加。

该按钮是 _可见启动器_ 部分中笔记的克隆（请参阅<a class="reference-link" href="../Notes/Cloning%20Notes.md">克隆笔记</a>），因此它始终显示笔记的当前标题和图标。右键单击它并选择 _从启动栏移除_ 以移除克隆；笔记本身仍保留在树中的位置。如果启动栏是笔记所在的唯一位置，则它会被移动到 _可用启动器_ 中，以免笔记被删除。

要列出笔记的子项而不是打开笔记，请右键单击按钮并勾选 _文件夹_，与[书签文件夹](../Navigation/Bookmarks.md)的方式相同。

## 自定义启动器

*   启动器的图标可以像普通笔记一样更改。更多信息请参阅[笔记图标](../Notes/Note%20Icons%20%26%20Colors.md)。
*   启动器的标题也可以更改。

### 重置

重置允许将启动栏（或其中一部分）恢复为 Trilium 的原始配置。只需右键单击某个启动器（甚至整个 _启动栏_ 部分）并选择 _重置_ 即可将其恢复为原始状态。

### 创建新的启动器/启动器类型

右键单击 _可用启动器_ 或 _可见启动器_ 部分，然后选择以下选项之一：

1.  **笔记启动器**  
    笔记启动器将简单地导航到指定的笔记。
    
    1.  将 `target` 提升属性设置为要导航到的笔记。
    2.  可选地，设置 `hoistedNote` 以提升特定笔记。更多信息请参阅<a class="reference-link" href="../Navigation/Note%20Hoisting.md">笔记提升</a>。
    3.  可选地，设置 `keyboardShortcut` 以触发启动器。
2.  **脚本启动器**  
    一种高级启动器，按下时将运行脚本。更多信息请参阅<a class="reference-link" href="../../Scripting.md">脚本</a>。
    
    1.  设置 `script` 以指向要运行的目标脚本。
    2.  可选地，设置 `keyboardShortcut` 以触发启动器。
3.  **自定义小组件**
    
    允许定义要在启动器内渲染的自定义小组件。更多信息请参阅<a class="reference-link" href="../../Scripting/Frontend%20Basics/Custom%20Widgets/Widget%20Basics.md">小组件基础</a>。
4.  **间隔符**  
    在其他启动器之间创建一定距离以实现更好的视觉区分的启动器。

启动器通过预定义的<a class="reference-link" href="../../Advanced%20Usage/Attributes/Promoted%20Attributes.md">提升属性</a>进行配置。
