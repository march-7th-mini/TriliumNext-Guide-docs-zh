# v0.106.0：移除 cheerio

`api.cheerio` 库已从后端脚本 API 中移除。

尝试使用 `api.cheerio` 的脚本现在将抛出错误，并附带迁移说明。

## 原因

`cheerio` 在 v0.103.0 中已被弃用，取而代之的是 `api.htmlParser`（[node-html-parser](https://github.com/taoqf/node-fast-html-parser)），Trilium 已经使用它进行所有自身的 HTML 解析。脚本 API 是唯一仍然需要 `cheerio` 的地方。

同时提供两个解析器的成本很高，因为 `cheerio` 在每个平台上启动时都会被加载。它为服务器和桌面构建增加了大约 1.35 MB 的打包代码，为浏览器内构建增加了大约 370 kB，在浏览器内构建中，它会在应用程序启动前被加载到数据库工作进程中。

## 迁移

将 `api.cheerio` 调用替换为 `api.htmlParser`。请注意，`api.htmlParser` 返回的是普通元素，而不是包装后的集合，因此没有 `$` 对象，也没有链式调用。

### 读取值

之前（`cheerio`）：

```javascript
const $ = api.cheerio.load(html);
const title = $('h1').text();
const links = $('a').map((i, el) => $(el).attr('href')).get();
```

之后（`htmlParser`）：

```javascript
const root = api.htmlParser.parse(html);
const title = root.querySelector('h1')?.textContent;
const links = root.querySelectorAll('a').map(a => a.getAttribute('href'));
```

### 修改文档

之前（`cheerio`）：

```javascript
const $ = api.cheerio.load(html);
$('a').each((i, el) => {
    $(el).attr('href', '#root/' + noteId);
    $(el).addClass('reference-link');
});
note.setContent($('body').html());
```

之后（`htmlParser`）：

```javascript
const root = api.htmlParser.parse(html);
for (const el of root.querySelectorAll('a')) {
    el.setAttribute('href', '#root/' + noteId);
    el.classList.add('reference-link');
}
note.setContent(root.toString());
```

### 等效操作

| `cheerio` | `htmlParser` |
| --- | --- |
| `api.cheerio.load(html)` | `api.htmlParser.parse(html)` |
| `$('sel')` | `root.querySelectorAll('sel')` |
| `$('sel').first()` | `root.querySelector('sel')` |
| `$el.text()` | `el.textContent` |
| `$el.html()` | `el.innerHTML` |
| `$el.attr('name')` | `el.getAttribute('name')` |
| `$el.attr('name', value)` | `el.setAttribute('name', value)` |
| `$el.addClass('name')` | `el.classList.add('name')` |
| `$('body').html()` | `root.toString()` |
