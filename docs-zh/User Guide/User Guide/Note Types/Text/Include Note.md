# 包含笔记

文本笔记可以“包含”另一条笔记，作为只读小组件或交互式小组件，具体取决于笔记的类型。

这对于例如包含动态生成的图表（来自脚本和“渲染 HTML”笔记）或其他更高级的用例非常有用。

## 包含笔记

在<a class="reference-link" href="Formatting%20toolbar.md">格式化工具栏</a>中，查找 <span class="tn-icon cke cke-trilium-note"></span> 按钮。也有为其定义的键盘快捷键，但默认未分配。

要包含一条已经链接的笔记，请在正在编辑的文本笔记中右键单击指向它的引用链接，然后选择菜单末尾的_将链接转换为包含的笔记_。包含框会获得适合该笔记的框尺寸，与通过按钮添加的包含框一样。

[附件](../../Basic%20Concepts%20and%20Features/Notes/Attachments.md)也可以通过相同方式包含，从其链接的上下文菜单中操作（参见其中的_嵌入附件_）。

指向文本笔记块的链接也以相同方式转换，使用_将链接转换为笔记摘录_，然后包含框仅显示这些块。参见<a class="reference-link" href="Block%20references.md">块引用</a>。

## 框尺寸

框尺寸设置显示包含笔记的多少内容。

*   _极小_显示单行而非内容：笔记的图标、其标题及上方指向该笔记的路径，以及用于操作该笔记的按钮。包含的笔记永远不会被渲染，因此无论在编辑器之外的何处显示该笔记，例如在打印中、在工具提示中或在共享页面上，_极小_包含框都会显示为指向所包含笔记的链接。
*   _小_和_中_在有限高度的框中显示内容。文本在框内滚动，而图片、图表或视频则缩小以适应框。
*   _完整_显示全部内容。
*   _可展开_仅显示标题，直到按下其 <span class="tn-icon bx bx-chevron-right"></span> 箭头。在只读笔记中，单击标题行上除按钮和链接以外的任何位置也可以展开或折叠它。

新的包含框会获得适合其显示内容的尺寸：

*   _极小_用于没有预览的笔记或附件，例如关系图或归档。
*   _小_用于音频。
*   _完整_用于代码笔记或代码文件，例如 `.js`、`.py` 或 `.txt` 附件，以及文本笔记块的摘录。
*   _中_用于其他所有情况。

包含笔记的对话框在选定笔记后会选择该尺寸，你也可以在其中选择其他尺寸。要稍后更改尺寸，请选择包含框并使用其工具栏中的_框尺寸_菜单，或其_更多操作_菜单中的_尺寸_子菜单。

## 调整大小

_小_、_中_或_可展开_的包含框可以调整为任意宽度和高度。_极小_或_完整_的包含框始终适应其内容。

*   要调整包含框的大小，请选择它并拖动其右下角的手柄。要仅更改宽度或仅更改高度，请改为拖动其右边缘或底边缘的中间位置，触摸屏在那里也会显示手柄。在从右到左的文本中，手柄位于左下角，宽度从左侧边缘变化。
*   调整大小可使用鼠标、触控笔或手指。
*   在高度变化时，将手柄移到笔记的顶部或底部附近会滚动笔记。
*   比笔记窄的包含框会居中，因此更改其宽度会移动其两侧。使其与笔记一样宽则恢复为全宽。
*   要取消调整大小，请在释放手柄之前按 <kbd>Esc</kbd>。
*   要重置尺寸，请双击角手柄，或在触摸屏上双击它。双击右边缘或底边缘仅重置宽度或高度。
*   选择框尺寸会重置高度。选择_极小_或_完整_也会重置宽度。
*   当_可展开_包含框处于折叠状态时，只能更改其宽度。

## 标题说明

包含框可以有标题说明，居中显示在其框的底部。标题说明是文本笔记的一部分，因此可以像其余文本一样进行格式化，例如加粗或添加链接。

*   要添加标题说明，请选择包含框，按下其工具栏中的 <span class="tn-icon cke cke-caption"></span> _开启标题说明_按钮，然后输入标题说明。
*   要移除标题说明，请再次按下同一按钮。再次按下可恢复其原有文本，只要笔记保持打开状态。
*   _极小_包含框没有标题说明。将包含框切换为_极小_会移除其标题说明，将其切换回较大尺寸会恢复标题说明，只要笔记保持打开状态。
*   _可展开_包含框在内容折叠时在标题下方显示标题说明，展开后在内容下方显示。

## 标题

包含框的标题行链接到所包含的笔记，并容纳其按钮。要仅显示内容，请选择包含框并按下其工具栏中的 <span class="tn-icon bx bx-window-alt"></span> _显示标题_按钮。再次按下则显示标题。

*   当标题隐藏时，包含框工具栏中的 <span class="tn-icon cke cke-three-vertical-dots"></span> _更多操作_按钮会打开所包含笔记的菜单。
*   _极小_或_可展开_包含框始终显示其标题，其工具栏没有_显示标题_按钮。

## 打开包含的笔记

要在新标签页中打开包含的笔记，请按下其标题末尾的 <span class="tn-icon bx bx-link-external"></span> _在新标签页中打开_按钮。嵌入的附件也有相同的按钮。

标题行末尾的 <span class="tn-icon bx bx-dots-vertical-rounded"></span> _更多操作_按钮打开的菜单与右键单击标题行任意位置相同：其他打开笔记的位置，以及对于嵌入的附件，对附件的操作。

在正在编辑的笔记中，该菜单还有包含框工具栏的命令：_尺寸_子菜单、_显示标题_和_显示标题说明_（生效时各自带有勾选标记），以及末尾的_转换为链接_。绘图画布、包含的文本、代码或 Markdown 笔记以及嵌入的代码或 Markdown 文件还有_可编辑_，位于_尺寸_上方。包含的 Markdown 笔记和嵌入的 Markdown 文件还有_源码视图_、_分屏视图_和_预览_，位于_可编辑_之后。对于嵌入的附件，它们跟随其第一组操作；对于包含的笔记，它们位于菜单末尾。

要在整个屏幕上显示_中_或_完整_尺寸的包含框，请按下其标题末尾的 <span class="tn-icon bx bx-fullscreen"></span> _全屏_按钮。笔记块的摘录在那里有一个 <span class="tn-icon bx bx-pencil"></span> _编辑摘录_按钮；参见<a class="reference-link" href="Block%20references.md">块引用</a>。要返回，请按右上角的 <span class="tn-icon bx bx-exit"></span> _退出全屏_，或按 <kbd>Esc</kbd>。

_极小_包含框则有以下按钮，后面跟着相同的_更多操作_按钮：

*   对于笔记，<span class="tn-icon bx bx-edit"></span> _快速编辑_在<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Navigation/Quick%20edit.md">快速编辑</a>中打开笔记，<span class="tn-icon bx bx-link-external"></span> _在新标签页中打开_在新标签页中打开它。
*   对于嵌入的附件，<span class="tn-icon bx bx-file-find"></span> _在外部打开_在其他应用程序中打开文件，<span class="tn-icon bx bx-download"></span> _下载_下载它。文件的大小显示在其标题下方。

## 将包含框转换为链接

要将包含框替换为指向所包含笔记的链接，请选择它并按下其工具栏中的 <span class="tn-icon cke cke-link"></span> _转换为链接_按钮，或在其_更多操作_菜单末尾选择_转换为链接_。嵌入的附件也以相同方式变为指向该附件的链接。

## 共享功能中的包含笔记

如果[共享笔记](../../Advanced%20Usage/Sharing.md)包含一个或多个包含的笔记，它们将显示在笔记内容中，就像它们是笔记本身的一部分一样。包含框的标题说明显示在所包含内容的下方。_极小_包含框则显示为指向所包含笔记的链接，会显示已在周围显示的笔记的包含框也是如此，例如包含自身的笔记。打印或导出的笔记同样如此。

为此，包含的笔记也必须被共享，否则它们将不会显示。但是，包含的笔记仍可通过 `#shareHiddenFromTree` 从笔记树中隐藏。

## 交互式笔记

自 v0.104.0 起，包含的笔记可能根据其笔记类型变为交互式：

*   <a class="reference-link" href="../../Collections.md">集合</a>（例如<a class="reference-link" href="../../Collections/Geo%20Map.md">地理地图</a>）将完全交互式渲染，包括创建新笔记。
*   <a class="reference-link" href="../Saved%20Search.md">保存的搜索</a>也会显示结果。
*   <a class="reference-link" href="../Web%20View.md">网页视图</a>提供网站的交互式预览。

## 包含的图片

包含的图片，无论是图片笔记还是图片附件，都显示在图片查看器中，可缩放和平移：

*   要缩放，请按下图片右下角的 <span class="tn-icon bx bx-plus-circle"></span> _放大_和 <span class="tn-icon bx bx-minus-circle"></span> _缩小_按钮，或在触摸屏上双指捏合。它们之间的百分比可重置缩放。
*   要使用鼠标滚轮缩放，请先单击图片。在此之前，鼠标滚轮会滚动笔记。
*   要平移已放大的图片，请拖动它。在其适应尺寸下，在触摸屏上拖动图片会滚动笔记。
*   要返回适应尺寸，请双击图片。

在_小_或_中_框中，图片会缩小以适应框的高度。在全屏中，它适应屏幕。

## 就地编辑包含框

包含的文本笔记、包含的代码笔记以及嵌入的代码文件（例如 `.js`、`.py` 或 `.txt` 附件）可以在不离开包含它们的笔记的情况下进行编辑。在此之前，代码笔记或文件会以语法高亮显示。包含的 Markdown 也可以编辑，参见下方的_包含的 Markdown_。

*   要编辑，请选择包含框并打开其工具栏开头的 <span class="tn-icon bx bx-edit-alt"></span> _可编辑_按钮，或在其 <span class="tn-icon cke cke-three-vertical-dots"></span> _更多操作_菜单中勾选_可编辑_。关闭_可编辑_以返回预览。
*   当_可编辑_开启时，方向键会将光标移入包含框并移出，如同穿过其余文本一样。从上方或左侧进入会将光标置于包含框的开头，从下方或右侧进入会将其置于末尾。折叠的_可展开_包含框会被跳过。
*   当包含的文本笔记获得焦点时，格式化工具栏应用于它。它依次包含的笔记保持只读。
*   代码在与<a class="reference-link" href="../Code.md">代码</a>笔记相同的代码编辑器中编辑，使用其主题、缩进和自动换行设置。
*   包含的代码笔记或嵌入的代码文件的工具栏还有<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Status%20bar.md">状态栏</a>的语言和缩进菜单，位于_可编辑_和_框尺寸_菜单之间：_更改语言模式_（显示当前语言）和_更改制表符宽度_（显示当前缩进）。_重新缩进内容至_会转换代码本身的缩进并将其保存到包含的笔记或文件，无论_可编辑_是否开启。
    *   对于包含的笔记，这些菜单会更改笔记，如同在其自己的标签页中一样。
    *   对于嵌入的代码文件，语言和缩进设置仅更改此包含框显示文件的方式，并与包含它的笔记一起保存。语言替换文件名给出的语言，_使用默认值_条目返回<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _代码笔记_中设置的缩进。这些设置不会更改文件本身，它的其他包含框保留自己的设置。
*   更改会在你输入时保存到包含的笔记或附件，如同在其自己的标签页中一样。
*   <a class="reference-link" href="Block%20references.md">块引用</a>的包含框仅编辑引用的块。
*   在[只读笔记](../../Basic%20Concepts%20and%20Features/Notes/Read-Only%20Notes.md)中、对于标记为 `#readOnly` 的包含笔记、或对于另一条笔记的附件，编辑不可用。
*   <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Navigation/Search%20in%20note.md">在笔记中搜索</a>会在周围笔记的结果中找到包含的文本和代码笔记的文本，并在_可编辑_开启时替换它。

## 包含的 Markdown

包含的<a class="reference-link" href="../Markdown.md">Markdown</a>笔记和嵌入的 Markdown 文件（例如 `.md` 附件）会以与 Markdown 笔记在其自己的标签页中相同的三种视图显示（参见<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20types%20with%20split%20view.md">带分屏视图的笔记类型</a>）：<span class="tn-icon bx bx-code"></span> _源码视图_、<span class="tn-icon bx bxs-dock-left"></span> _分屏视图_和 <span class="tn-icon bx bx-show"></span> _预览_。

*   要切换视图，请按下包含框标题行中的三个按钮之一。在正在编辑的笔记中，包含框的工具栏在_可编辑_之后有相同的按钮，其 <span class="tn-icon cke cke-three-vertical-dots"></span> _更多操作_菜单将它们作为_源码视图_、_分屏视图_和_预览_。
*   在选择视图之前，包含框显示_预览_，当_可编辑_开启时显示_分屏视图_。
*   要编辑 Markdown，请开启_可编辑_（参见上方的_就地编辑包含框_）。源码在 Markdown 笔记的代码编辑器中编辑，预览会随你输入而跟随更改。当_可编辑_关闭时，源码可以阅读和复制，但不能更改。
*   与在 Markdown 笔记中一样，预览随源码滚动并高亮光标所在的块，<kbd>Ctrl</kbd>+<kbd>B</kbd>、<kbd>Ctrl</kbd>+<kbd>I</kbd>、<kbd>Ctrl</kbd>+<kbd>M</kbd> 和 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> 会格式化所选内容。
*   在正在编辑的笔记中，视图与包含框一起保存，因此同一笔记的两个包含框可以显示不同的视图。在[只读笔记](../../Basic%20Concepts%20and%20Features/Notes/Read-Only%20Notes.md)中，视图也可以更改，直到笔记再次被打开。
*   当源码显示时，包含框具有其框尺寸的高度，或调整到的高度。_完整_包含框也会获得固定高度，而不是适应其内容。
*   <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Navigation/Search%20in%20note.md">在笔记中搜索</a>在源码显示时搜索源码，否则搜索预览。

## 绘图画布

绘图画布是一个 Excalidraw 画布，类似于<a class="reference-link" href="../Canvas.md">画布</a>笔记的画布，直接在文本笔记中绘制。它不是独立的笔记：绘图保存在文本笔记的 `Canvas.excalidraw` [附件](../../Basic%20Concepts%20and%20Features/Notes/Attachments.md)中，并与文本一起保存。

*   要插入绘图画布，请打开<a class="reference-link" href="Formatting%20toolbar.md">格式化工具栏</a>的 <span class="tn-icon cke cke-plus"></span> _插入_菜单，选择 <span class="tn-icon bx bx-pen"></span> _绘图画布_，位于_Mermaid 图表_上方。它也可在<a class="reference-link" href="Slash%20Commands.md">斜杠命令</a>中作为_绘图画布_使用。画布以空白且可编辑的状态添加，位于标题隐藏的_中_框中，并获得焦点，准备绘制。
*   要在图片上绘制或书写，请选择图片并按下其工具栏的 <span class="tn-icon bx bxs-pen"></span> _将图片转换为绘图画布_按钮。图片被替换为_中_框中的可编辑绘图画布，标题隐藏且焦点在其中。图片以原始尺寸位于画布中央，缩放以显示全部内容，并被锁定，以免被意外选中或移动。当它被锁定时，画布可以在图片上放大，但不能缩小超过它或滚动超出其边缘。要移动或调整图片大小，请右键单击它并选择_解锁_。图片的标题说明会保留，但其对齐方式或链接不会保留。只有单独一行的图片可以转换，段落内的图片不行。撤销可恢复图片。
*   使用 <span class="tn-icon cke cke-paper-clip"></span>_附加文件_按钮附加的 Excalidraw 文件（`.excalidraw`）也会变为绘图画布，位于以文件名命名的_中_框中。它开始时_可编辑_关闭，因此绘图会显示但无法更改，直到开启_可编辑_（见下文）。
*   要在没有焦点的画布上绘制，请先单击它。在此之前，触摸手势会滚动笔记。然后画布具有画布笔记的工具、菜单和键盘快捷键。工具栏、菜单和所选形状的属性仅在画布有焦点时显示，因此在其他地方绘图读起来就像文本中的图片。
*   鼠标滚轮和触控板在画布上也会滚动笔记，如同在文本上一样。要缩放，请使用画布工具栏的缩放按钮；要在绘图中移动，请使用 <span class="tn-icon bx bxs-hand"></span> _手形_工具。在全屏中，鼠标滚轮则移动和缩放绘图。
*   画布工具栏替换 Excalidraw 菜单：_导出图片_、_在画布上查找_、_库_和_帮助_位于其 <span class="tn-icon bx bx-category"></span> _更多工具_菜单的末尾。在全屏中，Excalidraw 菜单会再次显示。
*   新绘图具有笔记的背景颜色。从 Excalidraw 菜单选择的背景会替换它。
*   要保护已完成的绘图免受意外更改，请选择它并关闭其工具栏开头的 <span class="tn-icon bx bx-edit-alt"></span> _可编辑_按钮，或在其 <span class="tn-icon cke cke-three-vertical-dots"></span> _更多操作_菜单中取消勾选_可编辑_。然后绘图显示为静态图片，保持其原有的缩放和位置，不再能被更改、缩放或移动。要再次绘制，请重新开启_可编辑_。
*   框尺寸、调整大小、标题说明和标题的工作方式与包含的笔记相同，但绘图的工具栏将框尺寸、_显示标题_和_转换为链接_留给其_更多操作_菜单。
*   在桌面布局中，无论框多小，Excalidraw 都保持其桌面界面。在移动布局中，窄或短的框会将其切换为紧凑界面。要获得更多空间，请选择_完整_，或显示标题并按下 <span class="tn-icon bx bx-fullscreen"></span> _全屏_。
*   添加到绘图中的图片存储在同一附件中。转换的图片则保留为笔记的图片附件，以生成的代码命名。
*   在[只读笔记](../../Basic%20Concepts%20and%20Features/Notes/Read-Only%20Notes.md)中，绘图也显示为静态图片。
*   在[共享页面](../../Advanced%20Usage/Sharing.md)上，绘图以其自身尺寸显示为图片，无论其框的尺寸如何，以浅色或深色以匹配页面。对绘图的每次更改都会将此图片保存为笔记的 SVG 图片附件，也以生成的代码命名。

### 限制

*   Excalidraw 形状库不会为绘图画布保存。
*   在编辑器之外，例如在工具提示中、打印时或附件列表中，绘图显示为图片。
*   绘图在首次更改之前没有用于共享页面的图片，从图片转换的除外。在此之前，例如对于附加的 `.excalidraw` 文件，共享页面会显示一个下载绘图的链接。
*   在 Safari 中，共享页面上绘图的图片遵循系统的浅色或深色外观，而不是页面上选择的主题。
*   在同一笔记中粘贴的绘图画布副本与原始绘图共享绘图，因此对其中一个的更改只有在笔记再次打开后才会在另一个中显示。粘贴到另一条笔记中的副本则获得自己的绘图。
