# 隐私

在你发送消息之前，Trilium 不会向 AI 提供商发送任何内容。启用集成、添加提供商或打开对话本身都不会传输任何内容，唯一的例外是：列出某个提供商的模型时，会将你的 API 密钥发送给该提供商，以便获取模型列表。

一旦你发送消息或运行<a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>，离开你机器的内容取决于你选择的提供商以及启用了哪些上下文选项。

## 你的笔记去向何处

| 提供商类型 | 目的地 |
| --- | --- |
| 云提供商 | 提供商的服务器（Anthropic、OpenAI、Google、DeepSeek）。OpenRouter 会根据你 OpenRouter 账户的隐私设置，将每条消息转发给运行所选模型的实验室。 |
| 基于订阅 | 提供商的服务器，通过本地运行的 Claude Code |
| 本地 / 自托管 | 不会有任何内容离开运行模型的机器 |
| 自定义端点 | 指向的任何位置，可能是你自己的硬件或托管服务 |

这就是提供商列表如此分组的原因，也是 Trilium 不预选任何选项的原因：将你的笔记内容发送到何处，是由你在发送任何内容之前明确做出的选择。

> [!NOTE]
> <a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>有自己独立的模型选择，因此它可能由与对话中不同的提供商来回答。助手菜单底部的行始终标明当前正在使用的提供商。

## 实际发送的内容

*   **每条消息都会发送**
    *   对话本身：你的消息和助手的回复，包括之前的轮次
    *   Trilium 的系统提示词，描述如何格式化回答和使用工具。
*   **当前笔记，仅在启用笔记上下文时发送。**
    *   在侧边栏对话中，这是底部的文件图标；专用对话笔记类型从不发送当前笔记。
    *   传输的是一个元数据块：笔记的 ID、标题、类型、创建和修改日期、其父级 ID、最多 20 个子笔记的标题、最多 20 个属性，以及内容的预览。
    *   超过大小阈值的笔记会发送大小提示而非文本，模型必须调用工具才能进一步读取。
*   **模型请求的任何笔记，在启用笔记访问时。**
    *   工具允许模型搜索你的笔记树，并读取当前笔记之外的笔记、属性和附件。
    *   它决定获取什么，每次调用都会等待你允许，除非对话的权限模式允许读取或所有调用自行运行，或者你已为该对话允许了该工具。可访问范围是你的整个笔记树，但你排除的笔记除外（见下文_排除笔记_）。
*   **附件和提及**，当你添加它们时：图片、PDF 和文本文件会发送给提供商，`@` 提及会使该笔记可被获取。
*   **你的搜索查询**，当启用网络搜索时，模型的搜索词会到达提供商自己的搜索基础设施，或_工具_菜单中选择的搜索提供商（Brave Search、Tavily、Exa、Serper、Perplexity 或你的 SearXNG 实例）。
*   **模型读取的页面**，当网络搜索通过搜索提供商或 DeepSeek 模型的内置搜索进行时：Trilium 会从网站本身获取模型请求的每个页面，因此网站会看到来自运行 Trilium 的机器的请求。页面的文本随后会发送给模型的提供商。

## 编辑器内 AI 助手

运行<a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>发送的内容集与对话消息不同。对于快捷操作，它会在你选择操作的那一刻发送，没有发送按钮可供反悔。对于自由形式的_询问 AI_，有专门的发送按钮和模型选择器。

*   **你选中的段落**，或者当你选择快捷操作而未选中任何内容时光标所在的段落。
*   **该段落两侧各最多 1500 个字符的笔记内容**，以纯文本形式。助手会被告知这仅是上下文，不得重写，但无论你是否选中它都会被发送：对单个句子运行仍会传输其周围的段落。
*   **笔记所在位置**：其标题及其父级的标题，作为面包屑导航。
*   **Trilium 的写作助手指令**，描述它可能生成的格式。
*   **同一交换的之前轮次**，一旦你对某个回复进行追问。

不会发送笔记元数据块，网络搜索从不启用，助手没有笔记工具，因此除了上面列出的文本外无法读取任何内容。

## 受保护的笔记

当你的[受保护会话](../Basic%20Concepts%20and%20Features/Notes/Protected%20Notes.md)处于锁定状态时，受保护的笔记既不发送标题也不发送内容。**当它解锁时，它们会被当作任何其他笔记对待，**模型通过工具读取的笔记会完整发送给提供商。如果你在受保护的笔记中保存敏感材料，请注意解锁它们会在会话期间移除该边界。

这同样适用于<a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>：它作用于编辑器中打开的任何内容，因此在已解锁的受保护笔记中运行它会像任何其他笔记一样发送该笔记的文本。

## 排除笔记

为笔记添加 `#excludeFromLlm` [标签](../Advanced%20Usage/Attributes/Labels.md)，以将其从 AI 对话和 [MCP 服务器](MCP.md)中隐藏。该标签仅覆盖该笔记：其下方的笔记仍然可见，除非你使该标签[可继承](../Advanced%20Usage/Attributes/Attribute%20Inheritance.md)，并且子笔记可以通过 `#excludeFromLlm=false` 选择重新加入。

从模板创建的笔记会继承模板的所有标签（见<a class="reference-link" href="../Advanced%20Usage/Templates.md">模板</a>），因此向模板添加 `#excludeFromLlm` 会隐藏使用该模板的每个笔记，而不仅仅是模板本身。

对于被排除的笔记：

*   笔记工具会将其报告为未找到：它会被排除在搜索结果、子笔记列表和子树之外，指向它的关系也不会显示。
*   模型无法读取、编辑、移动、克隆或重命名它，无法在其下创建笔记，也无法移除该标签。它也无法删除下方有被排除笔记的笔记。
*   即使启用了笔记上下文，其元数据也不会作为当前笔记发送。
*   可见的子笔记不会将其显示为父级，模型也无法将子笔记移出它。

与受保护的笔记不同，被排除的笔记在你的受保护会话解锁时仍保持隐藏。排除仅适用于笔记工具。它不是加密，也不覆盖：

*   你自己附加到消息中的文件。
*   当你在笔记内运行<a class="reference-link" href="../Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>时。
*   该笔记的文本出现在其他笔记中的情况，例如带有该笔记标题的链接。
*   搜索查询可以测试的内容。搜索从不返回被排除的笔记，但查询仍可以通过被排除的笔记匹配到可见笔记：通过笔记路径中的标题、通过关系（`~link.title`）、父级或子级（`note.parents.content`），或可见笔记从它继承的标签。猜测的模型可以得知被排除的笔记是否包含某个给定词语。

## 你可以控制的内容

*   **哪个提供商**：决定是否有任何内容离开你机器的唯一决策。
*   **笔记访问**：在对话底部的 <span class="tn-icon bx bx-shield-quarter"></span>_工具_菜单中关闭它，模型除了你输入的内容外无法读取任何内容。
*   **当前笔记：**侧边栏对话中的文件图标。
*   **AI 无法触及的笔记：**`#excludeFromLlm` 标签，见上文_排除笔记_。
*   **网络搜索：**同样在_工具_菜单中。
*   **哪些工具调用会先询问：**_工具_菜单的_权限_子菜单。_始终询问_会让每次调用都等待你，包括读取。新对话会以你上次选择的模式开始，因此设置为_不询问_之后的对话也不会询问任何内容。在你选择模式之前，对话以_更改前询问_开始，此时 AI 会在不询问的情况下读取和搜索你的笔记。
*   **编辑器助手**：它没有每次运行的开关。你能控制的是是否运行它、运行前选中什么以及由哪个模型回答。

在笔记访问和笔记上下文都关闭的情况下，提供商只会收到你输入的词语。

## 保持一切本地化

添加 Ollama 或 LM Studio 提供商会将每条消息保留在运行模型的机器上，Trilium 将其模型标记为免费，因为不涉及计量的 API。代价是质量和硬件：小型本地模型可能在云模型能处理的工具调用上失败，因此行为异常的本地设置值得在报告为 bug 之前与云提供商进行基准测试。

## 遥测与安全

Trilium 本身不会从 AI 集成中收集任何遥测数据。

你的 API 密钥存储在你的数据库中，仅发送给其所属的提供商，并且通过选项 API 是只写的，因此恶意的<a class="reference-link" href="../Scripting.md">脚本</a>无法访问它。如果你启用了后端或 SQL 控制台访问，恶意脚本**可能潜在地窃取你的 API 密钥**。

内置 MCP 服务器默认关闭。启用后，每个请求都必须携带 ETAPI 令牌，该令牌授予与 REST API 相同的对你笔记的完整读写访问权限；请像对待密码一样对待它。在桌面上，除非你开启<a class="reference-link" href="../Installation%20%26%20Setup/Desktop%20Installation/Network%20Access.md">网络访问</a>，否则只能从 `localhost` 访问。
