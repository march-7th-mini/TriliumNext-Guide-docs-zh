# 错误日志

在提交错误报告时，提供所有可用的错误日志非常重要。

错误日志分为两种类型，在报告错误时两者都很有用。

*   <a class="reference-link" href="Error%20logs/Backend%20(server)%20logs.md">后端（服务器）日志</a>
*   <a class="reference-link" href="Error%20logs/Frontend%20logs.md">前端日志</a>

## 提供敏感数据

如果您不方便将日志或任何敏感信息附加到公开的 GitHub 问题中，欢迎通过我们的 Matrix [支持频道](https://github.com/TriliumNext/Trilium#-discuss-with-us) 联系开发者。

也可以使用此邮箱提供任何有助于分析错误的信息——例如正在导入的文件/图片/ZIP 压缩包或[匿名化数据库](Anonymized%20Database.md)。

### 导出笔记子树以用于复现

通常，错误会体现在特定的笔记中，拥有这些笔记将大大简化复现和修复过程。

在这种情况下，请在左侧树中右键点击相关笔记子树，选择“导出 - HTML 为 ZIP”进行导出：
