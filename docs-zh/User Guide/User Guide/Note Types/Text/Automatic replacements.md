# 自动替换
## 自动替换

当你在文本笔记中输入时，某些字符序列会被替换为它们所代表的排版符号。输入 `(c)` 会得到 `©`，输入 `...` 会得到 `…`，输入 `"quote"` 会得到 `“quote”`。

这些替换不会应用于代码块或行内代码中，粘贴的文本也永远不会受到影响，只有你手动输入的文本才会被替换。如果你粘贴了一段代码片段，或者在代码块中编写了代码，其中的字符会保持原样。

### 撤销替换

一旦自动替换发生，可以通过以下方式撤销：

*   在替换后立即按下 <kbd>Backspace</kbd> 可以撤销替换并恢复你输入的内容。
    *   注意这会消耗撤销操作，因此之后再按 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 可能会删除你输入的文本。
    *   按下 <kbd>Space</kbd> 或更改光标位置会禁用此功能。
*   按下 <kbd>Ctrl</kbd>+<kbd>Z</kbd>，即使在按下空格后仍然有效。

### 替换分组与配置

每个分组都可以在 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _文本笔记_ → _自动替换_ 中关闭。

| 分组 | 替换内容 |
| --- | --- |
| 标点符号 | `...` 替换为省略号（`…`），以及 _两侧带空格_ 的 `--` 和 `---` 替换为短破折号（`–`）和长破折号（`—`） |
| 数学符号 | 诸如 `1/2` 的分数替换为 `½`，以及运算符 `<=`、`>=`、`!=`、`<-` 和 `->` 替换为 `≤`、`≥`、`≠`、`←` 和 `→` |
| 版权和商标 | `(c)`、`(r)` 和 `(tm)` 替换为 `©`、`®` 和 `™` |
| 引号 | 直引号替换为排版引号——见下文 |

## 引号

引号的配置与其他替换分开，**双**引号键和**单**引号键各有一个设置，因为哪对引号对应哪个键在不同惯例中有所不同：英国排版传统上使用 `‘…’` 来设置引文，而美国则使用 `“…”`。

每个设置提供以下选项：

*   _基于笔记的内容语言_（默认）——英语给出 `“quote”`，德语给出 `„quote“`，法语给出 `« quote »`，日语给出 `「quote」`。关于如何确定笔记的语言，请参阅 <a class="reference-link" href="Content%20language%20%26%20Right-to-left%20support.md">内容语言与从右到左支持</a>。
*   _禁用_，直引号保持为直引号。
*   特定的引号对\_：\_ `“…”`、`‘…’`、`„…“`、`„…”`、`«…»`、`« … »`、`‹…›`、`「…」`、`『…』`。选择其中一个会将其应用于所有笔记，无论其内容语言是什么。

## 自定义替换

你可以在 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _文本笔记_ → _自动替换_ → _自定义替换_ 下添加自己的替换规则。输入要替换的文本和替换后的文本，然后按 Enter。已有的替换规则会以标签形式显示，点击每个标签上的 × 即可删除。

自定义替换在文本作为完整单词输入并后跟空格时生效，因此以它为开头的更长单词不会被替换——`TN` 替换不会重写 `BTN` 的结尾，`TNT` 仍然可以正常输入。

大小写遵循你输入的内容，除非替换文本本身有大写字母：

| **你定义的替换** | **你输入** | **你得到** |
| --- | --- | --- |
| `teh` → `the` | `teh` / `Teh` / `TEH` | `the` / `The` / `THE` |
| `TN` → `Trilium Notes` | `TN` 或 `tn` | `Trilium Notes`（不变，因为它有大写字母） |

注意事项：

*   要替换的文本是字面匹配的，不是模式匹配。
*   输入一个已存在于替换列表中的“要替换的文本”会更新现有的替换规则。同一个文本不能有多个替换规则。
*   同一个“要替换的文本”使用不同的大小写（例如 `TN` 和 `tn` 共存）是不行的，因为这会干扰上述大小写规则。

## 看起来被替换的字符（连字）

如果你在代码块中看到 `!=` 显示为 `≠` 或 `->` 显示为 `→`，那不是替换，因为替换从不在代码块中运行（除非代码块被应用于已有的文本）。这是一种 _字体连字_：默认的等宽字体将某些字符对绘制为单个符号。底层文本并未改变，复制出来仍然是 `!=` 和 `->`。

可以通过 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a>_→ 外观 → 字体 → 编程连字_ 来关闭此功能。
