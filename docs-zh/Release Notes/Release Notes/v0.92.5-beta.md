# v0.92.5-beta
> [!IMPORTANT]
> 由于多因素身份验证机制，数据库版本已升级。这意味着桌面客户端和服务器都需要更新到该版本，同步功能才能正常工作。

## 💡 主要亮点

*   Windows 二进制文件现已签名，因此更新后首次启动应用程序时，将不再出现“不受信任的应用程序”弹窗。非常感谢 NetPerfect 的 [deajan](https://github.com/deajan) 帮助我们获取 EV 证书和基础设施。
*   对于桌面应用程序，现在可以设置区域设置，以更改如提升属性等位置的数字或日期格式。
*   [多因素身份验证（Google OAuth 和 TOTP）](https://github.com/TriliumNext/Notes/pull/401) 由 @chesspro13 和 @jyc333 贡献

## ✨ 改进

*   日历视图：
    *   事件现在也有开始时间和结束时间，而不仅仅是日期。
    *   新增多种视图：周视图（含时间）、年视图、列表视图。
*   Mermaid：
    *   使用更好的缩放机制（与 mermaid.live 非常相似）。
    *   图表/代码区域现在可以调整大小。
    *   现在可以选择使用水平分割来显示代码/预览，类似于 mermaid.live。
    *   减少编辑图表时的闪烁。
    *   改进了错误的显示。
    *   [允许导出图表为 PNG（Mermaid / 思维导图）](https://github.com/TriliumNext/Notes/issues/536)
    *   [允许隐藏 Mermaid 图表文本](https://github.com/TriliumNext/Notes/issues/922)（通过只读模式）。
    *   改进了单文件导入/导出（支持 `.mermaid` 和 `.mmd` 扩展名）。
*   Markdown 导出：
    *   移除导出为 HTML 的表格上的 `joplin-table-wrapper`。
    *   表格内的代码块现在会将表格渲染为 HTML 以保证兼容性。
*   应用内帮助：
    *   改进代码块的样式
*   移动端视图：
    *   改进平板竖屏模式下的内容宽度。
*   思维导图：添加 PNG 导出功能。
*   对 TriliumNext 主题进行常规改进。
*   为日记笔记添加 {isoMonth} 月份模式，由 @jshprentz 贡献
*   [笔记源代码：禁用更改图标的功能](https://github.com/TriliumNext/Notes/issues/1377)
*   [禅模式：将默认键盘快捷键更改为 <kbd>F9</kbd>](https://github.com/TriliumNext/Notes/issues/1372)
*   笔记自动补全：
    *   显示笔记图标。
    *   出于性能考虑，输入少于三个字符时不进行搜索。
*   后端日志
    *   [允许自动换行](https://github.com/TriliumNext/Notes/issues/1496)
    *   将刷新按钮显示为浮动按钮以节省空间。
*   Markdown 导入/导出：规范化不间断空格
