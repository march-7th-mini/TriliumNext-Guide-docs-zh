# v0.102.0：升级至 jQuery 4.0.0

jQuery 4 移除了对旧版浏览器的支持（如 IE11 支持），同时也移除了一些被视为已弃用的 API，例如：

> `jQuery.isArray`、`jQuery.parseJSON`、`jQuery.trim`、`jQuery.type`、`jQuery.now`、`jQuery.isNumeric`、`jQuery.isFunction`、`jQuery.isWindow`、`jQuery.camelCase`、`jQuery.nodeName`、`jQuery.cssNumber`、`jQuery.cssProps` 以及 `jQuery.fx.interval`。
> 
> 请改用原生等价方法，如 `Array.isArray()`、`JSON.parse()`、`String.prototype.trim()` 和 `Date.now()`。

这可能会影响自定义脚本（如果它们或所使用的自定义 jQuery 库依赖于这些已弃用的 API）。

请注意，Trilium 对 `jQuery.isArray`、`isFunction` 和 `isPlainObject` 进行了 polyfill，因为我们的一个依赖项（自动补全）需要它们。

更多信息，请参阅[官方博客文章](https://blog.jquery.com/2026/01/17/jquery-4-0-0/)。
