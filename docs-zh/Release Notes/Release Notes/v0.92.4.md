# v0.92.4

## 此稳定版中的新功能

### 💡 主要亮点

*   支持在文本笔记和 Markdown 中使用警示框（信息框、警告框）。更多信息请参阅文档。
*   [macOS 签名二进制文件（感谢 @perfectra1n 的实现）。](https://github.com/TriliumNext/Notes/pull/1267)
*   添加了从右到左内容的基础支持。更多信息请参阅应用内帮助（F1）。
*   导入 HTML 时现在有更严格的规则，我们只允许极少数样式（颜色、边框等）。如果在导入时遇到任何问题，请尝试禁用“安全导入”并报告您可能遇到的任何问题。
*   [Trilium 现在可以在桌面版上直接将笔记导出为 PDF。](https://github.com/TriliumNext/Notes/pull/1091)
*   由 @pano9000 提供的 Linux RPM 包
*   [由 @pano9000 提供的 Linux Flatpak 包](https://github.com/TriliumNext/Notes/pull/1130)（尚未发布到 FlatHub）
*   现在有一个仍在开发中的应用内帮助，可以通过按 F1 触发。在某些笔记类型（例如地理地图）上有一个上下文相关的帮助按钮。
*   禅模式（极简用户界面）。更多详情请参阅应用内帮助。

### 🐞 错误修复

*   深色模式下登录界面渲染不正确。
*   [某些有效的 JavaScript 语法被高亮为错误](https://github.com/TriliumNext/Notes/issues/1218)
*   [澄清关于删除修订的误导性消息](https://github.com/TriliumNext/Notes/issues/1308)
*   [某些模板类型的笔记创建问题](https://github.com/TriliumNext/Notes/issues/357)

*   [某些语言在其自身标签下的语法高亮不生效](https://github.com/TriliumNext/Notes/issues/949)
*   Markdown 导入：
    *   修复标题包含特殊字符时的重复标题问题。
    *   修复转换为 HTML 时出现的不必要空白。
*   画布：[无法导出为图像](https://github.com/TriliumNext/Notes/issues/1431)。

### ✨ 改进

*   [允许浅色和深色主题作为基础主题](https://github.com/TriliumNext/Notes/pull/1361)
*   导出：
    *   保留附件顺序。
    *   为画布单独导出使用正确的扩展名（`.excalidraw`）。
*   导入：允许直接导入 `.excalidraw` 文件。
*   Markdown 导出：
    *   转义图片 URL 中的空格以获得更好的兼容性。
    *   为 Nginx 配置设置正确的语言标签。
    *   保留 `<kbd>`。
*   文本笔记现在将斜体文本存储为 `<em>` 而不是 `<i>`（与 Markdown 导入/导出的幂等性）。
*   应用内帮助：在笔记列表中预览内容
*   [代码块：添加对 MIPS 汇编的支持](https://github.com/TriliumNext/Notes/issues/1406)
*   文本笔记：允许将文本样式设置为键盘快捷键，请参阅文档
*   日历视图的改进，由 @rom1dep 提供：
    *   将“promotedAttributes”重命名为“displayedAttributes”，并允许显示非提升属性
    *   使具有自定义 `calendar:startDate` 和 `calendar:endDate` 的事件可以在日历视图上拖放
*   数学公式：显示模式现在可以移动到更多位置，例如列表中。
