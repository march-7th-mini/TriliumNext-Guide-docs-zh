# 地理地图
<figure class="image"><img style="aspect-ratio:1561/1149;" src="Geo Map_image.png" width="1561" height="1149"></figure>

此笔记类型根据属性在地图上显示子笔记。也可以使用内置界面在特定位置添加新笔记。

## 功能

*   在地图上添加标记，可使用图标、颜色和文本进行自定义。
*   搜索已在地图上的笔记，并查找世界各地的地点。
*   点击地图上已显示的地点将其转换为标记。
*   使用 `.gpx` 文件在地图上显示轨迹。
*   地图的 3D 视图，使用矢量地图时可显示建筑物。

## 系统要求

从 v0.105.0 开始，地理地图使用 MapLibre GL，这需要 WebGL v1 支持。通常，大多数设备都支持它，因为浏览器/Electron 在需要时可以以软件方式渲染。

如果由于无法初始化 WebGL 而导致地图无法绘制，则会显示错误消息而不是地图（_由于 WebGL 不可用，无法绘制此地图…_）。

## 交互

*   左上方是搜索栏。它会搜索已在地图上的笔记，也可以在您要求时在线搜索地点。当您在搜索结果中移动时，其下方会出现一个带有上一个和下一个按钮的计数器。
*   底部中央有一个中央工具栏，提供编辑功能：在地图上添加新标记和导入 GPX 轨迹。
*   右下角是视口项目：
    *   放大/缩小
        *   在移动设备上这些按钮是隐藏的，请改用捏合手势进行缩放。
        *   在桌面上，也可以使用鼠标滚轮调整缩放。
    *   全屏按钮，将整个地图聚焦到屏幕上，同时仍允许进行编辑。

## 创建新的地理地图

在 <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a> 中右键单击现有笔记，然后选择 _插入子笔记_ → _地理地图_。

默认情况下，地图为空，并显示整个世界。

## 重新定位地图

*   单击并拖动地图以在地图上移动。
*   使用鼠标滚轮、触控板上的双指手势或右下角的 +/- 按钮来调整缩放。

地图上的位置和缩放比例会保存在地图笔记中，并在再次访问该笔记时恢复。

## 搜索地图

地图左上角的搜索栏在两个位置进行搜索。它总是搜索已在地图上的笔记。它也可以在线搜索地点，但仅在您要求时进行。

### 搜索已在地图上的笔记

在搜索栏中键入内容，地图上的笔记会根据标题进行匹配。键入内容和标题中的重音符号都会被忽略，因此 `zurich` 可以找到 _Zürich Hauptbahnhof_。每个单词都会被单独搜索，因此 `hotel paris` 可以找到 _Paris Hotel_。没有 `#geolocation` 属性的笔记不会被提供，因为没有位置可去。GPS 轨迹会被提供，即使它们没有此类属性：选择一条轨迹会将整个路线纳入视野。

如果匹配的笔记多于列表可显示的数量，则会提供离您正在查看的区域最近的笔记。

### 在线搜索地点

查找地点会将您输入的内容发送到第三方服务。因此，这绝不会在您键入时发生。相反，结果列表的最后一行提供搜索。该行显示为 _在线搜索 "…"_，其下方是服务名称。仅当您按下该行或使用 Enter 键选择它时，搜索才会运行。

Trilium 使用 Nominatim，这是由 OpenStreetMap 基金会运营的地点搜索服务。它不需要帐户，也不需要 API 密钥。其名称会显示在属于它的每一行上：提供搜索的行、显示搜索正在运行的行，以及报告未找到任何内容或无法联系服务的行。

搜索优先考虑您正在查看的区域。当前视图内的地点会首先被搜索并列在其他地点之上。因此，如果您在查看自己所在城镇时搜索一家商店，您会找到该城镇的分店，而不是另一个大陆上同名的分店。视图始终被视为至少 25 公里宽，因此即使在放大到单条街道时进行搜索，也会覆盖其周围的城镇。

### 前往某个点

如果您在搜索栏中输入或粘贴坐标，一个 _前往_ 行会显示在所有其他结果之上。选择它会将地图移动到该确切位置并进行标记。然后您可以将其保留为标记，方式与保留通过搜索找到的地点相同。

一个点没有自己的名称。它只有您输入的坐标。因此，该笔记会被赋予与任何其他新笔记相同的名称，这也是您从 _添加标记_ 按钮和笔记树中的 + 按钮获得的名称。笔记打开时该名称处于选中状态，因此您可以直接键入覆盖。如果地图具有 <a class="reference-link" href="../Advanced%20Usage/Default%20Note%20Title.md">titleTemplate</a> 标签，则标记将按该模板命名。

可识别的格式包括：

*   简单的坐标对，例如 `45.9432, 24.9668`。这是 Google 地图和 OpenStreetMap 在您请求某个地点坐标时都会提供的内容，也是 `#geolocation` 属性所保存的内容。
*   地图本身通过 _打开位置_ 操作为某个地点提供的 `geo:` 链接。
*   Google 地图或 OpenStreetMap 上某个地点的地址，整体粘贴。

不是地球上的地点的坐标对，例如 `1234, 5678`，不会被提供。

### 阅读结果

结果按标题分组收集，每个组按距地图中心的距离排序：

*   _在此地图上_：已经在地图上的笔记，无论距离多远。
*   _附近_：在视图约 25 公里范围内找到的地点。
*   _远处_：所有其他地点。

仅当三个组中至少有两个包含内容时，标题才会出现。每个有位置的行都会显示距离，根据您的区域设置以公里或英里为单位。在线找到的地点会在第一行显示其名称，在第二行显示其地址。

### 选择结果

选择已在地图上的笔记会移动到其标记，并在地图旁边打开该笔记，就像点击标记一样。

选择在线找到的地点会将地图移动到该地点，并用临时图钉进行标记。该图钉的颜色与地图自身的标记不同。地图会适配到该地点覆盖的区域，因此一个国家会填满视图，而一栋房子则会显示在街道层面。有些地点有边界，例如国家、县或公园。当服务报告有边界时，该边界会在图钉下方勾勒出来。

然后会打开一个面板，显示该地点的完整地址及其坐标：在桌面上位于右上角，在移动设备上位于地图底部，顶部保留给搜索栏和结果计数器。按下坐标会将其复制到剪贴板。

### 将地点保留为标记

按下该面板中的 _添加为标记_ 以保留该地点。会在地图下创建一个子笔记。它会采用该地点的名称以及与其类型匹配的图标。其 `#geolocation` 属性已设置。笔记会在地图旁边打开，因此您可以立即编辑。临时图钉会消失，因为该地点现在与其他标记一样。

对于无法编辑的地图，不会提供此按钮，但面板仍可阅读。

按下面板的关闭按钮或 Escape 键，可以放弃该地点而不保留。图钉也会随之消失。

### 逐步浏览结果

选择结果后，搜索栏下方会出现一个计数器，带有上一个和下一个按钮。这些按钮会按照列出的顺序浏览搜索提供的所有内容。因此，您可以比较多个结果，而无需重新打开列表。按下计数器本身会将地图移回当前结果，这在您将地图移开后很有用。

### 键盘操作

*   **Enter** 在在线搜索行被选中时运行搜索，否则移动到高亮显示的结果。在获取结果后按下，会重新显示列表。
*   **Escape** 关闭结果列表，并关闭地点面板。
*   返回搜索栏会重新打开它之前显示的列表。
*   栏末尾的 **X** 会清空它，这也会从地图上移除搜索到的地点、其图钉和面板。

## 使用地图添加标记

### 使用加号按钮添加新笔记

1.  要创建标记，首先在地图上导航到所需点。然后按下地图底部中央的 _添加标记_ 按钮。
2.  按下后，地图将进入插入模式，如通知所示。此外，光标位置会显示标记的预览。
    
    只需点击地图上要放置标记的点即可。要取消，请按 Escape 键或再次按下 _添加标记_ 按钮。
3.  点击后，标记将显示在地图上，右侧会弹出一个弹出窗口，标题已选中可供更改。

### 使用上下文菜单添加新笔记

1.  在地图上的任意位置右键单击，以放置新创建的标记（以及相应的笔记）。
2.  选择 _在此位置添加标记_。
3.  在地图上的某个位置点击后，标记将显示在地图上，右侧会弹出一个弹出窗口，标题已选中可供更改。

### 从笔记树添加现有笔记

1.  在 <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a> 中选择所需的笔记。
2.  按住鼠标左键并按住笔记，将其拖到地图上的所需位置。
3.  地图应更新为新的标记。

这适用于：

*   不属于地理地图的笔记，在这种情况下将创建[克隆](../Basic%20Concepts%20and%20Features/Notes/Cloning%20Notes.md)。
*   是地理地图的子笔记但尚未在地图上定位的笔记。
*   是地理地图的子笔记且已定位的笔记，在这种情况下，标记将重新定位到新位置。

> [!注意]
> 仅当地图处于编辑模式时，拖动现有笔记才有效。有关更多信息，请参阅 _只读_ 部分。

### 从地图已显示的地点添加笔记

使用矢量地图样式时，地图本身会绘制正在查看区域周围的商店、咖啡馆、博物馆和其他地点。当地图放大到足以绘制这些地点时，可以点击它们：

1.  查找以橙色绘制的地点。这与通过搜索找到的地点使用的颜色相同。这些是您可以点击的地点。它们绘制得几乎是实心的，而地图上的其他地点则保持淡淡的灰色。
2.  将鼠标悬停在其中一个地点上。其名称会显示在其上方，鼠标光标会变为指针。地图将这些地点绘制为没有名称的图标，因此您需要通过悬停来读取名称。如果所有名称同时显示，它们会挤掉您自己标记的标题。
3.  点击它。会出现与通过搜索找到的地点相同的面板。它显示地点的名称和坐标，并在地图上放置一个图钉。
4.  按下 _添加为标记_ 以保留它。该笔记会以地点名称作为标题创建，并使用与其类型匹配的图标。

地点是从已下载的地图数据中读取的，因此点击一个地点不会向互联网发送任何内容。

需要记住的一些事项：

*   地图数据中没有名称的地点，例如长椅或停车位，不显示名称，也无法点击。点击它们不会执行任何操作，就像点击地图的空白部分一样。
*   地图自身的标记优先。如果标记覆盖了一个地点，点击它会打开笔记而不是地点。
*   这不适用于栅格（OpenStreetMap）样式，因为其地点是地图图像的一部分。它也不适用于 _Neutrino_ 样式，该样式不绘制任何地点。
*   在只读模式下，您仍然可以点击地点并阅读，但不能将其保留为标记。

## 标记位置如何存储

标记的位置存储在子笔记的 `#geolocation` 属性中：

如果需要，可以手动添加此值。该属性的值由纬度和经度组成，以逗号分隔。

## 重新定位标记

一旦设置了标记，可以使用以下两种方式之一重新定位：

*   右键单击标记并选择 _移动到另一个位置_。
*   单击标记以打开弹出窗口，然后选择标题栏下方的 _移动到另一个位置_ 按钮。

单击移动标记的按钮后，在地图上的所需位置单击以替换它。要取消操作，请按 Escape 键。

> [!注意]
> 如果地图已锁定编辑（见下文），则需要先解锁地图才能移动标记。

## 与标记交互

*   将鼠标悬停在标记上会显示一个 <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tooltip.md">笔记工具提示</a>，其中包含其所属笔记的内容。
    *   单击工具提示中的笔记标题将导航到当前视图中的该笔记。
*   右键单击标记将打开一个上下文菜单（如下所述）。
*   单击标记将聚焦于该标记，并显示一个专门的弹出窗口，其中包含详细信息。无论地图是否可编辑，这都有效。

### 弹出视图

当点击标记或轨迹时，右侧会打开一个弹出窗口，其中包含以下信息：

*   标记的标题和图标，均可编辑。
*   坐标指示器；点击它会将坐标复制到剪贴板。
*   一个最大化弹出窗口的按钮。
*   与标记交互的按钮：
    *   在同一窗格、新标签页等中打开标记。
    *   在专用应用程序（例如移动设备上的 Google 地图）中打开位置的按钮。
    *   用于更改标记颜色的颜色选择器。
    *   从地图上移除标记的按钮，可以选择删除其对应的笔记。不移除笔记而移除标记只会删除其 `#geolocation` 属性（在这种情况下，必须手动重新添加坐标才能使笔记再次显示在地图上）。
*   标记的 <a class="reference-link" href="../Advanced%20Usage/Attributes/Promoted%20Attributes.md">提升属性</a>（如果有）。
*   笔记的内容，可以直接从面板中编辑。

要关闭弹出窗口：

*   按弹出窗口右上角的 X 按钮。
*   在地图上，点击弹出窗口外部的任意位置。
*   或者直接按 Escape 键。

当点击标记时，地图会自动调整视口，以便在弹出窗口打开时标记仍然可见。当前选中的标记会显示得稍大一些。

即使在弹出视图已打开时，也可以通过点击标记在标记之间切换。

标记之间可以有 <a class="reference-link" href="../Note%20Types/Text/Links/Internal%20(reference)%20links.md">内部（引用）链接</a>，点击此类链接会自动将视口和弹出视图调整到新笔记。

### 上下文菜单

可以按鼠标右键显示上下文菜单。

1.  如果右键单击地图的空白部分（不在标记上），则可以：
    1.  显示纬度和经度。点击此选项会将它们复制到剪贴板。
    2.  使用外部应用程序打开该位置（如果操作系统支持）。
    3.  在该位置添加一个新标记。
2.  如果右键单击标记，则可以：
    1.  显示纬度和经度。点击此选项会将它们复制到剪贴板。
    2.  使用外部应用程序打开该位置（如果操作系统支持）。
    3.  在新标签页、分屏或窗口中打开笔记。
    4.  从地图上移除标记的按钮，可以选择删除其对应的笔记。不移除笔记而移除标记只会删除其 `#geolocation` 属性（在这种情况下，必须手动重新添加坐标才能使笔记再次显示在地图上）。

### 标记的图标和颜色

标记将具有与笔记相同的图标。

可以通过为标记分配 `#color` 属性（例如 `#color=green`）来添加自定义颜色。

### 手动添加坐标

搜索地点通常更快（请参阅上面的 _搜索地图_）。对于手头已有的坐标或搜索无法找到的地点，以下步骤仍然有用。

简而言之，创建一个子笔记并将 `#geolocation` 属性设置为坐标。

该属性的值由纬度和经度组成，以逗号分隔。

#### 从 Google 地图添加

1.  在 Google 地图网页版中：
    1.  查找所需位置，右键单击它，会出现一个上下文菜单。
    2.  只需点击显示坐标的第一项，它们就会被复制到剪贴板。
2.  在 Trilium 中，在地图下创建一个子笔记。
3.  然后将文本框中的值粘贴到地图子笔记的 `#geolocation` 属性中（不要忘记用 `"` 字符将值括起来）。

#### 从 OpenStreetMap 添加

与 Google 地图的方法类似：

1.  转到 openstreetmap.org 上的任何位置，右键单击以调出上下文菜单。选择 _显示地址_ 项。
2.  地址将显示在屏幕左上角，即搜索栏的位置。选择坐标并将其复制到剪贴板。
3.  只需将文本框中的值粘贴到地图子笔记的 `#geolocation` 属性中，然后它就应该显示在地图上了。

## 添加 GPS 轨迹 (.gpx)

<figure class="image"><img style="aspect-ratio:1566/1155;" src="1_Geo Map_image.png" width="1566" height="1155"></figure>

Trilium 可以以 `.gpx` 文件的形式在地理地图上显示 GPS 轨迹。

要添加轨迹，可以：

1.  将 `.gpx` 文件拖放到笔记树中的地理地图内。
    1.  为了使文件被识别为 GPS 轨迹，它需要在 _文件类型_ 字段中显示为 `application/gpx+xml`。
2.  按下 _从 GPX 文件添加 GPS 轨迹_，这将直接提示选择 GPX 文件并将其作为集合的子笔记导入。

返回地图时，轨迹现在应该可见。

轨迹的起点将显示为标记，其下方是笔记名称。起点标记也将遵循笔记的图标和 `color`。终点标记使用不同的图标显示。

如果轨迹文件包含多条轨迹，它们都将显示为标记。Trilium 也会拆分恰好具有不连续点的单条轨迹。

如果 GPX 包含航点，它们也会显示，包括其名称。

当点击轨迹时，整个路线会进入视野，右侧弹出窗口会显示轨迹的详细信息，例如距离、持续时间和海拔图。点击 `.gpx` 笔记本身时也会显示此信息。

当点击轨迹的标记（无论是起点或终点的内置标记，还是作为轨迹一部分的自定义标记）时，只有该标记会进入视野，而不是整个路线。

## 只读模式

当地图是[只读](../Basic%20Concepts%20and%20Features/Notes/Read-Only%20Notes.md)时，所有编辑功能都将被禁用，例如：

*   地图底部的添加按钮。
*   重新定位标记。
*   从上下文菜单进行编辑（移除位置或添加新项目）。
*   将地点保留为标记，无论您是通过搜索找到的还是在地图上点击的。您仍然可以搜索和点击，仍然可以查看地点并复制其坐标。

要将地图设置为只读，请转到 <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20buttons.md">笔记按钮</a> → _可编辑_ → _只读_（在新布局中，或在旧布局的 <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Ribbon.md">功能区</a> 的基本属性中）。

## 配置

### 地图样式

地图的样式可以在 <a class="reference-link" href="Collection%20Properties.md">集合属性</a> 中调整，或通过 `#map:style` 属性手动调整。

地理地图带有两种不同类型的样式：

*   栅格样式
    *   对于这些样式，地图表示为不同缩放级别的图像网格。这是 OpenStreetMap 过去的传统工作方式。
    *   缩放略有受限。
    *   目前，唯一的栅格主题是原始的 OpenStreetMap 样式。
*   矢量样式
    *   矢量样式不表示为图像，而是表示为几何形状。这使得渲染更加平滑，尤其是在缩放和查看建筑物边缘时。
    *   地图可以放大得更远。
    *   这些有各种样式，既有浅色（Colorful、Graybeard、Neutrino）也有深色（Eclipse、Shadow）。
    *   矢量样式来自 [VersaTiles](https://versatiles.org/)，这是一个基于 OpenStreetMap 提供地图瓦片的免费开源项目。
    *   VersaTiles 图层还提供 3D 建筑物信息（见下文）。

默认主题是 Versatiles Colorful（矢量）。

#### 带建筑物的 3D 视图

<figure class="image"><img style="aspect-ratio:2727/1642;" src="2_Geo Map_image.png" width="2727" height="1642"></figure>

Trilium v0.105.0 引入了 3D 视图，这得益于 MapLibre GL。要进入 3D 模式，只需按下地图右下角的相应按钮，或按住 Ctrl 并在地图上拖动。

建筑物只会从缩放级别 14 开始出现，以避免卡顿。

> [!注意]
> 要获得 3D 建筑物，请确保您使用的是 _VersaTiles_ 样式，该样式通过 `versatiles-shortbread` 源提供建筑物信息。

### 自定义地图样式 / 瓦片

从 v0.102.0 开始，可以使用自定义瓦片集，但仅限于栅格格式。

为此，请手动将 `#map:style` [标签](../Advanced%20Usage/Attributes/Labels.md) 设置为瓦片集的 URL。例如，要使用 Esri.NatGeoWorldMap，请将值设置为 [`https://server.arcgisonline.com/ArcGIS/rest/services/NatGeo_World_Map/MapServer/tile/{z}/{y}/{x}`。](https://server.arcgisonline.com/ArcGIS/rest/services/NatGeo_World_Map/MapServer/tile/%7Bz%7D/%7By%7D/%7Bx%7D.)

此外：

*   通过 `{r}` 占位符支持 Hi-DPI 瓦片。
*   要将自定义样式标记为深色（这会影响 UI 的样式），请应用 `map:darkStyle` 标签。此属性也会覆盖内置主题。

> [!注意]
> 有关瓦片集的列表，请参阅 [Leaflet Providers 预览](https://leaflet-extras.github.io/leaflet-providers/preview/) 页面。选择所需的瓦片集，然后从 _Plain JavaScript_ 示例中复制 URL。

自定义矢量地图支持已计划，但尚未实现。

### 其他选项

以下选项可以通过 <a class="reference-link" href="Collection%20Properties.md">集合属性</a> 配置，方法是点击设置（齿轮图标）。或者，这些选项中的每一个也有一个相应的 [标签](../Advanced%20Usage/Attributes/Labels.md) 可以手动设置。

*   比例尺，在地图左下角以公里或英里显示地图的比例。
    *   单位由 _语言与区域_ 中的 _格式区域设置_ 选项决定。
*   标记的名称默认显示在地图上的图钉下方。从 v0.102.0 开始，可以隐藏这些标签，这可以提高性能并减少地图上标记很多时的杂乱感。
*   v0.105.0 还引入了一项名为 _分组附近标记_ 的功能，该功能会在低缩放级别时将多个标记聚集在一起。
    *   聚类会显示其包含的项目数。颜色也会根据数量而变化。
    *   点击聚类会自动放大，以便组成聚类的各个标记现在可见。
