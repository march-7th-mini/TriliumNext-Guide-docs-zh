# 格式刷
<figure class="image image-style-align-right"><img style="aspect-ratio:220/76;" src="Format Painter_image.png" width="220" height="76"></figure>

格式刷是文本笔记中的一项功能，允许用户复制文本的格式（如**加粗**、_斜体_、~~删除线~~等）并将其应用到文档的其他部分。它有助于保持格式一致，并加快富内容的创建。

## 使用说明

点击要复制其格式的文本，然后使用 _复制格式_ 工具栏按钮（<span class="tn-icon cke cke-paint-roller"></span>）复制样式。然后用鼠标选择目标文本，或点击某个单词，即可应用该格式。

*   **复制格式**：将光标置于带有格式的文本中，然后点击 _复制格式_ 工具栏按钮。鼠标光标会发生变化，表示格式刷已激活。
*   **使用复制的格式进行刷取**：用鼠标选择目标文本。松开鼠标按钮时会应用格式，格式刷随即解除激活——光标恢复正常。点击或轻触某个单词会将其应用到整个单词。
*   **为通过其他方式（如键盘或触摸屏的选择手柄）做出的选择进行刷取**：选择目标文本，然后再次使用工具栏按钮，一旦选区发生移动，该按钮会显示为 _应用格式_。在手机上，格式刷激活期间格式行会保持打开，因此按钮始终触手可及。
*   **取消而不刷取**：在选择其他文本之前再次点击工具栏按钮，或按 <kbd>Escape</kbd>。

## 限制

1.  尚不支持使用块级格式（如标题或图片样式）进行刷取。这是因为在 <a class="reference-link" href="../../Advanced%20Usage/Technologies%20used/CKEditor.md">CKEditor</a> 中，它们被视为内容的一部分，而非文本格式。
2.  在单词外部点击（例如两个空格之间或行尾），只会定位光标，因此在那里输入的文本会采用复制的格式。
3.  格式刷是一次性的；每次刷取都需要重新复制格式。
