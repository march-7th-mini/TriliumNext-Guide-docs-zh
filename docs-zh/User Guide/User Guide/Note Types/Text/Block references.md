# 块引用

块引用是指向文本笔记中某个块的[链接](Links.md)，例如段落、标题、列表项或表格，也可以指向一段连续的块。块引用可以作为链接粘贴到另一篇笔记中，或转换为<a class="reference-link" href="Include%20Note.md">包含笔记</a>，仅显示被引用的块。

## 复制引用

1.  将光标置于要引用的块中。要引用多个连续的块，请选中它们。
2.  右键单击块手柄，即块左侧的一串圆点（参见<a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a>）。或者，右键单击文本并打开 _复制_ 子菜单。
3.  选择 _复制对此块的引用_，若选中了多个块则选择 _复制对这些块的引用_。被引用的块会短暂闪烁。
4.  转到要插入链接的笔记，按 <kbd>Ctrl</kbd>+<kbd>V</kbd>。

在<a class="reference-link" href="Content%20tabs.md">内容标签页</a>块内部，引用指向整个块。要链接到单个标签页，请改用 _复制标签页链接_。在<a class="reference-link" href="Multicolumn%20layout.md">多栏布局</a>内部，引用指向该栏中的块，包含笔记会显示这些块而不带周围的布局。

链接显示笔记的标题，后跟被引用文本的开头部分。指向同一笔记中块的链接仅显示被引用文本的开头部分。

如果笔记已[共享](../../Advanced%20Usage/Sharing.md)，块手柄的菜单还会提供 _复制此块的公开链接_。它会复制共享页面的网址并附加该引用，以便发送给在 Trilium 之外阅读该笔记的人。打开该地址会将共享页面滚动到被引用的块并使其闪烁。

右键菜单的 _粘贴_ 子菜单还提供另外两种插入已复制引用的方式：

*   _将引用粘贴为链接_ 仅插入链接，即使引用是以纯文本或与其他内容一起复制的。
*   _将引用粘贴为摘录_ 插入被引用块的包含笔记，如下所述。

在浏览器中，文本编辑器的右键菜单仅在右键单击选中的文本时打开。在其他位置，浏览器会显示自己的菜单。

## 跟随引用

单击块引用会打开笔记，滚动到被引用的块并使其闪烁。如果被引用的块已被删除，则会显示错误消息，并列出该范围中仍然存在的块。

## 包含被引用的块

要在另一篇笔记中显示被引用的块，请在正在编辑的笔记中右键单击该链接并选择 _将链接转换为笔记摘录_，或使用 _粘贴_ → _将引用粘贴为摘录_ 粘贴已复制的引用。包含笔记仅显示被引用的块，而非笔记的其余部分，并在其标题中标记 _摘录_ 徽章。它以 _完整_ 框尺寸启动，因此所有被引用的块都可见。要查看整篇笔记，请按同一标题中的 <span class="tn-icon bx bx-link-external"></span> 按钮，这会在新标签页中打开该笔记。将包含笔记转换回链接会保留该引用。

要在不离开笔记的情况下编辑被引用的块，请按包含笔记标题中的 <span class="tn-icon bx bx-pencil"></span> _编辑摘录_ 按钮，或在其工具栏中打开 _可编辑_（<span class="tn-icon bx bx-edit-alt"></span>），与任何<a class="reference-link" href="Include%20Note.md">包含笔记</a>一样。再次按该按钮可停止编辑。更改会保存到被引用的块，笔记的其余部分保持不变。在无法编辑块的位置（例如只读笔记中），该按钮会灰显。摘录没有 _全屏_ 按钮。

如果被引用的块已被删除，包含笔记会显示 _引用已损坏_。

## 限制

*   引用只能从正在编辑的笔记中复制，且在移动端布局中不可用。
*   仅覆盖列表或引用的一部分的范围（例如从第二项到其后的段落）的包含笔记无法就地编辑。
*   删除块会破坏对它的引用。
*   导出为 Markdown 时不会保留块引用。在[共享页面](../../Advanced%20Usage/Sharing.md)上，块引用会打开整篇笔记。
