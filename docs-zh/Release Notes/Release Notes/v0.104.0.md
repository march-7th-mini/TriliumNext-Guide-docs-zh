这个版本是 Trilium 历史上最大的版本，围绕两大主题构建：**安全性**和**互操作性**。桌面应用、服务器和共享笔记的攻击面已大幅减少——包含 16 项专门的安全修复和一些有意的破坏性变更（后端脚本和 SQL 控制台现在默认禁用），因此请在升级前查看“破坏性变更”部分。

将笔记导入和导出 Trilium 也变得更加容易：新增了针对 OneNote、Notion、Google Keep、Anytype 和 Obsidian 的导入器，以及更快、更节省内存的导入/导出管道，并且 Spreadsheet 现在支持 XLSX 和 CSV 的导入与导出。

此外，还有重新设计的设置和登录体验、更好的 AI 集成（包括能够使用您的 **Claude Code 订阅**）、更丰富的文本编辑（多状态 TODO 列表、可折叠块、链接预览）、仪表板集合，以及大量的优化——大约 86 个错误修复和 68 个较小的改进，几乎触及了应用的每个角落。以下部分提供了完整详情。

## 🚨 破坏性变更

1.  [**后端脚本现在默认禁用**](https://docs.triliumnotes.org/user-guide/scripts/Security)。
    1.  如果您使用这些脚本，请参阅文档（服务器或桌面设置的 `config.ini` 更改）。
    2.  此更改旨在加强 Trilium 的安全态势，因为后端脚本具有危险的强大访问级别（例如完全的文件系统访问权限）。前端脚本不受影响。
2.  [**SQL 控制台访问默认禁用**](https://docs.triliumnotes.org/user-guide/scripts/Security)**。**
    1.  与后端脚本类似，可以从 `config.ini` 重新激活。
3.  [桌面应用（基于 Electron）已针对潜在的 RCE 攻击进行了加固](https://docs.triliumnotes.org/user-guide/scripts/breaking-changes/disabling-node-integration)。如果您有依赖 Electron remote 或 Node.js 集成的前端脚本，您可能需要调整脚本。
4.  [桌面应用现在默认不再在本地网络上开放其端口](https://docs.triliumnotes.org/user-guide/setup/desktop/network-access)。
    1.  这通常只会在您对桌面客户端使用 ETAPI 或桌面到桌面同步时影响您（服务器不受影响）。
    2.  此选项可以在 选项 → 安全 中更改。
5.  此版本移除了 OPML v1 导出，保留了保留基本格式的 v2。导入仍支持 v1。

## ✨ 改进

除了主要功能外，68 个较小的改进完善了应用的几乎每个角落。有几个值得特别提及：**固定标签页**和重新设计的标签栏、**带预览模式的右侧边栏切换手柄**，以及**默认在模态框中打开而不是新标签页的选项**——这些更改您升级后几分钟内就会注意到。媒体笔记也得到了妥善处理，新增了**新的画廊式图像查看器**（缩放、键盘导航）和**全面改进的媒体播放器**（上一个/下一个、播放模式、媒体会话 API 集成），而 **Include note** 现在可以交互式渲染集合、Web 视图和已保存的搜索，画布笔记可以嵌入其他笔记并将图像存储为附件。

Markdown 继续成为一等公民：您现在可以**将文本笔记转换为 Markdown 并转换回来**，支持代码片段、代码块语言自动补全和更简洁的“复制为 Markdown”输出。设置界面跟随设置重新设计——**键盘快捷键部分**围绕按键记录器和冲突检测重建，**多因素身份验证**移入 _密码与身份验证_，并支持二维码生成和 TOTP 验证。其余部分是持续的优化：LLM 助手变得更加智能和流畅；电子表格、后端日志和导入/导出对话框都获得了有意义的升级；桌面应用获得了托盘隐藏和登录时启动等便利功能。

## 🔒️ 安全修复

安全是此版本的核心主题：16 项修复系统地缩小了 Trilium 的攻击面。内容现在在每条路径上都被净化（HTML、SVG、集合、共享笔记），注入向量（SQL、路径遍历、SSRF）已加固，会话和 Cookie 已收紧，Electron 桌面应用通过严格的权限、导航和会话隔离策略进行了锁定。这些修复与上述有意的破坏性变更相辅相成——它们共同使默认配置更加安全。
