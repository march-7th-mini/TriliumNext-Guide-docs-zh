# 插入按钮

按下<a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a>中的 <img src="4_Insert buttons_image.png" width="34" height="16"> 按钮，即可显示可插入的特殊项目和块，例如符号、数学表达式和分隔线。

## 书签

请参阅专门的<a class="reference-link" href="Anchors.md">锚点</a>部分。

## 表情符号

<figure class="image image-style-align-right image_resized" style="width:42.4%;"><img style="aspect-ratio:366/410;" src="Insert buttons_plus.png" width="366" height="410"></figure>

此功能允许插入 Unicode 表情符号字符。只需选择一个类别和所需的表情符号即可插入。

表情符号也可以通过其英文名称进行搜索，并且可以通过右侧的组合框选择肤色。

还可以通过直接输入 `:` 后跟表情符号名称来插入表情符号，这会触发表情符号列表的显示。只需使用箭头键选择一个，然后按 <kbd>Enter</kbd> 即可插入。

<img src="1_Insert buttons_plus.png" width="272" height="187">

## 符号

<figure class="image image-style-align-right"><img style="aspect-ratio:346/322;" src="1_Insert buttons_image.png" width="346" height="322"></figure>

按下 <img src="7_Insert buttons_image.png" width="18" height="15"> 按钮将弹出一个窗口，显示通常难以直接从键盘插入的字符列表，例如部分表情符号、引号字符等。

交互方式：

*   点击字符将其插入到当前光标位置。
*   窗口可以通过标题所在的顶部栏进行拖动，以免遮挡文本。
*   点击_类别_选择器以筛选字符。

请参阅专门的<a class="reference-link" href="Math%20Equations.md">数学公式</a>页面。

## Mermaid 图表

按下 <img src="2_Insert buttons_image.png" width="16" height="17"> 按钮可创建内联 Mermaid 图表。

此功能与<a class="reference-link" href="../Mermaid%20Diagrams.md">Mermaid 图表</a>笔记类型非常相似，旨在作为简单图表的替代方案。对于更复杂的图表，请使用<a class="reference-link" href="Include%20Note.md">包含笔记</a>功能来创建专门的 Mermaid 笔记。

## 水平分隔线

此功能将显示一条水平线，通常用于分隔文本的不同部分。为此，请按下<a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a>中的 <img src="5_Insert buttons_image.png" width="18" height="16"> 按钮。

<img src="3_Insert buttons_image.png" width="502" height="95">

或者，也可以通过输入 `---` 来插入水平分隔线。

## 分页符

<figure class="image image-style-align-right"><img style="aspect-ratio:371/79;" src="8_Insert buttons_image.png" width="371" height="79"></figure>

分页符提供了一种在打印时（无论是打印到真实打印机还是[导出为 PDF 时](../../Basic%20Concepts%20and%20Features/Notes/Printing%20%26%20Exporting%20as%20PDF.md)）强制将下一个段落或块（表格、图像等）显示在下一页的方法。

分页符在编辑器中以_分页符_字样标记，但在实际打印时不会显示。

*   要插入分页符，请按下格式工具栏中的 <img src="Insert buttons_image.png" width="20" height="19">。
*   要一次插入多个分页符，请先插入一个分页符，点击它并按 <kbd>Ctrl</kbd>+<kbd>C</kbd>。然后使用 <kbd>Ctrl</kbd>+<kbd>V</kbd> 按需多次粘贴。
