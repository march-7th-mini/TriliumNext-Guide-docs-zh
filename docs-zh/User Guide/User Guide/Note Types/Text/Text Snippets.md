# 文本片段

<figure class="image image-style-align-right"><img style="aspect-ratio:265/108;" src="Text Snippets_image.png" width="265" height="108"></figure>

文本片段与<a class="reference-link" href="../../Advanced%20Usage/Templates.md">模板</a>密切相关，但文本片段并非定义整个笔记的内容，而是可以轻松插入到文本笔记中的格式化文本片段。

## 创建文本片段

在<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a>中：

1.  右键单击要放置文本片段的笔记。
2.  选择 _插入子笔记_。
3.  选择 _文本片段_。

之后，只需在笔记内容中输入所需文本即可。文本的格式化方式与普通文本笔记相同。

笔记的标题将成为模板的标题。可选地，可以在<a class="reference-link" href="../../Advanced%20Usage/Attributes/Promoted%20Attributes.md">提升属性</a>部分添加描述。

## 插入片段

创建片段后，有两种插入方式：

1.  从<a class="reference-link" href="Formatting%20toolbar.md">格式化工具栏</a>中，查找 <img src="1_Text Snippets_image.png" width="19" height="19"> 按钮。
2.  使用<a class="reference-link" href="Slash%20Commands.md">斜杠命令</a>：
    1.  要查找特定模板，开始输入模板名称（其标题）。
    2.  要查找所有模板，输入 `template`。

> [!TIP]
> 新创建的片段没有出现？通常，一旦做出更改，模板列表刷新最多需要几秒钟。
>
> 如果仍未出现，请[重新加载应用程序](../../Troubleshooting/Refreshing%20the%20application.md)并向我们[报告问题](../../Troubleshooting/Reporting%20issues.md)。

## 限制

*   每当创建、删除片段或修改其标题/描述时，所有打开的文本笔记都需要刷新。这通常会导致不到一秒的轻微闪烁，但可能会引起一些不适。
*   与<a class="reference-link" href="../../Advanced%20Usage/Templates.md">模板</a>不同，片段不能限制在特定的[工作区](../../Basic%20Concepts%20and%20Features/Navigation/Workspaces.md)中。
