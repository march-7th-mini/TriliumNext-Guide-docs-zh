# 内部（引用）链接
内部链接是指向 Trilium 中其他笔记的链接。

你可以通过点击内部链接来打开它。也可以将鼠标悬停在内部链接上，查看其内容的只读预览。

## 插入内部链接

可以通过以下方式在文本笔记的当前位置创建内部链接：

1.  按下 <kbd>Ctrl</kbd> + <kbd>L</kbd>，或点击 <a class="reference-link" href="../Formatting%20toolbar.md">格式工具栏</a> 中 <span class="tn-icon cke cke-plus"></span> 菜单下方的 <span class="tn-icon cke cke-trilium"></span> 按钮。
2.  搜索想要链接的笔记标题。也可以在此对话框中创建新笔记：输入一个不存在的笔记标题，然后选择 _创建笔记_（将其放入 <a class="reference-link" href="../../../Basic%20Concepts%20and%20Features/Notes/Note%20Inbox.md">笔记收件箱</a>，即今天的日记笔记；如果未设置收件箱，则放在顶层），或选择 _创建子笔记_（将其放在当前正在编辑的笔记下）。

创建指向笔记的链接时，可以选择两种链接类型：

1.  _链接标题镜像笔记的当前标题_
    1.  有时也称为“引用链接”。
    2.  此链接的标题无法更改。它会始终显示所链接笔记的当前标题。
    3.  同时会显示所链接笔记的图标。
    4.  如果所链接的笔记被删除，链接会保留其最后显示的标题，以红色显示，并使用 <span class="tn-icon bx bx-x"></span> 图标代替笔记图标。在编辑时点击它会打开 _修复链接_ 对话框，该对话框会搜索该标题；选择一篇笔记或创建新笔记后，链接会被替换为指向该笔记的链接。
2.  _链接标题可以任意更改_
    1.  这会创建一个传统的超链接，其链接文本可以与笔记标题不同。

## 就地链接

你也可以使用 `@` 符号“内联”插入内部链接：

1.  在文本笔记中输入 `@`，会打开笔记搜索菜单。
2.  输入几个字符来搜索所需笔记的标题。使用 <kbd>Up</kbd> 和 <kbd>Down</kbd> 选择正确的笔记，然后按 <kbd>Enter</kbd> 或 <kbd>Tab</kbd> 创建链接。也可以通过此方法创建新笔记：输入一个不存在的笔记标题，然后如上所述选择 _创建笔记_ 或 _创建子笔记_。

## 粘贴内部链接

你也可以通过从笔记树中复制笔记来插入内部链接。

1.  在 <a class="reference-link" href="../../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a> 中，选择一篇笔记并按 <kbd>Ctrl</kbd> + <kbd>C</kbd>。
2.  在文本笔记中，按 <kbd>Ctrl</kbd> + <kbd>V</kbd> 粘贴链接。
