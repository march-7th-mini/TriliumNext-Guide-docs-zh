# v0.91.5
## 💡 主要亮点

*   我们现在提供无需 Docker 即可在 Linux ARM 上运行服务器的二进制文件（例如在 Raspberry Pi 上，感谢 @perfectra1n）。
*   [引入地图笔记类型](https://github.com/TriliumNext/Notes/pull/1017)
*   通过 @pano9000 和 @perfectra1n 增加了通过环境变量设置 Trilium 配置变量的功能
*   移动端进行了相当多的改进（**静候错误报告**）
    *   在移动端，现在强制使用水平布局（启动器栏显示在屏幕顶部而非左侧）。
        *   这为笔记内容提供了更多空间，并简化了移动端布局。
    *   启动栏也已移至底部，以符合现代应用程序布局。
    *   将树重构为侧边栏，可通过标题栏左侧的按钮触发。
    *   侧边栏也可以通过从屏幕左侧向右滑动来触发。_由于 iOS 和 Android 奇怪的后退按钮手势，仍有一些问题需要解决_。
    *   改进了底部栏和编辑器工具栏的定位。
    *   已启用标签页。目前我们使用与桌面端相同的实现，在移动端可能会有一些小问题。
    *   “跳转到笔记”功能现已可用。
    *   移动端视图现在拥有自己的启动器栏配置及其自己的启动器栏按钮。目前仅启用了少数几个。**如果您需要桌面端的任何按钮，请随时提出请求。**
    *   现在可以在 CKEditor 中插入脚注，这要归功于 [ThomasAitken/ckeditor5-footnotes](https://github.com/ThomasAitken/ckeditor5-footnotes) 的一个分支。
    *   也可以在文本笔记中创建内联 Mermaid 图表。
*   启动器栏现在可以放置在屏幕顶部而非左侧，并带有全宽的标签栏。有关更多信息，请参见 [#654](https://github.com/TriliumNext/Notes/pull/654)。
*   [@adoriandoran 和 @eliandoran 引入了一个名为 “TriliumNext” 的新主题](https://github.com/TriliumNext/Notes/pull/661)。此主题上的设置现在以卡片布局显示。重新设计了树操作按钮。
*   [原生标题栏按钮](https://github.com/TriliumNext/Notes/pull/702) 在 Windows 和 macOS 上关闭原生标题栏时可用。
*   在 Windows 上，如果运行在 Windows 下，TriliumNext 主题具有窗口透明效果，请参见 [Mica（Windows 透明效果）](https://github.com/TriliumNext/Notes/pull/717) 查看截图。不幸的是，它受到 Electron（我们用于桌面应用程序的库）的一些错误困扰，请参阅链接了解更多信息。
*   更新了 Docker 构建到 Node 22。**请留意任何潜在问题，尤其是对于测试较少的平台，如 ARM。**
