# 全局菜单

全局菜单用于配置当前窗口（缩放、保持窗口置顶）、切换主题，并提供对更多高级选项的访问。

![](Global%20menu_image.jpg)

## 访问全局菜单

请参阅[垂直与水平布局](Vertical%20and%20horizontal%20layout.md)，因为全局菜单的位置会根据所选布局而变化。

## 切换主题

_主题_子菜单无需打开<a class="reference-link" href="Options.md">选项</a>即可更改应用程序的外观。行末的勾选标记表示当前生效的选择。

*   在_配色方案_下，选择_跟随系统_以跟随操作系统的浅色或深色模式，或选择_浅色_或_深色_以强制使用其中一种。
*   在_主题_下，选择_现代_（默认主题）或某个自定义主题，每个自定义主题都会显示其笔记的图标。切换到_现代_会保留当前的配色方案。

自定义主题自带配色，因此在启用某个自定义主题时，配色方案不可用。旧版主题不会列出；请改为从<a class="reference-link" href="Options.md">选项</a> → _外观_中选择它。

有关内置主题和自定义主题的更多信息，请参阅<a class="reference-link" href="../Themes.md">主题</a>。
