# 排序
> [!IMPORTANT]
> 对选区进行排序是实验性功能，会随着功能成熟而发生变化。要使用它，请在<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _高级_ → _实验性选项_ 中开启 _在文本编辑器中排序选区_。

Trilium 可以对文本笔记中列表的条目、一组段落或表格的行进行排序，并按数值比较数字、日期和时间。

## 排序

*   要排序，请将光标放在列表或表格中，或选中要排序的段落，然后按<a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a>中的 <span class="tn-icon bx bx-sort-alt-2"></span> _排序_ 按钮以升序排序。其旁边的箭头提供 _升序_ 和 _降序_。使用浮动工具栏时，该按钮位于块级弹出菜单中。
*   当选区涵盖多个段落、列表项或表格单元格时，相同的选项也出现在块手柄菜单（块左侧的一串圆点）的子菜单中，就在 _删除块_ 上方，以及选区的右键菜单中。该子菜单以其排序对象命名：_排序块_、_排序列表项_ 或 _排序行_。
*   在<a class="reference-link" href="../../Installation%20%26%20Setup/Mobile%20Frontend.md">移动端前端</a>上，该按钮位于工具栏的主行以及 _列表 ›_ 按钮所在的行中。

排序可以用 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 撤销。

## 排序的对象

*   **列表项**：当光标位于列表中时，会对其所在层级的条目进行排序。嵌套条目会随其所属条目一起移动，并保持自身的顺序。若要只对部分条目排序，请选中它们。
*   **段落和其他块**：选中两个或更多段落、标题、引用、可折叠块或图片。每个块按其第一段文本排序：可折叠块按其标题，引用按其第一段，图片按其说明文字。将列表与其他块混合的选区无法排序。
*   **表格行**：行按光标所在的列排序，如<a class="reference-link" href="Tables.md">表格</a>中 _排序行_ 所述。在表格单元格内，会对列表或多个选中的段落进行排序，而不是对行排序。

值的比较方式与表格行相同，参见<a class="reference-link" href="Tables.md">表格</a>中的 _如何比较值_。

## 限制

*   代码块的行，或用 <kbd>Shift</kbd>+<kbd>Enter</kbd> 拆分的段落中的各行，不会逐行排序。<a class="reference-link" href="../Code.md">代码</a>笔记可以对其行进行排序，参见其中的 _转换文本_。
