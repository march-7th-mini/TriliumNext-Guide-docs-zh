# 保存状态指示器
<img class="image-style-align-right" src="Save status indicator_image.png" width="168" height="47">在笔记标题右侧，对文档进行更改后会临时显示一个指示器，显示文档是否已保存。

它表示以下状态：

*   <span class="tn-icon bx bx-pencil"></span> _未保存_，如果更改即将被保存。
*   <span class="tn-icon bx bx-loader"></span> _保存中_，如果更改正在被保存。
*   <span class="tn-icon bx bx-check"></span> _已保存_，如果所有更改已成功保存到服务器。
*   <span class="tn-icon bx bx-error"></span> _错误_，如果更改无法保存，例如由于与服务器通信失败。

在所有更改保存完成后，指示器将在几秒后自动隐藏。
