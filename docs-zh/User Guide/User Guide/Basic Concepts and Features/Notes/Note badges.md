# 笔记徽章
笔记徽章显示在固定笔记标题附近，用于指示笔记的重要信息，例如是否为只读。部分徽章还支持交互。

<figure class="image"><img style="aspect-ratio:910/49;" src="Note badges_image.png" width="910" height="49"></figure>

可用的徽章如下：

*   <span class="tn-icon bx bx-lock-alt"></span> **只读徽章**，当笔记因自动只读或手动只读而不可编辑时显示。点击该徽章可临时编辑笔记。
*   <span class="tn-icon bx bx-share-alt"></span> **共享徽章**，表示当前笔记已共享。该徽章还会指示共享是在本地网络（未设置<a class="reference-link" href="../../Installation%20%26%20Setup/Synchronization.md">同步</a>的桌面应用）还是可公开访问（服务器）。
*   <span class="tn-icon bx bx-globe"></span> **网页剪藏徽章**，表示笔记是否通过<a class="reference-link" href="../../Installation%20%26%20Setup/Web%20Clipper.md">网页剪藏器</a>剪藏。该徽章充当链接，可点击导航到页面，或右键点击查看更多选项。
*   <span class="tn-icon bx bx-play"></span> **执行徽章**，用于具有执行按钮或描述的[脚本](../../Scripting.md)或[保存的 SQL 查询](../../Advanced%20Usage/Database/Manually%20altering%20the%20database/SQL%20Console.md)。
*   对于<a class="reference-link" href="../Active%20content.md">活动内容</a>（例如脚本、样式），将显示一个专用徽章，指示笔记类型，并提供轻松启用或禁用的选项。
