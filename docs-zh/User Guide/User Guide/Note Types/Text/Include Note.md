# 包含笔记

文本笔记可以将另一条笔记“包含”为只读小组件或交互式小组件，具体取决于笔记的类型。

这对于例如包含动态生成的图表（来自脚本和“渲染 HTML”笔记）或其他更高级的用例非常有用。

## 包含一条笔记

在 <a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a> 中，找到 <span class="tn-icon cke cke-trilium-note"></span> 按钮。它也有一个键盘快捷键，但默认未分配。

要包含一条已经链接的笔记，在正在编辑的文本笔记中右键点击指向它的引用链接，然后选择菜单末尾的 _将链接转换为包含的笔记_。包含框会获得适合该笔记的框大小，与通过按钮添加的包含框一样。

[附件](../../Basic%20Concepts%20and%20Features/Notes/Attachments.md) 也可以用同样的方式包含，从指向它的链接的上下文菜单中操作（参见其中的 _嵌入附件_）。

指向文本笔记块的链接也会以同样的方式转换，使用 _将链接转换为笔记摘录_，然后包含框只显示那些块。参见 <a class="reference-link" href="Block%20references.md">块引用</a>。

## 框大小

框大小决定了包含的笔记显示多少内容。

*   _极小_ 显示单行而非内容：笔记的图标、其标题以及上方指向该笔记的路径，还有用于操作该笔记的按钮。包含的笔记永远不会被渲染，因此无论笔记在编辑器之外何处显示，例如在打印、工具提示或共享页面中，_极小_ 包含框都会显示为指向被包含笔记的链接。
*   _小_ 和 _中_ 在有限高度的框中显示内容。文本在框内滚动，而图片、图表或视频会缩小以适应框。
*   _完整_ 显示全部内容。
*   _可展开_ 仅显示标题，直到按下其 <span class="tn-icon bx bx-chevron-right"></span> 箭头。

新建的包含框会获得适合其显示内容的尺寸：

*   对于没有预览的笔记或附件（如关系图或归档），使用 _极小_。
*   对于音频，使用 _小_。
*   对于代码笔记或代码文件（如 `.js`、`.py` 或 `.txt` 附件），以及文本笔记块的摘录，使用 _完整_。
*   对于其他任何内容，使用 _中_。

包含笔记的对话框在选定笔记后会选择该尺寸，你也可以在其中选择其他尺寸。要稍后更改尺寸，选中包含框并使用其工具栏中的 _框大小_ 菜单，或使用其 _更多操作_ 菜单中的 _大小_ 子菜单。

## 调整大小

_小_、_中_ 或 _可展开_ 的包含框可以调整为任意宽度和高度。_极小_ 或 _完整_ 的包含框始终适应其内容。

*   要调整包含框的大小，选中它并拖动其右下角的手柄。要仅更改宽度或仅更改高度，请改为拖动其右边缘或下边缘的中间位置，触摸屏在那里也会显示手柄。在从右到左的文本中，手柄位于左下角，宽度从左边更改。
*   调整大小可使用鼠标、触控笔或手指。
*   当高度变化时，将手柄移到笔记的顶部或底部附近会滚动笔记。
*   比笔记窄的包含框会居中，因此更改其宽度会移动其两侧。将其设为与笔记一样宽会恢复为全宽。
*   要取消调整大小，在松开手柄前按 <kbd>Esc</kbd>。
*   要重置大小，双击角手柄，或在触摸屏上双击它。双击右边缘或下边缘仅重置宽度或高度。
*   选择框大小会重置高度。选择 _极小_ 或 _完整_ 也会重置宽度。
*   当 _可展开_ 包含框处于折叠状态时，只能更改其宽度。

## 题注

包含框可以有题注，居中显示在其框的底部。题注是文本笔记的一部分，因此可以像其余文本一样格式化，例如加粗或添加链接。

*   要添加题注，选中包含框，按下其工具栏中的 <span class="tn-icon cke cke-caption"></span> _切换题注开启_ 按钮，然后输入题注。
*   要移除题注，再次按下同一按钮。再按一次会恢复其原有文本，只要笔记保持打开状态。
*   _极小_ 包含框没有题注。将包含框切换为 _极小_ 会移除其题注，将其切换回较大尺寸会恢复题注，只要笔记保持打开状态。
*   _可展开_ 包含框在内容折叠时在标题下方显示题注，展开后在内容下方显示。

## 标题

包含框的标题行链接到被包含的笔记，并容纳其按钮。要仅显示内容，选中包含框并按下其工具栏中的 <span class="tn-icon bx bx-window-alt"></span> _显示标题_ 按钮。再次按下会显示标题。

*   当标题隐藏时，包含框工具栏中的 <span class="tn-icon cke cke-three-vertical-dots"></span> _更多操作_ 按钮会打开被包含笔记的菜单。
*   _极小_ 或 _可展开_ 包含框始终显示其标题，其工具栏没有 _显示标题_ 按钮。

## 打开被包含的笔记

要在新标签页中打开被包含的笔记，按下其标题末尾的 <span class="tn-icon bx bx-link-external"></span> _在新标签页中打开_ 按钮。嵌入的附件也有相同的按钮。

标题行末尾的 <span class="tn-icon bx bx-dots-vertical-rounded"></span> _更多操作_ 按钮会打开与右键点击标题行任意位置相同的菜单：其他打开笔记的位置，以及对于嵌入附件，对附件的操作。

在正在编辑的笔记中，该菜单还包含包含框工具栏的命令：_大小_ 子菜单、_显示标题_ 和 _显示题注_（生效时各自带有勾选标记），以及末尾的 _转换为链接_。绘图画布、包含的文本或代码笔记以及嵌入的代码文件在 _大小_ 上方还有 _可编辑_。对于嵌入附件，它们跟随其第一组操作；对于包含的笔记，它们位于菜单末尾。

要在整个屏幕上显示 _中_ 或 _完整_ 尺寸的包含框，按下其标题末尾的 <span class="tn-icon bx bx-fullscreen"></span> _全屏_ 按钮。笔记块的摘录在那里有一个 <span class="tn-icon bx bx-pencil"></span> _编辑摘录_ 按钮；参见 <a class="reference-link" href="Block%20references.md">块引用</a>。要返回，按下右上角的 <span class="tn-icon bx bx-exit"></span> _退出全屏_，或按 <kbd>Esc</kbd>。

_极小_ 包含框则有以下按钮，后面跟着相同的 _更多操作_ 按钮：

*   对于笔记，<span class="tn-icon bx bx-edit"></span> _快速编辑_ 在 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Navigation/Quick%20edit.md">快速编辑</a> 中打开笔记，<span class="tn-icon bx bx-link-external"></span> _在新标签页中打开_ 在新标签页中打开它。
*   对于嵌入附件，<span class="tn-icon bx bx-file-find"></span> _在外部打开_ 在其他应用程序中打开文件，<span class="tn-icon bx bx-download"></span> _下载_ 下载它。文件的大小显示在其标题下方。

## 将包含框转换为链接

要用指向被包含笔记的链接替换包含框，选中它并按下其工具栏中的 <span class="tn-icon cke cke-link"></span> _转换为链接_ 按钮，或选择其 _更多操作_ 菜单末尾的 _转换为链接_。嵌入的附件也会以同样的方式变为指向该附件的链接。

## 共享功能中的被包含笔记

如果 [共享笔记](../../Advanced%20Usage/Sharing.md) 包含一个或多个被包含的笔记，它们将显示在笔记内容中，就像它们是笔记本身的一部分一样。包含框的题注显示在被包含内容的下方。_极小_ 包含框则显示为指向被包含笔记的链接，对于会显示其周围已显示的笔记的包含框也是如此，例如包含自身的笔记。打印或导出的笔记也是如此。

为此，被包含的笔记也必须被共享，否则它们将不会显示。但是，被包含的笔记仍然可以通过 `#shareHiddenFromTree` 从笔记树中隐藏。

## 交互式笔记

自 v0.104.0 起，被包含的笔记可能会根据其笔记类型变为交互式：

*   <a class="reference-link" href="../../Collections.md">集合</a>（例如 <a class="reference-link" href="../../Collections/Geo%20Map.md">地理地图</a>）将完全交互式渲染，包括创建新笔记。
*   <a class="reference-link" href="../Saved%20Search.md">保存的搜索</a> 也会显示结果。
*   <a class="reference-link" href="../Web%20View.md">网页视图</a> 提供网站的交互式预览。

## 包含的图片

包含的图片，无论是图片笔记还是图片附件，都显示在图片查看器中，可以缩放和平移：

*   要缩放，按下图片右下角的 <span class="tn-icon bx bx-plus-circle"></span> _放大_ 和 <span class="tn-icon bx bx-minus-circle"></span> _缩小_ 按钮，或在触摸屏上双指捏合。它们之间的百分比可重置缩放。
*   要用鼠标滚轮缩放，请先点击图片。在此之前，鼠标滚轮会滚动笔记。
*   要平移已放大的图片，请拖动它。在其适应尺寸下，在触摸屏上拖动图片会滚动笔记。
*   要返回适应尺寸，双击图片。

在 _小_ 或 _中_ 框中，图片会缩小以适应框的高度。在全屏中，它适应屏幕。

## 就地编辑包含框

包含的文本笔记、包含的代码笔记以及嵌入的代码文件（如 `.js`、`.py` 或 `.txt` 附件）可以在不离开包含它们的笔记的情况下进行编辑。在此之前，代码笔记或文件会以语法高亮显示。

*   要编辑，选中包含框并打开其工具栏开头的 <span class="tn-icon bx bx-edit-alt"></span> _可编辑_ 按钮，或在其 <span class="tn-icon cke cke-three-vertical-dots"></span> _更多操作_ 菜单中勾选 _可编辑_。关闭 _可编辑_ 可返回预览。
*   当包含的文本笔记获得焦点时，格式工具栏会应用于它。它依次包含的笔记则保持只读。
*   代码在与 <a class="reference-link" href="../Code.md">代码</a> 笔记相同的代码编辑器中编辑，使用其主题、缩进和自动换行设置。
*   更改会在你输入时保存到被包含的笔记或附件中，就像在它们自己的标签页中一样。
*   对 <a class="reference-link" href="Block%20references.md">块引用</a> 的包含框仅编辑被引用的块。
*   在 [只读笔记](../../Basic%20Concepts%20and%20Features/Notes/Read-Only%20Notes.md) 中、对于标记为 `#readOnly` 的被包含笔记，或对于另一条笔记的附件，编辑不可用。

## 绘图画布

绘图画布是一个 Excalidraw 画布，类似于 <a class="reference-link" href="../Canvas.md">画布</a> 笔记的画布，直接在文本笔记中绘制。它不是一条独立的笔记：绘图保存在文本笔记的 `Canvas.excalidraw` [附件](../../Basic%20Concepts%20and%20Features/Notes/Attachments.md) 中，并与文本一起保存。

*   要插入绘图画布，打开 <a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a> 的 <span class="tn-icon cke cke-plus"></span> _插入_ 菜单，选择 <span class="tn-icon bx bx-pen"></span> _绘图画布_，位于 _Mermaid 图表_ 上方。它也可以在 <a class="reference-link" href="Slash%20Commands.md">斜杠命令</a> 中作为 _绘图画布_ 使用。画布以空白且可编辑的状态添加，位于隐藏标题的 _中_ 框中，并获得焦点，准备好绘图。
*   要在没有焦点的画布上绘图，请先点击它。在此之前，鼠标滚轮和触摸手势会滚动笔记。然后画布具有画布笔记的工具、菜单和键盘快捷键。工具栏、菜单和所选形状的属性仅在画布有焦点时显示，因此在其他地方，绘图读起来就像文本中的图片。
*   新绘图具有笔记的背景颜色。从 Excalidraw 菜单中选择的背景会替换它。
*   要保护已完成的绘图免受意外更改，选中它并关闭其工具栏开头的 <span class="tn-icon bx bx-edit-alt"></span> _可编辑_ 按钮，或在其 <span class="tn-icon cke cke-three-vertical-dots"></span> _更多操作_ 菜单中取消勾选 _可编辑_。然后绘图可以平移和缩放但不能更改，其工具栏仅包含缩放按钮。要再次绘图，请重新打开 _可编辑_。
*   框大小、调整大小、题注和标题的工作方式与包含的笔记相同，但绘图工具栏将框大小、_显示标题_ 和 _转换为链接_ 留给其 _更多操作_ 菜单。
*   在桌面布局中，无论框多小，Excalidraw 都保持其桌面界面。在移动布局中，窄或短的框会将其切换为紧凑界面。要获得更多空间，选择 _完整_，或显示标题并按下 <span class="tn-icon bx bx-fullscreen"></span> _全屏_。
*   添加到绘图中的图片存储在同一附件中。
*   在 [只读笔记](../../Basic%20Concepts%20and%20Features/Notes/Read-Only%20Notes.md) 中，绘图可以查看但不能更改。

### 限制

*   Excalidraw 形状库不会为绘图画布保存。
*   在编辑器之外，例如在工具提示中、打印时或附件列表中，绘图显示为图片。在 [共享页面](../../Advanced%20Usage/Sharing.md) 上，它显示为下载 `Canvas.excalidraw` 的链接。
*   粘贴到同一笔记中的绘图画布副本与原始绘图共享绘图，因此对其中一个的更改只有在笔记再次打开后才会显示在另一个中。粘贴到另一条笔记中的副本会获得自己的绘图。
