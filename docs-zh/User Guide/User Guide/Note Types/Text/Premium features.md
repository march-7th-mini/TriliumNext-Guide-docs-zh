# 高级功能

我们用于<a class="reference-link" href="../Text.md">文本</a>笔记的文本编辑器名为 CKEditor，它是一款商业产品。其核心组件是开源的，但[他们提供了不少功能](https://ckeditor.com/docs/trial/latest/index.html)，这些功能需要商业许可证才能使用。

我们已与 CKEditor 团队联系，以获取许可证来使用其中一些额外功能，并且基于签署的协议，他们已同意。

> [!NOTE]
> 自 v0.105.0 起，所有高级功能均被替换为专门为 Trilium 从头编写、采用 AGPL 许可证的插件。
> 
> 高级功能曾包括：
> 
> *   <a class="reference-link" href="Slash%20Commands.md">斜杠命令</a>
> *   <a class="reference-link" href="Text%20Snippets.md">文本片段</a>
> *   <a class="reference-link" href="Format%20Painter.md">格式刷</a>
