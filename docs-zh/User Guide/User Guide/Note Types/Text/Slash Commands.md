# 斜杠命令
<figure class="image image-style-align-right"><img style="aspect-ratio:419/571;" src="Slash Commands_image.png" width="419" height="571"></figure>

斜杠命令是<a class="reference-link" href="../Text.md">文本</a>笔记的一项功能，它允许仅通过键盘轻松访问常用命令，而无需记住专用的<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Keyboard%20Shortcuts.md">键盘快捷键</a>。

## 交互

*   顾名思义，要触发斜杠命令，只需按 / 键即可触发。请注意，这可以出现在段落中的任何位置，只要它不是单词的一部分即可；如果没有显示出来，只需按一下空格再按 / 键即可。
*   使用 ↑ 和 ↓ 键在选项之间导航。
*   默认情况下，会显示完整的命令列表。
*   要搜索，只需开始输入：命令可通过其标题或其其他名称找到（例如 `h2` 对应 _标题 2_）。
*   要触发高亮的操作，请按 Enter 或 Tab。
*   使用固定的<a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a>时，空段落旁边的块手柄会变成一个 <span class="tn-icon cke cke-plus"></span> 按钮。点击它会以菜单形式打开插入内容或将段落转换为其他块的命令，例如标题、列表、表格或链接，菜单顶部有一个框，可通过标题、描述或其他名称查找它们。仅更改段落的命令（例如对齐或缩进）不会出现在该菜单中。
*   <a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a>中描述的块手柄菜单以 _在上方插入_ 和 _在下方插入_ 开头，它们列出相同的命令，并将所选命令添加到块上方或下方的新段落中。在列表项旁边，用于添加空列表项的项会取代它们的位置。

## 与其他功能的集成

除了通用命令集之外，某些功能还与斜杠命令进行了特殊集成：

*   对于[警示框](Block%20quotes%20%26%20admonitions.md)，每种警示框类型（例如 note、tip）都会单独显示。
*   每个<a class="reference-link" href="Text%20Snippets.md">文本片段</a>也会单独显示，便于插入。
*   对于[链接](Links.md)，_链接到网页_、_链接到笔记（内部链接）_ 和 _链接到标题或锚点_ 会在对应页面打开 _添加链接_ 对话框。_链接到网页（带图标）_ 和 _链接到网页（作为卡片）_ 还会选择网页链接的显示方式，如<a class="reference-link" href="Link%20Previews.md">链接预览</a>中所述。
*   <a class="reference-link" href="In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>：专用的 _询问 AI_ 项以及所有预定义和[自定义快速操作](In-editor%20AI%20assistant/Custom%20AI%20quick%20actions.md)。
