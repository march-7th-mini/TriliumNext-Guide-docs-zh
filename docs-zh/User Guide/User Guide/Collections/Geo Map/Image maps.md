# 图像地图
图像地图是绘制在你自己图像上的地理地图，而不是世界地图，例如平面图、桌面游戏的奇幻地图或用于标注的示意图。标记和形状的用法与地理地图上相同，但它们的位置是在图像上测量的，而不是在经纬度上：以图像自身的像素为单位，或使用你选择的坐标系，例如电子游戏使用的坐标系。

## 创建图像地图

1.  将图像作为独立笔记上传，例如将文件拖入笔记树。支持 PNG、JPEG、WebP 和 GIF 图像；不支持 SVG 图像。
2.  创建地理地图，或打开现有的地理地图。
3.  在地理地图的属性中，添加一个指向该图像笔记的 `~map:image` [关系](../../Advanced%20Usage/Attributes/Relations.md)。

地图随后会显示该图像而不是世界地图，并在打开时显示完整图像。要返回世界地图，请移除该关系。

## 图像大小

图像在上传时会被调整大小，因此默认情况下，地图图像较长的一边最多为 2000 像素，这对于详细地图来说可能过于粗糙。要以更高分辨率保留图像，请在上传前执行以下操作之一：

*   在 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _媒体_ 中，提高 _最大图像尺寸_ 或关闭 _自动压缩图像_。
*   通过 _导入_ 对话框上传，并取消勾选 _压缩图像_。

已经上传的图像会保持其大小；更改设置后请重新上传。

图像由显卡作为单张图片绘制，这限制了它的大小。较长一边不超过 4096 像素的图像在几乎所有设备上都是安全的，大多数计算机可处理高达 16384 像素。在显卡无法容纳该图像的设备上，标记和形状仍会显示，但图像本身不会显示。

## 交互

添加、移动和移除标记、绘制形状、弹出视图和上下文菜单的用法与 <a class="reference-link" href="../Geo%20Map.md">地理地图</a> 中所述相同。相机保持在图像上方，最多可放大到超过图像自身分辨率四倍。

仅在真实地图上有意义的功能在图像地图上不可用：

*   搜索地图和在线搜索地点。
*   前往你的位置。
*   添加 GPS 轨迹。
*   点击底图显示的地点。
*   3D 建筑。
*   在外部地图应用中打开位置。

标记标题的外观跟随图像：如果图像较暗，请为地理地图添加 `#map:darkStyle` 标签，以便标题以浅色绘制。

## 选择坐标系

默认情况下，位置以图像原始大小的像素为单位，从图像左上角开始测量，`x` 向右增长，`y` 向下增长。

要改用你自己的坐标，请为地理地图添加 `#map:imageBounds` 标签，以 `x,y x,y` 的形式命名图像左上角和右下角的坐标，两个角之间用空格分隔。此后所有位置都以这些坐标读取和写入，包括上下文菜单和弹出视图中显示的位置。例如：

*   一张游戏地图的截图，其 `x` 从 -512 到 512，`y` 从 -512 到 512，且 `y` 向下增长：`#map:imageBounds=-512,-512 512,512`。从游戏中复制的坐标随后可以直接粘贴到 `#mapPosition` 中。
*   一个 `y` 向上增长、原点位于图像中心的世界：`#map:imageBounds=-2000,1000 2000,-1000`。左上角的 `y` 大于右下角的 `y` 即可翻转该轴。
*   以米为单位的平面图：`#map:imageBounds=0,0 24,12`。

两个轴不必使用相同的比例。圆始终以地图自身的单位测量，因此当两个轴上的单位被拉伸得不同时，它会显示为椭圆。

无法读取的值，或两个角的 `x` 或 `y` 相同的值，将被忽略，转而使用图像的像素。

## 坐标标尺

在集合属性中启用 _显示比例尺_ 会沿图像边缘绘制标尺，而不是距离比例尺。地图坐标的整数值会沿四条边用刻度标记，并沿顶部和左侧标注，同时图像上会显示淡淡的网格线。间距跟随缩放级别，数值在设置了 `#map:imageBounds` 时跟随该值。

标尺绘制在图像本身上，因此放大时它们会随图像边缘一起移出视野。网格线在图像上仍然可见。

## 位置如何存储

由于位置存储在与地理地图不同的标签中，同一个笔记可以同时放置在地理地图和图像地图上。

| 标签 | 内容 |
| --- | --- |
| `#mapPosition` | 标记的位置，格式为 `x,y`，例如 `#mapPosition=320,145`。 |
| `#mapShape` | 形状，格式与 `#geoShape` 相同（参见 <a class="reference-link" href="Drawing%20shapes.md">绘制形状</a>），但使用 `x,y` 对，圆的半径以地图的单位表示，例如 `#mapShape=circle:400,300 50`。 |

位置属于坐标系，而不属于图像。当用另一张图像替换该图像时，例如更高分辨率的副本，请保持 `#map:imageBounds` 描述新图像所覆盖的区域，这样每个标记都会留在原位。如果没有 `#map:imageBounds`，位置就是像素，因此不同大小的图像会使标记相对于图像所显示的内容发生移动；为避免这种情况，请在替换前将 `#map:imageBounds` 设置为旧图像的大小（`0,0 <width>,<height>`）。

> [!TIP]
> 要在图像上自由绘制而不是在其上放置笔记，请考虑使用 <a class="reference-link" href="../../Note%20Types/Canvas.md">画布</a>。
