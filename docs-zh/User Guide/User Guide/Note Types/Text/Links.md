# 链接

链接有两种类型：

*   <a class="reference-link" href="Links/External%20links.md">外部链接</a>，用于指向网站或其他资源的标准超链接。
*   <a class="reference-link" href="Links/Internal%20(reference)%20links.md">内部（引用）链接</a>，用于指向 Trilium 内其他笔记的链接。
    *   引用特定笔记的笔记列表称为<a class="reference-link" href="Links/Backlinks.md">反链</a>。

## 链接对话框

_添加链接_ 对话框为每种链接类型各有一个页面，在顶部进行选择：_网页_、_笔记_，以及在文本笔记中的 _标题 / 锚点_。每个页面都会保留你在其中输入的内容，即使你切换到另一个页面。_插入链接_（更改链接时为 _保存链接_）只会创建当前显示页面上的链接。
