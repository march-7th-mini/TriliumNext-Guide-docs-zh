# 面包屑导航
<figure class="image"><img style="aspect-ratio:1150/27;" src="Breadcrumb_image.png" width="1150" height="27"></figure>

面包屑导航允许快速查看当前笔记的笔记层级结构并在其中导航。

它是<a class="reference-link" href="Status%20bar.md">状态栏</a>的一部分，显示在屏幕的左下角。

## 布局与交互

*   如果某个笔记或工作区被提升，最左侧会显示一个徽章。
    *   点击该徽章将取消提升该笔记/工作区。
*   最左侧的图标代表根笔记，或被提升的笔记或工作区。
    *   点击该图标将跳转到根笔记。
    *   右键点击该图标将显示一个菜单，允许在新标签页、分屏等中打开该笔记。
*   每个片段显示当前笔记层级中某个笔记的标题。
    *   点击该图标将跳转到该笔记。
    *   右键点击将打开一个包含多个选项的菜单，例如在不同标签页/分屏/窗口中打开笔记、提升、移动/克隆笔记、创建副本以及更改笔记颜色。
*   点击每个片段旁边的箭头将显示该片段左侧的子笔记。
    *   点击某个图标将导航到该特定笔记。
    *   也可以从这里创建新的子笔记。
    *   该菜单可以选择隐藏已归档的笔记。
*   如果当前笔记位于层级结构的深处，片段将折叠为一个 \[…\] 按钮，以避免占用过多空间。
    *   点击此按钮将把每个折叠的条目显示为菜单项。点击某个菜单项将导航到该特定笔记。
*   右键点击面包屑导航右侧的空白区域（在其他状态栏项目之前）将显示另一个菜单，允许：
    *   切换是否在面包屑导航和笔记树中显示已归档的笔记。
    *   将当前笔记路径复制到剪贴板。
