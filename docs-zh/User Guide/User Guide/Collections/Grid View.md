# 网格视图
<figure class="image"><img style="aspect-ratio:990/590;" src="Grid View_image.png" width="990" height="590"></figure>

此视图以网格形式呈现子笔记，提供更具视觉化的导航体验。

每个磁贴包含：

*   笔记的标题。
*   内容片段。
*   对于空笔记，还会显示其子笔记，便于快速导航。

根据笔记类型的不同：

*   对于<a class="reference-link" href="../Note%20Types/Text.md">文本</a>笔记，可通过鼠标滚轮略微滚动文本以显示更多内容。
*   对于<a class="reference-link" href="../Note%20Types/Code.md">代码</a>笔记，会应用语法高亮，并像编辑器一样显示行号。
*   对于<a class="reference-link" href="../Note%20Types/File.md">文件</a>笔记，音频、视频和 PDF 笔记会提供预览。
*   如果笔记没有内容，则会改为显示其子笔记列表。

网格视图也是每个笔记的<a class="reference-link" href="../Basic%20Concepts%20and%20Features/Notes/Note%20List.md">笔记列表</a>默认使用的视图，便于导航到子笔记。

### 创建新表格

在<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a>中右键点击现有笔记，然后选择 _插入子笔记_ → _集合_ → _网格视图_。

## 配置

与大多数其他视图类型不同，网格视图实际上不可配置。
