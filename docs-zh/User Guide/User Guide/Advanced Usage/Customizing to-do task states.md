# 自定义待办任务状态

Trilium 支持自定义待办列表的任务状态。要自定义这些状态，请前往 <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _文本笔记_ → _相关设置_ → _待办列表的自定义复选框状态_。或者，在可编辑的文本笔记中右键点击复选框，然后点击铅笔图标；在<a class="reference-link" href="../Installation%20%26%20Setup/Mobile%20Frontend.md">移动端前端</a>上，铅笔图标位于待办列表的 _列表 ›_ 按钮所在行中。

> [!WARNING]
> 更改仅在重启应用程序后生效。

## 创建新的任务状态

点击左侧窗格中“任务状态”旁边的加号图标，然后按照下一节所述定义任务详情。

## 编辑任务状态

从侧边窗格中选择除“无”和“完成”之外的任何状态（这两个状态无法修改），会显示以下可编辑字段：

*   _图标_（必填）：显示在复选框内的符号。你可以像为任何普通笔记选择图标一样选择图标，包括从自定义图标包中选择。
*   _标题_（必填）：UI 中显示的任务状态名称。例如：“进行中”、“已推迟”。
*   _标识符_（必填）：状态的简短名称，只能使用字母、数字、“`-`”和“`_`”。它作为元数据存储在笔记的标记中，用于标识任务状态。两个任务状态不能共享相同的标识符。  
    请为自定义任务状态的标识符添加下划线“`_`”或连字符“`-`”前缀，以避免与 Trilium 未来版本中可能引入的任务状态发生冲突。
*   _Markdown 符号_：用于在 Markdown 语法中表示该状态的单个字符。例如，“`#`”会创建一个任务状态，可以在 Markdown 中使用“ `- [#]` ”来应用。请确保没有其他任务状态使用相同的符号。
*   _计为已完成_：如果勾选，该任务将被视为已完成。
*   _颜色_：复选框的颜色。其亮度和饱和度会自动调整，以匹配当前配色方案或主题。
*   _从工具栏隐藏_：该状态不会在 UI 中列出。当你希望现有笔记继续正确渲染该状态，但不再需要自己应用它时，这很有用。

> [!NOTE]
> 任务定义详情会在启动时进行验证。如果发现错误，会通过提示消息提供详细信息，并且受影响的任务定义将被忽略。

## 重新排序任务状态

要更改任务状态在 UI 中出现的顺序以及使用键盘循环切换时的顺序，只需在侧边窗格（或树面板，如果适用）中重新排列这些状态即可。

## 删除任务状态

除“无”和“完成”之外的任何任务状态都可以删除。

删除后，使用该状态的待办项将不再显示自定义复选框。它们会根据该状态的“计为已完成”设置回退到“无”或“完成”状态。标识符和标题会保留在笔记中，直到你将复选框设置为新的状态。

## 在 Trilium 数据库实例之间传输带有自定义任务状态的笔记

将笔记导出到另一个 Trilium 数据库实例会保留待办项的任务状态，但不会包含自定义任务定义。因此，除非你在目标实例中使用相同的标识符和 Markdown 符号重新创建该任务状态，否则目标实例将不知道如何渲染该复选框。

> [!NOTE]
> 这是当前版本的一个已知限制。如果社区对更轻松地在 Trilium 数据库实例之间传输笔记有足够兴趣，Trilium 团队可能会考虑更好的状态定义机制。
