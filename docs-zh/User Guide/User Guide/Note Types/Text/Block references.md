# 块引用

块引用是指向文本笔记中某个块的[链接](Links.md)，例如段落、标题、列表项或表格，也可以指向一段连续的块。块引用可以作为链接粘贴到另一篇笔记中，也可以转换为<a class="reference-link" href="Include%20Note.md">包含笔记</a>，仅显示被引用的块。

## 复制引用

1.  将光标置于要引用的块中。要引用多个连续的块，请选中它们。
2.  右键点击块手柄（即块左侧的一串圆点，参见<a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a>），然后选择 _复制引用_。使用固定格式工具栏时，点击块手柄会打开相同的菜单。或者，右键点击文本，在 _复制_ 子菜单中选择 _复制指向此块的引用_，若为选中内容则选择 _复制指向这些块的引用_。被引用的块会短暂闪烁。
3.  转到要插入链接的笔记，按 <kbd>Ctrl</kbd>+<kbd>V</kbd>。

在<a class="reference-link" href="Content%20tabs.md">内容标签页</a>块内部，引用指向整个块。要链接到单个标签页，请改用标签页块的 <span class="tn-icon cke cke-three-vertical-dots"></span> _更多操作_ 菜单中的 _复制指向此标签页的引用_。在<a class="reference-link" href="Multicolumn%20layout.md">多栏布局</a>内部，引用指向该栏中的块，而包含笔记会显示这些块，但不包含其周围的布局。

链接显示笔记的标题，后跟被引用文本的开头部分。指向同一笔记中块的链接仅显示被引用文本的开头部分，而指向同一笔记中标题的链接则显示整个标题。

如果笔记已[共享](../../Advanced%20Usage/Sharing.md)，块手柄的菜单还会提供 _复制公开链接_。它会复制共享页面的网址并附加该引用，以便发送给在 Trilium 之外阅读该笔记的人。打开该地址会将共享页面滚动到被引用的块并使其闪烁。在共享页面上，指向另一篇共享笔记中块的链接也会执行相同的操作。

右键菜单的 _粘贴_ 子菜单提供了另外两种插入已复制引用的方式：

*   _将引用粘贴为链接_ 仅插入链接，即使引用是以纯文本形式或连同其他内容一起复制的。
*   _将引用粘贴为摘录_ 插入被引用块的包含笔记，如下所述。

在浏览器中，文本编辑器的右键菜单仅在右键点击选中文本时才会打开。在其他位置，浏览器会显示其自身的菜单。

## 链接到标题

自 v0.107.0 起，可以从 _添加链接_ 对话框创建指向同一笔记中标题的链接：

*   将光标置于链接的所需位置，或选中要转换为链接的文本。
*   按 <kbd>Ctrl</kbd>+<kbd>K</kbd> 或<a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a>中的 <span class="tn-icon cke cke-link"></span> 按钮，然后在对话框顶部选择 _标题 / 锚点_。或者，在<a class="reference-link" href="Slash%20Commands.md">斜杠命令</a>中选择 _链接到标题或锚点_，这会在该页面打开对话框。
*   在 _标题_ 下，点击所需的标题以将其勾选。子标题列在其父标题下，默认处于折叠状态；使用标题前的箭头展开或折叠标题，或在标题获得焦点时使用 <kbd>→</kbd> 和 <kbd>←</kbd>。可选地，输入 _链接标题_。
*   按 <kbd>Enter</kbd> 或 _插入链接_ 以确认。

未设置链接标题时，链接显示标题的文本。如果标题发生更改，在你停止输入后不久，链接会自动重命名为新文本。带有自身标题的链接会保留该标题。

该链接是指向该标题的块引用，因此当标题移动时它仍然有效。要更改链接，请点击它并在其弹出窗口中按 <span class="tn-icon cke cke-pencil"></span> _编辑链接_ 按钮。对于带有自身标题的链接，将光标置于其中并按 <kbd>Ctrl</kbd>+<kbd>K</kbd> 也可以。对话框会在 _标题 / 锚点_ 页面打开，并勾选该标题。在此处清空 _链接标题_ 会使链接再次显示标题的文本。

## 跟随引用

点击块引用会打开笔记，滚动到被引用的块并使其闪烁。如果被引用的块已被删除，则会改为显示错误消息，并列出该范围中仍然存在的块。

指向链接所在笔记中块的链接（例如指向标题的链接）会滚动到这些块并使其闪烁，而不会离开该笔记，就像网页内的链接一样。这在只读笔记和共享页面上同样有效。在编辑时，点击链接会显示其弹出窗口：在其中按 _跳转到标题_，对于其他块则按 _跳转到块_。

## 包含被引用的块

要在另一篇笔记中显示被引用的块，请在正在编辑的笔记中右键点击该链接并选择 _将链接转换为笔记摘录_，或使用 _粘贴_ → _将引用粘贴为摘录_ 粘贴已复制的引用。包含笔记仅显示被引用的块，而不显示笔记的其余部分，并在其标题中用 _摘录_ 徽章标记它们。它初始为 _完整_ 框大小，因此所有被引用的块都可见。要查看整篇笔记，请按同一标题中的 <span class="tn-icon bx bx-link-external"></span> 按钮，这会在新标签页中打开该笔记。将包含笔记转换回链接会保留该引用。

要在不离开笔记的情况下编辑被引用的块，请按包含笔记标题中的 <span class="tn-icon bx bx-pencil"></span> _编辑摘录_ 按钮，或在其工具栏中打开 _可编辑_（<span class="tn-icon bx bx-edit-alt"></span>），与任何<a class="reference-link" href="Include%20Note.md">包含笔记</a>一样。再次按该按钮可停止编辑。更改会保存到被引用的块中，笔记的其余部分保持不变。在无法编辑块的地方（例如只读笔记中），该按钮会灰显。摘录没有 _全屏_ 按钮。

如果被引用的块已被删除，包含笔记会显示 _引用已损坏_。

## 限制

*   引用只能从正在编辑的笔记中复制，且在移动端布局中不可用。
*   仅覆盖列表或引用的一部分的范围（例如从其第二项到其后的一个段落）的包含笔记无法就地编辑。
*   删除块会破坏指向它的引用。
*   导出为 Markdown 时不会保留块引用。在[共享页面](../../Advanced%20Usage/Sharing.md)上，块引用会打开整篇笔记。
