## 💡 主要亮点

*   共享笔记功能改进：
    *   引入了一个新的默认主题，名为 Trilium.Rocks（最初由 @zerebos 开发），并已适配到我们的项目。该主题的新功能包括：搜索、可折叠树、浅色/深色模式、移动端适配。
    *   为代码块添加了基础语法高亮，但仅在明确指定语言时生效。
    *   笔记图标现在会显示在共享树中。
    *   数学公式现在可以在文本笔记中渲染。
