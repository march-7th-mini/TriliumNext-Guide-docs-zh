# v0.90.0-beta
**注意：** 此版本目前不面向公众使用，仅用于内部测试。原因在于它可能相当不稳定。尽管如此，如果您了解相关风险，欢迎进行测试。

### 与最新版 Trilium Notes (0.63.7) 相比有何新变化？

理论上，没有。此版本基于 Trilium Notes 0.63.7，但引入了重大的代码重构：服务器端已从 JavaScript 移植到 TypeScript。

对于最终用户而言，除了某些功能可能在此过程中出现问题外，一切应保持不变。

作为 TriliumNext 的首个版本，我们只需通过日常使用来检查是否存在任何回归问题。欢迎[报告任何问题](https://github.com/TriliumNext/Notes/issues/new/choose)。

### 我需要做什么才能开始？

对于桌面应用程序，只需从发布页面下载，并按照与安装原始 Trilium Notes 类似的方式解压即可。

关于数据，请注意 **Trilium Notes 与 Trilium Notes 共享同一个数据库。** 强烈建议手动备份数据库：

*   在 Windows 上，打开资源管理器，在地址栏输入 `%appdata%`。找到 `trilium-data` 文件夹，直接复制并粘贴即可。
*   在 Linux 上，数据目录位于 `~/.local/share/trilium-data`。

通常，您现有的笔记应该是相当安全的（没有数据库迁移或 API 变更，只有一致性检查可能受到影响），测试中未发现任何问题。

此外，由于同步版本也未更改，您应该可以在 Trilium Notes 和 Trilium Notes 之间混合使用客户端和服务器。

服务器也已打包并随发布提供。对于 Docker 构建，Docker 镜像会自动构建，并可在 GitHub 的 Docker 注册表中获取。

### 为什么是 v0.90.0

当前 [zadam/trilium](https://github.com/zadam/trilium/releases/tag/v0.63.7) 的发布版本是 0.63.7。

如果我们将版本号重置为 0.1，会有一些缺点：

*   这可能会导致迁移和更新检查出现问题。
*   TriliumNext 0.1.0 基于 Trilium 0.63.7 这一事实可能会相当令人困惑。

同时，我们不想直接跳到下一个版本，因为这会与 Trilium 未来的版本直接产生冲突。因此，我们将其提升到 0.90。
