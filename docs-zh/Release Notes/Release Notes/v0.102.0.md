## 💡 主要亮点

*   Trilium 现在支持**自定义图标包**，可用于笔记图标。更多信息和[官方图标包](https://triliumnotes.org/en/resources)列表，请参见 [图标包 - 用户指南](https://docs.triliumnotes.org/user-guide/concepts/themes/icon-packs)。
*   新布局现在在笔记标题附近提供了一个保存指示器。
*   Trilium 现在使用自己的 PDF 渲染器（基于 Mozilla 的 PDF.js 查看器）。这允许更多功能，如注释、搜索（在当前文件内）、填写表单以及记住最后阅读位置。更多信息请参见[文档](https://docs.triliumnotes.org/user-guide/note-types/file/pdf)。
*   某些集合将默认在笔记树中隐藏其子项。详情请参见[文档](https://docs.triliumnotes.org/user-guide/concepts/ui/note-tree/hiding-subtree)。
*   **jQuery 已更新至 v4.0.0，这引入了可能影响您脚本的破坏性变更。**
*   桌面应用：macOS 现在支持背景效果（Vibrancy）。

## 📱 移动端改进

*   集合现在显示“集合属性”工具栏，允许切换视图和配置集合。
*   移除了标签行，取而代之的是更像浏览器的标签切换器，以带有笔记预览的模态框形式显示。
*   标题行发生了显著变化：
    *   现在显示笔记图标，并且可以更改图标。
    *   继承了桌面端新布局的功能：笔记徽章（只读、共享）、保存指示器。
    *   图标现在应该更容易点击。
    *   新布局中文本和代码笔记的内联标题现在可用。
*   笔记操作菜单（笔记标题右侧）：
    *   桌面端新布局中可用的所有功能现在都可用，允许搜索、切换共享/模板/书签、更改笔记类型/可编辑性，甚至导入/导出/打印等功能。
    *   状态栏中的一些组件也迁移到了移动端：反链、笔记路径、附件、笔记信息、相似笔记以及文本/代码语言切换器。
    *   自定义笔记操作（特定于笔记的）也已移植，例如“运行活动笔记”、“切换只读”、“上传新修订”等按钮。
