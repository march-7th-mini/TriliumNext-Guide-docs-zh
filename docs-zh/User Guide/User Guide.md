# 用户指南
Trilium 是一个用于笔记记录和个人知识库整理的开源解决方案。你可以在桌面端本地使用它，也可以将其与自托管服务器同步，从而随时随地保留你的笔记。

> [!TIP]
> 在 Trilium Notes 应用程序内按 F1 即可访问相同的本地文档。
