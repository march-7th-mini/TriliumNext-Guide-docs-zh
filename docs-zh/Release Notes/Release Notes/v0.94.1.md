## ✨ 改进

*   geomap：GPX 轨迹线现在遵循 `#color` 属性。
*   所有键盘快捷键的描述由 @FliegendeWurst 提供
*   将代码笔记的主题更新至最新版本。
*   分享：为自定义分享模板传递 `t` 以进行翻译，并改进对无法找到笔记的错误日志记录。
*   在 Docker 上，我们现在也发布 `linux/arm/v8` 架构（功能上与 `linux/amd64` 相同），但为了兼容不同的提供商。
*   [Alt+T 快捷键的日期/时间格式可配置](https://github.com/TriliumNext/Notes/pull/2083)
*   书签改进：
    *   [单击导航](https://github.com/TriliumNext/Notes/issues/2187)
    *   将鼠标悬停在书签链接上时显示书签段落
*   [LLM 改进](https://github.com/TriliumNext/Notes/pull/2181) 由 @perfectra1n 提供
*   [文本笔记：撤销/重做后滚动到选区以保持光标可见](https://github.com/TriliumNext/Notes/pull/2197) 由 @SiriusXT 提供
