# 使用 TOTP 的多因素身份验证
多因素身份验证（MFA）是一种安全流程，要求用户提供两个或更多验证因素才能访问系统、应用程序或账户。这在仅使用密码之外增加了额外一层保护。

通过要求多种验证方式，即使有人获取了你的密码，MFA 也有助于降低未经授权访问的风险。强烈建议使用它来保护存储在笔记中的敏感信息。

## 与 OpenID Connect（OIDC）的关系

多因素身份验证通过要求除密码之外的额外身份证明，让你的 Trilium 登录更加安全。<a class="reference-link" href="Signing%20in%20with%20OpenID%20Connect.md">使用 OpenID Connect 登录</a> 是一个不同的概念，它将你的身份验证委托给外部提供方（例如你的 Google 提供方，或自托管的提供方如 Authelia）。这些身份验证提供方可能提供自己的安全功能，例如 TOTP 或通行密钥。

## 基于时间的一次性密码（TOTP）

TOTP（基于时间的一次性密码）是一项安全功能，它会在你的设备（如智能手机）上生成一个唯一的临时验证码，每 30 秒更换一次。你将此验证码与密码一起用于登录账户，使其他人更难访问你的账户。

1.  转到 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _密码与身份验证。_
2.  确保 _登录方式_ 中选择了 _本地密码_。
3.  在 _双因素身份验证_ 部分，按 _设置。_
4.  扫描二维码或在身份验证器应用中手动输入代码。
5.  输入身份验证器应用中的验证码以确认设置成功，然后按 _验证并继续_。
6.  保存恢复代码，然后勾选确认并按 _完成设置_。
7.  TOTP 设置完成后（刷新页面后）将需要重新登录。

## 登录

启用 TOTP 后，登录页面会在密码下方的 _一次性密码或恢复代码_ 中要求输入身份验证器应用中的验证码。

Trilium 接受当前 30 秒时间段以及前后时间段的验证码，因此即使时钟略有偏差也能正常工作。自 v0.106.0 起，每个验证码仅被接受一次：成功登录后，该验证码及任何更早的验证码都会被拒绝，即使它们仍然有效。

错误的一次性密码与错误的密码一样，计入相同的失败尝试次数限制。请参阅 <a class="reference-link" href="Authentication.md">身份验证</a> 中的 _暴力破解防护_。

## 将设备连接到服务器

启用 TOTP 后，通过 <a class="reference-link" href="../Synchronization.md">同步</a> 将新的桌面或移动应用连接到服务器时也会要求第二因素。在 _连接到现有服务器_ 屏幕上，在服务器密码下方的 _一次性密码或恢复代码_ 中输入一次性密码或恢复代码。没有它，服务器将拒绝设置同步。

仅在设备首次连接时才要求第二因素。已设置好的设备会继续同步而无需它。

> [!NOTE]
> v0.107.0 之前的版本在设置同步时不要求第二因素。请将桌面和移动应用与服务器一起更新，因为旧版应用没有用于发送它的字段。

## 恢复代码

如果你无法访问身份验证器，可以使用恢复代码代替 TOTP。Trilium 提供 8 个不同的恢复代码，每个恢复代码只能使用一次。

要使用恢复代码，只需用密码登录并将恢复代码用作安全令牌。

初始恢复代码集在首次设置 TOTP 时生成。你可以随时转到 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _密码与身份验证_ 并按 _重新生成恢复代码_ 按钮来重新生成它们。这将生成一组新的恢复代码，同时禁用之前的恢复代码。
