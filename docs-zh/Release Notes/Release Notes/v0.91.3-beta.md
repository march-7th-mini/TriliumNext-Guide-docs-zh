# v0.91.3-beta
## 💡 主要亮点

*   已完成多项移动端改进（**期待您的错误报告**）
    *   在移动端，现在强制使用水平布局（启动器栏显示在屏幕顶部，而非左侧）。
        *   这为笔记内容提供了更多可用空间，并简化了移动端布局。
    *   启动栏也已移至底部，以符合现代应用程序的布局惯例。
    *   将树结构重构为侧边栏，可通过标题栏左侧的按钮触发。
    *   侧边栏也可以通过从屏幕左边缘向右滑动来触发。_由于 iOS 和 Android 奇怪的后退按钮手势，仍有一些问题需要解决_。
    *   改进了底部栏和编辑器工具栏的定位。
    *   已启用标签页功能。目前我们使用与桌面端相同的实现，这在移动端可能会有一些小问题。
    *   现在可以使用“跳转到笔记”功能。
    *   移动端视图现在拥有独立的启动器栏配置及其专属的启动器栏按钮。目前仅启用了少数几个。**如果您需要桌面端的任何按钮，请随时提出请求。**
    *   现在可以在 CKEditor 中插入脚注，这要归功于 [ThomasAitken/ckeditor5-footnotes](https://github.com/ThomasAitken/ckeditor5-footnotes) 的一个分支。
    *   也可以在文本笔记中创建内联 Mermaid 图表。
