## 💡 主要亮点

*   “Books”已更名为 Collections，以更好地符合其用途。
    *   **引入了一种新的集合，** _**table。**_
        *   有关更多信息，请参阅应用内文档。
        *   由 @adoriandoran 提供的 Trilium 自定义表格主题。
    *   地理地图：地理地图已从独立的笔记类型转换为集合。
    *   集合不再直接显示在笔记树中的“插入子笔记”中，而是带有预定义配置（如提升属性），以便于使用（例如，用于日历、地理地图）。
*   引入了一种新的编辑机制：快速编辑。这会在弹出窗口中打开笔记进行编辑，而不是在标签页中，从而方便访问。这对于集合尤其有用，可以在不切换上下文的情况下编辑笔记。
