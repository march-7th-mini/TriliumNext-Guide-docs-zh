# 编辑器内 AI 助手
<figure class="image image-style-align-center image_resized" style="width:76.29%;"><img style="aspect-ratio:1479/865;" src="In-editor AI assistant_image.png" width="1479" height="865"></figure>

AI 助手会处理你正在撰写的文本：选中一段文字，让它重写、翻译或转换为表格，或者在光标处请求新内容。与 [AI 对话](../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/AI%20chat%20tab.md) 不同，它不会打开对话窗口，结果会就地预览，只有在你接受后才会写入笔记。

## 要求

只有在 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _AI / LLM_ 中至少配置了一个提供商，并为其选择了至少一个模型后，助手才可用。在此之前，工具栏入口完全不会显示。

## 访问 AI 助手

要访问 AI 助手：

*   在 <a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a> 中查找 <img class="image_resized" style="aspect-ratio:150/150;width:3.16%;" src="In-editor AI assistant_ai.svg" width="150" height="150"> 按钮。按下按钮本身进入 _询问 AI_ 模式，或按下其旁边的箭头键以访问快捷命令和模型选择。
*   在 <a class="reference-link" href="Slash%20Commands.md">斜杠命令</a> 中查找 _AI 助手_ 或任何以 _AI_ 为前缀的快捷命令。
*   按 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd>。
*   选中一段文本，然后在 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20contextual%20menu.md">笔记上下文菜单</a> 中选择 _AI 助手_ 选项。

## 助手处理的内容

| 情况 | 发送的内容 |
| --- | --- |
| 已选中文本 | 选中的内容。 |
| 未选中任何内容，且你选择了快捷操作 | 光标所在的段落。 |
| 未选中任何内容，且你输入了自己的提示词 | 不发送任何内容，响应是在光标处写入的新内容。 |

在所有情况下，助手还会发送目标文本前后的文本，以便模型能够判断它正在写入什么内容：当被要求 _继续写作_ 或进行总结时，如果模型只能看到选中的词语，就只能猜测它们周围的文档内容。这些周围文本仅作为上下文，绝不会被重写。

> [!IMPORTANT]
> 这意味着单次运行发送的内容不止你高亮的那段文字。关于究竟有哪些内容离开你的机器，请参阅 <a class="reference-link" href="../../AI/Privacy.md">隐私</a>。

## 快捷操作

工具栏按钮旁边的箭头会打开一个现成指令菜单，按用途分组。

*   _重新格式化_ 操作会生成真正的 Trilium 内容，而非纯文本：_图表_ 会插入 Mermaid 图表，_标注_ 会插入警示框，_可折叠_ 会插入可折叠块。
*   _翻译_ 组会列出你已启用的 [内容语言](Content%20language%20%26%20Right-to-left%20support.md)，如果未设置内容语言，则列出一个预定义列表。它可以在编辑器内填充，子菜单的最后一项会直接打开语言配置。

需要操作对象的操作在没有任何可操作对象时（例如没有选区的空段落）会显示为灰色。

## 请求特定内容

选择 _询问 AI…_ 会打开一个提示框，你可以用自己的话描述所需的更改，例如："让这段不那么正式"、"添加一行 2024"、"为这一节写一段引言"。按 <kbd>Enter</kbd> 或发送按钮来运行它。

收到响应后，你可以在同一提示框中继续对话，助手会将其视为对话而非全新请求：在执行 _将此翻译成德语_ 之后，再要求 _让它更短_，会缩短德语版本，而不是原文。

## 查看结果

响应会在生成时流式传输，并且可以随时按 _停止_ 按钮中断；在此之前已到达的内容仍然可用。

在你确认之前，不会向笔记写入任何内容。查看界面提供：

*   **结果**，按插入时的样子显示响应。
*   **更改**，显示与原文的内联差异，并标出插入和删除。当模型是重写而非编辑该段落时，查看界面会改为打开 _结果_：两段几乎没有共同点的文本的差异比答案本身更难阅读。
*   **重试**，重新运行同一指令。
*   **替换**，替换原段落
*   **插入到下方**，保留原文并在其后添加响应。

Trilium 还会报告生成响应的模型、消耗的 token 数，以及对于会报告价格的提供商，还会报告价格。

如果你请求更正但没有任何可更正的内容，助手会指出这一点，而不是显示空白差异。

## 选择模型

快捷操作菜单的底部会显示助手运行所用的模型，并允许你从在 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _AI / LLM_ 中选择的模型中另选一个，按提供商分组。

模型也可以在请求特定内容时更改，或在助手生成响应后更改（即如果响应需要更好的模型）。

此选择与对话所使用的模型相互独立，并会在笔记和设备之间记住。如果未设置，助手会遵循第一个配置的提供商。
