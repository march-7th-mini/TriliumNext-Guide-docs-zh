# 图像地图

图像地图是绘制在你自己提供的图像上的地理地图，而不是世界地图，例如平面图、桌游的奇幻地图或用于标注的示意图。标记和形状的用法与地理地图上相同，但它们的位置是在图像上测量的，而不是在经纬度上测量：以图像自身的像素为单位，或使用你选择的坐标系，例如某款电子游戏所用的坐标系。

## 创建图像地图

1.  将图像作为独立笔记上传，例如将文件拖入笔记树。支持 PNG、JPEG、WebP 和 GIF 图像；不支持 SVG 图像。
2.  创建地理地图，或打开现有的地理地图。
3.  从<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">笔记菜单</a>或<a class="reference-link" href="../Collection%20Properties.md">集合属性</a>的设置菜单中打开 <span class="tn-icon bx bx-cog"></span>_地理地图属性_对话框。
4.  在_背景_下，将_类型_设为_自定义图像_，然后在_图像笔记_中选择图像笔记。列表只提供地图能够绘制的格式（PNG、JPEG、WebP 或 GIF）的图像笔记，并且在输入任何内容之前会显示全部此类笔记。

随后地图会显示该图像而不是世界地图，并在打开时显示完整图像。要返回世界地图，请将_类型_设回_矢量与栅格_。图像是被停用而不是被移除：其关系被重命名为 `~disabled:map:image`，因此再次将_类型_设为_自定义图像_会恢复同一图像及其坐标。地理地图从父笔记或模板继承的图像只能在其所属的笔记上停用。

图像笔记存储在地理地图的 `~map:image` [关系](../../Advanced%20Usage/Attributes/Relations.md)中，也可以手动添加。

## 图像尺寸

图像在上传时会被调整大小，因此默认情况下，地图的图像长边最多为 2000 像素，这对于细节丰富的地图来说可能过于粗糙。要让图像保持更高分辨率，请在上传前执行以下操作之一：

*   在<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _媒体_中，调高_最大图像尺寸_或关闭_自动压缩图像_。
*   通过_导入_对话框上传，并取消勾选_压缩图像_。

已上传的图像会保持其尺寸；更改设置后请重新上传。

图像由显卡作为单张图片绘制，这限制了它的最大尺寸。长边不超过 4096 像素的图像在几乎所有设备上都是安全的，大多数计算机可处理高达 16384 像素的图像。在显卡无法容纳该图像的设备上，标记和形状仍会显示，但图像本身不会显示。_地理地图属性_对话框会对大于 4096 像素的图像以及完全无法使用的图像（例如 SVG 图像）发出警告。

## 交互

添加、移动和移除标记、绘制形状、弹出视图和上下文菜单的用法与<a class="reference-link" href="../Geo%20Map.md">地理地图</a>中所述相同。相机停留在图像上方，最多可放大到超过图像自身分辨率的四倍。

仅在真实地图上才有意义的功能在图像地图上不可用：

*   搜索地图以及在线搜索地点。
*   前往你的位置。
*   添加 GPS 轨迹。
*   点击底图显示的地点。
*   3D 建筑。
*   在外部地图应用中打开位置。

标记标题的外观跟随图像：如果图像较暗，请在_地理地图属性_对话框的_背景_下开启_深色图像_，以便标题以浅色绘制。这会设置 `#map:darkStyle` 标签。

_地图样式_设置不适用于图像地图，因此当地图带有图像时，它会从集合的设置菜单中隐藏。

## 选择坐标系

默认情况下，位置以图像原始尺寸的像素为单位，从左上角开始测量，`x` 向右增大，`y` 向下增大。

要改用你自己的坐标，请打开_地理地图属性_对话框，将_背景_下的_坐标_设为_自定义_，然后输入图像_左上角_和_右下角_的坐标。切换到_自定义_时会以图像的像素尺寸为起点，因此在更改角点之前标记会保持原位；因此，只有在图像加载完成后才能选择_自定义_。之后所有位置都以这些坐标读取和写入，包括上下文菜单和弹出视图中显示的位置。要返回像素，请将_坐标_设为_图像像素_。地理地图从父笔记或模板继承的角点只能在其所属的笔记上移除；在此地图上输入其他角点会覆盖它们。

角点以 `x,y x,y` 的形式存储在地理地图的 `#map:imageBounds` 标签中，两个角点之间用空格分隔，也可以手动设置。例如：

*   一张游戏地图的截图，其 `x` 从 -512 到 512，`y` 从 -512 到 512，且 `y` 向下增大：`#map:imageBounds=-512,-512 512,512`。从游戏中复制的坐标随后可以直接粘贴到 `#mapPosition` 中。
*   一个 `y` 向上增大的世界，原点位于图像中心：`#map:imageBounds=-2000,1000 2000,-1000`。左上角的 `y` 大于右下角的 `y` 正是翻转轴的方式。
*   以米为单位的平面图：`#map:imageBounds=0,0 24,12`。

两个轴不必使用相同的比例。圆始终以地图自身的单位测量，因此当两个轴上的单位被不同程度拉伸时，它会显示为椭圆。

共享相同 `x` 或 `y` 的角点不构成一个区域：对话框不会保存它们，而包含此类角点的标签或无法读取的值会被忽略，并改用图像的像素。

## 坐标标尺

在集合属性中启用_显示比例尺_会沿图像边缘绘制标尺，而不是距离比例尺。地图坐标的整数值沿所有四条边用刻度标记，沿顶部和左侧边标注，并带有横跨图像的浅色网格线。间距跟随缩放级别，当设置了 `#map:imageBounds` 时，数值跟随该标签。

标尺绘制在图像本身上，因此放大时会随图像边缘一起移出视野。网格线在整个图像上保持可见。

## 位置如何存储

由于位置存储在与地理地图不同的标签中，同一笔记既可以放置在地理地图上，也可以放置在图像地图上。

| 标签 | 内容 |
| --- | --- |
| `#mapPosition` | 标记的位置，格式为 `x,y`，例如 `#mapPosition=320,145`。 |
| `#mapShape` | 形状，格式与 `#geoShape` 相同（参见<a class="reference-link" href="Drawing%20shapes.md">绘制形状</a>），但使用 `x,y` 对，圆的半径以地图的单位表示，例如 `#mapShape=circle:400,300 50`。 |

位置属于坐标系，而不属于图像。当用另一张图像替换时（例如更高分辨率的副本），只要保持 `#map:imageBounds` 描述新图像所覆盖的区域，每个标记都会留在原位。使用_图像像素_时，位置就是像素，因此不同尺寸的图像会使标记相对于图像所显示的内容发生移动；为避免这种情况，请在替换图像前将_坐标_切换为_自定义_，这会保留旧图像的尺寸（`0,0 <width>,<height>`）作为角点。

> [!TIP]
> 要在图像上自由绘制而不是在其上放置笔记，请考虑使用<a class="reference-link" href="../../Note%20Types/Canvas.md">画布</a>。
