# 笔记按钮

笔记按钮是笔记右上角的一个区域，包含几个按钮：

*   <a class="reference-link" href="Note%20menu.md">笔记菜单</a>，提供针对该笔记或其子树的命令，例如导入、导出、查看[笔记源代码](../../Advanced%20Usage/Note%20source.md)或[附件](../Notes/Attachments.md)。
*   <a class="reference-link" href="Split%20View.md">分屏视图</a>控件
    *   <span class="tn-icon bx bx-dock-right"></span> 打开新的分屏
    *   <span class="tn-icon bx bx-chevron-right"></span>/<span class="tn-icon bx bx-chevron-left"></span> 移动窗格位置
    *   <span class="tn-icon bx bx-x"></span> 关闭窗格。
*   在某些笔记类型（如<a class="reference-link" href="../../Note%20Types/File.md">文件</a>和图片）上，有专用按钮（例如 <span class="tn-icon bx bx-download"></span> 将文件下载到本地）。
