# 新建笔记类型切换器
当创建一个空的 <a class="reference-link" href="../../Note%20Types/Text.md">文本</a> 笔记时，一个笔记类型切换器会出现在行内 <a class="reference-link" href="Title.md">标题</a> 下方。除了更改笔记类型外，还可以应用[模板](../../Advanced%20Usage/Templates.md)：

*   <span class="tn-icon bx bxl-markdown"></span> _Markdown_ 和 <span class="tn-icon bx bx-pen"></span> _Canvas_ 可一键将笔记切换为该类型。
*   <span class="tn-icon bx bx-code"></span> _代码_ 列出脚本笔记（_自定义 CSS_、_小组件_ 和 _后端脚本_），然后是已启用的代码语言。
*   <span class="tn-icon bx bx-book"></span> _集合_ 和 <span class="tn-icon bx bx-copy-alt"></span>_模板_ 列出集合和模板。
*   <span class="tn-icon bx bx-dots-vertical-rounded"></span> _所有类型_ 显示的菜单与 <a class="reference-link" href="../UI%20Elements/Note%20Tree/Note%20tree%20contextual%20menu.md">笔记树上下文菜单</a> 中的 _在此之后插入笔记_ 相同，包含所有笔记类型和模板。

当 <span class="tn-icon bx bx-code"></span> _代码_、<span class="tn-icon bx bx-copy-alt"></span> _模板_ 或 <span class="tn-icon bx bx-dots-vertical-rounded"></span> _所有类型_ 菜单打开时输入内容，会将其缩小到匹配的条目。

一旦输入文本，切换器就会消失。
