# 开发者专用格式
### 行内代码

行内代码使用等宽字体格式化文本，以表示句子中的技术内容，例如代码、路径等。

![](Developer-specific%20formatting_image.png)

使用行内代码来标示文件系统路径以及 shell 命令（此处为 `git`）的示例。

要插入行内代码：

*   通过[格式工具栏](Formatting%20toolbar.md)，找到 <span class="tn-icon cke cke-code"></span> 按钮。
*   输入 \`code\`，其中 `code` 是希望自动格式化为行内代码的文本。
*   粘贴从 Visual Studio Code 复制的单行内容。关于粘贴多行内容，请参阅[代码块](Developer-specific%20formatting/Code%20blocks.md)。

### 代码块

代码块将代码片段显示为专用块：

![](1_Developer-specific%20formatting_image.jpg)

启用了 JavaScript 语法高亮的代码块。

请注意，这些不适用于非常大量的代码。请改用专用的[代码](../Code.md)笔记类型。

更多信息请参阅专门文档：[代码块](Developer-specific%20formatting/Code%20blocks.md)

### 键盘快捷键

这允许将部分文本标记为快捷键。

![](Developer-specific%20formatting_image.jpg)

要应用此样式，请按[格式工具栏](Formatting%20toolbar.md)中 <span class="tn-icon bx bx-text"></span> 组内的 <span class="tn-icon cke cke-trilium-kbd"></span> 按钮。在浮动工具栏上，选中文本时会出现这些按钮。

或者，按 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>K</kbd> 组合键，对当前选中的文本应用键盘快捷键格式。

再次按下该按钮（从界面或键盘）或使用 <span class="tn-icon cke cke-remove-format"></span> _移除格式_ 按钮即可移除该格式。
