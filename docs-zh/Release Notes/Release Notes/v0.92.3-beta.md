# v0.92.3-beta
## 💡 主要亮点

*   [macOS 签名二进制文件（感谢 @perfectra1n 的实现）。](https://github.com/TriliumNext/Notes/pull/1267)
*   增加了对从右到左内容的基本支持。更多信息请参阅应用内帮助（F1）。

## 🐞 错误修复

*   [导入某些 .enex 文件时发生错误](https://github.com/TriliumNext/Notes/issues/943)
*   访问受密码保护的分享时，出现关于发送两次请求头的错误日志。
*   自 Trilium 0.60.4 以来的迁移现已正常工作，无需在迁移到 TriliumNext 之前更新到最新的 zadam 版 Trilium。
*   [自定义小组件位置不起作用](https://github.com/TriliumNext/Notes/issues/1321)
*   画布：无法在画布上复制粘贴元素。
*   无法从添加链接对话框添加外部链接（感谢 @JYC333）
