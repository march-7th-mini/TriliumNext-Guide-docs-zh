# v0.92.1-beta
## 💡 主要亮点

*   在导入 HTML 时现在有更严格的规则，我们只允许极少数样式（颜色、边框等）。如果您在导入时遇到任何问题，请尝试禁用“安全导入”并报告您可能遇到的任何问题。

## 🐞 错误修复

*   地理地图：在两个地理地图之间切换时，视口和缩放无法正确恢复。
*   [导入的 Evernote Enex 文件与 Trilium UI 重叠](https://github.com/TriliumNext/Notes/issues/931)

## ✨ 改进

*   网页视图现在使用 `<iframe>` 在浏览器中渲染。它可能有一些小问题，但在基本用例中似乎可以正常工作。
*   渲染包含文本的文件笔记时，仅显示文本片段以提高界面响应速度。
*   [将 .mdx 文件视为 Markdown](https://github.com/TriliumNext/Notes/issues/1236)
*   日历视图
    
    *   由 @rom1dep 提供的可自定义日历条目
    *   日历现在以全高度显示。
    *   增加隐藏周末的选项。
    *   如果设置了图标，现在会显示在事件旁边。
    *   日历现在是递归的，因此它会在子笔记的子笔记中查找日历笔记，依此类推。
    *   与日记笔记的基本集成，如果日历视图设置为 `#calendarRoot`，它将渲染所有日记笔记及其子笔记（1 级嵌套）。更多信息请参阅帮助。
*   支持导入 UTF-16 LE（例如从 Outlook 保存为 HTML 的邮件）内容。
*   设置
    
    *   由 @pano9000 提供的友好数字保护会话超时
    *   由 @pano9000 提供的友好数字笔记修订
*   分享：[允许在未认证时将 `/` 重定向到 `#shareRoot`](https://github.com/TriliumNext/Notes/pull/1207) 由 @maphew 提供
*   应用内帮助：
    
    *   移除所有不再使用的帮助笔记。
    *   恢复帮助笔记的图标。
*   [Markdown 标题现在使用 ATX 语法（`#`）导出，而不是 setext（`------`）](https://github.com/TriliumNext/Notes/issues/1251)
*   默认添加 TypeScript 笔记类型 由 @pano9000 提供
*   [地理标签：可着色标记](https://github.com/TriliumNext/Notes/pull/1229) 由 @McSido 提供
