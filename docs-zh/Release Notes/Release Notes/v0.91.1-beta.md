# v0.91.1-beta
## 💡 主要亮点

*   启动器栏现在可以放置在屏幕顶部而不是左侧，并带有全宽标签栏。更多信息请参阅 [#654](https://github.com/TriliumNext/Notes/pull/654)。
*   [引入了一个名为“TriliumNext”的新主题](https://github.com/TriliumNext/Notes/pull/661)，由 @adoriandoran 和 @eliandoran 开发。该主题的设置现在以卡片布局显示。重新设计了树操作按钮。
*   当 Windows 和 macOS 的原生标题栏关闭时，[使用原生标题栏按钮](https://github.com/TriliumNext/Notes/pull/702)。
*   在 Windows 上，TriliumNext 主题在 Windows 下运行时具有窗口透明效果，截图请参阅 [Mica（Windows 透明效果）](https://github.com/TriliumNext/Notes/pull/717)。遗憾的是，它受到 Electron（我们用于桌面应用程序的库）的一些 bug 困扰，更多信息请参阅链接。
*   将 Docker 构建更新到 Node 22。**请留意任何潜在问题，尤其是对于 ARM 等测试较少的平台。**
