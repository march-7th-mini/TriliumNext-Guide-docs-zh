# 外部链接
外部链接是指向例如网站的标准网页链接。例如，[https://en.wikipedia.org/wiki/South\_China\_Sea](https://en.wikipedia.org/wiki/South_China_Sea) 是一个指向维基百科页面的外部链接。

要创建不带自定义文本的链接：

*   在<a class="reference-link" href="../Formatting%20toolbar.md">格式工具栏</a>中按 <span class="tn-icon cke cke-link"></span>，或按 <kbd>Ctrl</kbd>+<kbd>K</kbd>：
    *   自 v0.107.0 起，_添加链接_ 对话框会在 _网页链接_ 上打开，在桌面端以光标旁的弹出窗口形式显示。输入或粘贴地址，并可选择填写 _链接标题_；若不填写，链接将显示其地址。
    *   _显示为_ 可将地址插入为 _纯链接_，或作为<a class="reference-link" href="../Link%20Previews.md">链接预览</a>之一：_内联_、_卡片_，或对于 YouTube 视频，_YouTube 嵌入_。
    *   按 <kbd>Enter</kbd> 或 _添加链接_ 以确认。
*   更简单的方法是粘贴原始链接并按空格，将其自动转换为链接。
*   <a class="reference-link" href="Internal%20(reference)%20links.md">内部（引用）链接</a>的 <span class="tn-icon cke cke-trilium"></span> 按钮和 <kbd>Ctrl</kbd>+<kbd>L</kbd> 会在 _笔记_ 上打开同一对话框。在对话框顶部选择 _网页链接_ 即可从那里创建外部链接。

不带协议的地址（如 `example.com`）会自动补上 `https://`。粘贴到 _笔记_ 字段中或从其搜索中选择的 URL 会将对话框切换为 _网页链接_。当选中的文本是 URL 时，对话框也会在 _网页链接_ 上打开。

要创建带自定义文本的链接：

*   首先，输入并选中将要转换为链接的文本。
*   如上所述打开 _添加链接_ 对话框（通过格式工具栏或 <kbd>Ctrl</kbd>+<kbd>K</kbd>）。选中的文本会成为链接的文本，因此对话框不提供 _显示为_。
*   或者，直接在选中的文本上粘贴（<kbd>Ctrl</kbd>+<kbd>V</kbd>）将其转换为链接。

插入链接后：

*   如有需要，可以更改链接内的文本，但链接本身会保留。
*   要修改链接，点击链接以显示弹出窗口，然后按 <span class="tn-icon cke cke-pencil"></span> _编辑链接_ 按钮。它会打开 _编辑链接_ 对话框，其中填充了链接的地址和文本；将光标置于链接内并按 <kbd>Ctrl</kbd>+<kbd>K</kbd>、<kbd>Ctrl</kbd>+<kbd>L</kbd> 或其中一个链接按钮也会如此。_保存链接_ 会更改整个链接（包括其文本），该对话框还可将其转换为指向笔记的链接。
*   要移除链接，点击它并按 <span class="tn-icon cke cke-unlink"></span> _取消链接_ 按钮。

你可以通过双击（将打开新标签页/窗口）外部链接，或右键点击它们并选择“在新标签页中打开”来访问外部链接。
