# 块引用

块引用是指向文本笔记中某个块的[链接](Links.md),例如段落、标题、列表项或表格,或者指向一系列连续块。块引用可以作为链接粘贴到另一篇笔记中,也可以转换为<a class="reference-link" href="Include%20Note.md">包含笔记</a>,仅显示被引用的块。

## 复制引用

1.  将光标放在要引用的块中。要引用多个连续块,请选中它们。
2.  右键点击块手柄,即块左侧的一串圆点(参见<a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a>)。或者,右键点击文本并打开 _复制_ 子菜单。
3.  选择 _复制此块的引用_,如果是选中内容则选择 _复制这些块的引用_。被引用的块会短暂闪烁。
4.  转到要插入链接的笔记,按 <kbd>Ctrl</kbd>+<kbd>V</kbd>。

在<a class="reference-link" href="Content%20tabs.md">内容标签页</a>块内,引用指向整个块。要链接到单个标签页,请改用 _复制标签页链接_。在<a class="reference-link" href="Multicolumn%20layout.md">多栏布局</a>内,引用指向该栏中的块,包含内容会显示这些块而不带周围的布局。

链接显示笔记标题,后跟被引用文本的开头。指向同一笔记中块的链接仅显示被引用文本的开头。

上下文菜单的 _粘贴_ 子菜单提供了另外两种插入已复制引用的方式:

*   _将引用粘贴为链接_ 仅插入链接,即使引用是以纯文本或连同其他内容一起复制的。
*   _将引用粘贴为摘录_ 插入被引用块的包含内容,如下所述。

在浏览器中,文本编辑器的上下文菜单仅在右键点击选中文本时打开。在其他位置,浏览器会显示自己的菜单。

## 跳转到引用

点击块引用会打开笔记,滚动到被引用的块并使其闪烁。如果被引用的块已被删除,则会显示错误消息,并列出该范围中仍然存在的块。

## 包含被引用的块

要在另一篇笔记中显示被引用的块,请在正在编辑的笔记中右键点击该链接并选择 _将链接转换为笔记摘录_,或者使用 _粘贴_ → _将引用粘贴为摘录_ 粘贴已复制的引用。包含内容仅显示被引用的块,而非笔记的其余部分,并在其标题中标记 _摘录_ 徽章。它从 _完整_ 框尺寸开始,因此所有被引用的块都可见。要查看整篇笔记,请按同一标题中的 <span class="tn-icon bx bx-link-external"></span> 按钮,它会在新标签页中打开该笔记。将包含内容转换回链接会保留引用。

要在不离开笔记的情况下编辑被引用的块,请按包含内容标题中的 <span class="tn-icon bx bx-pencil"></span> _编辑摘录_ 按钮,或在其工具栏中打开 _可编辑_,与任何<a class="reference-link" href="Include%20Note.md">包含笔记</a>一样。再次按该按钮可停止编辑。更改会保存到被引用的块,笔记的其余部分保持不变。在无法编辑块的位置(例如只读笔记中),该按钮会灰显。摘录没有 _全屏_ 按钮。

如果被引用的块已被删除,包含内容会显示 _引用已损坏_。

## 限制

*   引用只能从正在编辑的笔记中复制,且在移动端布局中不可用。
*   仅覆盖列表或引用一部分的范围(例如从其第二项到其后的段落)的包含内容,无法就地编辑。
*   删除块会破坏对它的引用。
*   导出为 Markdown 时不会保留块引用。在[共享页面](../../Advanced%20Usage/Sharing.md)上,块引用会打开整篇笔记。
