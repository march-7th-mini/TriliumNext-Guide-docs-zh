## 高级用法

### 属性

属性是笔记的元数据。它们可用于存储有关笔记的额外信息，例如作者、状态、标签或任何其他自定义数据。

属性在**属性**部分中显示在笔记编辑器的顶部。

#### 属性定义

属性定义是属性的模式。它们定义了属性的名称、类型以及可能的其他选项，例如标签或默认值。

属性定义是类型为**属性定义**的笔记。它们可以位于属性定义根目录下的任何位置。

#### 属性类型

属性可以是以下类型之一：

*   **文本**：一个简单的文本值。
*   **数字**：一个数值。
*   **布尔值**：一个真/假值。
*   **日期**：一个日期值。
*   **标签**：一个标签值。
*   **列表**：一个值列表。
*   **关系**：对另一个笔记的引用。
*   **关系列表**：对多个笔记的引用。

#### 属性变更

属性变更是一个脚本，当笔记的属性发生变化时执行。它可用于自动执行任务，例如更新其他笔记或发送通知。

属性变更是类型为**属性变更**的笔记。它们可以位于属性变更根目录下的任何位置。

### 脚本

脚本是可用于自动化任务或扩展 Trilium 功能的代码片段。它们可以用 JavaScript 或 Python 编写。

脚本可以在各种上下文中执行，例如：

*   **后端启动时**：当 Trilium 后端启动时。
*   **后端脚本执行**：手动或通过 API 执行。
*   **后端脚本**：在服务器上执行的脚本。
*   **前端脚本**：在浏览器中执行的脚本。

#### 后端脚本

后端脚本在服务器上执行。它们可以访问数据库和文件系统。后端脚本可用于自动化任务，例如创建笔记、更新属性或发送电子邮件。

后端脚本是类型为**后端脚本**的笔记。它们可以位于后端脚本根目录下的任何位置。

#### 前端脚本

前端脚本在浏览器中执行。它们可以访问 DOM 和浏览器 API。前端脚本可用于自定义 Trilium 的用户界面或添加新功能。

前端脚本是类型为**代码笔记**的笔记，其语言设置为 `javascript`。它们可以位于代码笔记根目录下的任何位置。

### 关系

关系是笔记之间的定向链接。它们可用于在笔记之间创建语义连接，例如“A 是 B 的父级”或“A 与 B 相关”。

关系在**关系**部分中显示在笔记编辑器的底部。

关系是类型为**关系**的笔记。它们可以位于关系根目录下的任何位置。

### 模板

模板是可用于创建新笔记的预定义笔记。它们可以包含文本、代码、属性和其他元素。

模板是类型为**模板**的笔记。它们可以位于模板根目录下的任何位置。

### 小组件

小组件是显示在笔记编辑器中的可自定义 UI 元素。它们可用于显示信息、执行操作或与其他笔记交互。

小组件是类型为**内置小组件**或**自定义小组件**的笔记。它们可以位于小组件根目录下的任何位置。

#### 内置小组件

Trilium 附带了一些内置小组件，例如：

*   **仪表板**：显示笔记统计信息的仪表板。
*   **日历**：显示笔记的日历。
*   **反链**：显示指向当前笔记的笔记列表。

#### 自定义小组件

自定义小组件是用户创建的小组件。它们可以使用 HTML、CSS 和 JavaScript 构建。

自定义小组件是类型为**自定义小组件**的笔记。它们可以位于自定义小组件根目录下的任何位置。

### 启动器

启动器是显示在**可用启动器**部分中的可点击图标。它们可用于快速执行操作，例如创建新笔记、打开特定笔记或运行脚本。

启动器是类型为**启动器**的笔记。它们可以位于启动器根目录下的任何位置。
