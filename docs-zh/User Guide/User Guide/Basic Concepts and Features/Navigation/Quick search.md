# 快速搜索
<figure class="image image-style-align-center"><img style="aspect-ratio:659/256;" src="Quick search_image.png" width="659" height="256"></figure>

_快速搜索_ 功能执行全文搜索（即搜索笔记内容，而不仅仅是笔记标题），并以易于访问的方式显示结果。

快速搜索的替代方案是 <a class="reference-link" href="Search.md">搜索</a> 功能，它在专用标签页中打开，并支持高级查询。

为了实现更快速的导航，可以使用 <a class="reference-link" href="Jump%20to%20%26%20command%20palette.md">跳转至 &amp; 命令面板</a>，它只搜索笔记标题而不搜索内容。

## 布局

基于 <a class="reference-link" href="../UI%20Elements/Vertical%20and%20horizontal%20layout.md">垂直和水平布局</a>，快速搜索的位置如下：

*   在垂直布局中，它显示在 <a class="reference-link" href="../UI%20Elements/Note%20Tree.md">笔记树</a> 的正上方。
*   在水平布局中，它显示在 <a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">启动栏</a> 中，可以像其他任何图标一样进行定位。

## 搜索功能

快速搜索包含以下功能：

### 内容预览

搜索结果现在会在笔记标题下方显示笔记内容的 200 个字符预览。此预览显示搜索词出现的上下文，使您无需打开笔记即可更轻松地识别正确的笔记。

### 无限滚动

结果会随着滚动逐步加载：

*   初始显示 15 条结果
*   滚动到接近底部时自动加载 10 条更多结果
*   继续滚动以加载所有匹配的笔记

### 视觉功能

*   **高亮**：搜索词以粗体和强调色显示
*   **分隔**：结果之间用分隔线隔开
*   **主题支持**：高亮颜色适配浅色/深色主题

### 搜索行为

快速搜索使用渐进式搜索：

1.  首先显示精确匹配
2.  当精确结果少于 5 条时，包含模糊匹配
3.  精确匹配显示在模糊匹配之前

### 搜索范围

快速搜索仅覆盖您当前所在的工作子树：

*   未提升时，覆盖整个笔记树。
*   在[提升的笔记](Note%20Hoisting.md)下或在[工作区](Workspaces.md)内时，仅覆盖该子树。
*   仅存在于隐藏树中的笔记（例如内置帮助页面和启动栏配置）不会被返回。提升到帮助中以搜索它，或使用[跳转至…](Jump%20to%20%26%20command%20palette.md)，它会在隐藏树中搜索标题。

要在提升状态下搜索整个数据库，请使用完整的 <a class="reference-link" href="Search.md">搜索</a> 并将 _Ancestor_ 字段留空。

### 键盘导航

*   按 `Enter` 打开第一条结果
*   使用方向键在结果中导航
*   按 `Escape` 关闭快速搜索

## 使用快速搜索

1.  **容错**：即使有轻微拼写错误，搜索也能找到结果
2.  **内容预览**：200 个字符的片段显示匹配上下文
3.  **无限滚动**：滚动时加载更多结果
4.  **具体术语**：具体的搜索词返回更聚焦的结果
5.  **匹配位置**：粗体文本指示匹配发生的位置

## 快速搜索 - 精确匹配运算符

快速搜索与完整的 <a class="reference-link" href="Search.md">搜索</a> 共享相同的搜索引擎，因此精确匹配运算符（`=`）在两者中的行为完全相同。在查询开头使用 `=`（后面不加空格），即可从默认的"包含"行为切换为精确的整词或短语匹配。

**`=`** **实际的作用：** 它查找标题或内容中包含您的搜索词作为**整词或短语**的笔记，忽略周围的标点符号。它**不**要求整个笔记等于您的搜索词，也**不**进行子字符串或模糊匹配。

| 查询 | 示例笔记内容 | 是否匹配？ | 原因 |
| --- | --- | --- | --- |
| `sync` | `synchronize the database now` | 是 | 默认搜索匹配子字符串 |
| `=sync` | `see (sync) mode` | 是 | `=` 匹配整词 `sync`，忽略标点符号 |
| `=sync` | `synchronize the database now` | 否 | `=` 从不匹配子字符串 |
| `="project plan"` | `the (project plan) is ready to share` | 是 | 用引号括起多词短语以精确匹配 |

搜索不区分大小写和变音符号。有关三种匹配模式、模糊运算符和相关性排名的完整说明，请参阅完整搜索文档中的[搜索如何匹配您的文本](Search.md)。

### 限制

*   `=` 运算符必须位于搜索查询的最开头。
*   `=` 后紧跟空格将被视为常规搜索。
*   多个 `=` 运算符（如 `==example`）将被视为常规文本搜索。

### 相关功能

*   对于属性、属性值、布尔值和排序查询，请使用完整的[搜索](Search.md)功能。
*   对于模糊匹配（即使有拼写错误也能找到结果），请在完整搜索中使用 `~=` 或 `~*` 运算符。
*   对于使用通配符的部分匹配，请在完整搜索中使用 `*=*`、`=*` 或 `*=` 等运算符。
