# v0.103.0：移除 axios

`api.axios` 库已从后端脚本 API 中移除。

尝试使用 `api.axios` 的脚本现在将抛出错误，并附带迁移说明。

## 原因

Axios 至少从 2024 年 4 月起就被标记为已弃用，取而代之的是原生 `fetch()` API，该 API 在浏览器和 Node.js 环境中均可用。经过两年的弃用期后，该库在 [2026 年 3 月 npm 供应链事件](https://www.malwarebytes.com/blog/news/2026/03/axios-supply-chain-attack-chops-away-at-npm-trust) 后被移除，当时攻击者发布了部署远程访问木马的恶意版本。Trilium 的主要开发者险些受到攻击，但 `pnpm` 不信任未知的安装后脚本，成功避免了这一风险。

## 迁移

将 `api.axios` 调用替换为原生 `fetch()` API。

### `GET` 调用

之前（Axios）：

```javascript
const response = await api.axios.get('https://api.example.com/data');
const data = response.data;
```

之后（`fetch`）：

```javascript
const response = await fetch('https://api.example.com/data');
const data = await response.json();
```

### `POST` 调用

之前（Axios）：

```javascript
await api.axios.post('https://api.example.com/data', { key: 'value' });
```

之后（fetch）：

```javascript
await fetch('https://api.example.com/data', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ key: 'value' })
});
```
