# 外部链接
外部链接是指向例如网站的标准网页链接。例如，[https://en.wikipedia.org/wiki/South\_China\_Sea](https://en.wikipedia.org/wiki/South_China_Sea) 就是一个指向 Wikipedia 页面的外部链接。

要创建不带自定义文本的链接：

*   在<a class="reference-link" href="../Formatting%20toolbar.md">格式工具栏</a>中按 <span class="tn-icon cke cke-link"></span>：
    *   将出现一个弹窗，在框中输入或粘贴 URL。
    *   按 <kbd>Enter</kbd> 或勾选图标以确认。
*   或者，按 <kbd>Ctrl</kbd>+<kbd>K</kbd> 触发上述弹窗。
*   更简单的方法是粘贴原始链接并按空格，将其自动转换为链接。

要创建带自定义文本的链接：

*   首先，输入并选中将要转换为链接的文本。
*   按照前面的步骤打开链接界面（通过格式工具栏，或 <kbd>Ctrl</kbd>+<kbd>K</kbd>）。
*   或者，直接在选中的文本上粘贴（<kbd>Ctrl</kbd>+<kbd>V</kbd>）将其转换为链接。

插入链接后：

*   如有需要，可以更改链接内的文本，但链接本身将保留。
*   要修改链接，点击链接以显示弹窗，然后按 <span class="tn-icon cke cke-pencil"></span> _编辑链接_ 按钮。
*   要移除链接，点击它并按 <span class="tn-icon cke cke-unlink"></span> _取消链接_ 按钮。

你可以通过双击外部链接（将打开新标签页/窗口）或右键点击并选择“在新标签页中打开”来访问外部链接。
