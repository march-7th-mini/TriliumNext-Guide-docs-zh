> [!WARNING]
> **升级之前。** 此版本包含可能破坏现有设置的更改。
> 
> 1.  **MCP 现在需要身份验证**,并且可以选择通过网络访问。→ _请使用凭据重新配置你现有的 MCP 客户端。_
> 2.  **文本笔记中的通用 HTML 支持现在默认禁用。** 这使得从网站复制粘贴的行为更加良好,不会抓取诸如输入框之类不需要的标签。→ _可通过 选项 → 文本笔记 → 保留不支持的 HTML 标签 重新启用。_
> 3.  文本笔记中的 `**<div>**` **现在会被解包**,而不是按原样保留,无论设置如何。这可以防止输入新段落时出现异常行为,以及诸如无法退出代码块之类的 bug。

## ✨ 亮点

#### 了解你的数据库中有什么——并把它收回来

<figure class="image image-style-align-right image_resized" style="width:45.59%;"><img style="aspect-ratio:1509/1329;" src="v0.105.0_image.png" width="1509" height="1329"></figure>

两个新工具从相反的方向回答同一个问题:到底是什么占用了那么多空间?

*   **空间使用情况** 以矩形树图的形式呈现——笔记、修订和附件按占用空间大小排列——这样悄悄吞噬你磁盘的东西就能一目了然,而不用靠猜。**清理工具** 则针对你发现的内容采取行动:清除已删除的笔记、裁剪旧修订、删除未使用的附件并压缩数据库。
*   **压缩图片** 针对常见的罪魁祸首,调整过大的图片尺寸并重新保存为更小的文件——可以从笔记、笔记树、附件列表、图片查看器或清理运行本身发起。它会在开始前告诉你发现了什么,并在完成时告诉你节省了多少。

上传、粘贴和导入时的自动压缩现在会让 PNG 保持为 PNG,不碰已经压缩过的图片,并在服务应用之外的线程上运行,因此大型导入不再会冻结 Trilium。_(@adoriandoran)_

### 属性终于有了自己的归属

<figure class="image image-style-align-left image_resized" style="width:19.59%;"><img style="aspect-ratio:529/952;" src="2_v0.105.0_image.png" width="529" height="952"></figure>

一个专门的 **属性** 侧边栏标签页在一个清晰的列表中显示自有、继承和提升的属性,并允许你就地编辑它们。系统属性在侧边栏中用图标标记,在自动补全中用徽章标记,并且现在每一个都有描述。它们的值使用合适的控件进行编辑——颜色选择器、URL 字段、日期选择器。

移动端获得了一个具有相同界面的属性编辑器,经典的属性编辑器及其配置模态框也得到了一轮修复。

### 可以锁定、并且真正能还原的备份

备份现在可以**压缩和加密**。加密使用 AES-256-GCM,密码由你自己设置,保存在操作系统的密钥环中,因此写入同步或共享文件夹的备份无法被其他能访问该文件夹的人读取——并且后续的篡改或损坏会被检测到。两者默认都关闭。

更重要的是,Trilium 现在可以**还原备份**。设置实例时提供从备份还原作为第四条路径,与新建知识库、从服务器同步以及与桌面应用配对并列;运行中的实例可以从 选项 → 备份 进入同一界面,并且会先提供现有内容的副本。候选备份在替换任何内容之前会被检查,失败的还原会回滚——因此不可用的备份会让你的笔记保持原样。以 GB 计的备份也能被妥善处理:浏览器以可恢复的分块方式发送,桌面应用则直接读取它所在的位置。_(@adoriandoran)_

### 查看你的数据库正在运行的一切

数据库多年来会积累脚本、主题和小组件,而到目前为止还没有一个统一的地方来查看它们——或者判断是哪一个导致了你一直忍受的异常行为。

**内容管理器** 将它们全部列出,按类别分组,并允许你关闭其中任何一个而不删除它。关掉某个东西,看看问题是否消失,再把它打开。_(@adoriandoran)_

### 让编辑器来写作

<figure class="image image_resized image-style-align-right" style="width:61.67%;"><img style="aspect-ratio:1068/747;" src="1_v0.105.0_image.png" width="1068" height="747"></figure>

Trilium 的 LLM 支持已经从聊天面板移到了文本编辑器中。选中任何内容并交给模型——校对、精简、总结——然后就地采用结果,无需将文本复制到聊天窗口再复制回来。自定义提示词让你可以保留经常使用的操作。需要配置 LLM 提供商;GitHub Copilot 订阅现在也可以作为一个提供商,与现有的提供商并列。

### 可搜索的设置,适配屏幕的界面

每个设置页面都已在共享的卡片组件上重建——每个主题一张卡片,每行一个设置,说明位于名称下方而非旁边——并且一个**搜索字段**现在可以一次搜索所有设置。它会显示设置本身,实时且可就地操作,按各自所属的页面分组,并且也能找到页面自身的命令:立即备份、还原备份、创建 ETAPI 令牌。_(@adoriandoran)_

## 🎁 其他新增内容

*   **基于 MapLibre 的地理地图** — WebGL 渲染、3D 地形、标记聚合、全屏模式以及每个标记的浮动信息面板,并完整支持 GPX 轨迹。
*   **思维导图节点面板** — 颜色、字体、图标、图片和富文本备忘录,来自侧边面板。
*   **日历焕新** — 新的主题和布局,以及用于创建和编辑事件的更友好的弹出窗口。
*   **连接侧边栏标签页** — 反链、笔记路径和笔记地图集中在一处。
*   **Office 和 EPUB 预览** — `.docx`、`.xlsx`、`.pptx`、ODF、RTF 和 EPUB 可在 Trilium 中打开。
*   一个会累积组件和事件监听器的重要内存泄漏已被修复,一致性检查在拥有 2 万+ 笔记的数据库上不再需要数分钟。
