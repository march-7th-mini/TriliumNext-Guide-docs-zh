## 访问最近更改

*   要查看所有文档中的更改概览，请按下 <a class="reference-link" href="Launch%20Bar.md">启动栏</a> 中的 <img src="Recent Changes_image.png" width="25" height="21"> 按钮。
    *   如果存在[提升笔记](../Navigation/Note%20Hoisting.md)或[工作区](../Navigation/Workspaces.md)，则最近更改列表将仅限于提升笔记或工作区的后代笔记。
*   要将最近更改列表限制为某个笔记及其后代笔记，请在<a class="reference-link" href="Note%20Tree/Note%20tree%20contextual%20menu.md">笔记树上下文菜单</a> → 高级中查找相应选项。

## 交互

*   更改过的笔记将按时间倒序显示（最新的更新在前）。
*   显示笔记的标题以及笔记路径。点击笔记标题将关闭对话框并导航到该特定笔记。
*   已删除的笔记也会在此处列出，并显示其删除时间。按下其旁边的 _取消删除_ 链接以恢复它们。
