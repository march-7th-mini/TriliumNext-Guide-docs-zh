# 笔记提升

提升是标准大纲工具的一项功能，它允许你通过隐藏所有父笔记和同级笔记，专注于（或“放大到”）某个特定笔记及其子树。演示：

![](Note%20Hoisting_note-hoisting.gif)

除了仅显示该子树之外，这还会将全文搜索和[“跳转到笔记”](Note%20Navigation.md)的范围缩小到仅提升子树中存在的笔记。

## 再次显示所有笔记

当某个笔记被提升时，桌面界面会在<a class="reference-link" href="../UI%20Elements/Note%20Tree.md">笔记树</a>上方显示一个带有 <span class="tn-icon bx bx-arrow-back"></span> 图标的*显示所有笔记*按钮。点击它以取消提升该笔记并再次查看整个树。

另请参阅扩展了此功能的[工作区](Workspaces.md)。
