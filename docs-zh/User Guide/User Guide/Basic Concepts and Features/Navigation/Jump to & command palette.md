## 跳转到笔记

_跳转到笔记_ 功能允许通过搜索笔记标题来轻松地在笔记之间导航。除此之外，它还可以触发全文搜索或创建笔记。

要进入“跳转”对话框：

*   在 <a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">启动栏</a> 中，点击 ![](2_Jump%20to%20&%20command%20palette_image.png) 按钮。
*   使用键盘，按下 <kbd>Ctrl</kbd> + <kbd>J</kbd>。

除了搜索笔记，还可以搜索命令。更多信息请参见下面的专门章节。

### 交互

*   默认情况下，当未输入任何文本时，它会显示最近的笔记。
*   使用键盘上的向上或向下箭头键在项目之间导航。按 <kbd>Enter</kbd> 打开所需的笔记。
*   如果笔记不存在，可以通过输入所需的笔记标题并选择 _创建并链接子笔记_ 选项来创建它。

## 最近笔记

跳转到笔记还具有显示最近查看/编辑的笔记列表并快速跳转到该笔记的功能。

要访问此功能，请点击顶部的 `跳转` 按钮。默认情况下，（当自动完成框中未输入任何内容时），此对话框将显示最近笔记的列表。

或者，您可以点击右侧的“时间”图标。

## 命令面板

<figure class="image image-style-align-center"><img style="aspect-ratio:982/524;" src="Jump to &amp; command palette_image.png" width="982" height="524"></figure>

命令面板是一个允许轻松执行应用程序中各种命令（例如来自菜单或键盘快捷键的命令）的功能。此功能直接集成到“跳转”对话框中。

### 交互

要触发命令面板：

*   按 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> 直接显示命令面板。
*   如果在“跳转”对话框中，请在搜索框中输入 `>` 以切换到命令面板。

交互：

*   输入几个词以在命令之间进行过滤。
*   使用键盘上的向上和向下箭头键或鼠标选择一个命令。
*   按 <kbd>Enter</kbd> 执行命令。

要退出命令面板：

*   删除搜索框中的 `>` 以返回笔记搜索。
*   按 <kbd>Esc</kbd> 完全关闭对话框。

### 可用选项

目前显示以下选项：

*   大多数 <a class="reference-link" href="../Keyboard%20Shortcuts.md">键盘快捷键</a> 都有一个条目，但那些过于具体而无法从对话框运行的快捷键除外。
*   一些尚不能作为键盘快捷键使用，但可以从各种菜单访问的附加选项，例如：导出笔记、显示附件、搜索笔记或配置 <a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">启动栏</a>。

### 限制

目前无法定义显示在命令面板中的自定义操作。将来，这可能会通过集成启动栏中的选项来改变，启动栏可以根据需要进行自定义。
