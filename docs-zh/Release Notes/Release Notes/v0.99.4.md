*   [将全局快捷键发送到当前窗口](https://github.com/TriliumNext/Trilium/pull/7645)
*   日历集合现在使用“日期和数字格式”。
*   [许多 UI 改进](https://github.com/TriliumNext/Trilium/pull/7655) 由 @adoriandoran 贡献
    *   **禅模式全面改进** – 改进了禅模式视图的外观和布局。文本笔记的内容现在垂直对齐，字体稍大以增强专注度。内容宽度现在遵循“最大内容宽度”选项。格式工具栏已移至底部，即使在分笔记视图中也保持全宽。您现在可以直接从禅模式激活只读笔记的编辑模式。启动栏中也添加了禅模式的启动器（默认隐藏，要将其添加到启动栏：右键单击工具栏，选择配置启动栏，然后右键单击禅模式并选择移至可见启动器）。
    *   **“最大内容宽度”选项和内容对齐改进** – “最大内容宽度”选项的内部行为已被重写。内容现在默认左对齐（在 RTL 模式下右对齐）。要居中内容，请在选项 → 外观下启用“保持内容居中”。笔记标题和功能区现在始终跨越全宽，滚动条与边缘保持对齐。更改宽度值不再需要重新启动前端。
    *   **只读笔记提示栏** – 为了更好地突出笔记为只读状态并使编辑更直观，笔记顶部现在会出现一个消息栏，其中包含启用编辑的按钮。以前用于此目的的浮动铅笔按钮已被移除。笔记菜单中也添加了“编辑”命令。
    *   **快速编辑对话框背景着色** – 快速编辑对话框的背景色现在反映笔记的颜色属性。
    *   **额外 Mica 效果** – 在 Windows 11 上，桌面应用现在将 Mica 背景效果应用于设置页面、右侧窗格和空标签页。
