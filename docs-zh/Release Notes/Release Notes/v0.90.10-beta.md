# v0.90.10-beta
## 💡 主要亮点

*   在可编辑和只读文本笔记的代码块中实现语法高亮（通过 Highlight.js），主要基于 [antoniotejada](https://github.com/antoniotejada) 的 [Trilium-SyntaxHighlightWidget](https://github.com/antoniotejada/Trilium-SyntaxHighlightWidget)。

## 🐞 错误修复

*   代码笔记与笔记列表重叠的问题。
*   修复在 0.90.9-beta 版本中运行脚本时的错误。
*   修复设置更新时外观设置中的字体部分闪烁的问题。
*   [裁剪文件名并防止截断扩展名](https://github.com/TriliumNext/Notes/pull/541) / 画布笔记导出为 html 后因标题名称长度为 13-15 位而无法查看，由 @SiriusXT 贡献
*   删除关系模态框中重复的笔记计数。
*   文档笔记（例如启动器配置说明）未在 Electron/桌面版本中显示的问题。

## ✨ 改进

*   文本笔记中代码块的可调自动换行。
*   文本笔记中代码块的可调主题，并略微改进设计。
*   应用程序现在应对自定义小组件和脚本引起的错误具有更高的容错性，不会导致用户界面也崩溃（参见 [#511](https://github.com/TriliumNext/Notes/issues/511)）。
*   [关闭右侧标签页](https://github.com/TriliumNext/Notes/pull/542) 由 @SiriusXT 贡献
*   [聚焦时自动触发自动补全](https://github.com/TriliumNext/Notes/pull/534) 由 @SiriusXT 贡献

## 🌍 国际化

*   翻译每日笔记的星期和月份名称。
*   切换语言时更新服务器翻译。
