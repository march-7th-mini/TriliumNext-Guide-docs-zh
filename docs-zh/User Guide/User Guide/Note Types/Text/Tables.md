# 表格

表格是<a class="reference-link" href="../Text.md">文本</a>笔记的一项强大功能，因为编辑表格通常很容易。

<figure class="image image-style-align-right"><img style="aspect-ratio:176/204;" src="2_Tables_image.png" width="176" height="204"></figure>

要创建表格，只需按下表格按钮，然后用鼠标选择所需的列数和行数，如右图所示。

自 v0.107.0 起，同一菜单以 _插入表格…_ 项开头，用于创建大于网格的表格，或直接输入其尺寸：

1.  点击 <span class="tn-icon cke cke-table"></span>按钮并选择 _插入表格…_。光标处会打开一个小表单。
2.  输入 _列_ 数（最多 100）和 _行_ 数（最多 1000）。表格最多可有 5000 个单元格，例如 1000 行 5 列。
3.  按 _插入_ 或 <kbd>Enter</kbd>。

要关闭表单而不插入表格，请按 <kbd>Esc</kbd> 或点击其外部。使用键盘时，菜单打开期间 <kbd>Tab</kbd> 会在 _插入表格…_ 和网格之间移动。

在<a class="reference-link" href="../../Installation%20%26%20Setup/Mobile%20Frontend.md">移动端前端</a>上，<span class="tn-icon cke cke-table"></span>按钮会直接打开表单，而不显示网格。

## 上下文菜单

自 v0.106.0 起，在表格内任意位置右键单击会打开一个上下文菜单，其中包含最常用的表格操作：

*   _在上方插入行_ 和 _在下方插入行_ 会在当前单元格所在行的旁边插入一个空白行。当选择范围跨越多行时，会插入相同数量的行。
*   _在左侧插入列_ 和 _在右侧插入列_ 对列的作用相同。
*   自 v0.107.0 起，根据选择情况，_设为表头_ 或 _将表头设置到本行_ 会将行变为表头行，表头行始终从表格顶部开始：
    *   当选择从第一行开始时显示 _设为表头_，并将每个选中的行变为表头行。
    *   当选择位于第一行以下的单行中时显示 _将表头设置到本行_，并将该行及其上方的每一行变为表头行。
    *   当选择跨越第一行以下的多个行时，两者都不显示。
    *   勾选标记表示这些行已经是表头行。再次选择该项会将它们及其下方的每个表头行恢复为常规行。例如，在一个有五个表头行的表格中，在第三行选择 _将表头设置到本行_ 后，只有前两行保留为表头行。
*   _合并单元格_ 将选中的单元格合并为一个。选中的单元格必须构成一个矩形。
*   _拆分单元格_ 将每个选中的单元格拆分为两个，可以是 _垂直_ 或 _水平_ 拆分。同一子菜单中的 _取消合并单元格_ 会将选择中的每个合并单元格恢复为其覆盖的单个单元格，并将其内容保留在左上角的单元格中；未合并的单元格保持不变。
*   _均匀分布列_ 会将选择所触及的列的组合宽度平均分配给它们。其他列和表格宽度保持不变。它需要跨越至少两列的选择；合并单元格按其覆盖的每一列计算。
*   _剪切_、_复制_ 和 _复制为 Markdown_ 作用于选中的单元格。自 v0.107.0 起，_复制_ 和 _粘贴_ 会打开包含其变体的子菜单，例如 _复制为 Markdown_ 和 _粘贴为纯文本_；点击 _复制_ 或 _粘贴_ 本身仍会执行复制或粘贴：
    *   剪切或复制会生成一个仅包含选中单元格的较小表格。将其粘贴到单元格选择上会替换这些单元格；粘贴到其他位置会将其作为独立表格插入。剪切会清除单元格内容，但不会删除行或列。
    *   _复制为 Markdown_ 会将选中的单元格转换为 Markdown 表格。选中的表头行会成为 Markdown 表头；如果没有表头行，则会生成一个空表头行，因为 Markdown 表格需要表头。
*   自 v0.107.0 起，_粘贴_ 子菜单中的 _在上方粘贴行_ 和 _在下方粘贴行_ 会将剪贴板内容作为新行粘贴到当前单元格所在行的旁边，而不是从光标处开始覆盖单元格。它们仅在选择位于单行中时显示，并且与 _粘贴_ 一样，仅在可以读取剪贴板的位置显示：
    *   复制的表格会为其每一行生成一个新行，从第一列开始填充。当其列数多于表格时，表格会增加列，与常规粘贴相同。其他内容会放入单个新行的第一个单元格中。
    *   新行随后会被选中。
    *   当合并单元格将该行与其他行连接时，新行会位于整个行块的上方或下方。
*   剪贴板部分下方的 _排序_ 会按当前单元格所在列对行进行 _升序_ 或 _降序_ 排序。参见[对行排序](#sorting-rows)。
*   _排序_ 下方的 _删除行_ 和 _删除列_ 会删除选择所触及的每一行或每一列，即使只选中了其中的部分单元格。
*   _删除表格_ 会删除整个表格，并在其位置留下一个空段落。在嵌套于另一个表格内的表格中，只会删除内部表格。
*   自 v0.107.0 起，_删除表格_ 下方的 _选择_ 会选择选择所触及的每一行（_行_）或每一列（_列_）的单元格，或表格的每个单元格（_表格_）。与将表格作为整体选择的 <span class="tn-icon cke cke-drag-handle"></span>按钮不同，_表格_ 会选择其单元格，因此诸如 _合并单元格_ 之类的单元格操作会应用于所有单元格。在嵌套于另一个表格内的表格中，_表格_ 只会选择内部表格的单元格。

右键单击不属于当前选择的单元格会先将光标移到那里，因此菜单始终应用于指针下的单元格。

> [!NOTE]
> 在浏览器中，Trilium 的菜单会替换表格内浏览器自带的上下文菜单。要访问浏览器的菜单（例如其拼写检查建议），请在右键单击时按住 <kbd>Shift</kbd>。桌面应用程序不受影响，因为其菜单已包含拼写建议。在浏览器中，菜单仅在页面可以读取剪贴板时才提供 _粘贴_，这需要安全（HTTPS）上下文和你的许可；否则，请使用 <kbd>Ctrl</kbd>+<kbd>V</kbd> 粘贴。

## 导航表格

*   使用鼠标：
    *   点击单元格以聚焦它。
    *   点击表格顶部或底部的 <span class="tn-icon cke cke-return-arrow"></span> 按钮，在其附近插入一个空段落。
    *   点击表格左上角的 <span style="--tn-color:hsl(0,0%,60%);color:hsl(0,0%,60%);"><span class="tn-icon cke cke-drag-handle"></span></span> 按钮以完全选中表格（便于复制粘贴或剪切），或拖放它以重新定位表格。
*   使用键盘：
    *   使用键盘上的方向键可以轻松在单元格之间导航。
    *   也可以使用 <kbd>Tab</kbd> 转到下一个单元格，使用 Shift+Tab 转到上一个单元格。
    *   与方向键不同，在表格末尾（最后一行、最后一列）按 <kbd>Tab</kbd> 会自动创建新行。
    *   要选择多个单元格，请在使用方向键时按住 <kbd>Shift</kbd>。
*   使用触摸：
    *   自 v0.107.0 起，触摸表格会勾勒出光标所在单元格或选中单元格的轮廓，并在轮廓的每个角显示一个手柄。
    *   要选择多个单元格，请将其中一个手柄拖过表格。对角处的单元格保持选中状态，因此选择范围会随着手指移动而扩大或缩小。当手柄到达屏幕边缘时，笔记和宽表格会滚动。

## 调整单元格大小

*   可以通过将鼠标悬停在两个相邻单元格的边界上并拖动来调整列宽。
*   要使多列具有相同宽度，请选择跨越这些列的单元格，然后从格式工具栏的 <span class="tn-icon cke cke-table-column"></span>按钮或从[上下文菜单](#context-menu)中选择 _均匀分布列_。
*   默认情况下，行高无法使用鼠标调整，但可以从单元格设置中配置（见下文）。
*   要精确调整单元格的宽度（以像素或百分比表示），请选择 <span class="tn-icon cke cke-table-cell-properties"></span> 按钮。

### 使用触摸调整大小

自 v0.107.0 起，触摸表格会在笔记底部显示一个栏，在移动端位于格式工具栏上方。该栏为表格的每一列都有一个分段，每列末尾有一个分隔线。只有光标所在列的分隔线是可调整大小的手柄；其他分隔线仅标记列的交汇处，因此在其上滑动会滚动。当选中多个单元格时，它们覆盖的每一列都有一个手柄。

*   要调整列宽，请将光标放在其某个单元格中或点击其分段，然后拖动手柄。表格会随列一起增大或缩小，当手柄到达屏幕边缘时会滚动。列会吸附到其起始宽度和相邻列的宽度。
*   要取消调整大小，请将手柄拖回其起始位置，或用第二根手指触摸屏幕。
*   要使一列和下一列具有相同宽度，请双击它们之间的手柄。
*   要选择一列，请点击其分段。要打开列菜单，请长按该分段。
*   要横向滚动宽表格，请沿该栏滑动。

宽表格会滚动到略微超过其末尾的位置，因此其最后一列的手柄会远离屏幕边缘，而在该边缘处滑动会导航返回。

## 宽表格

自 v0.107.0 起，表格可以比<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Content%20width.md">内容宽度</a>更宽。这样的表格会横向滚动，而笔记的其余部分保持其宽度。

*   新表格与内容一样宽。要使其更宽，请将其最后一列的右边框拖过内容边缘。边框会吸附到边缘并短暂停留，因此很容易将表格恢复到内容宽度。
*   要设置精确宽度，请在 <span class="tn-icon cke cke-table-properties"></span> [表格属性](#table-properties)中输入高于 `100%` 的百分比或以像素为单位的宽度。
*   内容需要比笔记更多空间的表格，例如具有许多列的粘贴表格，也会滚动而不是拉伸笔记。
*   宽表格在只读笔记和共享页面中以相同方式滚动。
*   打印或导出为 PDF 时，宽表格会缩小以适应页面。

其他块内的表格，例如块引用、警示框、可折叠块、列或标签页，受限于其块的宽度，不会滚动。

### 移动端支持

在<a class="reference-link" href="../../Installation%20%26%20Setup/Mobile%20Frontend.md">移动端前端</a>上，表格保持其在桌面上的宽度并横向滚动，而不是将其列挤压到屏幕宽度内。表格的完整宽度是移动设备上<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _外观_ → _内容宽度_ 中设置的 _最大内容宽度_，默认为 1200 像素。例如，设置为 `50%` 的表格宽度为 600 像素。

要在移动端调整列宽，请使用[使用触摸调整大小](#resizing-with-touch)中描述的栏。

## 长表格

自 v0.107.0 起，当你滚动浏览表格的其余部分时，表格的表头行会保持在笔记顶部可见，并随表格末尾一起离开。这在只读笔记、共享页面和宽表格中也有效。

要将行变为表头行，请使用[上下文菜单](#context-menu)中的 _设为表头_，或格式工具栏 <span class="tn-icon cke cke-table-row"></span> 按钮中的 _表头行_。

要让表头行随表格的其余部分一起滚动离开，请关闭<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _文本笔记_ → _功能_ → _为表格使用粘性表头行_。该设置仅适用于当前设备，共享页面保留其粘性表头行。

## 插入新行和新列

*   要插入新列，请点击所需位置，然后按格式工具栏中的 <span class="tn-icon cke cke-table-column"></span> 按钮并选择 _在左侧或右侧插入列_。
*   要插入新行，请点击所需位置，然后按 <span class="tn-icon cke cke-table-row"></span> 按钮并选择 _在上方插入行_ 或 _在下方插入行_。
    *   在表格末尾创建新行的更快替代方法是按 <kbd>Tab</kbd> 键。
*   这两种操作也可在[上下文菜单](#context-menu)中使用，它会插入与选择跨度相同数量的行或列。

## 移动行和列

自 v0.106.0 起，可以使用键盘重新排列行和列：

*   <kbd>Alt</kbd>+<kbd>Up</kbd> 和 <kbd>Alt</kbd>+<kbd>Down</kbd> 将选择所触及的行向上或向下移动。
*   <kbd>Alt</kbd>+<kbd>Left</kbd> 和 <kbd>Alt</kbd>+<kbd>Right</kbd> 将选择所触及的列向左或向右移动。

合并单元格永远不会因移动而被拆分。由合并单元格连接在一起的行或列会作为一个块移动，向这样的块移动会完全跳过它。

当表格有表头行时，移到表头区域下方的表头行会变为常规行，而移入表头区域的常规行会变为表头行。表头列的行为相同。

在表格之外，<kbd>Alt</kbd>+<kbd>Left</kbd> 和 <kbd>Alt</kbd>+<kbd>Right</kbd> 继续导航笔记历史，而 <kbd>Alt</kbd>+<kbd>Up</kbd> 和 <kbd>Alt</kbd>+<kbd>Down</kbd> 继续移动当前段落。

## 对行排序

自 v0.107.0 起，可以按某一列的值对表格的行进行排序：

*   要对所有行排序，请将光标放在要作为排序依据的列的任意单元格中，然后从[上下文菜单](#context-menu)中选择 _排序_ → _升序_ 或 _降序_。相同的项也位于格式工具栏的 <span class="tn-icon bx bx-sort-alt-2"></span>按钮中。
*   要仅对部分行排序，请在要作为排序依据的列中选择它们的单元格，然后以相同方式排序。当选择跨越多个列时，排序不可用。

表头行始终保持在表格顶部，永远不会被排序。可以使用 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 撤销排序。

### 值如何比较

每个单元格都作为纯文本读取，因此格式不会影响顺序。Trilium 随后会检测单元格包含的值类型：

| 类型 | 示例 | 比较依据 |
| --- | --- | --- |
| 时间 | `15:02`、`15:02:38`、`3:02 PM` | 一天中的时间。 |
| 日期 | `2026-09-30`、`2026-09-30 15:02`、`30 September 2026`、`Wednesday, 30 September 2026`、`2026-09-30T15:02:38+03:00` | 日期和时间。 |
| 数字 | `12`、`-3.5`、`1,234.56`、`$ 12.04`、`21 RON`、`24.5m` | 数值。 |
| 文本 | 其他任何内容。 | 按字母顺序，忽略大小写，文本中的数字按数值顺序排列（`Item 9` 在 `Item 10` 之前）。重音符号计入，因此 `a` 和 `á` 不同。 |
| 空 | 空单元格，或仅包含空格的单元格。 | 不比较。空单元格始终排在最后。 |

升序将时间排在最前，然后是日期、数字和文本。降序则相反。空单元格在两个方向上都排在最后。

具有相同值的数字、日期和时间按其文本排序，因此 `5 apples` 在 `5 pears` 之前。单元格包含相同文本（忽略大小写）的行保持其相对顺序。

*   日期也会以笔记语言的格式识别，例如德语中的 `30.09.2026` 或 `30. September 2026`，以及在<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _文本笔记_ → _编辑器_ → _日期/时间格式_ 中选择的用于[插入日期和时间](Insert%20buttons.md)的格式。
*   数字可以以货币符号开头，例如 `$`、`€` 或 `£`。数字后面的任何内容（例如单位）都会被忽略，因此单位不会转换：`1 km` 排在 `500 m` 之前。以字母开头的单元格（例如 `RON 21`）是文本。
*   小数分隔符遵循笔记的语言：`1.500` 在英语中是一点五，但在德语中是一千五百。逗号或句点后面不是恰好三位数字时，始终作为小数分隔符读取，因此 `1,5` 在两种语言中都是一点五。
*   笔记的语言在<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Status%20bar.md">状态栏</a>中通过 <span class="tn-icon bx bx-globe"></span> 图标设置，否则为默认内容语言。参见<a class="reference-link" href="Content%20language%20%26%20Right-to-left%20support.md">内容语言与从右到左支持</a>。

### 合并单元格

由合并单元格连接的行会保持在一起并作为一个块移动。该块按其第一行中的值排序。当该块在排序列中有多个单元格时，其他单元格不会影响顺序，并会显示一条消息：_某些行被一起排序，因为合并单元格将它们相互连接_。

当选择仅覆盖此类块的一部分时，整个块都会被排序。

## 合并单元格

要将两个或多个单元格合并在一起，只需通过拖放选择它们，然后按格式工具栏中的 <span class="tn-icon cke cke-table-merge-cell"></span> 按钮。

按旁边的箭头可获得更多选项：

*   点击单个单元格并选择向上/向下/向右/向左合并单元格，以与相邻单元格合并。
*   选择 _合并选中的单元格_ 以合并选中的单元格，与按按钮本身相同。
*   选择 _垂直拆分单元格_ 或 _水平拆分单元格_，以将单元格拆分为多个单元格（也可用于撤销合并）。
*   选择 _取消合并单元格_ 以将选择中的每个合并单元格恢复为其覆盖的单个单元格，并将其内容保留在左上角的单元格中。

_合并选中的单元格_ 和 _取消合并单元格_ 自 v0.107.0 起可用。合并和拆分也可通过右键单击选中的单元格，经由[上下文菜单](#context-menu)使用，其中 _取消合并单元格_ 位于 _拆分单元格_ 子菜单中。

## 表格属性

<figure class="image image-style-align-right"><img style="aspect-ratio:312/311;" src="Tables_image.png" width="312" height="311"></figure>

表格属性可通过 <span class="tn-icon cke cke-table-properties"></span> 按钮访问，允许进行以下调整：

*   边框（不是单元格的边框，而是表格的外边缘），包括样式（单线、双线）、颜色和宽度。
*   背景颜色，默认不设置。
*   表格的宽度和高度，以百分比（必须以 `%` 结尾）或像素（必须以 `px` 结尾）表示。
*   表格的对齐方式。
    *   左对齐或右对齐，在这种情况下文本会环绕在其旁边。
    *   居中，在这种情况下文本会避开表格，无论表格宽度如何。

表格会立即更新以反映更改，但必须按 _保存_ 按钮才能使更改持久化。

## 单元格属性

<figure class="image image-style-align-right"><img style="aspect-ratio:320/386;" src="1_Tables_image.png" width="320" height="386"></figure>

与表格属性类似，<span class="tn-icon cke cke-table-cell-properties"></span> 按钮会打开一个弹出窗口，根据用户的选择调整一个或多个单元格的样式。

可以调整以下选项：

*   边框样式、颜色和宽度（与表格属性相同），但仅应用于当前单元格。
*   背景颜色，默认不设置。
*   单元格的宽度和高度，以百分比（必须以 `%` 结尾）或像素（必须以 `px` 结尾）表示。
*   内边距（文本与单元格边框的距离）。
*   文本的对齐方式，包括水平（左对齐、居中、右对齐、两端对齐）和垂直（顶部、中部或底部）。

单元格会立即更新以反映更改，但必须按 _保存_ 按钮才能使更改持久化。

## 边框和背景颜色

表格和单元格的边框和背景颜色会像[文本颜色](General%20formatting.md)一样适应[主题](../../Basic%20Concepts%20and%20Features/Themes.md)。从调色板中选择、使用颜色选择器选择或输入的颜色会以适合当前主题的较浅或较深色调显示，因此边框保持可见，文本在背景上保持可读。色相保持不变，表格保留所选颜色。

使用旧版 Trilium 应用的颜色会完全按照所选显示，直到笔记下次被编辑。

无法适应颜色的旧版浏览器会完全按照所选显示颜色。

## 标题

按 <span class="tn-icon cke cke-caption"></span> 按钮以插入表格的标题或文本描述，它将显示在表格上方。

## 表格边框

默认情况下，表格会带有预定义的灰色边框。

要调整边框，请按照以下步骤操作：

1.  选择表格。
2.  在浮动面板中，选择 _表格属性_ 选项（<span class="tn-icon cke cke-table-properties"></span>）。
    1.  在新打开的面板顶部查找 _边框_ 部分。
    2.  这将控制表格的外边框。
    3.  为边框选择一种样式。通常 _单线_ 是理想的选择。
    4.  为边框选择一种颜色。
    5.  为边框选择一种宽度，以像素表示。
3.  选择表格的所有单元格，然后按 _单元格属性_ 选项（<span class="tn-icon cke cke-table-cell-properties"></span>）。
    1.  这将在单元格级别控制表格的内边框。
    2.  请注意，可以通过选择一个或多个单元格来单独更改边框，在这种情况下，它只会更改与这些单元格相交的边框。
    3.  重复与步骤 (2) 相同的步骤。

### 无边框表格

可以将表格设置为具有不可见边框，以便对文本或[图片](Images.md)进行基本布局（列、网格），而不会受到边框的干扰：

1.  首先插入具有所需列数和行数的表格。
2.  选择整个表格。
3.  在 _表格属性_ 中，设置：
    1.  _样式_ 为 _单线_
    2.  _颜色_ 为 `transparent`
    3.  宽度为 `1px`。
4.  在单元格属性中，设置与上一步相同。

## 表格缩进

自 v0.104.1 起，表格可以作为一个块缩进（整个表格移动，而不仅仅是单元格的内容）。

1.  点击 <span style="--tn-color:hsl(0,0%,60%);color:hsl(0,0%,60%);"><span class="tn-icon cke cke-drag-handle"></span></span> 按钮以选择整个表格。否则，缩进仅应用于当前单元格的内容。
2.  按 <kbd>Tab</kbd> 增加缩进，或按 <kbd>Shift</kbd>+<kbd>Tab</kbd> 减少缩进。或者，使用格式工具栏中的缩进按钮。

Markdown 不支持缩进的表格，因此转换为 Markdown 时缩进会丢失。

## Markdown 导入/导出

简单表格会以 GitHub 风格的 Markdown 格式导出（例如一系列 `|` 项）。如果发现表格更复杂（包含 HTML 元素、具有自定义尺寸或图片），则表格会改为转换为 HTML 表格。

通常，由于回退到 HTML 格式，导出为 Markdown 时格式丢失应该很少。
