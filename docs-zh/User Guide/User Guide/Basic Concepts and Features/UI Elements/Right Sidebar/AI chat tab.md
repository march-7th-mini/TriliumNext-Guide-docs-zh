# AI 对话标签页
一旦激活 <a class="reference-link" href="../../../AI.md">AI</a> 集成，<a class="reference-link" href="../Right%20Sidebar.md">右侧边栏</a>中就会出现一个 _对话_ 条目。

*   与专用笔记类型不同，侧边栏可以选择访问当前笔记，从而无需先搜索笔记即可轻松询问信息或修改笔记。
    *   要切换当前笔记是否对 AI 可见，只需点击对话界面底部的文件图标。
*   侧边栏右上角有三个按钮：
    *   <span class="tn-icon bx bx-plus"></span> 创建新对话。
    *   <span class="tn-icon bx bx-history"></span> 转到之前的对话。
    *   <span class="tn-icon bx bx-dots-vertical-rounded"></span> 打开菜单，可重命名或删除当前对话，或将其保存为<a class="reference-link" href="../../../Advanced%20Usage/Advanced%20Showcases/Day%20Notes.md">日记</a>中的专用笔记，从而将其变为专用对话笔记。

> [!NOTE]
> 侧边栏对话存储在<a class="reference-link" href="../../../Advanced%20Usage/Hidden%20Notes.md">隐藏笔记</a>中，可在 _AI 对话历史_ 部分查看。

## 移动端

在移动端，对话是笔记面板的 _AI 对话_ 标签页（参见<a class="reference-link" href="../Right%20Sidebar.md">右侧边栏</a>）。其按钮位于面板的标题栏中：

*   左侧的 <span class="tn-icon bx bx-plus"></span> 创建新对话。
*   中间的当前对话标题，点击后会列出之前的对话。
*   关闭按钮旁边的 <span class="tn-icon bx bx-dots-vertical-rounded"></span> 打开与桌面端相同的菜单。
