# 内部（引用）链接
内部链接是指向 Trilium 中其他笔记的链接。

你可以通过点击来打开内部链接。也可以将鼠标悬停在内部链接上，查看其内容的只读预览。

## 插入内部链接

可以通过以下方式在文本笔记的当前位置创建内部链接：

1.  按下 <kbd>Ctrl</kbd> + <kbd>L</kbd>，或点击 <a class="reference-link" href="../Formatting%20toolbar.md">格式工具栏</a> 中 <span class="tn-icon cke cke-plus"></span> 菜单下方的 <span class="tn-icon cke cke-trilium"></span> 按钮。
2.  搜索要链接的笔记标题。也可以在此对话框中创建新笔记：输入一个不存在的笔记标题，然后选择 _创建笔记_（将其放入 <a class="reference-link" href="../../../Basic%20Concepts%20and%20Features/Notes/Note%20Inbox.md">笔记收件箱</a>，即今天的日记笔记；若未设置收件箱，则放入顶层），或选择 _创建子笔记_（将其放在当前正在编辑的笔记下）。

链接有两种类型，通过对话框中的 _镜像笔记标题_ 开关选择，该开关默认开启：

1.  开关开启时，链接会镜像笔记的标题。
    1.  这有时也被称为“引用链接”。
    2.  此链接的标题无法更改，而是始终显示所链接笔记的当前标题。
    3.  同时还会显示所链接笔记的图标。
    4.  如果所链接的笔记被删除，链接会保留其最后显示的标题，以红色显示，并用 <span class="tn-icon bx bx-x"></span> 图标代替笔记图标。在编辑时点击它，会打开 _修复链接_ 对话框，该对话框会搜索该标题；选择一篇笔记或创建新笔记，即可将链接替换为指向该笔记的链接。
2.  开关关闭时，链接拥有自己的标题，在 _链接标题_ 字段中输入。
    1.  这会创建一个传统超链接，其中链接文本可以与笔记标题不同。

自 v0.107.0 起，要更改标题不镜像笔记的链接，请点击它并按下其弹出窗口中的 <span class="tn-icon cke cke-pencil"></span> _编辑链接_ 按钮，或将光标置于其中并按下 <kbd>Ctrl</kbd> + <kbd>L</kbd> 或 <span class="tn-icon cke cke-trilium"></span> 按钮。_编辑链接_ 对话框会在所链接的笔记上打开，显示其锚点和链接文本；_保存链接_ 会更改整个链接。在此处开启 _镜像笔记标题_ 会将其变为镜像标题的链接。

## 就地链接

你也可以使用 `@` 符号“内联”插入内部链接：

1.  在文本笔记中输入 `@`，会打开笔记搜索菜单。
2.  输入几个字符来搜索所需笔记的标题。使用 <kbd>Up</kbd> 和 <kbd>Down</kbd> 选择正确的笔记，然后按 <kbd>Enter</kbd> 或 <kbd>Tab</kbd> 创建链接。也可以使用此方法创建新笔记：输入一个不存在的笔记标题，然后选择 _创建笔记_ 或 _创建子笔记_，如上所述。

## 粘贴内部链接

你也可以通过从笔记树中复制笔记来插入内部链接。

1.  在 <a class="reference-link" href="../../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a> 中，选择一篇笔记并按 <kbd>Ctrl</kbd> + <kbd>C</kbd>。
2.  在文本笔记中，按 <kbd>Ctrl</kbd> + <kbd>V</kbd> 粘贴链接。
