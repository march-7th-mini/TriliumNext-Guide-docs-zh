# 用户指南

Trilium 是一款用于笔记记录和组织个人知识库的开源解决方案。您可以在桌面端本地使用它，或通过自托管服务器进行同步，随时随地访问您的笔记。

> [!TIP]
> 在 Trilium Notes 应用程序中按 F1 键，也可以本地访问相同的文档。
