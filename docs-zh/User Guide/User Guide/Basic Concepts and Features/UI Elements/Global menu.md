# 全局菜单
全局菜单用于配置当前窗口（缩放、窗口置顶）、切换主题，并提供对一些更高级选项的访问。

![](Global%20menu_image.jpg)

## 访问全局菜单

请参阅[垂直与水平布局](Vertical%20and%20horizontal%20layout.md)，因为全局菜单的位置会根据所选布局而变化。

## 切换主题

_主题_ 子菜单可在不打开<a class="reference-link" href="Options.md">选项</a>的情况下更改应用程序的外观。每行末尾的勾选标记表示当前选中的选项。该子菜单在移动端不显示；在移动端请从<a class="reference-link" href="Options.md">选项</a> → _外观_ 中更改主题。

*   在 _配色方案_ 下，选择 _系统_ 以跟随操作系统的浅色或深色模式，或选择 _浅色_ 或 _深色_ 以强制使用其中一种。
*   在 _主题_ 下，选择 _现代_（默认主题）或某个自定义主题，每个自定义主题都会显示其笔记的图标。切换到 _现代_ 会保留当前的配色方案。

自定义主题自带配色，因此在其启用期间配色方案不可用。旧版主题不会列出；请改为从<a class="reference-link" href="Options.md">选项</a> → _外观_ 中选择它。

有关内置主题和自定义主题的更多信息，请参阅<a class="reference-link" href="../Themes.md">主题</a>。
