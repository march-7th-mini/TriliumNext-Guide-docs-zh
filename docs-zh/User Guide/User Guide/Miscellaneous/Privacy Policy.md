# 隐私政策
### Trilium Notes

Trilium Notes 不会收集/发送用户安装中的任何数据，即没有分析、没有遥测等。数据仅在用户控制/安装的应用程序之间流动，没有任何中间方。

自动网络活动包括：

*   Trilium 会定期查询 URL [https://github.com/TriliumNext/Trilium/releases](https://github.com/TriliumNext/Trilium/releases) 以检查是否有新的稳定版本发布。（仅检查，不会自动下载和/或安装）。
*   根据语言设置，Trilium 将根据需要自动下载拼写词典。

### Trilium Web Clipper

Trilium Web Clipper 不会收集/发送用户安装中的任何数据，即没有分析、没有遥测等。数据仅在用户控制/安装的应用程序之间流动，没有任何中间方。

### Trilium Sender for Android

Trilium Sender for Android 不会收集/发送用户安装中的任何数据，即没有分析、没有遥测等。数据仅在用户控制/安装的应用程序之间流动，没有任何中间方。
