# 书签

常用的笔记可以添加书签，这样它们就会出现在<a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">启动栏</a>中，方便访问。

## 配置启动栏

如果书签没有出现在启动栏中，那么很可能是书签区域被隐藏了。从<a class="reference-link" href="../UI%20Elements/Global%20menu.md">全局菜单</a>进入<a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">启动栏</a>配置，确保 _书签_ 位于 _可见启动器_ 区域中。

## 书签文件夹

左侧面板的空间有限，而你可能想为许多项目添加书签。一个可行的解决方案是为文件夹添加书签，这样它就会显示其子项：

为此，请为一个文件夹添加书签，然后在<a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">启动栏</a>中右键单击其按钮并勾选 _文件夹_。该按钮随后会打开一个菜单而不是笔记本身：笔记位于顶部，其后是它的子项。取消勾选 _文件夹_ 即可将其恢复为普通书签。

如果某个子项自身还有子项，则会在其行末显示一个箭头。单击箭头可在子菜单中列出其子项，或单击该行的其余部分以打开笔记。子菜单最多可嵌套四层。列出超过 15 个子项的菜单会在其上方显示一个筛选字段：输入标题的一部分即可只列出匹配的笔记。子树被隐藏的笔记（参见<a class="reference-link" href="../UI%20Elements/Note%20Tree/Hiding%20the%20subtree.md">隐藏子树</a>）在这里也不会列出其子项。

菜单中的笔记打开方式与链接相同：中键单击或 <kbd>Ctrl</kbd>+单击会在新标签页中打开笔记，<kbd>Shift</kbd>+单击会在新窗口中打开它，右键单击则会列出其他可以打开它的位置。

_文件夹_ 会将 `#bookmarkFolder` 标签分配给该笔记，因此手动添加该标签也同样有效。由于该标签属于笔记本身，一个既被添加了书签又被拖放到启动栏上的笔记会在两个位置都显示其子项。

## 移动端

在移动端，书签仅从 v0.102.0 开始显示。由于屏幕尺寸更为受限，书签会分组在单个图标下，而不是作为单独的图标显示。

按下后，会出现一个菜单列出所有书签。书签文件夹也受支持，并会显示为子菜单。每个子菜单都以其自身的笔记开头，因此带有子项的笔记既可以打开也可以浏览。
