# 用户指南
Trilium 是一款用于笔记记录和个人知识库整理的开源解决方案。你可以在桌面端本地使用它，也可以将其与自托管服务器同步，让笔记随时随地可用。

> [!TIP]
> 同样的文档也可以在 Trilium Notes 应用程序内按 F1 键从本地访问。
