# 格式工具栏

Trilium 根据您的偏好，为文本笔记提供两种不同的编辑体验。

格式工具栏的类型可以通过进入 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> 然后在其中查找 <a class="reference-link" href="#root/_options/_optionsTextNotes">文本笔记</a> 部分来更改。在该部分中，查找 _格式工具栏_ 类别。

## 浮动

浮动栏是一种更简约的选项，其中格式功能隐藏在两个不同的弹出窗口后面。

### 块级弹出窗口

第一个弹出窗口是块级弹出窗口。它会以一系列圆点的形式出现在您当前正在编辑的段落左侧：  
![](1_Formatting%20toolbar_image.png)

点击此弹出窗口将显示适用于整个段落的格式选项，例如设置标题、列表、表格等。

![](3_Formatting%20toolbar_image.png)

### 行内弹出窗口

当选中文本时，行内弹出窗口会自动出现：

![](Formatting%20toolbar_image.png)

这里的所有选项仅适用于选中的文本部分，例如更改字体大小或使文本加粗。

## 固定

固定格式提供更传统的编辑范式，通常在需要大量格式设置时非常有用。

所有选项都合并到一个工具栏中，该工具栏将作为 [功能区](../../Basic%20Concepts%20and%20Features/UI%20Elements/Ribbon.md) 的一部分出现。

![](2_Formatting%20toolbar_image.png)

默认情况下，如果工具栏无法在屏幕上完全显示，其余选项将分组到末尾的单个选项中。可以通过勾选 _格式工具栏_ 部分中的相应选项来在多行上显示项目。
