# 多栏布局
多栏布局将内容并排排列为两到四栏。每一栏可以容纳任何类型的内容，包括表格、图片以及另一个多栏布局。

## 插入布局

*   在格式栏中，转到 _插入_ → <span class="tn-icon cke cke-trilium-multicolumn"></span> _多栏布局_ 以插入一个两栏布局。其子菜单提供 _2 栏_、_3 栏_ 和 _4 栏_。
*   或者，输入 `/columns` 并选择 _2 栏布局_、_3 栏布局_ 或 _4 栏布局_，如 <a class="reference-link" href="Slash%20Commands.md">斜杠命令</a> 中所述。

新布局的各栏宽度相等。如果在插入布局时选中了文本，所选内容会移入第一栏。

## 更改栏

### 更改布局

当光标位于布局内部时，其上方会出现一个工具栏，其中有一个显示当前布局的按钮。点击它会打开一行图形，每个可用布局对应一个图形；将鼠标悬停在图形上会显示其栏数及各栏宽度：

| 栏数 | 宽度 |
| --- | --- |
| 2 | 50%-50%、25%-75%、75%-25% |
| 3 | 33%-33%-33%、25%-50%-25% |
| 4 | 25%-25%-25%-25% |

*   选择栏数更多的布局会在末尾添加空栏。
*   选择栏数更少的布局会移除末尾的栏，并将其内容移到最后一个剩余栏的末尾。

### 添加栏

当光标位于某一栏中时，你可以使用以下组合键：

*   <kbd>Ctrl</kbd> + <kbd>Enter</kbd>：在当前栏之后添加一栏。
*   <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Enter</kbd>：在当前栏之前添加一栏。

新栏为空，光标会移入其中。随后所有栏的宽度相等。一个布局最多有四栏，因此在已有四栏的布局中这些按键不起作用。

<kbd>Ctrl</kbd> + <kbd>Enter</kbd> 在链接、待办事项和可折叠块的标题中保留其通常功能，<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Enter</kbd> 在待办事项中也是如此。

### 重新排列栏

当光标位于某一栏内的任意位置时，你可以使用以下组合键：

*   <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Right</kbd>：将该栏向右移动。
*   <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Left</kbd>：将该栏向左移动。
*   <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Home</kbd>：使其成为第一栏。
*   <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>End</kbd>：使其成为最后一栏。

在具有两个不同宽度栏的布局中，该栏会保持其宽度。

## 在栏之间移动内容

要将内容移动到另一栏，请选中它，然后使用以下组合键：

*   <kbd>Ctrl</kbd> + <kbd>Right</kbd>：移动到右侧的栏。
*   <kbd>Ctrl</kbd> + <kbd>Left</kbd>：移动到左侧的栏。
*   <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>End</kbd>：移动到最后一栏。
*   <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Home</kbd>：移动到第一栏。

段落、列表项、表格和其他块会整体移动，即使只选中了它们的一部分。移动到左侧栏的内容会放到该栏的末尾，而移动到右侧栏的内容会放到其开头，因此它在阅读顺序中保持其位置。

在没有选中内容时，这些按键保留其通常功能：按词移动光标，或选择到该栏的开头或结尾。

当布局和 <a class="reference-link" href="Content%20tabs.md">内容标签页</a> 相互嵌套时，组合键会作用于最靠近光标的那个。

## 移除布局

*   要移除布局但保留其内容，请点击布局工具栏中的 <span class="tn-icon cke cke-remove"></span> _移除布局_ 按钮。各栏的内容会依次放置在布局原来的位置，空栏会被略去。
*   要连同其内容一起删除布局，请点击其左上角的手柄以选中它，然后按 <kbd>Delete</kbd>。

## 窄屏幕

当布局为其各栏提供的空间过少时（窄于约 500 像素，例如在手机上），各栏会上下堆叠。编辑时，交替的背景颜色可区分各栏。这分别适用于每个布局，因此窄栏内的布局会堆叠，而外层布局仍保持并排。

## 打印和导出

*   在打印或[导出为 PDF](../../Basic%20Concepts%20and%20Features/Notes/Printing%20%26%20Exporting%20as%20PDF.md) 时，各栏会并排打印。
*   Markdown 没有栏的概念，因此 Markdown 导出会将布局和每一栏保留为 HTML `<div>` 标签，每一栏的内容以 Markdown 形式写在它们之间。将文件重新导入会恢复该布局。不支持 HTML 的 Markdown 查看器会依次显示各栏的内容。
