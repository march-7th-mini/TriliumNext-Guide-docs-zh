# 内部（引用）链接
内部链接是指向 Trilium 中其他笔记的链接。

你可以通过点击内部链接来打开它。也可以将鼠标悬停在内部链接上，查看其内容的只读预览。

## 插入内部链接

可以通过以下方式在文本笔记的当前位置创建内部链接：

1.  按下 <kbd>Ctrl</kbd> + <kbd>L</kbd>，或点击 <a class="reference-link" href="../Formatting%20toolbar.md">格式工具栏</a> 中 <img src="1_Internal (reference) links_image.png" width="34" height="16"> 菜单下方的 <img src="Internal (reference) links_image.png" width="20" height="17"> 按钮。
2.  搜索想要链接的笔记标题。也可以在此对话框中创建新笔记，方法是输入一个不存在的笔记标题，然后选择 _创建笔记_（将其放入 <a class="reference-link" href="../../../Basic%20Concepts%20and%20Features/Notes/Note%20Inbox.md">笔记收件箱</a>，即今天的日记笔记；如果未设置收件箱，则放入顶层），或选择 _创建子笔记_（将其放在正在编辑的笔记下方）。

创建指向笔记的链接时，可以选择两种链接类型：

1.  _链接标题镜像笔记的当前标题_
    1.  有时也称为“引用链接”。
    2.  此链接的标题无法更改。相反，它将始终显示所链接笔记的当前标题。
    3.  所链接笔记的图标也会一并显示。
2.  _链接标题可任意更改_
    1.  这将创建一个传统超链接，其中链接文本可以与笔记标题不同。

## 就地链接

你也可以使用 `@` 符号“内联”插入内部链接：

1.  在文本笔记中输入 `@`，将打开笔记搜索菜单。
2.  输入几个字符来搜索所需笔记的标题。使用 <kbd>Up</kbd> 和 <kbd>Down</kbd> 选择正确的笔记，然后按 <kbd>Enter</kbd> 或 <kbd>Tab</kbd> 创建链接。也可以使用此方法创建新笔记，方法是输入一个不存在的笔记标题，然后选择 _创建笔记_ 或 _创建子笔记_，如上所述。

## 粘贴内部链接

你也可以通过从笔记树中复制笔记来插入内部链接。

1.  在 <a class="reference-link" href="../../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a> 中，选择一条笔记并按 <kbd>Ctrl</kbd> + <kbd>C</kbd>。
2.  在文本笔记中，按 <kbd>Ctrl</kbd> + <kbd>V</kbd> 粘贴链接。
