# 可折叠标题
标题可以折叠，以隐藏其下方的内容，直到下一个同级或更高级别的标题为止。较低级别的标题会连同其余内容一起被隐藏，并保留其自身的状态。

## 折叠与展开

*   要折叠或展开标题，请点击标题末尾的箭头。当鼠标悬停在标题上或光标位于其中时，箭头会出现，并且在标题折叠期间保持可见。
*   若要使用键盘，请将光标置于标题中，然后按 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Enter</kbd>。
*   标题旁拖动柄的菜单中也提供 _折叠章节_ 和 _展开章节_。

折叠状态会随笔记一起保存，因此再次打开笔记时标题会保持折叠状态。

## 在折叠标题周围编辑

*   在折叠标题末尾按 <kbd>Enter</kbd>，会在隐藏内容下方添加一个同级标题。
*   方向键会将光标移过隐藏内容。
*   在折叠标题内容的正下方按 <kbd>Backspace</kbd>，或在折叠标题末尾按 <kbd>Delete</kbd>，会展开标题而不是删除隐藏内容。如果隐藏内容正下方的行为空，则任一按键都会删除该空行。
*   通过拖动柄拖动折叠标题时，其隐藏内容会随之移动。
*   当向折叠标题的章节添加内容时（例如通过粘贴或在其下方拖放块），该标题会展开。
*   _在笔记中搜索_、目录以及指向块的链接在跳转到隐藏内容时会显示该内容，但不会展开标题。

## 只读笔记

箭头在只读显示的笔记中同样有效（参见 <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Notes/Read-Only%20Notes.md">只读笔记</a>），但在那里更改不会被保存：重新打开笔记时会再次显示其保存的状态。

要在那里使用键盘，请按 <kbd>Tab</kbd> 移动到下方有内容的标题，然后按 <kbd>Enter</kbd> 或 <kbd>Space</kbd> 来折叠或展开它。

## 限制

*   共享笔记和打印输出始终显示所有内容。
*   折叠状态会保留在 HTML 导出中，但不会保留在 Markdown 导出中。
