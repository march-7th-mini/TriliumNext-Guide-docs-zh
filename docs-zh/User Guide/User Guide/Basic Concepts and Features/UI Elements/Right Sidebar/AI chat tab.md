# AI对话标签页

一旦 <a class="reference-link" href="../../../AI.md">AI</a> 集成被激活，_对话_ 条目将出现在 <a class="reference-link" href="../Right%20Sidebar.md">右侧边栏</a> 中。

*   与专门的笔记类型不同，侧边栏可以可选地访问当前笔记，使得无需先搜索笔记即可轻松询问信息或修改笔记。
    *   要切换当前笔记是否对 AI 可见，只需点击聊天界面底部的文件图标。
*   在侧边栏的右上角有三个按钮：
    *   创建新对话。
    *   前往之前的对话。
    *   将当前对话保存为 <a class="reference-link" href="../../../Advanced%20Usage/Advanced%20Showcases/Day%20Notes.md">每日笔记</a> 中的专门笔记，这将其转换为专门的对话笔记。

> [!NOTE]
> 侧边栏对话存储在 <a class="reference-link" href="../../../Advanced%20Usage/Hidden%20Notes.md">隐藏笔记</a> 中，可以在 _AI 对话历史_ 部分查看。
