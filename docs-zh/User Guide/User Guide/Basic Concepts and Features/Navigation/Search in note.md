# 在笔记中搜索
<figure class="image image_resized" style="width:100%;"><img style="aspect-ratio:898/93;" src="Search in note_image.png" width="898" height="93"></figure>

本地搜索允许你在当前显示的笔记中进行搜索。

## 其他方式

*   在浏览器中，当焦点不在<a class="reference-link" href="../../Note%20Types/Text.md">文本</a>或<a class="reference-link" href="../../Note%20Types/Code.md">代码</a>笔记中时，按下 Ctrl+F 将触发浏览器的原生搜索。这也会查找属于 Trilium 用户界面一部分的文本。
*   在<a class="reference-link" href="../../Note%20Types/Text.md">文本</a>笔记中按下 Ctrl+F 将显示<a class="reference-link" href="../../Advanced%20Usage/Technologies%20used/CKEditor.md">CKEditor</a>的搜索功能。

## 访问搜索功能

*   在桌面上，按下<kbd>Ctrl</kbd> + <kbd>F</kbd>
*   在<a class="reference-link" href="../UI%20Elements/Note%20buttons.md">笔记按钮</a>中，找到上下文菜单并选择_在笔记中搜索_。

## 交互操作

*   查找：
    *   在_在文本中查找…_中填写要搜索的文本。
    *   搜索将在后台自动执行。
    *   使用文本框的上、下箭头在结果之间导航。
*   替换：
    *   在_在文本中查找…_字段中填写要替换的文本。
    *   在_替换为…_字段中填写要替换成的文本。
    *   按下_替换_仅替换当前结果。
    *   按下_全部替换_一次性替换所有结果。
*   选项：
    *   _区分大小写_ – 搜索将区分大写和小写字符（例如，搜索 Hello 将不会匹配 `hello`）。
    *   _全字匹配_ - 搜索将仅查找精确的单词匹配（例如，搜索 `Java` 将不会匹配 `JavaScript`）。
