# 脚注
<figure class="image image-style-align-right"><img style="aspect-ratio:199/187;" src="Footnotes_image.png" width="199" height="187"></figure>

脚注是插入对段落或细节的引用的好地方，这些引用会显示在笔记底部。

## 交互

*   要插入新脚注，请打开<a class="reference-link" href="Formatting%20toolbar.md">格式工具栏</a>的<span class="tn-icon cke cke-plus"></span> _插入_ 菜单，然后选择<span class="tn-icon cke cke-trilium-insert-footnote"></span> _脚注_（或在其子菜单中选择_新建脚注_）。
*   要插入对现有脚注的引用，请打开_脚注_的子菜单并选择_插入脚注_，然后选择要插入的脚注编号。
*   将鼠标悬停在引用（例如 `[1]`）上时，会在工具提示中显示脚注内容，便于参考。
*   点击文本中的引用（例如 `[1]`）将导航到相应的脚注。
*   同样，点击脚注的 `^` 按钮将导航到文本中相应的引用。
