# Vim 完整参考

本页列出 Vim 模式的按键和命令，适用于文本笔记和<a class="reference-link" href="../../Code.md">代码</a>笔记。除非某行另有说明，否则两者均适用。入门介绍请参阅<a class="reference-link" href="Vim%20beginner%20guide.md">Vim 入门指南</a>；关于设置、最常用的按键以及文本笔记如何按行读取，请参阅<a class="reference-link" href="../Vim%20mode.md">Vim 模式</a>。

## 阅读表格

*   依次输入的按键写在一起：`dd` 表示按两次 `d`。同时按住的按键用加号表示：<kbd>Ctrl</kbd>+<kbd>R</kbd>。
*   `{motion}` 代表 _移动_ 中的任意按键，`{char}` 代表任意字符，`{count}` 代表数字，`{register}` 代表寄存器的名称。
*   除非某节另有说明，按键均在普通模式下输入。
*   在 Windows 和 Linux 的浏览器中，<kbd>Ctrl</kbd>+<kbd>W</kbd>、<kbd>Ctrl</kbd>+<kbd>T</kbd> 和 <kbd>Ctrl</kbd>+<kbd>N</kbd> 会被浏览器保留，用于关闭标签页或打开标签页或窗口，因此它们永远不会到达 Trilium。使用这些按键的行会注明这一点。桌面应用和 macOS 不受影响。

描述末尾的徽章说明该行的适用范围：

*   **仅文本笔记**：在代码笔记中不可用。
*   **仅代码笔记**：在文本笔记中不可用。
*   **Trilium 独有**：由 Trilium 引入的命令，或行为已适配 Trilium 的 Vim 命令。

### 可用但不保证

在文本笔记中，大多数按键和命令已适配富文本并经过测试。以下按键和命令在纯文本上的行为与 Vim 一致，但针对文本笔记的结构（如表格、图片和嵌套列表）测试较少。如果其中某个按键对文本做出了意外更改，请按 `u` 撤销，并在继续之前检查结果。应用在按键列表和命令行中以相同的名称列出它们。

*   宏：`q` 和 `@`。
*   带名称的寄存器：`"a` 到 `"z`、编号寄存器和特殊寄存器。这不包括未指定名称时使用的寄存器，也不包括剪贴板寄存器 `"+` 和 `"*`。
*   标记：`m`、`'` 和 `` ` ``。
*   命令行中的这些命令：`:g`、`:v`、`:normal`、`:d`、`:y`、`:pu`、`:j`、`:registers`、`:marks`、`:delmarks`，以及按键映射（`:map` 及其变体、`:unmap`、`:mapclear`）。

以下各节在适用处会再次说明。代码笔记没有这种区分。

| `s` | 删除光标下的字符并插入。 |

## 移动

移动会移动光标。在操作符之后，它告诉操作符作用于多少文本。在可视模式中，它扩展选择。

### 字符与行

| 按键 | 移动到 |
| --- | --- |
| `h` / `l` | 行内左 / 右的字符。也可用 <kbd>←</kbd> 或 <kbd>Backspace</kbd>，以及 <kbd>→</kbd> 或 <kbd>Space</kbd>。 |
| `j` / `k` | 下 / 上一行。也可用 <kbd>↓</kbd> 和 <kbd>↑</kbd>。在文本笔记的表格中，它们沿列向下 / 向上移动。 |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> / <kbd>Ctrl</kbd>+<kbd>P</kbd> | 与 `j` / `k` 相同。在 Windows 和 Linux 的浏览器中，<kbd>Ctrl</kbd>+<kbd>N</kbd> 不起作用。 |
| `gj` / `gk` | 在换行的行内，下 / 上一个屏幕行。 |
| `0` 或 <kbd>Home</kbd> | 行的开头。 |
| `^` | 行的第一个非空白字符。 |
| `$` 或 <kbd>End</kbd> | 行的末尾。 |
| `g0` 或 `g^` / `g$` | 屏幕行的开头 / 末尾。 |
| `{count}\|` | 该编号的列。 |
| `+` 或 <kbd>Enter</kbd> / `-` | 下 / 上一行的第一个非空白字符。 |
| `_` | 当前行的第一个非空白字符。 |

### 单词与句子

| 按键 | 移动到 |
| --- | --- |
| `w` / `b` | 下 / 上一个单词的开头。 |
| `e` / `ge` | 单词 / 上一个单词的末尾。 |
| `W` `B` `E` `gE` | 相同，但仅针对以空格分隔的单词，因此标点符号属于单词的一部分。 |
| `(` / `)` | 上 / 下一句的开头。 |

### 行内

| 按键 | 移动到 |
| --- | --- |
| `f{char}` / `F{char}` | 行内下 / 上一个 `{char}`。 |
| `t{char}` / `T{char}` | 行内下 / 上一个 `{char}` 之前 / 之后。 |
| `;` / `,` | 以相同 / 相反方向重复上一次 `f`、`F`、`t` 或 `T`。 |
| `%` | 与光标下括号匹配的括号：`()`、`[]` 或 `{}`。 |
| `[(` / `])` | 光标周围括号对的开 / 闭括号。 |
| `[{` / `]}` | 光标周围花括号对的开 / 闭括号。 |

### 块与标题

| 按键 | 移动到 |
| --- | --- |
| `{` / `}` | 上 / 下一段落，以空行分隔。在文本笔记中，光标嵌套层级的上 / 下一块（段落、列表项、表格、引用等）。 |
| `[[` / `]]` | 上 / 下一个标题。**Trilium 独有** **仅文本笔记** |
| `[]` / `][` | 上 / 下一个标题之前的行。**Trilium 独有** **仅文本笔记** |
| `[z` / `]z` | 光标所在节的标题 / 最后一行。**Trilium 独有** **仅文本笔记** |
| `zk` / `zj` | 上 / 下一个标题。**Trilium 独有** **仅文本笔记** |

### 笔记与屏幕

| 按键 | 移动到 |
| --- | --- |
| `gg` / `G` | 笔记的第一 / 最后一行。 |
| `{count}G` 或 `{count}gg` | 该编号的行。 |
| `{count}%` | 笔记中该百分比处的行。**仅文本笔记** |
| `H` / `M` / `L` | 屏幕上的顶 / 中 / 底行。 |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> / <kbd>Ctrl</kbd>+<kbd>U</kbd> | 向下 / 向上半页。 |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> / <kbd>Ctrl</kbd>+<kbd>B</kbd> | 向下 / 向上一页。也可用 <kbd>Page Down</kbd> 和 <kbd>Page Up</kbd>。 |

## 滚动

这些按键滚动笔记，并将光标留在其所在行。

| 按键 | 操作 |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> | 向下 / 向上滚动一行。 |
| `zz` / `zt` / `zb` | 将光标所在行滚动到屏幕的中间 / 顶部 / 底部。 |
| `z.` / `z`<kbd>Enter</kbd> / `z-` | 相同，并将光标移动到第一个非空白字符。 |

## 操作符

操作符作用于其后的移动或文本对象所覆盖的文本：`dw`、`c$`、`yap`。连续输入操作符的最后一个键两次会将其应用于整行：`dd`、`yy`、`cc`、`>>`、`g~~`、`guu`、`gUU`。在可视模式中，操作符作用于选择内容。

| 按键 | 操作 |
| --- | --- |
| `d{motion}` | 删除。删除的文本进入寄存器，因此 `p` 可以将其放回。 |
| `y{motion}` | 复制（yank），复制到寄存器。 |
| `c{motion}` | 更改：删除，然后进入插入模式。 |
| `>{motion}` / `<{motion}` | 增加 / 减少缩进。在文本笔记中，这会更改列表项的级别或段落的缩进。 |
| `g~{motion}` | 在大写和小写之间切换。 |
| `gu{motion}` / `gU{motion}` | 转为小写 / 大写。 |
| `g?{motion}` | 使用 ROT13 编码。 |
| `={motion}` | 按其语言的规则重新缩进代码。`==` 对当前行执行。**仅代码笔记** |
| `gq{motion}` / `gw{motion}` | 按文本宽度（默认为 80 个字符，除非 `:set textwidth` 更改）换行长行。`gw` 将光标留在原处。**仅代码笔记** |
| `gc{motion}` | 在有行注释的语言中，将行变为注释，或恢复为代码。`gcc` 对当前行执行。**仅代码笔记** |

| `D` | `d$` | 删除到行尾。 |

| `Y` | `yy` | 复制整行。 |
| `s` | `cl` | 更改光标下的字符。 |
| `S` | `cc` | 更改整行。 |
| `~` |  | 切换光标下字符的大小写并向右移动。 |

## 其他更改

| 按键 | 操作 |
| --- | --- |
| `r{char}` | 将光标下的字符替换为 `{char}`。 |
| `J` | 将下一行连接到本行，中间加一个空格。在文本笔记中，行的连接方式与在下一行开头按 <kbd>Backspace</kbd> 相同。 |
| `gJ` | 连接时不加空格。 |
| `p` / `P` | 将寄存器内容放在光标后 / 前。复制的行放在当前行下方 / 上方。 |
| `]p` / `[p` | 放置，并采用当前行的缩进。在文本笔记中，与 `p` 和 `P` 相同。 |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> / <kbd>Ctrl</kbd>+<kbd>X</kbd> | 将光标处或之后的数字加一 / 减一。带计数时，加减该数量。 |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | 与 `u` 和 <kbd>Ctrl</kbd>+<kbd>R</kbd> 相同。**仅文本笔记** |

## 文本对象

文本对象在操作符之后或可视模式中输入，指定光标周围的一段文本。`i` 取内部，`a` 还包括其周围的内容：`ciw`、`da(`、`yip`。

| 按键 | 选择 |
| --- | --- |
| `iw` / `aw` | 单词，不含 / 含旁边的空格。 |
| `iW` / `aW` | 相同，但针对以空格分隔的单词。 |
| `is` / `as` | 句子。 |
| `ip` / `ap` | 段落，不含 / 含其后的空行。在文本笔记中，光标周围的块：段落、列表项（使用 `ap` 时还包括其嵌套项）、引用、表格单元格、代码块。在标题上，`ip` 是标题，`ap` 是标题及其节。 |
| `i(` / `a(` | 括号内的文本，不含 / 含括号。也可用 `i)` 和 `ib`。 |
| `i[` / `a[` | 方括号内的文本，不含 / 含括号。 |
| `i{` / `a{` | 花括号内的文本，不含 / 含括号。也可用 `i}` 和 `iB`。 |
| `i<` / `a<` | 尖括号内的文本，不含 / 含括号。 |
| `i"` / `a"` | 双引号内的文本，不含 / 含引号。 |
| `i'` / `a'` | 单引号内的文本，不含 / 含引号。 |
| `` i` `` / `` a` `` | 两个反引号之间的文本，不含 / 含反引号。第二个键是反引号。 |
| `it` / `at` | 标签的内容，不含 / 含标签，用于语言有标签的笔记，如 HTML。**仅代码笔记** |

## 可视模式

| 按键 | 操作 |
| --- | --- |
| 任意移动或文本对象 | 扩展选择。 |
| `o` | 转到选择的另一端。 |
| `v` / `V` | 在字符和整行之间切换。当前模式的按键会离开可视模式。 |
| `d` 或 `x` | 删除选择内容。 |
| `y` | 复制选择内容。 |
| `c` 或 `s` | 更改选择内容。 |
| `D` / `Y` | 删除 / 复制选择内容所在的整行。 |
| `S` 或 `R` | 更改选择内容所在的整行。 |
| `>` / `<` | 增加 / 减少所选行的缩进。 |
| `~` / `u` / `U` | 切换大小写 / 转为小写 / 转为大写。 |
| `J` / `gJ` | 连接所选行，含 / 不含空格。 |
| `r{char}` | 将每个所选字符替换为 `{char}`。 |
| `p` 或 `P` | 用寄存器内容替换选择内容。 |
| `:` | 为所选行打开命令行。 |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | 将选择内容连同其格式复制到剪贴板，并离开可视模式。**仅文本笔记** |
| <kbd>Esc</kbd> | 离开可视模式。 |

在文本笔记中，在普通模式下用鼠标选择会进入可视模式。

## 寄存器

寄存器保存复制或删除的文本。要使用寄存器，请在命令前输入 `"` 及其名称：`"ayy` 将行复制到 `a`，`"ap` 将其放置。在文本笔记中，带名称的寄存器是 _可用但不保证_ 的。

| 寄存器 | 保存 |
| --- | --- |
| `""` | 最后一次复制或删除的文本。这是未指定名称时使用的寄存器。 |
| `"a` 到 `"z` | 你放入的内容。使用大写字母 `"A` 到 `"Z` 时，文本会追加到寄存器已有的内容中。 |
| `"0` | 最后一次复制的文本。 |
| `"1` 到 `"9` | 最后删除的行，最近的在前。 |
| `"-` | 最后一次删除的短于一行文本。 |
| `"_` | 无：删除到其中的文本会消失，其他寄存器保持不变。 |
| `".` | 最后插入的文本。 |
| `":` | 命令行的最后一条命令。 |
| `"/` | 最后的搜索模式。 |
| `"+` | 系统剪贴板。在文本笔记中，`"+y` 复制时保留格式。 |
| `"*` | 也是系统剪贴板。**仅文本笔记** |

| 按键 | 操作 |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> `{register}` | 在插入模式中，插入寄存器内容。 |
| `:registers` | 列出寄存器及其内容。 |

在文本笔记中，寄存器保留文本的格式，如粗体、链接和颜色。所有文本笔记共享一组寄存器，代码笔记有另一组。

## 标记与跳转

标记记住笔记中的一个位置。跳转列表记住大型移动（如 `G`、`/` 和 `%`）离开的位置。在文本笔记中，标记是 _可用但不保证_ 的。

两个按键可转到标记：反引号，写作 `` ` ``，以及撇号，写作 `'`。

| 按键 | 操作 |
| --- | --- |
| `m{a-z}` | 在光标处设置该字母的标记：`ma`。 |
| 反引号，然后字母 | 转到标记：`` `a ``。 |
| 撇号，然后字母 | 转到标记所在行的第一个非空白字符：`'a`。 |
| 反引号或撇号，两次 | 回到上一次跳转前的位置：` `` ` 或 `''`。 |
| 反引号，然后 `.` | 转到上一次更改：`` `. ``。 |
| 反引号，然后 `<` 或 `>` | 转到上一次选择的开始 / 结束：`` `< ``、`` `> ``。 |
| `]`，然后反引号 / `[`，然后反引号 | 转到下 / 上一个标记。 |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> / <kbd>Ctrl</kbd>+<kbd>I</kbd> | 在跳转列表中向后 / 向前。 |
| `:marks` | 列出标记。 |
| `:delmarks {marks}` | 删除标记：`:delmarks a`、`:delmarks a-d`。 |

## 宏

宏记录按键并再次播放。在文本笔记中，宏是 _可用但不保证_ 的。

| 按键 | 操作 |
| --- | --- |
| `q{a-z}` | 开始记录到该字母的寄存器。`q` 停止记录。 |
| `@{a-z}` | 播放该寄存器的宏。带计数时，播放该次数。 |
| `@@` | 再次播放下一次播放的宏。 |

## 搜索

| 按键 | 操作 |
| --- | --- |
| `/pattern` 和 <kbd>Enter</kbd> | 向前搜索。输入时匹配项会高亮显示。 |
| `?pattern` 和 <kbd>Enter</kbd> | 向后搜索。 |
| `n` / `N` | 转到下 / 上一个匹配项。 |
| `*` / `#` | 向前 / 向后搜索光标下的单词，作为完整单词。 |
| `g*` / `g#` | 相同，也包括在更长的单词内部。 |
| `gn` / `gN` | 选择下 / 上一个匹配项。在操作符之后，对其执行操作：`cgn` 更改下一个匹配项。 |
| `:noh` | 清除高亮。在文本笔记中，普通模式下按 <kbd>Esc</kbd> 也可清除。 |

*   模式是 JavaScript 正则表达式，而非 Vim 自身语法的表达式。
*   除非模式包含大写字母，否则大小写视为相同。
*   在搜索提示中，<kbd>↑</kbd> 和 <kbd>↓</kbd> 可调出之前的搜索，<kbd>Ctrl</kbd>+<kbd>U</kbd> 清除提示。
*   在文本笔记中，匹配项不能跨越多行。搜索会查看折叠的标题和列表项内部，并展开包含匹配项的那一个。

| `zA` / `zO` / `zC` | 与 `za`、`zo` 和 `zc` 相同，包括嵌套在内部的节。**Trilium 独有** **仅文本笔记** |

## 插入模式

在插入模式中，按键输入文本。以下按键是例外，分为两组。

### 始终遵循 Vim 的按键

| 按键 | 操作 |
| --- | --- |
| <kbd>Esc</kbd>、<kbd>Ctrl</kbd>+<kbd>[</kbd> 或 <kbd>Ctrl</kbd>+<kbd>C</kbd> | 返回普通模式。在文本笔记中，有选中内容时 <kbd>Ctrl</kbd>+<kbd>C</kbd> 会复制。 |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | 运行一条普通模式命令，然后返回插入模式。 |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | 删除光标前的单词。在 Windows 和 Linux 的浏览器中不起作用，在那里它会关闭浏览器标签页。 |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> `{register}` | 插入寄存器内容。 |
| <kbd>Ctrl</kbd>+<kbd>T</kbd> / <kbd>Ctrl</kbd>+<kbd>D</kbd> | 增加 / 减少行的缩进。在 Windows 和 Linux 的浏览器中 <kbd>Ctrl</kbd>+<kbd>T</kbd> 不起作用，在那里它会打开浏览器标签页。 |

### 取决于设置的按键

在文本笔记中，以下六个快捷键仅在 _插入模式中的 Vim 按键_ 设置开启时才遵循 Vim，请参阅<a class="reference-link" href="../Vim%20mode.md">Vim 模式</a>。当它关闭时（默认情况），它们保留编辑器赋予的含义：<kbd>Ctrl</kbd>+<kbd>U</kbd> 加下划线，<kbd>Ctrl</kbd>+<kbd>Y</kbd> 重做，<kbd>Ctrl</kbd>+<kbd>K</kbd> 创建链接，<kbd>Ctrl</kbd>+<kbd>V</kbd> 粘贴，<kbd>Ctrl</kbd>+<kbd>A</kbd> 全选。

代码笔记没有此设置。在那里，<kbd>Ctrl</kbd>+<kbd>U</kbd> 始终遵循 Vim，其他五个不是 Vim 按键。

| 按键 | 操作 |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | 从光标删除到行首。在文本笔记中，设置开启时；在代码笔记中，始终如此。 |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> | 插入光标下 / 上的字符。设置开启时。**仅文本笔记** |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> `{char}{char}` | 插入二合字母，即用两个键输入的字符：`e:` 得到 `ë`。设置开启时。**仅文本笔记** |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> `{key}` | 按原样插入下一个按键，如 <kbd>Tab</kbd>。设置开启时。**仅文本笔记** |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | 再次插入最后插入的文本。设置开启时。**仅文本笔记** |

## 命令行

`:` 打开命令行。输入命令并按 <kbd>Enter</kbd> 运行，或按 <kbd>Esc</kbd> 取消。命令可以缩短为其首字母，如表格所示：`:s` 即 `:substitute`。在文本笔记中，命令行在状态栏中打开；在代码笔记中，在编辑器底部打开。

| 按键 | 操作 |
| --- | --- |
| <kbd>Enter</kbd> | 运行命令。 |
| <kbd>Esc</kbd> | 关闭命令行。 |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 调出之前的命令。 |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | 清除命令行。 |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | 转到下 / 上一个建议。**仅文本笔记** |
| <kbd>↓</kbd> / <kbd>↑</kbd> | 在建议显示时转到下 / 上一个建议。在你输入或选择建议之前，<kbd>↑</kbd> 会改为调出之前的命令，之后 <kbd>↓</kbd> 也是如此。**仅文本笔记** |

### 范围

许多命令作用于一个行范围，写在名称之前。没有范围时，它们作用于当前行。

| 范围 | 行 |
| --- | --- |
| `:12` | 第 12 行。单独输入时，将光标移动到该行。 |
| `:.` / `:$` | 当前行 / 最后一行。 |
| `:%` | 整个笔记。 |
| `:5,12` | 第 5 到 12 行。 |
| `:.,+3` | 当前行及接下来三行。 |
| `:.,$` | 从当前行到末尾。 |
| `:'a,'b` | 从标记 `a` 到标记 `b`。 |
| `:'<,'>` | 选择内容所在的行。在可视模式中按 `:` 会为你写入。 |

### 命令

| 命令 | 操作 |
| --- | --- |
| `:s/pattern/replacement/flags` | 替换范围内每行中模式的第一个匹配项。参见下方的 _替换_。 |
| `:sor` | 对行排序。参见下方的 _排序_。 |
| `:u` / `:red` | 撤销 / 重做。 |
| `:start` | 进入插入模式。 |
| `:noh` | 清除搜索高亮。 |
| `:se` | 更改选项。参见下方的 _选项_。 |

### 在文本笔记中可用但不保证的命令

这些命令在两种笔记中均可使用。在文本笔记中，它们属于 _可用但不保证_ 下描述的级别，下方的按键映射也是如此。

| 命令 | 操作 |
| --- | --- |
| `:g/pattern/command` | 在每一匹配模式的行上运行命令：`:g/^TODO/d`。 |
| `:v/pattern/command` | 在每一不匹配的行上运行命令。 |
| `:d` | 删除行。 |
| `:y` | 复制行。 |
| `:pu` | 将寄存器内容放在该行下方。 |
| `:j` | 连接行。 |
| `:norm {keys}` | 在范围内的每一行上输入普通模式按键。 |
| `:reg` | 列出寄存器。 |
| `:marks` / `:delm {marks}` | 列出 / 删除标记。 |

### Trilium 命令

代码笔记没有这些命令：在那里，`:w` 不起作用，`:q` 不是命令，因为笔记由 Trilium 自身保存。

| 命令 | 操作 |
| --- | --- |
| `:w` | 立即保存笔记。Trilium 也会自行保存。**Trilium 独有** **仅文本笔记** |
| `:q` | 保存后关闭笔记的标签页或其分屏。`:wq` 和 `:x` 相同。**Trilium 独有** **仅文本笔记** |
| `:ck {command} {value}` | 按名称运行文本编辑器的命令：`:ck bold`、`:ck heading heading2`、`:ck horizontalLine`。带范围或在选择之后，它作用于该文本。输入时命令行会列出命令。**Trilium 独有** **仅文本笔记** |
| `:set hints` / `:set nohints` | 打开 / 关闭按键提示。**Trilium 独有** **仅文本笔记** |

### 替换

`:s/pattern/replacement/flags` 替换当前行中的文本，`:%s` 替换整个笔记，`:'<,'>s` 替换所选行。

| 部分 | 含义 |
| --- | --- |
| `pattern` | JavaScript 正则表达式。 |
| 替换中的 `$1`、`$2` | 模式中某个组的文本。 |
| 替换中的 `$&` | 整个匹配项，在文本笔记中。在代码笔记中，整个匹配项写作 `&`。 |
| 替换中的 `\n` | 换行符。在文本笔记中，它会开始一个新段落。 |
| 标志 `g` | 替换行中的每个匹配项，而不仅是第一个。 |
| 标志 `i` | 将大小写视为相同。 |
| 标志 `c` | 每次替换前询问：`y` 替换，`n` 跳过，`a` 替换其余全部，`q` 停止，`l` 替换此个并停止。 |

### 排序

`:sort` 对范围内或选择内容所在的行排序。

| 参数 | 含义 |
| --- | --- |
| `!` | 反转顺序：`:sort!`。 |
| `i` | 将大小写视为相同。 |
| `n` | 按每行中的第一个数字排序。`x` 读取十六进制数字，`o` 读取八进制数字。 |
| `u` | 相等的行只保留一个。 |
| `/pattern/` | 按匹配项之后的文本排序。使用 `r` 时，按匹配项本身排序。 |

在文本笔记中，`:sort` 整体移动段落和列表项及其格式，列表项会带上其嵌套项。没有范围时，它按光标所在层级对光标所在的列表排序，或对光标周围的段落排序；在代码笔记中，它对整个笔记排序。不同类型的行（如段落与列表项混合）以及表格的行不能以这种方式排序。要排序表格及更多选项，请参阅<a class="reference-link" href="../Sorting.md">排序</a>。

### 按键映射

映射赋予按键另一种含义。在文本笔记中，映射是 _可用但不保证_ 的。

| 命令 | 操作 |
| --- | --- |
| `:map {keys} {target}` | 使 `{keys}` 在所有模式下作为 `{target}` 起作用。 |
| `:nmap` / `:vmap` / `:imap` | 相同，但仅在普通 / 可视 / 插入模式下。 |
| `:noremap`、`:nnoremap`、`:vnoremap`、`:inoremap` | 相同，但目标的按键即使也被映射，仍保留其原始含义。 |
| `:unmap {keys}` | 移除用 `:map` 创建的映射。它不会移除某一模式的映射。 |
| `:mapclear` | 移除所有映射。`:nmapclear`、`:vmapclear` 和 `:imapclear` 移除某一模式的映射。 |

*   有名称的按键写在尖括号中：`<Esc>`、`<CR>` 表示 <kbd>Enter</kbd>、`<Space>`、`<BS>` 表示 <kbd>Backspace</kbd>、`<C-r>` 表示 <kbd>Ctrl</kbd>+<kbd>R</kbd>。
*   以 `:` 开头的目标是命令行命令。以 `<CR>` 结尾可立即运行：`:nmap gs :sort<CR>`。没有 `<CR>` 时，命令行会打开并已输入命令，等待 <kbd>Enter</kbd>。
*   `:imap jk <Esc>` 在快速连续输入 `j` 和 `k` 时离开插入模式。
*   映射持续到 Trilium 重新加载。要在文本笔记中保留映射，请将其添加到 _启动命令_ 设置中，请参阅<a class="reference-link" href="../Vim%20mode.md">Vim 模式</a>。

### 选项

| 命令 | 操作 |
| --- | --- |
| `:set hints` / `:set nohints` | 打开 / 关闭按键提示。**Trilium 独有** **仅文本笔记** |
| `:set textwidth=80` | 设置 `gq` 换行的宽度。也可用 `:set tw=80`。**仅代码笔记** |

## 不支持

Vim 的这些部分在两种笔记中均不可用：

*   Vim 的窗口、缓冲区、标签页和文件：普通模式下以 <kbd>Ctrl</kbd>+<kbd>W</kbd> 开头的窗口命令，以及 `:e` 和 `:help` 等命令。在插入模式中，<kbd>Ctrl</kbd>+<kbd>W</kbd> 受支持并删除一个单词。`:q!` 和 `ZQ` 在文本笔记中只显示一条消息，因为没有可丢弃的内容。
*   下表中的普通模式命令。
*   标记 `[` 和 `]`，在 Vim 中它们保存最后更改文本的两端。
*   Vim 自身语法的搜索模式。
*   为 Vim 制作的插件、脚本和 `.vimrc` 文件。
*   可视块模式，跨多行选择矩形文本。在文本笔记中，<kbd>Ctrl</kbd>+<kbd>V</kbd> 在普通和可视模式下粘贴。在代码笔记中，<kbd>Ctrl</kbd>+<kbd>V</kbd> 或 <kbd>Ctrl</kbd>+<kbd>Q</kbd> 确实会启动该模式，但选择停留在一行上，因此不能作为矩形使用。

| 普通模式按键 | 在 Vim 中的作用 |
| --- | --- |
| `gp` / `gP` | 放置，并将光标留在放置文本之后。 |
| `@:` | 重复命令行的最后一条命令。 |
| `&` / `g&` | 在当前行 / 每一行上重复上一次 `:s`。`:s` 替换中的 `&` 是另一回事，在 _替换_ 下描述。 |
| `g;` / `g,` | 转到上 / 下一个文本被更改的位置。 |
| `U` | 撤销对该行所做的所有更改。在可视模式中，`U` 将选择内容转为大写，这是受支持的。 |
| `K` | 查找光标下的单词。 |
| `Q` | 切换到 Ex 模式。 |
| <kbd>Ctrl</kbd>+<kbd>]</kbd> | 跳转到光标下单词的定义。 |
| `zf` | 手动创建折叠。 |
