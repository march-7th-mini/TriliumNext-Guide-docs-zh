## ✨ 改进

*   在基本属性中：
    *   添加了一个模态框，可以从笔记类型下拉菜单中轻松配置代码笔记类型，而无需进入设置。
    *   为内容语言添加了一个模态框，可以轻松配置语言，而无需进入设置。
    *   文本片段列表现在显示实际的笔记图标和颜色。
*   对 API 日志进行了小幅改进。
*   改进窗口背景效果 由 @adoriandoran 提供
*   主题改进 由 @adoriandoran 提供
*   添加一个选项以禁用 Electron 应用的平滑滚动 由 @adoriandoran 提供
*   [修订对话框可以选择显示修订之间的源差异](https://github.com/TriliumNext/Trilium/pull/6887) 由 @SiriusXT 提供
*   分割区域现在可以调整大小 由 @SiriusXT 提供
*   对集合的改进：
    *   地理地图：如果书在拖动时被锁定，则添加通知。
    *   表格：如果正在排序，则禁用按位置插入。
    *   看板
        *   改进列和笔记的拖动体验。
        *   重新设计了添加笔记的方式，不再先添加笔记。
        *   在添加笔记时按 Esc 键将取消操作，而不是添加一个空笔记。
        *   可以通过将鼠标悬停在卡片上并点击旁边的编辑按钮，直接在看板上编辑笔记标题。
        *   编辑时，笔记标题现在将多行显示，以更好地匹配最终结果。
        *   轻微的风格改进（更平滑的阴影，无位移）。
        *   添加上下文菜单选项以归档/取消归档当前项目。
    *   所有集合（地理地图、日历、看板、表格）现在都通过将项目变灰来指示已归档的笔记。
    *   添加了一个选项，可以通过功能区中的“集合属性”选项卡在集合中显示已归档的笔记。
*   笔记信息选项卡中的笔记 ID 现在以等宽字体显示。
*   笔记树中的上下文菜单选项，用于归档/取消归档笔记。
*   提高折叠子树的性能 由 @werererer 提供
*   创建更无缝的 PWA 顶栏 由 @qwreey 提供
*   [打开 PDF 笔记时默认隐藏文件详细信息](https://github.com/TriliumNext/Trilium/issues/6873)
*   对新用户默认在亮点列表中禁用粗体和斜体。
*   现在可以从 选项 → 文本笔记 → 功能 中禁用斜杠命令。
*   为文本笔记选项中的编辑器功能添加了描述。

## 🛠️ 技术更新

*   我们对开发环境进行了一些更改，**因为我们已不再使用 NX**。如果您是在 Trilium 上工作的开发者，请查看[此 PR](https://github.com/TriliumNext/Trilium/pull/6842) 了解更多信息。
*   一些重要的 UI 组件，如功能区、笔记操作、浮动按钮和笔记标题、SQL 控制台、搜索结果、某些菜单，已迁移到 React。**请报告您可能遇到的任何问题。**
*   [修复了 /login/token 缺少 TOTP 验证的问题](https://github.com/TriliumNext/Trilium/pull/6823) 由 @Nriver 修复
*   改进了服务器启动消息的格式。
*   感谢 @FliegendeWurst 在我们更改开发环境后帮助修复 Nix flakes。
