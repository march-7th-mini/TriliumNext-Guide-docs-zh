# 右侧边栏
<figure class="image"><img style="aspect-ratio:1990/1168;" src="1_Right Sidebar_image.png" width="1990" height="1168"></figure>

右侧边栏显示当前笔记的特定内容。边栏分为多个标签页：

*   <a class="reference-link" href="Right%20Sidebar/Outline%20tab.md">大纲标签页</a>，根据笔记类型显示目录、高亮及其他导航相关部分。
*   <a class="reference-link" href="Right%20Sidebar/Attributes%20tab.md">属性标签页</a>，为当前笔记的<a class="reference-link" href="../../Advanced%20Usage/Attributes.md">属性</a>提供可视化编辑器。
*   <a class="reference-link" href="Right%20Sidebar/AI%20chat%20tab.md">AI对话标签页</a>，使用<a class="reference-link" href="../../AI.md">AI</a>集成进行对话，并可选择访问当前笔记。
*   <a class="reference-link" href="Right%20Sidebar/Connections%20tab.md">连接标签页</a>，将笔记地图、笔记路径、反链和相似笔记分组在一起。

> [!WARNING]
> 目前有两种类型的边栏；本文档仅指在<a class="reference-link" href="New%20Layout.md">新布局</a>中定义的那一种。旧布局有不同的边栏机制，仅显示目录和高亮。

## 切换右侧边栏

有两种方式可以切换右侧边栏：

*   通过标题栏附近的 <img src="Right Sidebar_image.png" width="25" height="21"> 图标，用于切换边栏是否停靠。
*   通过 _切换右侧面板_ [键盘快捷键](../Keyboard%20Shortcuts.md)，默认情况下未分配。

## 预览边栏

在应用程序右边缘附近有一个小条带，显示箭头图标。

*   当边栏隐藏时，按下边缘将_预览_边栏。
    *   在此模式下，边栏会临时显示在内容上方，而不会移动笔记内容。
    *   在预览模式下点击边栏外部将直接隐藏边栏。X 按钮和点击右边缘也是如此。
    *   按下图钉图标将停靠边栏。
*   当边栏停靠时，按下边缘将隐藏边栏（类似于顶部的切换图标）。
