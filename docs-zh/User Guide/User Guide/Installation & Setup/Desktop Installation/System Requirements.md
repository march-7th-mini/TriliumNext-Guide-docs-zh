# 系统要求
Trilium 的桌面版支持所有三种主流操作系统：

=== "<span class="tn-icon bx bxl-windows"></span> Windows"

    *   正式支持 Windows 11。
    *   也支持 ARM 架构的 Windows

=== "<span class="tn-icon bx bxl-tux"></span> Linux"

    *   支持大多数现代发行版，包括 NixOS。
    *   支持 `aarch64` 架构的 ARM（不支持 ARM v7）。

=== "<span class="tn-icon bx bxl-apple"></span> macOS"

    *   最低支持的操作系统：macOS Ventura
    *   同时支持 Intel 和 Apple Silicon 设备。
