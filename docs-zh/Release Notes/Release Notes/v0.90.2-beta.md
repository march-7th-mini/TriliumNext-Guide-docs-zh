# v0.90.2-beta
## 🐞 错误修复

*   [(错误报告) 初始同步无法完成](https://github.com/TriliumNext/Notes/issues/266)

## ✨ 技术改进

重要变更：

*   最大的变更在于服务器已从 Common.js 移植到 ES 模块。请注意，这种规模的变更必然会在整个应用中引发一些异常，欢迎提交错误报告。
*   将 Electron 从 25.9.8 更新至 31.2.1 ([#231](https://github.com/TriliumNext/Notes/pull/231))

此外：

*   将 CKEditor 从 41.0.0 更新至 41.4.2。
*   开始添加国际化支持 ([#248](https://github.com/TriliumNext/Notes/pull/248))。该应用很快将能够翻译成多种语言。
*   改进了脚本的错误管理：
    *   如果小组件发生严重的意外错误，会显示一条提示消息（toast）说明情况并建议进入安全模式，而不是显示空白页面。
    *   如果基础小组件渲染失败，会显示一条提示消息（toast），而不是导致应用崩溃。
*   提示消息（toast）现在支持换行（通过在消息中添加 `\n`），以获得稍好的格式。
