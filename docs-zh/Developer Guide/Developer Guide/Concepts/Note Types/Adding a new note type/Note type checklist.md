# 笔记类型检查清单
本检查清单的目标是确保对笔记类型进行良好的实现或重新测试。

## 实现检查清单

笔记类型小组件必须按照<a class="reference-link" href="First%20steps.md">第一步</a>创建：

*   在服务器中注册笔记类型
*   在客户端上下文菜单中注册笔记类型
*   创建类型小组件
*   注册类型小组件
*   添加默认图标映射
*   添加到笔记类型选择器
*   将笔记添加到服务器允许的笔记类型
*   更新演示文档以包含此新笔记类型
*   提升服务器同步版本（否则旧实例会在同步时将新类型的笔记变为文件笔记）。

## 验证检查清单

### 确保笔记正确渲染

*   当刷新到已显示的笔记时
*   当转到另一个笔记然后返回时
*   当创建给定类型的新笔记时
*   打开同一笔记类型的两个标签页并在它们之间切换

### 确保数据持久化

*   通过间隔更新修改更改时保存数据

### 确保数据检索

*   转到此类型的笔记并刷新页面
*   在另一个此类型的笔记上创建此类型的新笔记，并确保内容设置正确。

### 设置笔记预览

有关实现参考，请参阅<a class="reference-link" href="SVG%20rendering.md">SVG 渲染</a>。

*   笔记预览渲染（转到父笔记并查看笔记列表）。
*   包含笔记
*   分享
*   笔记修订

### 导入/导出

*   导出和导入，确保在此过程中没有数据丢失。
*   完全删除数据文件夹，以测试首次设置时演示文档是否正确导入。
    *   确保预览也能正常工作（检查根笔记中的预览）。
