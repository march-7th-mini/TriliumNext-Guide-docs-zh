# 相似笔记
<figure class="image image-style-align-right image_resized" style="width:50.46%;"><img style="aspect-ratio:538/290;" src="Similar Notes_image.png" width="538" height="290"></figure>

相似笔记功能旨在通过分析笔记的内容、它们之间的关系以及创建日期，来识别与当前笔记相关的笔记。

要访问相似笔记列表：

*   在<a class="reference-link" href="../UI%20Elements/New%20Layout.md">新布局</a>中，前往<a class="reference-link" href="../UI%20Elements/Right%20Sidebar.md">右侧边栏</a>的<a class="reference-link" href="../UI%20Elements/Right%20Sidebar/Connections%20tab.md">连接选项卡</a>，查找相应部分。
*   在旧布局中，点击<a class="reference-link" href="../UI%20Elements/Ribbon.md">功能区</a>中的 _相似笔记_ 选项卡。

## 交互

*   将鼠标悬停在笔记上可查看笔记的简短预览。
*   点击笔记可在当前视图中打开。
*   按住 <kbd>Ctrl</kbd> 并点击笔记可在新标签页中打开。
