# 功能亮点
本节按版本介绍最重要的变更。如需查看完整的变更列表，请查阅每个版本的更新日志。为简洁起见，跳过了测试版本，并将功能汇总到最近的稳定版本。

*   v0.105.0：
    *   文本笔记现在拥有<a class="reference-link" href="Note%20Types/Text/In-editor%20AI%20assistant.md">编辑器内 AI 助手</a>，可用于快速校对和其他无需完整对话的基于文本的操作。
*   v0.101.0：
    *   引入了<a class="reference-link" href="Basic%20Concepts%20and%20Features/UI%20Elements/New%20Layout.md">新布局</a>，对 UI/UX 进行了重大修改，例如将功能区（Ribbon）和浮动按钮整合到其他 UI 元素中，并引入了<a class="reference-link" href="Basic%20Concepts%20and%20Features/UI%20Elements/New%20Layout/Breadcrumb.md">面包屑</a>等新功能。
*   v0.97.0：
    *   书籍（Books）现在是<a class="reference-link" href="Collections.md">集合</a>。
    *   <a class="reference-link" href="Collections/Table.md">表格</a>是一种新的集合类型，可在可编辑的网格中显示笔记和属性。
    *   引入了<a class="reference-link" href="Basic%20Concepts%20and%20Features/Navigation/Quick%20edit.md">快速编辑</a>，提供了一种在弹出窗口中编辑笔记的新方式，而无需打开新标签页。它还与<a class="reference-link" href="Collections.md">集合</a>很好地集成。
*   v0.96.0：
    *   得益于与 CKEditor 团队的合作，<a class="reference-link" href="Note%20Types/Text.md">文本</a>获得了高级功能：
        *   <a class="reference-link" href="Note%20Types/Text/Slash%20Commands.md">斜杠命令</a>
        *   <a class="reference-link" href="Note%20Types/Text/Text%20Snippets.md">文本片段</a>
*   v0.95.0：
    *   为<a class="reference-link" href="Advanced%20Usage/Sharing.md">分享</a>引入了更友好的主题，支持搜索、可展开树、夜间模式等功能。
*   v0.94.0：
    *   增加了与<a class="reference-link" href="AI.md">AI</a>的集成（使用自托管 LLM，如 Ollama，或行业标准，如 ChatGPT）。
*   v0.92.5：
    *   Windows 二进制文件现已签名。
    *   引入了<a class="reference-link" href="Installation%20%26%20Setup/Server%20Installation/Multi-factor%20authentication%20with%20TOTP.md">使用 TOTP 的多因素身份验证</a>。
*   v0.92.4：
    *   macOS 二进制文件现已签名。
    *   <a class="reference-link" href="Note%20Types/Text.md">文本</a>笔记现在可以调整<a class="reference-link" href="Note%20Types/Text/Content%20language%20%26%20Right-to-left%20support.md">内容语言和从右到左支持</a>。
    *   <a class="reference-link" href="Basic%20Concepts%20and%20Features/Notes/Printing%20%26%20Exporting%20as%20PDF.md">打印和导出为 PDF</a>
    *   <a class="reference-link" href="Basic%20Concepts%20and%20Features/Zen%20mode.md">禅定模式</a>
    *   <a class="reference-link" href="Collections/Calendar.md">日历</a>，允许根据开始和结束日期在月度网格中显示笔记。
*   v0.91.5：
    *   移动端有显著改进。
    *   <a class="reference-link" href="Note%20Types/Text/Footnotes.md">脚注</a>现在受<a class="reference-link" href="Note%20Types/Text.md">文本</a>笔记支持。
    *   Mermaid 图表现在可以内联插入到<a class="reference-link" href="Note%20Types/Text.md">文本</a>笔记中。
    *   引入了 TriliumNext 主题，为应用程序带来了更现代的设计。
    *   <a class="reference-link" href="Collections/Geo%20Map.md">地理地图</a>，将笔记作为标记显示在地图上，方便规划旅行。
*   v0.90.8：
    *   引入了一种新的笔记类型：<a class="reference-link" href="Note%20Types/Mind%20Map.md">思维导图</a>
