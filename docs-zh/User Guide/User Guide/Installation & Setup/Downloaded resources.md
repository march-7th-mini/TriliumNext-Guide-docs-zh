# 已下载的资源

已下载的资源是一些功能需要但 Trilium 并未自带的大型文件，例如用于转写会议的语音识别模型。Trilium 会在功能首次需要它们时下载，并将其保留在设备上以供后续使用。

目前，只有桌面应用上的<a class="reference-link" href="../Meeting%20transcription.md">会议转写</a>会使用已下载的资源：

| 资源 | 大小 | 许可证 | 用途 |
| --- | --- | --- | --- |
| Parakeet TDT 0.6B v3（标准） | 0.6 GB | CC-BY-4.0 | 使用_标准_模型识别语音。 |
| Parakeet TDT 0.6B v3（高精度） | 2.4 GB | CC-BY-4.0 | 使用_高精度_模型识别语音。 |
| Silero VAD | 0.6 MB | MIT | 检测何时有人说话。 |
| TitaNet | 40 MB | Apache-2.0 | 在开启_识别说话人_时区分不同的说话人。 |

## 下载资源

当某项功能需要设备上尚不存在的资源时，Trilium 会在下载前询问。对话框会列出每个资源及其用途、下载来源、许可证和大小，随后显示总下载大小和磁盘上的可用空间。

*   要开始下载，请按_下载_。每个资源都会显示其进度，所有资源下载完成后该功能将继续。
*   要停止下载，请按_取消_或关闭对话框。已下载的文件会被保留，下次下载会从本次停止的位置继续，即使是在一个大文件内部也是如此。
*   如果磁盘没有足够的可用空间，对话框会予以提示，并且无法开始下载。

每个文件在使用前都会与 Trilium 内置的校验和进行核对，因此在下载过程中损坏或被篡改的文件会被丢弃。

> [!NOTE]
> 已下载的资源不会被同步。每个使用某项功能的设备都会单独下载其资源，即使笔记通过<a class="reference-link" href="Synchronization.md">同步</a>保持同步也是如此。

## 管理已下载的资源

要查看已下载的资源，请转到<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _已下载的资源_。每个已下载的资源，或因下载中断而部分下载的资源，都会连同其占用的磁盘空间和状态一起列出。在列表下方，_已用空间_显示它们总共占用的空间，以及磁盘上剩余的可用空间。

*   要打开某个资源的文件夹，请按 <span class="tn-icon bx bx-folder-open"></span> 按钮（仅限桌面）。
*   要删除某个资源，请按 <span class="tn-icon bx bx-trash"></span> 按钮。如果某项功能再次需要它，它会被重新下载。

列表还会以淡出方式显示资源文件夹中的其他内容：

*   _旧版本_：某个资源早期版本的文件。当资源更新时，新版本会被下载到新文件夹中，旧版本则被遗留。
*   _未使用_：此安装的任何功能都不使用的资源，例如由已移除的功能下载的资源。
*   _未知_：任何其他文件或文件夹，例如手动复制到那里的文件。

这些内容也可以用同样的方式删除。

> [!WARNING]
> 如果服务器和桌面应用共享同一个数据目录，那么仅由其中一方使用的资源会在另一方显示为_未使用_。在那里删除它会对两者都将其移除。

## 位置

资源存储在<a class="reference-link" href="Data%20directory.md">数据目录</a>的 `resources` 文件夹中，每个资源一个文件夹。要将它们存储在其他位置，请在启动 Trilium 之前将 `TRILIUM_RESOURCES_DIR` 环境变量设置为另一个文件夹。

## 在没有互联网连接的情况下安装

要在无法下载资源的设备上安装某个资源，请从已有该资源的设备的 `resources` 文件夹中将其文件夹复制到另一台设备的相同位置。下次某项功能请求下载它时，请按_下载_：已就位的文件会与其校验和进行核对并保留，只下载缺失的文件。
