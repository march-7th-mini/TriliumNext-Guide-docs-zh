# 笔记按钮

在[功能区](Ribbon.md)的右侧还有几个按钮：![](Note%20buttons_image.png)

*   笔记修订按钮会显示该特定笔记的[笔记修订](../Notes/Note%20Revisions.md)。
*   上下文菜单提供针对该笔记或其子树的命令，例如导入、导出、查看[笔记源代码](../../Advanced%20Usage/Note%20source.md)或[附件](../Notes/Attachments.md)。

在<a class="reference-link" href="New%20Layout.md">新布局</a>上，按钮区域填充了更多特定于当前笔记的按钮。例如，对于图片和<a class="reference-link" href="../../Note%20Types/File.md">文件</a>笔记，下载和复制按钮被移到了那里。
