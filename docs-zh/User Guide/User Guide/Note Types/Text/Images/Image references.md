# 图片引用
<figure class="image image-style-align-right image_resized" style="width:50.47%;"><img style="aspect-ratio:880/553;" src="Image references_image.png" width="880" height="553"></figure>

图片引用是一种将其他类型笔记的预览嵌入到<a class="reference-link" href="../../Text.md">文本</a>笔记中的简便方法。

## 支持的笔记类型

*   <a class="reference-link" href="../../Canvas.md">画布</a>
*   <a class="reference-link" href="../../Mermaid%20Diagrams.md">Mermaid 图表</a>
*   <a class="reference-link" href="../../Mind%20Map.md">思维导图</a>

## 步骤

1.  前往上述支持的笔记类型之一，在<a class="reference-link" href="../../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20buttons.md">笔记按钮</a>区域中查找 <span class="tn-icon bx bx-copy"></span> 按钮。
2.  前往一篇<a class="reference-link" href="../../Text.md">文本</a>笔记，使用粘贴功能插入对该笔记的引用。

## 交互

*   在文本笔记中双击图片引用将自动打开目标笔记。
*   按住 <kbd>Ctrl</kbd> 的同时点击图片引用将在新标签页中打开目标笔记。
*   修改目标笔记时也应同步更新图片引用。如果没有更新，请考虑<a class="reference-link" href="../../../Troubleshooting/Refreshing%20the%20application.md">刷新应用程序</a>。
