# Vim 入门指南
Vim 是一款围绕键盘构建的文本编辑器。Trilium 可以在文本笔记和代码笔记中模仿它的工作方式，这被称为 Vim 模式。本页解释其背后的理念、每种模式的作用以及应首先学习哪些按键。它适用于两种笔记，如有差异，文中会予以说明。

> [!NOTE]
> Vim 模式是可选的，默认关闭。在开启之前，本页内容均不适用，请参阅下方的_开启方式_。

## 按键的书写方式

在这些页面中，命令按需依次按下的按键书写。`dd` 表示按两次 `d`，`ciw` 表示按 `c`，然后按 `i`，再按 `w`。这些按键不是同时按住的。

同时按住的按键用加号书写，例如 <kbd>Ctrl</kbd>+<kbd>R</kbd>。大写字母很重要：`A` 需配合 <kbd>Shift</kbd> 输入，其作用与 `a` 不同。

## 什么是 Vim？

[Vim](https://www.vim.org/) 是一款流行的文本编辑器。其最显著的特征是它是一款**模态**编辑器。在大多数编辑器中，按下一个字母总是输入该字母。在 Vim 中，按键的作用取决于编辑器所处的模式：在一种模式下，字母用于输入文本；在另一种模式下，相同的字母则是命令，用于移动光标、删除单词或复制一行。

Trilium 并不包含 Vim 本身。它在自己的编辑器内部模仿 Vim 的按键，因此你的笔记仍然是普通的 Trilium 笔记。

## 为什么要使用它？

*   **双手无需离开键盘。** 移动、选择、复制和搜索都通过字母键完成，无需伸手去拿鼠标或方向键。鼠标仍可照常使用。
*   **命令可以组合。** 只需学习少量按键，然后组合使用：`d` 表示删除，`w` 表示一个单词，因此 `dw` 删除一个单词。
*   **更改可以重复。** `.` 重复上一次更改，命令前的数字表示执行该命令的次数。
*   **大部分操作可以迁移。** 许多移动和编辑命令在 Vim 本身以及其他编辑器的 Vim 模式中同样有效。Trilium 有一些自己的命令，文本笔记在某些地方有所不同，因为它们保存的是富文本，而非纯文本文件。

Vim 模式可能需要一些时间才能适应。如果它不适合你，关闭该选项即可恢复常规编辑器。

## 开启方式

文本笔记和代码笔记各有自己的选项，且均仅对当前设备生效：

*   对于文本笔记，前往 <a class="reference-link" href="../../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _文本笔记_ → _功能_，然后开启 _Vim 模式_。要为单个笔记关闭它，请点击状态栏中的 _Vim_ 徽章。有关其设置，请参阅 <a class="reference-link" href="../Vim%20mode.md">Vim 模式</a>。
*   对于代码笔记，前往 <a class="reference-link" href="../../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">选项</a> → _代码笔记_ → _编辑器_，然后开启 _Vim 键位绑定_。

## 模式

模式决定键盘的作用。共有五种主要模式：

| 模式 | 按键的作用 | 如何进入 |
| --- | --- | --- |
| 普通 | 运行命令：移动、删除、复制、粘贴。 | 从任何其他模式按 <kbd>Esc</kbd> |
| 插入 | 输入文本，如同常规编辑器。 | `i` |
| 可视 | 选择文本。 | `v` 选择字符，`V` 选择整行 |
| 替换 | 在现有文本上输入。 | `R` |
| 命令行 | 按名称输入命令，或输入要搜索的文本。 | `:` 输入命令，`/` 或 `?` 进行搜索 |

Vim 还有可视块模式，用于跨多行选择矩形文本区域。目前尚不支持。在文本笔记中，<kbd>Ctrl</kbd>+<kbd>V</kbd> 在普通模式和可视模式下粘贴，在输入时也可粘贴，除非开启了 _插入模式下的 Vim 按键_ 设置。在代码笔记中，<kbd>Ctrl</kbd>+<kbd>V</kbd> 或 <kbd>Ctrl</kbd>+<kbd>Q</kbd> 确实会启动该模式，但选择范围保持在一行内，因此无法作为矩形区域使用。

### 普通模式

普通模式是笔记打开时所处的模式，也是两次编辑之间返回的模式。字母键在此不输入文本。每个键都是一个命令：`j` 向下移动一行，`x` 删除一个字符，`u` 撤销上一次更改。

这是最初感觉奇怪的部分。其理念是，在笔记中花费的大部分时间用于阅读、移动和更改现有文本，而非输入新文本，因此手指下的按键被分配给了这些任务。

笔记起始模式有一个例外：在开启 Vim 模式时已经打开的文本笔记处于插入模式，以便输入继续有效。按 <kbd>Esc</kbd> 进入普通模式。

### 插入模式

插入模式就是你已熟悉的编辑器：按键输入文本。在普通模式下按 `i` 进入，按 <kbd>Esc</kbd> 离开。

在文本笔记中，常规编辑功能在插入模式下仍然可用，例如格式快捷键、斜杠命令和工具栏。少数 <kbd>Ctrl</kbd> 快捷键在此具有 Vim 含义：请参阅 <a class="reference-link" href="../Vim%20mode.md">Vim 模式</a>。

> [!TIP]
> 有多种方式进入插入模式，取决于你想在哪里输入：`i` 在光标前，`a` 在光标后，`A` 在行尾，`o` 在下方新行。

### 可视模式

可视模式用于选择文本。按 `v`，然后移动光标：选择范围随之扩展。然后按一个键对选择内容执行操作，例如 `d` 删除或 `y` 复制。`V` 以相同方式选择整行。<kbd>Esc</kbd> 离开可视模式而不做任何更改。

### 替换模式

在替换模式下，输入的每个字符会替换光标下的字符，而非插入其前。按 `R` 进入，按 <kbd>Esc</kbd> 离开。

### 命令行

有些命令按名称输入。在普通模式下按 `:` 打开命令行，输入命令后按 <kbd>Enter</kbd>。例如，`:sort` 对行排序。按 `/` 则打开用于搜索，按 `?` 用于向后搜索。<kbd>Esc</kbd> 关闭而不执行任何操作。

在文本笔记中，命令行在 <a class="reference-link" href="../../../Basic%20Concepts%20and%20Features/UI%20Elements/Status%20bar.md">状态栏</a> 中打开，即面包屑所在位置。在代码笔记中，它在编辑器底部打开。

### 我处于哪种模式？

*   在文本笔记中，状态栏显示模式：`NORMAL`、`INSERT`、`VISUAL`、`VISUAL LINE` 或 `REPLACE`。
*   在两种笔记中，光标也能指示模式。在普通模式和可视模式下，它是一个覆盖字符的块。在插入模式下，块消失，取而代之的是普通的细插入符。

## 第一次会话

本练习旨在让你感受普通模式与插入模式之间的切换，而非死记按键。使用一个可以随意试验的笔记，例如新建笔记或现有笔记的副本，然后：

1.  按 `i` 并输入几个词。你处于插入模式。
2.  按 <kbd>Esc</kbd>。你回到普通模式，光标变为块状。
3.  用 `h`（左）、`j`（下）、`k`（上）和 `l`（右）移动光标。
4.  按 `x` 删除光标下的字符，然后按 `u` 撤销该操作。
5.  按 `dd` 删除整行，按 `u` 将其恢复。
6.  按 `A`。光标跳到行尾，处于插入模式。输入一些内容，然后按 <kbd>Esc</kbd>。
7.  按 `v`，用 `l` 移动几个字符，然后按 `d`。选中的文本被删除。

这就是完整的循环：普通模式用于移动和更改，插入模式用于输入，<kbd>Esc</kbd> 用于返回。

## 移动光标

| 按键 | 移动到 |
| --- | --- |
| `h` `j` `k` `l` | 左、下、上、右。方向键同样有效。 |
| `w` / `b` | 下一个 / 上一个单词。 |
| `0` / `$` | 行首 / 行尾。 |
| `gg` / `G` | 笔记的第一行 / 最后一行。 |
| `/text` 和 <kbd>Enter</kbd> | "text" 出现的下一个位置。`n` 前往下一个。 |

在文本笔记中，一行就是一个完整段落，即使它在屏幕上占据多行。因此 `j` 移动到下一段落，`0` 和 `$` 前往其开头和结尾。

## 更改文本

| 按键 | 作用 |
| --- | --- |
| `x` | 删除光标下的字符。 |
| `dd` | 删除该行。 |
| `cw` | 删除单词的剩余部分并进入插入模式，以输入新单词。 |
| `r` 和一个字符 | 将光标下的字符替换为该字符。 |
| `u` | 撤销上一次更改。 |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> | 重做已撤销的操作。 |
| `.` | 重复上一次更改。 |

## 组合按键

Vim 的大多数命令由两部分组成，如同一个短句：做什么，以及对什么做。

*   第一部分是**操作符**：`d` 删除，`c` 更改（删除后允许你输入），`y` 复制。
*   第二部分是**动作**，即任何移动光标的按键：`w` 表示一个单词，`$` 表示行尾，`G` 表示笔记末尾。

| 按键 | 含义 |
| --- | --- |
| `dw` | 删除到下一个单词。 |
| `d$` | 删除到行尾。 |
| `cw` | 更改单词的剩余部分。 |
| `yG` | 从这里复制到笔记末尾。 |

还有两个概念使整体更完整：

*   **数字表示重复。** `3w` 向前移动三个单词，`3dd` 删除三行。
*   **文本对象指代光标周围的事物。** `iw` 是"光标所在的单词"，`ip` 是"本段落"。因此 `diw` 删除光标下的单词，无论光标位于其中何处，`yip` 复制该段落。

由于操作符几乎可以与任何动作和文本对象组合，少量按键就能产生大量命令，无需逐一记忆。

## 复制和粘贴

Vim 有自己的术语：**yank** 即复制，**put** 即粘贴。

*   `yy` 复制当前行，`yw` 复制一个单词。
*   `p` 将复制的内容粘贴到光标之后，`P` 粘贴到之前。
*   删除的文本也可以粘贴：`dd` 后接 `p` 将一行下移。
*   在可视模式下，`y` 复制选择内容。

复制的内容保存在**寄存器**中，这是 Vim 自己的存储，与计算机的剪贴板分离。要使用剪贴板，在命令前输入 `"+`：`"+yy` 将行复制到剪贴板，`"+p` 从剪贴板粘贴。在文本笔记中，<kbd>Ctrl</kbd>+<kbd>C</kbd> 和 <kbd>Ctrl</kbd>+<kbd>V</kbd> 也可与剪贴板配合使用。

剪贴板也是在文本笔记和代码笔记之间传递文本的方式，因为两种笔记不共享寄存器：在一个中 `"+y`，在另一个中 `"+p`。

## 搜索和替换

*   要搜索，按 `/`，输入文本并按 <kbd>Enter</kbd>。`n` 前往下一个匹配项，`N` 前往上一个。
*   要搜索光标下的单词，按 `*`。
*   要在当前行替换，输入 `:s/old/new/`。
*   要在笔记中全局替换，输入 `:%s/old/new/g`。

> [!NOTE]
> 要搜索的文本按 JavaScript 语法的正则表达式读取。字母、数字和空格表示其本身，但 `.`、`*`、`(` 和 `[` 等字符具有特殊含义。要按原样搜索其中之一，在其前加 `\`：`/1\.5` 查找 "1.5"。

## 摆脱困境

*   **不确定发生了什么？** 按 <kbd>Esc</kbd>，必要时按两次。它会取消输入了一半的命令并返回普通模式。
*   **按键不输入文本。** 编辑器处于普通模式。按 `i`。
*   **输入以奇怪的方式更改了笔记。** 编辑器处于普通模式，字母作为命令执行了。按 <kbd>Esc</kbd>，然后按一次 `u` 并查看结果。仅在还有可撤销内容时才继续重复，因为每次进一步的 `u` 也会撤销你更早的编辑。<kbd>Ctrl</kbd>+<kbd>R</kbd> 重做撤销过头的一步。
*   **Vim 模式碍事。** 关闭该选项。你的笔记不受影响。

> [!TIP]
> 在文本笔记中，状态栏在学习过程中很有帮助：它显示当前模式的按键，在命令中途短暂停顿后，显示可跟随的按键。要查看该模式的所有按键，点击状态栏中的模式或按 <kbd>Alt</kbd>+<kbd>F1</kbd>。
