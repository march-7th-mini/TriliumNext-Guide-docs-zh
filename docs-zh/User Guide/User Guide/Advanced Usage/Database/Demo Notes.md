### 恢复演示笔记

在某些情况下，你可能希望恢复原始的演示笔记。例如，如果你尝试了一些更高级的功能并希望查看原始参考，或者你只是想探索演示笔记的最新版本（其中可能展示了新功能）。

你可以通过使用 Trilium 的内置导入功能轻松恢复演示笔记：

*   下载包含最新版本演示笔记的 [.zip 压缩包](https://github.com/TriliumNext/Trilium/raw/refs/heads/main/apps/server/src/assets/db/demo.zip)
*   在笔记树中右键单击任意笔记，你希望将演示笔记导入到该笔记下
*   点击“导入到笔记…”
*   选择要导入的 .zip 压缩包
