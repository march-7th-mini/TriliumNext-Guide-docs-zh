# 可折叠块

可折叠块是可以展开和折叠的内容区块，让你在需要时才显示细节。

一个可折叠块由以下部分组成：

*   **始终可见的标题**，包含：
    *   **一个箭头**，点击时展开或折叠该块。
    *   **一行摘要**，作为该块的标题。将光标置于摘要行中，按 <kbd>Ctrl</kbd>+<kbd>Enter</kbd> 展开或折叠该块。
    *   **一个拖动手柄**，用于在笔记内重新定位该块。
*   **正文**，在块折叠时隐藏。它可以容纳任何类型的内容，包括嵌套的可折叠块。要跳出可折叠块并在其外部继续输入，请在块的末尾按两次 <kbd>Enter</kbd>。

你可以使用方向键在摘要行、块的正文以及块周围的文本之间自由移动光标。

## 插入可折叠块

在格式栏中，转到 _插入_ → _可折叠块_。

> [!TIP]
> 将多个可折叠块依次放置以创建手风琴效果，其中每个块都可以独立展开或折叠。
