# 绘制形状
以下形状可以在地图上绘制：路径、区域、矩形或圆形。

与标记不同，形状的标题不会直接显示在地图上，但悬停时会显示。

如果设置了[笔记颜色](../../Basic%20Concepts%20and%20Features/Notes/Note%20Icons%20%26%20Colors.md)，形状也会以该颜色绘制。

## 在地图上绘制形状

要绘制形状，请使用工具栏，该工具栏在桌面端出现在顶部中央区域，在移动端和分屏视图中出现在左侧中央区域。

形状一旦绘制完成，就无法移动或修改。如需调整，只需删除该形状并重新绘制一个即可。

### 绘制路径或区域

1.  按下 _在地图上绘制路径_（<span class="tn-icon bx bx-vector"></span>）或 _在地图上绘制区域_（<span class="tn-icon bx bx-shape-polygon"></span>）按钮。工具激活期间按钮保持按下状态，并会显示通知说明操作方法。
2.  在地图上为每个点单击一次。形状会随着绘制实时预览。
3.  按 <kbd>Enter</kbd> 完成绘制。路径也可以通过再次单击最后一个点来完成，区域则可以通过单击起始的角点来完成。路径至少需要两个点，区域至少需要三个点。

### 绘制矩形或圆形

1.  按下 _在地图上绘制矩形_（<span class="tn-icon bx bx-shape-square"></span>）或 _在地图上绘制圆形_（<span class="tn-icon bx bx-shape-circle"></span>）按钮。
2.  单击一次以设置第一个角点，或圆心。再次单击以设置对角点，或圆的半径距离。
3.  除了两次单击外，也可以从一个点拖动到另一个点。这在移动端和其他触屏应用上同样适用。

### 完成与取消

如需在绘制过程中放弃某个形状，请按 <kbd>Escape</kbd> 或再次按下该工具的按钮。已绘制的部分将被丢弃。

形状绘制完成后工具会自动停用，因此绘制第二个形状需要再次按下按钮。

## 交互

形状创建完成后：

*   单击形状会打开标准面板，可更改标题、内容，并通过按钮打开笔记或删除形状。
    *   单击时，标记的优先级高于形状。
*   右键单击形状会打开与标记类似的上下文菜单，可打开对应笔记或删除形状。
*   在地图的搜索栏中输入内容可按标题查找形状，与标记相同。选中某一项会将整个形状带入视野。

## 形状的表示方式

形状的表示方式与标记非常相似，即每个形状都是一个笔记。相关信息通过一个名为 `geoShape` 的[标签](../../Advanced%20Usage/Attributes/Labels.md)存储。
