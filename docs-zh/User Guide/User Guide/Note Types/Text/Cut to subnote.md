# 剪切到子笔记
<figure class="image image_resized image-style-align-right" style="width:64.63%;"><img style="aspect-ratio:812/585;" src="Cut to subnote_cut-to-subnote.gif" width="812" height="585"></figure>

当编辑的文档变得过大时，你可以将其拆分为子笔记：

1.  选中所需的文本并将其剪切到剪贴板。
2.  创建一个新的子笔记并为其命名。
3.  将剪贴板中的内容粘贴到子笔记中。

Trilium 可以自动化此过程。在笔记中选中一些文本，然后在选择工具栏中点击剪刀图标以执行“剪切并粘贴所选内容到子笔记”操作。标题会被自动检测，新子笔记会据此命名。你也可以为此操作分配键盘快捷键。此功能可通过块工具栏图标使用。在手机上，剪刀图标位于文本格式行的末尾，在你选中文本时会显示出来。
