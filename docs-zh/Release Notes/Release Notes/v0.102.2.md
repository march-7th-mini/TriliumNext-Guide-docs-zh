## 🔒️ 安全改进

*   内容处理
    *   改进了分享路由中 SVG 内容的请求处理
    *   改进了主 API 中 SVG 内容的请求处理
    *   增强了 Mermaid 图表编辑器中的内容渲染
    *   修复了通知提示以正确转义内容
    *   为文档渲染器中的 `docName` 属性添加了验证
    *   在公共模块中将 `docName` 标记为敏感属性
*   桌面应用程序 (Electron)
    *   添加了 Electron 保险丝以强化桌面应用程序，防止外部滥用
    *   改进了应用程序完整性检查
*   API 与导入
    *   为通过 ETAPI 上传的图片添加了 MIME 类型验证
    *   使附件上传验证与笔记上传验证保持一致
    *   导入不再保留命名的笔记 ID 以防止潜在冲突
*   身份验证
    *   OpenID Connect 现在使用更安全的随机数生成器

我们还更新了 SECURITY.MD 文件，以详细说明我们的安全实践以及如何报告漏洞。
