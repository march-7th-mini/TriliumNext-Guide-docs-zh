## 常用快捷键

> [!TIP]
> 本节中的键盘快捷键仅列出了我们所使用的编辑器技术 <a class="reference-link" href="../../Advanced%20Usage/Technologies%20used/CKEditor.md">CKEditor</a> 所支持的快捷键子集。这些快捷键摘自[官方文档](https://ckeditor.com/docs/ckeditor5/latest/features/accessibility.html#keyboard-shortcuts)。请注意，原始文档中的快捷键并非全部适用（因为使用了不同的配置）。

### 与块交互

块是指图像、表格、引用块、标注。

| 操作 | PC | Mac |
| --- | --- | --- |
| 在小组件之后直接插入新段落 | Enter |  |
| 在小组件之前直接插入新段落 | Shift+Enter | ⇧Enter |
| 移动光标以允许直接在小组件之前输入 | ↑, ← |  |
| 移动光标以允许直接在小组件之后输入 | ↓, → |  |
| 进入嵌套可编辑区域后，将选区移动到最近的祖先小组件。例如：从图像说明移动到整个图像小组件。 | Tab then Esc |  |

| 操作 | PC | Mac |
| --- | --- | --- |
| 增加列表项缩进 | ⇥ |  |
| 减少列表项缩进 | Shift+⇥ | ⇧⇥ |

表格内：

| 操作 | PC | Mac |
| --- | --- | --- |
| 将选区移动到下一个单元格 | ⇥ |  |
| 将选区移动到上一个单元格 | Shift+⇥ | ⇧⇥ |
| 插入新的表格行（当位于表格最后一个单元格时） | ⇥ |  |
| 在表格中导航 | ↑, →, ↓, ← |  |

### 常规界面快捷键
