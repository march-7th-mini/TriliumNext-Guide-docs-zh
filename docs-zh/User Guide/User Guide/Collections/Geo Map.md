# 地理地图
<figure class="image"><img style="aspect-ratio:1561/1149;" src="Geo Map_image.png" width="1561" height="1149"></figure>

此笔记类型基于某个属性，在地理地图上显示子笔记。也可以使用内置界面在特定位置添加新笔记。

## 功能

*   在地图上添加标记，可使用图标、颜色和文本进行自定义。
*   搜索地图上已有的笔记，并查找世界任何地方的地点。
*   通过点击地图上已显示的地点，将其变为标记。
*   在地图上绘制路径、区域、矩形和圆形。
*   使用 `.gpx` 文件在地图上显示轨迹。
*   在地图上显示你自己的位置，并在你移动时跟随它。
*   地图的 3D 视图，在使用矢量地图时显示建筑物。

## 系统要求

从 v0.105.0 开始，地理地图使用 MapLibre GL，它需要 WebGL v1 支持。一般来说，大多数设备都支持它，因为浏览器/Electron 在需要时可以以软件方式渲染。

如果由于无法初始化 WebGL 而无法绘制地图，将显示一条错误消息而不是地图（_无法绘制此地图，因为 WebGL 不可用……_）。

只有在通过 HTTPS 访问 Trilium、在桌面应用程序中或在移动应用程序中时，才会提供显示你位置的按钮。浏览器拒绝与通过纯 HTTP 提供服务的页面共享设备位置，因此在此类服务器上不会显示该按钮。

## 交互

*   左上角是搜索栏。它搜索地图上已有的笔记，当你要求时，它也可以在线搜索地点。当你在搜索结果中移动时，其下方会出现一个带有上一个和下一个按钮的计数器。
*   底部中央有一个中央工具栏，提供编辑功能：在地图上添加新标记和导入 GPX 轨迹。
*   右下角是视口项目：
    *   放大/缩小
        *   在移动设备上这些是隐藏的，请改用双指捏合缩放。
        *   在桌面上，也可以使用滚轮调整缩放。
    *   一个在地图上显示你位置并跟随它的按钮（参见下面的_前往你的位置_）。
    *   全屏按钮，将整个地图聚焦到屏幕上，同时仍允许编辑。
*   顶部中央（在桌面上，或在移动设备和分屏视图中为左侧中央）是绘图工具，如路径、区域、矩形和圆形。
    *   当地图为只读时，不显示工具栏。

## 创建新的地理地图

在<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a>中右键单击现有笔记，然后选择_插入子笔记_ → _地理地图_。

默认情况下，地图将为空并显示整个世界。

## 重新定位地图

*   单击并拖动地图以在地图上移动。
*   使用鼠标滚轮、触控板上的双指手势或右下角的 +/- 按钮来调整缩放。

地图上的位置和缩放保存在地图笔记内，并在再次访问该笔记时恢复。

尚未保存位置的地图在打开时会以其包含的标记为中心进行框选，因此它们都在视野中，无需去寻找它们。不包含任何标记的地图则显示整个世界。

实际上，这适用于其标记是通过脚本或通过<a class="reference-link" href="../Advanced%20Usage/ETAPI%20(REST%20API).md">ETAPI (REST API)</a>从外部添加的地图。当你自己添加标记时，你已经将地图移动到要标记的地点，而该移动会保存一个位置。

## 前往你的位置

按地图右下角缩放按钮旁边的_显示你的位置_按钮。第一次时，浏览器或操作系统会询问 Trilium 是否可以知道设备所在位置。在桌面应用程序中，由操作系统的位置设置决定。

然后地图会移动到设备所在位置，并用蓝点标记它。点周围的较浅圆圈显示位置的精确度：带 GPS 的手机给出街道上的一个点，而通过网络连接定位的计算机可能给出覆盖一个街区的圆圈。地图会随着点的移动而跟随它，按钮在跟随期间保持按下状态。

拖动地图会使其停止跟随。点会保留并继续移动，再次按下按钮会将地图带回它那里。在地图跟随期间按下按钮会关闭该点。

单击该点可在显示搜索地点的面板中查看其坐标。从那里可以将该位置保留为标记（参见_将地点保留为标记_）。单击点周围的较浅圆圈相当于单击地图。

如果无法找到位置，会显示一条消息说明，并且按钮会继续等待；再次按下它以停止。如果你拒绝权限，按钮将被禁用，直到再次打开地图。若要最终允许，请在浏览器或系统的位置设置中更改 Trilium 的权限。

你的位置不会存储在笔记中，Trilium 也不会自行将其发送到任何地方。将地图移动到那里与任何其他平移或缩放所做的一样：地图样式背后的瓦片提供商会看到当前屏幕上区域的坐标。地图确实会记住你离开它的位置，就像任何其他移动之后一样，因此你带到自己位置的地图下次会在那里打开。

## 搜索地图

地图左上角的搜索栏在两个地方进行搜索。它始终搜索地图上已有的笔记。它也可以在线搜索地点，但仅当你要求时。

### 搜索地图上已有的笔记

在搜索栏中输入，地图上的笔记会随着你输入而按标题匹配。你输入的内容和标题中的重音符号都会被忽略，因此 `zurich` 可以找到 _Zürich Hauptbahnhof_。每个词单独搜索，因此 `hotel paris` 可以找到 _Paris Hotel_。没有 `#geolocation` 属性的笔记不会被提供，因为没有可去的地方。绘制的形状和 GPS 轨迹会被提供，即使它们不带有此类属性：选择其中一个会将整个形状或路线带入视野。

如果匹配的笔记多于列表可显示的数量，会向你提供距离你正在查看区域最近的笔记。

### 在线搜索地点

查找地点会将你输入的内容发送到第三方服务。因此，它绝不会在你输入时发生。相反，结果列表的最后一行提供搜索。该行显示_在线搜索“……”_，其下方是服务名称。只有当你按下该行或用 Enter 选择它时，搜索才会运行。

Trilium 使用 Nominatim，这是由 OpenStreetMap 基金会运营的地点搜索。它不需要账户，也不需要 API 密钥。其名称显示在属于它的每一行上：提供搜索的行、显示搜索正在运行的行，以及报告未找到任何内容或无法访问该服务的行。

搜索优先考虑你正在查看的区域。当前视图内的地点会首先被搜索并列在其他地点之上。因此，如果你在查看自己所在城镇时搜索一家商店，你会找到该城镇的分店，而不是另一个大陆上同名的分店。视图始终被视为至少 25 公里宽，因此即使放大到单条街道进行搜索，仍会覆盖其周围的城镇。

### 前往某个点

如果你在搜索栏中输入或粘贴坐标，会在所有其他结果之上提供_前往_行。选择它会将地图移动到该确切位置并标记它。然后你可以将其保留为标记，方式与保留通过搜索找到的地点相同。

一个点没有自己的名称。它只有你输入的坐标。因此，该笔记会被赋予与任何其他新笔记相同的名称，这也是你从_添加标记_按钮和笔记树中的 + 按钮得到的名称。笔记打开时该名称已被选中，因此你可以直接输入覆盖它。如果地图有<a class="reference-link" href="../Advanced%20Usage/Default%20Note%20Title.md">默认笔记标题</a>标签，则标记会改为以该模板命名。

可理解的形式有：

*   普通的一对坐标，例如 `45.9432, 24.9668`。这是 Google Maps 和 OpenStreetMap 在你请求某个地点的坐标时都会给出的格式，也是 `#geolocation` 属性所保存的内容。
*   地图本身通过_打开位置_操作为某个地点提供的 `geo:` 链接。
*   完整粘贴的 Google Maps 或 OpenStreetMap 上某个地点的地址。

不是地球上某个地点的一对坐标，例如 `1234, 5678`，不会被提供。

### 阅读结果

结果按标题分组收集，每组按距地图中心的距离排序：

*   _在此地图上_：已经在地图上的笔记，无论其距离如何。
*   _附近_：在视图约 25 公里范围内找到的地点。
*   _远处_：所有其他地点。

只有当三组中至少有两组包含内容时，才会显示这些标题。每个有位置的行都会显示其距离，根据你的区域设置以公里或英里为单位。在线找到的地点第一行显示其名称，第二行显示其地址。

### 选择结果

选择地图上已有的笔记会移动到其标记，并在地图旁边打开该笔记，就像单击标记一样。

选择在线找到的地点会将地图移动到它，并用临时图钉标记它。图钉的颜色与地图自己的标记不同。地图会适配该地点覆盖的区域，因此一个国家会填满视图，而一栋房子会以街道级别显示。有些地点有边界，例如国家、县或公园。当服务报告边界时，该边界会在图钉下方勾勒出来。

然后会打开一个面板，显示该地点的完整地址及其坐标：在桌面上位于右上角，在移动设备上位于地图底部，因为顶部保留给搜索栏和结果计数器。按下坐标会将其复制到剪贴板。

### 将地点保留为标记

在该面板中按_添加为标记_以保留该地点。会在地图下创建一个子笔记。它采用该地点的名称，以及与其地点类型匹配的图标。其 `#geolocation` 属性已经设置。该笔记会在地图旁边打开，因此你可以立即编辑它。临时图钉会消失，因为该地点现在像其他标记一样是一个标记。

在无法编辑的地图上不提供该按钮，但面板仍可阅读。

按面板的关闭按钮或 Escape 键，可在不保留的情况下送走该地点。图钉也随之消失。

### 逐步浏览结果

一旦你选择了一个结果，搜索栏下方会出现一个计数器，带有上一个和下一个按钮。这些按钮按列出顺序遍历搜索提供的所有内容。因此，你无需再次打开列表即可比较多个结果。按下计数器本身会将地图移回当前结果，这在你已将地图移开它之后很有用。

### 键盘

*   **Enter** 在其行被选中时运行在线搜索，否则移动到高亮的结果。在已取用结果后按下，会重新显示列表。
*   **Escape** 关闭结果列表，并关闭地点面板。
*   返回搜索栏会重新打开它之前显示的列表。
*   栏末的 **X** 会清空它，这也会将搜索到的地点、其图钉和面板从地图上移除。

## 使用地图添加标记

### 使用加号按钮添加新笔记

1.  要创建标记，首先导航到地图上所需的点。然后按地图底部中央的_添加标记_按钮。
2.  按下后，地图将进入插入模式，如通知所示。此外，光标位置会显示标记的预览。
    
    只需单击地图上要放置标记的点。要取消，请按 Escape 键或再次按_添加标记_按钮。
3.  单击后，标记将显示在地图上，右侧会显示一个弹出窗口，标题已被选中以便更改。

### 使用上下文菜单添加新笔记

1.  在地图上要放置新创建标记（及对应笔记）的任何位置右键单击。
2.  选择_在此位置添加标记_。
3.  单击地图上的某个位置后，标记将显示在地图上，右侧会显示一个弹出窗口，标题已被选中以便更改。

### 从笔记树添加现有笔记

1.  在<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">笔记树</a>中选择所需的笔记。
2.  按住笔记并将其拖动到地图上所需的位置。
3.  地图应更新为新标记。

这适用于：

*   不属于地理地图的笔记，在这种情况下将创建一个[克隆](../Basic%20Concepts%20and%20Features/Notes/Cloning%20Notes.md)。
*   是地理地图的子笔记但尚未在地图上定位的笔记。
*   是地理地图的子笔记且已定位的笔记，在这种情况下标记将重新定位到新位置。

> [!NOTE]
> 仅当地图处于编辑模式时，拖动现有笔记才有效。有关更多信息，请参阅_只读_部分。

### 从地图已显示的地点添加笔记

当使用矢量地图样式时，地图本身会绘制正在查看区域周围的商店、咖啡馆、博物馆和其他地点。一旦地图放大到足以绘制这些地点，就可以单击它们：

1.  寻找以橙色绘制的地点。这与搜索找到的地点使用的颜色相同。这些是你可以单击的地点。它们绘制得几乎实心，而地图上的其他地点保持淡灰色。
2.  将鼠标停留在其中一个上。其名称会出现在其上方，鼠标光标变为指针。地图将这些地点绘制为没有名称的图标，因此你通过悬停来读取名称。如果所有名称都同时显示，它们会挤掉你自己标记的标题。
3.  单击它。会出现与搜索找到的地点使用的相同面板。它显示地点的名称及其坐标，并在地图上放置一个图钉。
4.  按_添加为标记_以保留它。创建的笔记以该地点的名称作为标题，并使用与其地点类型匹配的图标。

地点是从已下载的地图数据中读取的，因此单击一个地点不会向互联网发送任何内容。

需要记住的一些事项：

*   地图数据中没有名称的地点，例如长椅或停车位，不显示名称且无法单击。单击它们没有任何效果，就像单击地图的空白部分一样。
*   地图自己的标记优先。如果标记覆盖了某个地点，单击它会打开笔记而不是该地点。
*   这不适用于栅格（OpenStreetMap）样式，因为其地点是地图图像的一部分。它也不适用于_Neutrino_样式，该样式不绘制地点。
*   在只读模式下，你仍然可以单击地点并阅读它，但不能将其保留为标记。

## 标记的位置如何存储

标记的位置存储在子笔记的 `#geolocation` 属性中：

如果需要，可以手动添加此值。该属性的值由纬度和经度组成，以逗号分隔。

## 重新定位标记

一旦设置了标记，可以使用以下两种方式之一重新定位它：

*   右键单击标记并选择_移动到另一个位置_。
*   单击标记以打开弹出窗口，然后选择标题栏下方的_移动到另一个位置_按钮。

单击移动标记的按钮后，在地图上单击所需位置以替换它。要取消操作，请按 Escape。

> [!NOTE]
> 如果地图被锁定以进行编辑（见下文），则需要先解锁地图才能移动标记。

## 与标记、轨迹或形状的交互

*   将鼠标悬停在标记上会显示一个<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tooltip.md">笔记工具提示</a>，其中包含其所属笔记的内容。
    *   单击工具提示中的笔记标题将在当前视图中导航到该笔记。
*   右键单击标记将打开上下文菜单（如下所述）。
*   单击标记将聚焦于该标记，并显示带有详细信息的专用弹出窗口。无论地图是否可编辑，这都有效。

### 弹出视图

当单击标记、[形状](Geo%20Map/Drawing%20shapes.md)或轨迹时，右侧会打开一个弹出窗口，其中包含以下信息：

*   标记的标题和图标，两者均可编辑。
*   坐标指示器；单击它会将坐标复制到剪贴板。
*   最大化弹出窗口的按钮。
*   与当前项目交互的按钮：
    *   在同一窗格、新标签页等中打开标记。
    *   在专用应用程序（例如移动设备上的 Google Maps）中打开位置的按钮。
    *   用于更改标记颜色的颜色选择器。
    *   标记也可以移动，与轨迹或形状不同（后者需要重新绘制）。
    *   从地图移除标记的按钮，可以选择删除其对应的笔记。
        *   移除标记而不删除笔记只会移除其 `#geolocation` 属性（在这种情况下，必须手动重新添加坐标才能使笔记再次显示在地图上）。
        *   同样，移除形状会移除其 `#geoShape` 属性。
*   标记的<a class="reference-link" href="../Advanced%20Usage/Attributes/Promoted%20Attributes.md">提升属性</a>（如果有）。
*   笔记的内容，可以直接从面板编辑。

要关闭弹出窗口：

*   按弹出窗口右上角的 X 按钮。
*   在地图上，按弹出窗口外的任何位置。
*   或者直接按 Escape 键。

单击标记时，地图会自动调整视口，以便在弹出窗口打开时标记仍然可见。当前选中的标记显示得稍大一些。

即使弹出视图已经打开，也可以通过单击标记在它们之间切换。

标记之间可以有<a class="reference-link" href="../Note%20Types/Text/Links/Internal%20(reference)%20links.md">内部（引用）链接</a>，单击此类链接会自动将视口和弹出视图调整到新笔记。

### 上下文菜单

可以按鼠标右键显示上下文菜单。

1.  如果右键单击地图的空白部分（不是标记），它可以：
    1.  显示纬度和经度。单击此选项会将它们复制到剪贴板。
    2.  使用外部应用程序打开位置（如果操作系统支持）。
    3.  在该位置添加新标记。
2.  如果右键单击标记，它可以：
    1.  显示纬度和经度。单击此选项会将它们复制到剪贴板。
    2.  使用外部应用程序打开位置（如果操作系统支持）。
    3.  在新标签页、分屏或窗口中打开笔记。
    4.  从地图移除标记的按钮，可以选择删除其对应的笔记。移除标记而不删除笔记只会移除其 `#geolocation` 属性（在这种情况下，必须手动重新添加坐标才能使笔记再次显示在地图上）。
3.  形状也可以右键单击，菜单与标记类似，但它们不能移动。

### 图标和颜色

标记将具有与笔记相同的图标。

可以通过为标记分配 `#color` 属性（例如 `#color=green`）来为其添加自定义颜色。

### 手动添加坐标

搜索地点通常更快（参见上面的_搜索地图_）。以下步骤对于已手头已有的坐标，或搜索无法找到的地点仍然有用。

简而言之，创建一个子笔记并将 `#geolocation` 属性设置为坐标。

该属性的值由纬度和经度组成，以逗号分隔。

#### 从 Google Maps 添加

1.  在网页版 Google Maps 中：
    1.  寻找所需位置，右键单击它，会出现上下文菜单。
    2.  只需单击显示坐标的第一项，它们就会被复制到剪贴板。
2.  在 Trilium 中，在地图下创建一个子笔记。
3.  然后将文本框中的值粘贴到地图子笔记的 `#geolocation` 属性中（不要忘记用 `"` 字符包围该值）。

#### 从 OpenStreetMap 添加

与 Google Maps 方法类似：

1.  转到 openstreetmap.org 上的任何位置，右键单击以调出上下文菜单。选择_显示地址_项。
2.  地址将显示在屏幕左上角，即搜索栏的位置。选择坐标并将它们复制到剪贴板。
3.  只需将文本框中的值粘贴到地图子笔记的 `#geolocation` 属性中，然后它就应该显示在地图上。

## 添加 GPS 轨迹（.gpx）

<figure class="image"><img style="aspect-ratio:1566/1155;" src="1_Geo Map_image.png" width="1566" height="1155"></figure>

Trilium 可以以 `.gpx` 文件的形式在地理地图上显示 GPS 轨迹。

要添加轨迹，可以：

1.  将 `.gpx` 文件拖放到笔记树中的地理地图内。
    1.  为了使文件被识别为 GPS 轨迹，它需要在_文件类型_字段中显示为 `application/gpx+xml`。
2.  按_从 GPX 文件添加 GPS 轨迹_，它将直接提示选择 GPX 文件并将其作为集合的子笔记导入。

返回地图时，轨迹现在应该可见。

轨迹的起点将显示为标记，其下方是笔记的名称。起点标记也将遵循笔记的图标和 `color`。终点标记使用不同的图标显示。

如果轨迹文件包含多条轨迹，它们都将作为标记显示。Trilium 还会拆分恰好具有不连续点的单条轨迹。

如果 GPX 包含航点，它们也会显示，包括其名称。

单击轨迹时，整个路线会被带入视野，右侧弹出窗口将指示有关轨迹的详细信息，例如距离、持续时间和海拔图。单击 `.gpx` 笔记本身时也会显示此信息。

单击轨迹的标记时（无论是起点还是终点内置标记，还是属于轨迹的自定义标记），只会将该标记带入视野，而不是整个路线。

## 只读模式

当地图为[只读](../Basic%20Concepts%20and%20Features/Notes/Read-Only%20Notes.md)时，所有编辑功能都将被禁用，例如：

*   地图底部的添加按钮。
*   重新定位标记。
*   从上下文菜单编辑（移除位置或添加新项目）。
*   将地点保留为标记，无论你是通过搜索找到它还是在地图上单击它。你仍然可以搜索和单击，仍然可以查看地点并复制其坐标。
*   绘制[形状](Geo%20Map/Drawing%20shapes.md)。

要将地图设置为只读，请转到<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20buttons.md">笔记按钮</a> → _可编辑_ → _只读_（在新布局中，或对于旧布局，在<a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Ribbon.md">功能区</a>的基本属性中）。

## 配置

### 地图样式

地图的样式可以在<a class="reference-link" href="Collection%20Properties.md">集合属性</a>中调整，或通过 `#map:style` 属性手动调整。

地理地图附带两种不同类型的样式：

*   栅格样式
    *   对于这些样式，地图表示为不同缩放级别的图像网格。这是 OpenStreetMap 过去使用的传统方式。
    *   缩放略微受限。
    *   目前，唯一的栅格主题是原始的 OpenStreetMap 样式。
*   矢量样式
    *   矢量样式不是表示为图像，而是表示为几何形状。这使得渲染更加平滑，尤其是在缩放和查看建筑物边缘时。
    *   地图可以放大得多。
    *   这些有多种样式，既有浅色（Colorful、Graybeard、Neutrino）也有深色（Eclipse、Shadow）。
    *   矢量样式来自 [VersaTiles](https://versatiles.org/)，这是一个免费开源项目，提供基于 OpenStreetMap 的地图瓦片。
    *   VersaTiles 图层还提供 3D 建筑物信息（见下文）。

默认主题是 Versatiles Colorful（矢量）。

#### 带建筑物的 3D 视图

<figure class="image"><img style="aspect-ratio:2727/1642;" src="2_Geo Map_image.png" width="2727" height="1642"></figure>

Trilium v0.105.0 引入了 3D 视图，由 MapLibre GL 提供。要进入 3D 模式，只需按地图右下角的相应按钮，或按 Ctrl 并在地图上拖动。

建筑物只会从缩放级别 14 开始出现，以避免卡顿。

> [!NOTE]
> 要获得 3D 建筑物，请确保你使用的是 _VersaTiles_ 样式，它们通过 `versatiles-shortbread` 源提供建筑物信息。

### 自定义地图样式 / 瓦片

从 v0.102.0 开始，可以使用自定义瓦片集，但仅限栅格格式。

为此，手动将 `#map:style` [标签](../Advanced%20Usage/Attributes/Labels.md)设置为瓦片集的 URL。例如，要使用 Esri.NatGeoWorldMap，请将值设置为 [`https://server.arcgisonline.com/ArcGIS/rest/services/NatGeo_World_Map/MapServer/tile/{z}/{y}/{x}`。](https://server.arcgisonline.com/ArcGIS/rest/services/NatGeo_World_Map/MapServer/tile/%7Bz%7D/%7By%7D/%7Bx%7D.)

此外：

*   通过 `{r}` 占位符支持 Hi-DPI 瓦片。
*   要将自定义样式标记为深色（这会影响 UI 的样式），请应用 `map:darkStyle` 标签。此属性也会覆盖内置主题。

> [!NOTE]
> 有关瓦片集列表，请参阅 [Leaflet Providers 预览](https://leaflet-extras.github.io/leaflet-providers/preview/)页面。选择所需的瓦片集，然后从_纯 JavaScript_ 示例中复制 URL。

自定义矢量地图支持已计划，但尚未实现。

### 其他选项

以下选项可以通过<a class="reference-link" href="Collection%20Properties.md">集合属性</a>配置，方法是单击设置（齿轮图标）。或者，这些选项中的每一个也有一个可以手动设置的对应[标签](../Advanced%20Usage/Attributes/Labels.md)。

*   比例尺，在地图左下角以公里或英里显示地图的比例。
    *   单位由_语言和区域_中的_格式区域设置_选项决定。
*   标记的名称默认显示在地图上图钉的下方。从 v0.102.0 开始，可以隐藏这些标签，这在地图上有许多标记时可以提高性能并减少杂乱。
*   v0.105.0 还引入了一个名为_分组附近标记_的功能，它会在低缩放级别将多个标记聚集在一起。
    *   聚类显示其包含的项目数。颜色也会根据数量而变化。
    *   单击聚类会自动放大，以便组成该聚类的各个标记现在可见。
