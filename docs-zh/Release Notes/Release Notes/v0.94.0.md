## 💡 主要亮点

*   @perfectra1n 完成了[大量工作](https://github.com/TriliumNext/Notes/pull/1325)，将 Ollama 和 ChatGPT 等大语言模型集成到 Trilium 中。
    *   目标不仅仅是提供基础的 API 集成，而是真正让大语言模型理解您知识库中的笔记。
    *   有关更多信息，请查阅应用内用户指南（<kbd>F1</kbd>）并查找 AI 部分。
    *   由于这是一项高度实验性的工作，AI/大语言模型对话功能可能运行良好，也可能存在不少问题，请务必牢记这一点。
*   此版本对我们的库进行了重大更新：
    *   文本笔记使用的 CKEditor 现已更新至最新版本，带来了新功能（见下文）和性能改进。
    *   代码笔记使用的 CodeMirror 已升级到新一代版本。
    *   代码笔记现在也支持主题，类似于代码块。

## ✨ 改进

*   改进了文本编辑器样式，以匹配 TriliumNext。
*   图片说明中的脚注由 @werererer 实现
*   文本笔记的改进（更多详情请参阅应用内帮助）：
    *   书签，类似于 HTML 锚点。
    *   表情符号。
*   [在树上右键单击时显示触发事件的节点](https://github.com/TriliumNext/Notes/pull/1861) 由 @SiriusXT 实现
*   [仅展开/折叠聚焦窗口的左侧窗格](https://github.com/TriliumNext/Notes/pull/1905) 由 @SiriusXT 实现
*   代码笔记：
    *   为代码笔记和文本笔记中的代码块添加了 GDScript（Godot）语言支持。
    *   添加了 Nix 语言支持（也支持文本笔记中的代码块）。
    *   添加了缩进标记。
    *   注意：由于缺乏上游支持，某些语言（主要是 HTML 模板语言，如 EJS、JSP）的语法高亮不再受支持。如果这是个问题，请随时报告问题，我们可以看看能做些什么。
*   为文本笔记中的代码块添加了额外的语法高亮支持：Cypher、XML-DTD、Jinja2、ClojureScript、Perl、Scala、Scheme、Swift、SystemVerilog、mIRC、Cobol、Dylan、RPM Specfile、TCCN3。
*   Mermaid 图表：基础语法高亮（并非所有图表类型都受支持）和代码折叠。
*   外观设置中的轻微整理：代码块主题现在位于“文本笔记”下，在外观中新增了“相关设置”部分。
*   [支持在启动器面板、笔记树或笔记图片中使用 Ctrl+Shift+单击在新标签页中打开并激活笔记](https://github.com/TriliumNext/Notes/pull/1854) 由 @SiriusXT 实现
*   [样式和脚注改进](https://github.com/TriliumNext/Notes/pull/1913) 由 @SiriusXT 实现
*   后端日志：禁用某些编辑器功能以提高大型日志的性能（语法高亮、折叠等）。
*   [可折叠的目录](https://github.com/TriliumNext/Notes/pull/1954) 由 @SiriusXT 实现
*   会话（登录）不再作为文件存储在数据目录中，而是作为数据库中的条目存储。这提高了 Windows 平台上的会话可靠性。
*   文本笔记中的代码块：
    *   对于可编辑笔记，单击代码块将显示一个工具栏，其中包含轻松更改编程语言的方法和另一个将文本复制到剪贴板的按钮。
    *   对于只读笔记，一个浮动按钮允许将代码片段复制到剪贴板。
*   [文本笔记中的数学公式：方程现在可以多行显示](https://github.com/TriliumNext/Notes/pull/2003) 由 @SiriusXT 实现
*   [指标端点](https://github.com/TriliumNext/Notes/pull/2024) 由 @perfectra1n 实现
*   Docker：@perfectra1n 提供了[无根 Dockerfile](https://github.com/TriliumNext/Notes/pull/1923/files)
*   [文本笔记：添加通过键盘快捷键上下移动文本行的方法](https://github.com/TriliumNext/Notes/issues/1002) 由 @dogfuntom 实现
*   [通过将标签页滚动从即时行为切换为平滑行为来改善用户体验](https://github.com/TriliumNext/Notes/pull/2030) 由 @SiriusXT 实现
*   日历视图：如果设置了 `#viewType=calendar`，则显示日历视图。
*   [思维导图：添加搜索支持](https://github.com/TriliumNext/Notes/pull/2055) 由 @SiriusXT 实现
*   地图：
    *   轨迹笔记的名称、图标和颜色显示为起点。
    *   为终点标记添加了不同的图标。
