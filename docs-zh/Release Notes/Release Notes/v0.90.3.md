# v0.90.3

这是 TriliumNext 首个被认为是稳定的公开版本。

## ❔ 为什么选择 TriliumNext？

TriliumNext 始于 2024 年初作为 [Trilium Notes](https://github.com/zadam/trilium) 的一个分支。之所以进行这项工作，是因为上游项目已进入[维护阶段](https://github.com/zadam/trilium/issues/4620)，而我们希望扩展该应用程序。

迄今为止的工作更侧重于技术方面，因为大部分工作由 @zadam 完成，而移交如此规模的项目并非易事。在接下来的版本中，我们还将进行一些技术性更强的工作，之后项目将专注于尽可能改善用户体验。

从用户角度来看，接下来计划内容的简要概述：

*   支持多种语言。
*   改进现有主题并精简用户界面。
*   移动端改进。
*   探索额外的编辑器，例如基于 Markdown 的编辑器。

## ⬆️ 从 Trilium Notes 迁移？

数据库结构没有变化。

TriliumNext 可以直接替代原版 Trilium Notes 运行，并且应该可以开箱即用，因为它会复用相同的数据库。

如有需要，也应该可以降级回 Trilium Notes，无需任何更改或数据丢失。

服务器端也是如此，应该可以开箱即用。可以在 TriliumNext 和 Trilium Notes 之间混合使用。

## 🐞 版本稳定性如何

通常您不会遇到严重的错误，因为之前的版本已经过测试并作为日常驱动使用了数周。

如果您遇到任何问题，欢迎在我们的 [GitHub issues](https://github.com/TriliumNext/Notes/issues) 上报告。

    *   引入了 Windows 安装程序，取代了 .zip 安装方式。
    *   修复了与服务器 TypeScript 移植相关的错误。
*   v0.90.0-beta
    *   在技术方面，服务器已用 TypeScript 重写。得益于该语言的类型安全性，这应能提高当前和未来开发的稳定性。这也将使开发稍微容易一些。
