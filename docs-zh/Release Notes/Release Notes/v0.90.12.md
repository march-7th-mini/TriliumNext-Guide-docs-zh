# v0.90.12
## 💡 主要亮点

*   现在可以为文本笔记设置固定工具栏，取代标准的浮动工具栏，更多信息请参见 [文本笔记经典编辑器（带固定工具栏）](https://github.com/TriliumNext/Notes/pull/571)。
*   可编辑和只读文本笔记中的代码块支持语法高亮（通过 Highlight.js），主要基于 [antoniotejada](https://github.com/antoniotejada) 的 [Trilium-SyntaxHighlightWidget](https://github.com/antoniotejada/Trilium-SyntaxHighlightWidget)。
