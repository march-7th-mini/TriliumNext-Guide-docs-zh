## 💡 主要亮点

*   现在可以直接在 Trilium 中创建演示文稿，包括能够全屏演示。
    *   演示文稿是一种新的集合类型。
    *   有关更多信息，请参阅应用内文档或[在线文档](https://docs.triliumnotes.org/User%20Guide/User%20Guide/Note%20Types/Collections/Presentation%20View.html)。
*   整个打印机制已从头开始重新设计。
    *   这应该意味着跨笔记类型的打印或导出为 PDF 更加稳定。
    *   新的演示文稿集合也可以导出为 PDF。
    *   有关更多信息，请参阅[文档](https://docs.triliumnotes.org/User%20Guide/User%20Guide/Basic%20Concepts%20and%20Features/Notes/Printing%20%2526%20Exporting%20as%20PDF.html)。
