# 思维导图
<figure class="image image-style-align-center"><img style="aspect-ratio:892/675;" src="Mind Map_image.png" width="892" height="675"></figure>

思维导图允许轻松记录想法，并以层级结构存储它们。

## 术语

*   一个**节点**代表一个单一的想法，根据深度不同而呈现不同形式（根笔记为填充圆角矩形，子想法为未填充矩形，子子想法仅为线条）。
*   **根节点**是所有其他节点派生的最顶层节点，显示为填充矩形。只能有一个根节点。

## 交互

*   要在当前节点同一层级创建新节点，请按 <kbd>Enter</kbd>，输入所需文本，然后再次按 <kbd>Enter</kbd> 确认。
*   类似地，要创建子节点，请按 <kbd>Tab</kbd>，输入所需文本，然后按 <kbd>Enter</kbd>。
*   要创建父节点，请改用 <kbd>Ctrl</kbd>+<kbd>Enter</kbd>。
*   要删除节点，请按 <kbd>Delete</kbd>。
*   要向上或向下移动节点，请按 <kbd>Page Up</kbd> 或 <kbd>Page Down</kbd>。
*   要调整字体大小、文本或背景颜色或添加链接，请点击节点并使用右侧出现的浮动面板。
*   要选择一个或多个笔记，请在导图上拖放。
*   右键点击节点可弹出上下文菜单，其中包含创建新节点、聚焦特定笔记或在它们之间创建链接等选项。
*   使用左上角的按钮来更改节点相对于根节点的位置（左侧、右侧或两侧）。
*   在 <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Floating%20buttons.md">浮动按钮</a> 区域：
    *   可以复制一个 [图片引用](Text/Images/Image%20references.md)，以将思维导图粘贴到文本笔记中。
    *   图表可以导出为 SVG（矢量）或 PNG（栅格）格式。
    *   笔记可以切换为 [只读](../Basic%20Concepts%20and%20Features/Notes/Read-Only%20Notes.md)。
