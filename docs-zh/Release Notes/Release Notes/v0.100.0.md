## 💡 主要亮点

*   [允许从树中更改笔记颜色](https://github.com/TriliumNext/Trilium/issues/4137) 由 @adoriandoran 贡献
*   更多集合类型现在可以打印或导出为 PDF：
    *   列表集合将以类似书籍的方式渲染，包含其所有子项并保留笔记层级结构，具有可用的目录和链接（适用于 PDF）。
    *   表格集合现在将渲染为可打印的表格。
    *   更多信息请参阅[文档](https://docs.triliumnotes.org/user-guide/concepts/notes/printing-and-pdf-export#printing-multiple-notes)。
*   看板视图改进
    *   现在显示每列中的项目数量。
    *   现在可以使用提升属性为每个笔记显示属性（标签和关系），有关操作方法请查阅文档。
*   移动端现在支持基本的分屏功能（最多两个），在智能手机上垂直布局。
*   **重大变更**：`#calendar:color` 已完全移除，取而代之的是全局 `#color` 属性。
