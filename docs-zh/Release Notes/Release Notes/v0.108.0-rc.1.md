现在，链接可以指向标题或锚点，而不再只是整个笔记，这在文本笔记和 Markdown 笔记以及 PDF、EPUB、Word 和 OpenDocument 文件中均适用。大纲标签页也会列出这些文件的标题，并提供筛选功能以及复制任意标题引用的方式。文本笔记还新增了可折叠标题、旁注块，以及一个可标记搜索结果和彩色文本的滚动条。

Android 迎来了首个稳定版本，APK 附于下方。它与同版本的服务器同步，并与 nightly 构建版并排安装，因此从 nightly 迁移意味着需要重新同步或恢复备份。

## 💡 重点亮点

### 文本笔记中的 Vim 模式

代码笔记多年来一直支持 Vim 键绑定，但文本笔记——Trilium 中大部分写作发生的地方——却一直没有。对于习惯 Vim 的人来说，每篇文本笔记都意味着要把这个习惯放在一边，回到鼠标和方向键。Vim 用户自 2021 年起就一直在请求这一功能，现在终于到了将它实现的时候：文本笔记有了自己的 Vim 模式。它运行在与代码笔记相同的 Vim 引擎上，因此命令的工作方式与那里一致，并且它理解富文本的结构：一个段落、一个标题、一个列表项、一个表格单元格和一行代码各自是一行；一张图片、一个图表或一个包含的笔记是一行，`j` 和 `k` 会停在其上，`dd` 会将其删除；被复制的文本在放回时会保留其加粗、链接和颜色。插入模式就是原来的编辑器，具有其格式化快捷键、斜杠命令和 Markdown 自动格式化。

动作、操作符、文本对象、计数、使用 `.` 重复、寄存器、标记、宏、搜索和 `:s` 均可使用，在包含的笔记中也是如此。Trilium 命令也加入其中：`:w` 保存笔记，`:q` 关闭笔记，`gf` 跟随光标下的链接，`za` 折叠标题、列表项或可折叠块，`:sort` 对行排序，`:ck` 运行任意编辑器命令，`"+y` 将带格式的内容复制到系统剪贴板。状态栏显示模式、待执行命令的按键和宏录制状态，`: `、`/` 和 `?` 会在面包屑导航的位置打开命令行。禅模式会同时保留两者。

按键提示在你学习时提供帮助，其他时候则保持安静。普通模式和可视模式会在状态栏中显示其按键，命令中途的暂停会显示可以跟随其后的按键。命令行使用 `Tab` 补全命令名称，搜索提示会说明模式的读取方式，`Alt+F1` 或点击模式会列出所有按键。普通模式下的 `Esc` 在按键和面包屑导航之间切换，按键提示选项可以将其关闭。

在选项 → 文本笔记 → 功能 → Vim 模式中，在你想使用它的每台设备上开启它。状态栏中的 Vim 徽章或 `#vimMode` 标签可以为单个笔记开启或关闭它，启动命令可以设置诸如 `imap jk <Esc>` 之类的映射。

### 更快的启动，桌面端和手机端皆然

Trilium 现在的启动速度明显加快。它会先显示启动栏、标签页和笔记树，只有在你使用其余部分时才加载它们。这同样适用于手机。

在较慢的设备上差异最大。在 20 Mbit/s 连接上模拟较慢设备时，桌面端笔记可在 2.5 秒内准备好编辑，而不是 5.2 秒；手机端为 2.3 秒，而不是 4.8 秒。在快速计算机上，它大约提前 30% 准备好。

### 直接链接到笔记内的标题

当你创建指向笔记的链接时，可以选择一个标题，使链接打开到该章节。这适用于文本笔记、Markdown、PDF、EPUB、ODT 和 DOCX。


## 🚨 破坏性变更

*   对于主题开发者：`--background-material` CSS 变量不再有效果。Trilium 现在根据布局自行选择 Mica 或 vibrancy 背景，并且仅将其应用于 Next 主题以及基于它们并使用 `#appThemeBase` 的自定义主题。`window.electronApi.window` 的 `setBackgroundMaterial()` 和 `setVibrancy()` 方法已被移除。

## 🔒️ 安全改进

1.  在桌面应用中，网页可以将笔记发送到网页剪藏端点，并且通过 DNS 重绑定可以植入一个在应用下次启动时运行的脚本。
2.  共享笔记的访问者可以使用共享搜索一次一个字符地读取从未共享的笔记的标题、标签和内容。
3.  在启用网络访问的桌面应用中，设置初始密码现在仅限于桌面应用本身。
4.  笔记图标在显示之前会经过更严格的验证。
5.  桌面应用程序不再在不询问的情况下打开笔记中的程序文件。
6.  安全导入还会禁用通过 Markdown front matter、Evernote 标签以及 Notion、Anytype 或 Obsidian 属性设置的脚本和其他活动内容。
