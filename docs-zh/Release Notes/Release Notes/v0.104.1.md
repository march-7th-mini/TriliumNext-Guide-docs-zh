## 💡 主要亮点

1.  OneNote 导入的显著改进：
    1.  [在持续的 Graph 限流下存活](https://github.com/TriliumNext/Trilium/pull/10600) 由 @perfectra1n 贡献
    2.  [处理 504 错误而不是崩溃](https://github.com/TriliumNext/Trilium/issues/10558)。
    3.  跳过无法下载的页面并报告它们。
    4.  添加设备代码流程，允许从 Web 应用（不仅仅是桌面端）进行导入。
    5.  刷新令牌，使得长达数小时的导入成为可能。
    6.  更好地支持屏幕剪辑、表格大小和背景、支持浅色/深色主题的绘图、改进的创建日期处理。
    7.  保留 `newNotesOnTop`。
    8.  改进的笔记本选择器。
    9.  现在通过考虑元信息（不仅仅是 API 返回的创建日期）来更好地保留创建日期。
    10.  [加密部分会被妥善容忍并报告。](https://github.com/TriliumNext/Trilium/issues/10662)
2.  大语言模型的改进
    1.  大语言模型选择已重新设计：不再使用固定的模型列表，而是从提供商（ChatGPT、Gemini）动态获取模型，并且模型列表现在可以自定义。
        1.  如果您从以前的版本迁移，模型列表将显示为空。只需在模型下拉菜单中按下与您的提供商对应的编辑按钮即可。
    2.  大语言模型现在可以阅读应用程序自带的用户指南，并能回答关于 Trilium 功能的问题。
    3.  改进了提供商设置流程。
    4.  [添加了对 DeepSeek 的支持](https://github.com/TriliumNext/Trilium/issues/10338)，但没有网络搜索功能。
    5.  [对自定义 OpenAI 兼容提供商的一手支持](https://github.com/TriliumNext/Trilium/issues/10601)
    6.  添加了对 Ollama 和 LM Studio 以及任何自托管提供商的支持（@Kureii & @eliandoran）

23.  修复了键盘快捷键提示与浮动按钮重叠的问题。

    2.  链接预览元数据现在出现在快速搜索片段中（URL、标题和描述分别在不同的行）。
    3.  快速搜索片段现在解码 HTML 实体，因此您可以看到 `<`、`&` 和真正的空格，而不是 `&lt;`、`&amp;` 和 `&nbsp;`。
6.  由 @adoriandoran 贡献的可折叠块改进
    1.  可折叠块现在会记住它们的展开/折叠状态。
    2.  当搜索结果在其正文中被高亮时，可折叠块会自动展开。
7.  由 @adoriandoran 改进了自定义任务复选框字形和标签的对齐方式
8.  桌面端：添加了禁用 GPU 加速的选项
