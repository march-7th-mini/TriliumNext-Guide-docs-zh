# 恢复已删除的笔记
已删除的笔记列在 _已删除笔记_ 对话框中（<a class="reference-link" href="../UI%20Elements/Global%20menu.md">全局菜单</a> → _已删除笔记_），可通过点击 _取消删除_ 链接来恢复。

如果笔记有子笔记，它们将随笔记一同恢复。若原位置已不存在（例如父笔记已被删除），笔记将恢复到新笔记的默认位置（<a class="reference-link" href="Note%20Inbox.md">笔记收件箱</a>）。

> [!NOTE]
> 当笔记在树中被提升时，对话框仅显示从该提升笔记的子树中删除的笔记。

要永久清除已删除的笔记并清空列表，请点击三点菜单并选择 _立即清除已删除笔记_。

已删除的笔记会在一定时间后（默认为 7 天）被永久清除。要更改此间隔，请点击三点菜单并选择 _已删除笔记设置_。
