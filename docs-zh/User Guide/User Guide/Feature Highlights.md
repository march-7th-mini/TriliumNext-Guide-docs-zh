# 功能亮点

本节按版本介绍最重要的变更。如需查看完整的变更列表，请查阅每个版本的更新日志。为简洁起见，测试版被跳过，其功能汇总至最近的稳定版本。

*   v0.101.0：
    *   引入了<a class="reference-link" href="Basic%20Concepts%20and%20Features/UI%20Elements/New%20Layout.md">新布局</a>，对UI/UX进行了重大修改，例如将功能区（ribbon）和浮动按钮整合到其他UI元素中，并引入了诸如<a class="reference-link" href="Basic%20Concepts%20and%20Features/UI%20Elements/New%20Layout/Breadcrumb.md">面包屑</a>等新功能。
*   v0.97.0：
    *   书籍（Books）现在是<a class="reference-link" href="Collections.md">集合</a>。
    *   <a class="reference-link" href="Collections/Table.md">表格</a>是一种新的集合类型，可在可编辑的网格中显示笔记和属性。
    *   引入了<a class="reference-link" href="Basic%20Concepts%20and%20Features/Navigation/Quick%20edit.md">快速编辑</a>，增加了一种在弹出窗口中编辑笔记的新方式，而无需打开新标签页。它还与<a class="reference-link" href="Collections.md">集合</a>很好地集成。
*   v0.96.0：
    *   得益于与CKEditor团队的合作，<a class="reference-link" href="Note%20Types/Text.md">文本</a>笔记获得了高级功能：
        *   <a class="reference-link" href="Note%20Types/Text/Slash%20Commands.md">斜杠命令</a>
        *   <a class="reference-link" href="Note%20Types/Text/Text%20Snippets.md">文本片段</a>
*   v0.95.0：
    *   为<a class="reference-link" href="Advanced%20Usage/Sharing.md">分享</a>引入了更友好的主题，支持搜索、可展开的树、夜间模式等功能。
*   v0.94.0：
    *   增加了与<a class="reference-link" href="AI.md">AI</a>的集成（使用自托管的LLM，如Ollama，或行业标准，如ChatGPT）。
*   v0.92.5：
    *   Windows 二进制文件现已签名。
    *   引入了<a class="reference-link" href="Installation%20%26%20Setup/Server%20Installation/Multi-factor%20authentication%20with%20TOTP.md">基于 TOTP 的多因素身份验证</a>。
*   v0.92.4：
    *   macOS 二进制文件现已签名。
    *   <a class="reference-link" href="Note%20Types/Text.md">文本</a>笔记现在支持可调整的<a class="reference-link" href="Note%20Types/Text/Content%20language%20%26%20Right-to-left%20support.md">内容语言和从右到左支持</a>。
    *   <a class="reference-link" href="Basic%20Concepts%20and%20Features/Notes/Printing%20%26%20Exporting%20as%20PDF.md">打印和导出为 PDF</a>
    *   <a class="reference-link" href="Basic%20Concepts%20and%20Features/Zen%20mode.md">禅定模式</a>
    *   <a class="reference-link" href="Collections/Calendar.md">日历</a>，允许笔记根据开始和结束日期在月度网格中显示。
*   v0.91.5：
    *   移动端显著改进。
    *   <a class="reference-link" href="Note%20Types/Text/Footnotes.md">脚注</a>现已在<a class="reference-link" href="Note%20Types/Text.md">文本</a>笔记中得到支持。
    *   Mermaid 图表现在可以内联插入到<a class="reference-link" href="Note%20Types/Text.md">文本</a>笔记中。
    *   引入了 TriliumNext 主题，为应用程序带来了更现代的设计。
    *   <a class="reference-link" href="Collections/Geo%20Map.md">地理地图</a>，将笔记作为标记显示在地理地图上，便于旅行规划。
*   v0.90.8：
    *   引入了一种新的笔记类型：<a class="reference-link" href="Note%20Types/Mind%20Map.md">思维导图</a>
