# 用户指南
Trilium 是一款用于笔记记录和组织个人知识库的开源解决方案。您可以在桌面上本地使用它，也可以将其与自托管的服务器同步，随时随地访问您的笔记。

> [!TIP]
> 在 Trilium Notes 应用程序内按 <kbd>F1</kbd> 键，也可以访问相同的文档。
