# v0.91.1-beta
## 💡 主要亮点

*   启动器栏现在可以放置在屏幕顶部而非左侧，并带有全宽标签栏。更多信息请参见 [#654](https://github.com/TriliumNext/Notes/pull/654)。
*   [引入了一个名为“TriliumNext”的新主题](https://github.com/TriliumNext/Notes/pull/661)，由 @adoriandoran 和 @eliandoran 贡献。该主题的设置现在以卡片布局显示。重新设计了树操作按钮。
*   在 Windows 和 macOS 上关闭原生标题栏时，[使用原生标题栏按钮](https://github.com/TriliumNext/Notes/pull/702)。
*   在 Windows 上，如果运行于 Windows 系统，TriliumNext 主题具有窗口透明效果，参见 [Mica（Windows 透明效果）](https://github.com/TriliumNext/Notes/pull/717) 查看截图。不幸的是，它受到我们用于桌面应用程序的库 Electron 的一些 bug 困扰，更多信息请参见链接。
*   更新 Docker 构建至 Node 22。**请留意任何潜在问题，尤其是在测试较少的平台（如 ARM）上。**
