# 剪切到子笔记
<figure class="image image_resized image-style-align-right" style="width:64.63%;"><img style="aspect-ratio:812/585;" src="Cut to subnote_cut-to-subnote.gif" width="812" height="585"></figure>

当编辑的文档变得过于庞大时，您可以将其拆分为子笔记：

1.  选择所需的文本并将其剪切到剪贴板。
2.  创建一个新的子笔记并为其命名。
3.  将剪贴板中的内容粘贴到子笔记中。

Trilium 可以自动化此过程。在笔记中选择一些文本，然后在选择工具栏中，点击“剪切并粘贴所选内容到子笔记”操作的剪刀图标。系统会自动检测标题，并相应地命名新的子笔记。您也可以为此操作分配键盘快捷键。此功能可通过块工具栏图标使用。
