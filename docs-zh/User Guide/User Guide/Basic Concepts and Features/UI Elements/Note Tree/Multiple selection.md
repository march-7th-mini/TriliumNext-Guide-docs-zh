# 多选

在<a class="reference-link" href="../Note%20Tree.md">笔记树</a>中，可以同时选中多个笔记。这不会影响当前显示的笔记，但允许进行批量操作。

## 多选的类型

<figure class="image image-style-align-right image_resized" style="width:28.54%;"><img style="aspect-ratio:335/306;" src="Multiple selection_image.png" width="335" height="306"></figure>

### 逐个选择笔记

要单独选中每个笔记，请按住 <kbd>Alt</kbd> 键并点击要选中的笔记。

被选中的笔记会通过不同的背景颜色和图标来标识。

### 按顺序选择笔记

<figure class="image image-style-align-right image_resized" style="width:29.24%;"><img style="aspect-ratio:233/205;" src="Multiple selection_image.jpg" width="233" height="205"></figure>

当笔记处于连续顺序时（例如一个接一个排列），只需选中第一个和最后一个项目即可完成整个选择，而无需逐个点击所有笔记。

为此，首先选中作为选择起点的笔记。然后按住 <kbd>Shift</kbd> 并点击作为选择终点的笔记。起点和终点之间的所有笔记也会被选中。

## 选中的笔记与活动笔记

_选中的笔记_与_活动笔记_之间存在区别：

*   _选中的笔记_仅仅是在多选过程中被选中的笔记（即通过 <kbd>Alt</kbd> 或 <kbd>Shift</kbd> 选中的）。
*   _活动笔记_则是其内容正显示在笔记树右侧的笔记。
    *   在视觉上，它在笔记树中通过不同的背景颜色和细微的阴影来标识。
    *   活动笔记也可以同时被选中，此时图标和背景也会发生变化：
