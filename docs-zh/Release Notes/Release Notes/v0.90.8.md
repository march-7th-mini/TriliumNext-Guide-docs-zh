# v0.90.8
## 💡 主要亮点

*   引入了一种名为“思维导图”的新笔记类型，该类型使用了 MindElixir 库。
*   同步版本已从 32 提升到 33，以防止思维导图笔记出现问题。这意味着服务器也需要更新到此版本，否则同步将被拒绝。
*   国际化支持（西班牙语、中文、罗马尼亚语、法语）。
*   各种错误修复（见下文）。
