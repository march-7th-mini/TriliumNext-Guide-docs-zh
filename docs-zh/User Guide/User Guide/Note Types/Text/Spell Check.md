# 拼写检查
Trilium 支持对笔记进行拼写检查。其工作方式取决于你使用的是**桌面应用程序**（Electron）还是通过**网页浏览器**访问 Trilium。

## 桌面

桌面应用使用 Chromium 内置的拼写检查器。你可以从 _选项_ → _拼写检查_ 进行配置。

### 启用拼写检查

切换 _检查拼写_ 以启用或禁用拼写检查器。更改需要重启才能生效——请使用该部分底部的重启按钮。

### 选择语言

启用拼写检查后，会出现一个 _拼写检查语言_ 部分，列出系统上所有可用的语言。通过勾选复选框选择一种或多种语言。拼写检查器将接受在所选**任一**语言中有效的单词。

可用语言取决于操作系统已安装的语言包。例如，在 Windows 上，你可以通过 _选项_ → _时间和语言_ → _语言和区域_ → _添加语言_ 来添加语言。

> [!NOTE]
> 更改仅在重启应用程序后才会生效。

### 自定义词典

> [!TIP]
> 此功能从 Trilium v0.103.0 开始可用。

你添加到词典中的单词（例如通过右键上下文菜单 →“添加到词典”）会存储在 Trilium 内的一个**同步笔记**中。这意味着你的自定义词典会自动同步到所有设备。

你可以直接从 _设置_ → _拼写检查_ → _自定义词典_ → _编辑词典_ 查看和编辑词典。这会打开底层笔记，其中每行包含一个单词。你可以随意添加、删除或修改条目。

> [!NOTE]
> 对自定义词典的更改（无论是从编辑器还是上下文菜单）都需要在重启应用程序后才会生效。

#### 自定义词典的工作原理

*   当你右键单击拼写错误的单词并选择“添加到词典”时，该单词会同时保存到 Electron 的本地拼写检查器和同步词典笔记中。
*   启动时，Trilium 会将词典笔记中的所有单词加载到拼写检查器会话中。
*   如果 Trilium 检测到 Electron 本地词典中有单词，但词典笔记为空（例如首次使用时），它会将这些单词**一次性导入**到笔记中。
*   位于 Electron 本地词典中但**不在**笔记中的单词（例如你手动删除了它们）会在启动时从本地词典中清理掉。

#### 已知限制

在 Windows 和 macOS 上，Electron 将“添加到词典”委托给操作系统的用户词典。这意味着：

*   通过上下文菜单添加的单词也会写入操作系统级词典（例如 Windows 上的 `%APPDATA%\Microsoft\Spelling\<language>\default.dic`）。
*   从 Trilium 词典笔记中**删除单词**会阻止其在下次启动时加载到拼写检查器中，但**不会**将其从操作系统词典中删除。在你手动从操作系统词典中删除该单词之前，操作系统拼写检查器可能仍会接受它。

## 网页浏览器

通过网页浏览器访问 Trilium 时，拼写检查完全由浏览器本身处理。Trilium 不控制浏览器的拼写检查器——语言选择、词典以及所有其他设置都通过浏览器的首选项进行管理。

<a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20contextual%20menu.md">笔记上下文菜单</a> 有一种特殊行为：右键单击某个单词（未选中）时会显示浏览器的默认上下文菜单，从而使拼写检查能够正常工作。

Trilium 中的拼写检查设置页面会提示这些选项仅适用于桌面版本。

## 常见问题

### 每次更改后都需要重启吗？

是的。拼写检查语言选择和自定义词典在启动时只加载一次。任何更改都需要重启才能生效。

### 我可以同时使用多种拼写检查语言吗？

可以。从清单中选择你需要的任意多种语言。拼写检查器将接受所选任一语言中的单词。

### 我的自定义单词在同步到新设备后消失了——发生了什么？

在新设备首次启动时，Trilium 可能会将现有的本地词典单词导入到笔记中。如果笔记中已有来自另一台设备的单词（通过同步），这些单词会被保留。请确保在新设备上重启应用程序之前同步已完成。

### 我从词典笔记中删除了一个单词，但它仍然被接受

这可能是由于操作系统级词典保留了该单词（参见上文的[已知限制](#known-limitations)）。你可以手动从操作系统的用户词典中删除它。
